> 适用版本：C++17。前置：1.1 的区间约定（左闭右开）；会用 `sort`。

## 要点

- 二分的前提是：对要找的下标或数值，判定函数 `check(x)` 的结果单调，形如“假…假真…真”或“真…真假…假”。
- 所有二分都可以看成两种问题：找**第一个**使 `check` 为真的位置，或找**最后一个**使 `check` 为真的位置。
- 写对二分的办法：固定区间含义，循环不变式写清楚，不凭感觉加减 1。
- 二分答案：答案本身是个数，且“答案为 x 时是否可行”是单调的，就在答案的取值范围上二分，每次用贪心或模拟判断可行性。
- 复杂度 O(log 范围 × check 的耗时)。

## 在有序数组上二分

![在 [lo, hi) 里找第一个 ≥ 5 的位置，每次根据 mid 处的值决定丢掉左半还是右半](/qmx-Gameknowledge/assets/algo/c1-bs-template.svg)

模板一：在区间 `[lo, hi)` 中找第一个 `check` 为真的位置，找不到返回 `hi`。

```cpp
// 第一个满足 check 的下标，都不满足返回 hi
int lo = 0, hi = n;
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (check(mid)) hi = mid;     // mid 满足，答案在 [lo, mid]，但 mid 本身可能是答案，所以 hi = mid
    else            lo = mid + 1; // mid 不满足，答案在 [mid+1, hi)
}
// 循环结束时 lo == hi，就是答案
```

不变式：答案一定在 `[lo, hi]` 内（`hi` 表示“没有”）。每次迭代区间长度严格变小，循环必然结束，不会死循环。

对排序数组 `a`，`check(i)` 取 `a[i] >= x` 就是 `lower_bound`，取 `a[i] > x` 就是 `upper_bound`。

模板二：找最后一个 `check` 为真的位置。把区间写成闭区间 `[lo, hi]`，mid 要向上取整，否则会死循环。

```cpp
// 最后一个满足 check 的位置，保证 lo 处一定满足（或事先判断过存在）
int lo = L, hi = R;
while (lo < hi) {
    int mid = lo + (hi - lo + 1) / 2;   // 向上取整
    if (check(mid)) lo = mid;           // mid 满足，答案在 [mid, hi]
    else            hi = mid - 1;       // mid 不满足，答案在 [lo, mid-1]
}
// lo 就是答案
```

为什么要向上取整：区间只剩两个数 `lo, lo+1` 时，向下取整得到 `mid = lo`，若 `check(lo)` 为真则 `lo = mid` 没有任何进展，永远循环。

## 例 1：元素的第一个和最后一个位置（LeetCode 34）

原题是[LeetCode 34 在排序数组中查找元素的第一个和最后一个位置](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/)（中等）：在升序数组中找 `x` 出现的第一个和最后一个下标，不存在返回 -1。

第一个位置是第一个 `>= x` 的下标，最后一个位置是第一个 `> x` 的下标减 1。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 第一个 a[i] >= x 的下标，没有返回 n
int firstGE(const vector<int>& a, int x) {
    int lo = 0, hi = a.size();
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] >= x) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}

// 第一个 a[i] > x 的下标，没有返回 n
int firstGT(const vector<int>& a, int x) {
    int lo = 0, hi = a.size();
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] > x) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}

int main() {
    vector<int> a = {1, 3, 3, 5, 7, 9, 11};
    int l = firstGE(a, 3), r = firstGT(a, 3) - 1;
    if (l > r) puts("-1 -1");
    else printf("%d %d\n", l, r);   // 1 2
    printf("%d\n", firstGE(a, 5));   // 3，与图一致
}
```

这两个函数和 `std::lower_bound`、`std::upper_bound` 完全一致，比赛里直接调用标准库即可，但要能自己写出，因为二分答案没有现成函数。

## 二分答案

![最小化问题的答案是第一个“真”，最大化问题的答案是最后一个“真”](/qmx-Gameknowledge/assets/algo/c1-bs-answer.svg)

很多题问“最小的最大值”或“最大的最小值”。直接求很难，但反过来问“如果答案是 x，能不能做到”往往简单，而且 x 越宽松越容易做到（或越严格越难做到），单调性就有了。流程：

1. 确定答案的范围 `[lo, hi]`。
2. 写 `check(x)`，用贪心或模拟判断。
3. 判断单调方向，选模板一（最小值）或模板二（最大值）。

### 例 2：分割数组的最大值（LeetCode 410）

原题是[LeetCode 410 分割数组的最大值](https://leetcode.cn/problems/split-array-largest-sum/)（困难）：把数组分成 `m` 个连续非空子数组，使这 `m` 个子数组各自和的最大值最小，求这个最小值。

设答案为 `x`：每段和不超过 `x`，最少需要几段？从左到右贪心地装，装不下就开新段。段数 `≤ m` 就可行。`x` 越大越容易可行，所以求第一个可行的 `x`。范围下界是 `max(a)`（每个数至少单独成段），上界是 `sum(a)`。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> a = {7, 2, 5, 10, 8};
    int m = 2;
    long long lo = *max_element(a.begin(), a.end());
    long long hi = accumulate(a.begin(), a.end(), 0LL);
    auto check = [&](long long x) {      // 每段和 ≤ x 时，段数是否 ≤ m
        int parts = 1;
        long long cur = 0;
        for (int v : a) {
            if (cur + v > x) { parts++; cur = 0; }
            cur += v;
        }
        return parts <= m;
    };
    while (lo < hi) {                    // 第一个可行的 x
        long long mid = lo + (hi - lo) / 2;
        if (check(mid)) hi = mid;
        else lo = mid + 1;
    }
    printf("%lld\n", lo);   // 18：[7,2,5] 和 [10,8]
}
```

复杂度 O(n log(sum))。同一题用动态规划做是 O(n²m)，二分答案把它降到了近似线性。

### 例 3：进击的奶牛（洛谷 P1824）

`n` 个牛栏排在一条直线上，坐标已知，要放 `c` 头牛，使得任意两头牛之间的最小距离尽可能大，求这个最大的最小距离。

设最小距离至少为 `d`：把坐标排序后从左到右贪心地放，第一头放在最左，之后每次放在距离上一头至少 `d` 的第一个牛栏。能放下 `c` 头就可行。`d` 越小越容易可行，所以求**最后一个**可行的 `d`，用模板二。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> x = {1, 2, 8, 4, 9};
    int c = 3;
    sort(x.begin(), x.end());
    auto check = [&](int d) {            // 最小距离 ≥ d 时能否放下 c 头
        int cnt = 1, last = x[0];
        for (int i = 1; i < (int)x.size(); i++)
            if (x[i] - last >= d) { cnt++; last = x[i]; }
        return cnt >= c;
    };
    int lo = 1, hi = x.back() - x[0];    // d = 1 一定可行（题目保证坐标互不相同）
    while (lo < hi) {
        int mid = lo + (hi - lo + 1) / 2;   // 向上取整
        if (check(mid)) lo = mid;
        else hi = mid - 1;
    }
    printf("%d\n", lo);   // 3：放在 1, 4, 8（或 1, 4, 9）
}
```

## 实数二分

答案是实数时，不用 `lo < hi`，改成固定迭代次数，每次 `mid = (lo + hi) / 2`，根据 `check` 令 `lo = mid` 或 `hi = mid`。迭代 50 到 100 次精度足够，不要用 `hi - lo > eps` 当循环条件，当 `lo`、`hi` 很大时浮点数相邻值之间的间隔可能大于 `eps`，导致死循环。

## 常见坑

- 死循环：模板二里 `mid` 向下取整，或 `lo = mid` 与 `hi = mid` 的写法与取整方向不匹配。记住：写 `lo = mid` 就必须向上取整，写 `hi = mid` 就必须向下取整。
- `(lo + hi) / 2` 在值域接近 int 上限时溢出，用 `lo + (hi - lo) / 2`；答案范围可能超过 int，先想清楚用 `long long`。
- 二分答案忘了验证单调性。写 `check` 之前先问自己：x 变大，可行性是单调变好还是变坏？
- `check` 里的贪心本身要正确。上面的两个例子里，贪心“装满再换段”“能放就放”都有正确性论证，换成别的题时要重新证明。
- 值域的上下界取错，例如把下界设成 0，而 `check(0)` 没有意义或除零。
