> 适用版本：C++17。前置：1.1 归并排序（本篇是它的一般化）；0.2 递归树。

## 要点

- 分治（divide and conquer）三步：**分解**（拆成规模更小的子问题）、**解决**（递归求解，规模足够小时直接解）、**合并**（用子问题的答案拼出原问题的答案）。
- 子问题之间**相互独立**，这是它和动态规划的分界线：子问题有重叠时用记忆化或 DP（第 6 章），分治不会重复计算。
- 写分治先想清楚“合并”这一步怎么做，大部分难度都在这里。
- 复杂度用递归树或主定理（0.4）估算：`T(n) = aT(n/b) + f(n)`。常见的两种：一分为二、合并 O(n) 得到 O(n log n)；一分为二、合并 O(1) 得到 O(n)。
- 归并排序、快速排序、快速幂、二分都是分治。

## 例 1：最大子段和

给定整数数组，求和最大的连续非空子数组。这个问题有 O(n) 的动态规划解（6.2），这里用分治，目的是练习“合并”怎么设计。

把区间 `[l, r]` 从中间 `mid` 分成两半，最优子段只可能是三种之一：

1. 完全在左半 `[l, mid]` 内，递归求解。
2. 完全在右半 `[mid+1, r]` 内，递归求解。
3. 跨过中点，既含 `a[mid]` 又含 `a[mid+1]`。

第三种的最优解是：从 `mid` 向左延伸能得到的最大和（最大后缀和）加上从 `mid+1` 向右延伸能得到的最大和（最大前缀和），各扫一遍即可，O(r - l)。

![最优段在左半、右半，或跨过中点，取三者最大](/qmx-Gameknowledge/assets/algo/c1-divide-maxsub.svg)

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> a;

// 闭区间 [l, r] 内的最大子段和
long long solve(int l, int r) {
    if (l == r) return a[l];
    int mid = (l + r) / 2;
    long long best = max(solve(l, mid), solve(mid + 1, r));
    // 跨中点：向左、向右各取最大延伸
    long long sum = 0, lmax = LLONG_MIN, rmax = LLONG_MIN;
    for (int i = mid; i >= l; i--) { sum += a[i]; lmax = max(lmax, sum); }
    sum = 0;
    for (int i = mid + 1; i <= r; i++) { sum += a[i]; rmax = max(rmax, sum); }
    return max(best, lmax + rmax);
}

int main() {
    a = {-2, 1, -3, 4, -1, 2, 1, -5, 4};
    printf("%lld\n", solve(0, a.size() - 1));   // 6
}
```

递归式 `T(n) = 2T(n/2) + O(n)`，解得 O(n log n)。

## 例 2：快速幂

计算 `x^n mod p`，`n` 很大（如 10¹⁸）。逐个相乘要 n 次，不可行。

观察：`x^n = (x^(n/2))²`（n 为偶数），`x^n = x · (x^(n/2))²`（n 为奇数）。每次指数减半，只需 O(log n) 次乘法。关键是 `x^(n/2)` **只算一次**再平方，写成两次递归调用就退化回 O(n)。

```cpp
#include <bits/stdc++.h>
using namespace std;

long long power(long long x, long long n, long long p) {
    if (n == 0) return 1 % p;
    long long half = power(x, n / 2, p);          // 只算一次
    long long res = half * half % p;
    if (n & 1) res = res * (x % p) % p;
    return res;
}

int main() {
    printf("%lld\n", power(2, 10, 1000000007));          // 1024
    printf("%lld\n", power(3, 1000000000000000000LL, 1000000007));
}
```

乘法 `half * half` 在 `p` 不超过约 3·10⁹ 时不会溢出 `long long`；`p` 更大时要用 `__int128`。快速幂是 8.1 逆元、6.8 矩阵快速幂优化的基础。

## 例 3：为运算表达式设计优先级（LeetCode 241）

给定只含数字和 `+ - *` 的表达式字符串，求通过加括号可以得到的所有结果。

遇到每个运算符，就以它为“最后计算的一步”，把表达式分成左右两段：左段所有可能的结果与右段所有可能的结果两两组合。这是分治里“合并”的另一种形式：笛卡尔积。

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> ways(const string& s) {
    vector<int> res;
    for (int i = 0; i < (int)s.size(); i++) {
        char c = s[i];
        if (c == '+' || c == '-' || c == '*') {
            vector<int> L = ways(s.substr(0, i)), R = ways(s.substr(i + 1));
            for (int x : L)
                for (int y : R)
                    res.push_back(c == '+' ? x + y : c == '-' ? x - y : x * y);
        }
    }
    if (res.empty()) res.push_back(stoi(s));   // 没有运算符，整个是一个数
    return res;
}

int main() {
    auto r = ways("2*3-4*5");
    sort(r.begin(), r.end());
    for (int x : r) printf("%d ", x);   // -34 -14 -10 -10 10
    puts("");
}
```

这里同一个子串会被重复计算（如 `3-4*5` 在不同分法里都会出现），子问题有重叠，加一个 `map<string, vector<int>>` 记忆化就变成 DP（见 6.1）。分治与 DP 的区别就在于此。

## 常见坑

- 递归没有边界，或者边界漏了长度为 1、2 的区间，导致死循环或越界。
- 区间约定混乱：闭区间 `[l, r]` 时 `solve(l, mid)` 与 `solve(mid + 1, r)`，左闭右开时是 `solve(l, mid)` 与 `solve(mid, r)`，二者不要混用。
- 分治本身没有提升效率，只有“合并”足够快时才有收益。快速幂里两次递归就是反例。
- 递归深度：每次折半的分治深度只有 log n，不会爆栈；但把问题每次只缩小 1 的递归（O(n) 深度）在 n 很大时要改成循环。
