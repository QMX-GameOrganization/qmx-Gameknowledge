> 适用版本：C++17。前置：1.4 双指针与滑动窗口（窗口的增删思想）。什么时候需要学它：有很多区间询问，统计量不能由两个前缀相减得到，又很难用线段树合并（如区间内不同数的个数、各数出现次数的平方和），且允许离线。

## 要点

- 莫队（Mo's algorithm）：把所有询问离线，按一定顺序排序，用一个窗口 `[l, r]` 依次移动到每个询问的区间上，每次移动一格就增删一个元素并 O(1) 更新统计量。
- 排序规则：把左端点按块长 `B` 分块，先按左端点所在块排序，同一块内按右端点升序。
- 总移动次数：右端点在每个块内只往右走，总共 O(n · n/B)；左端点在块内最多来回 B 格，共 O(q · B)。取 `B = n / √q`，总复杂度 O(n√q)。
- 条件：统计量支持 O(1) 的“加入一个元素”和“删除一个元素”。
- 只能离线，且询问之间不能互相依赖。

## 直觉

![询问按左端点所在块分组，块内按右端点升序，右端点在块内一路向右](/qmx-Gameknowledge/assets/algo/c1-mo-order.svg)

如果按输入顺序处理每个询问，窗口可能每次都要从头走到尾，总共 O(nq)。如果询问的区间彼此相邻，窗口只要挪一点点就行。排序的目的是**让相邻处理的两个询问尽量接近**。

分块排序保证了两点：

- 同块内，左端点之间相差不超过 `B`，处理下一个询问时 `l` 最多移动 `B`。
- 同块内，右端点升序，所以 `r` 在一个块内总共只会向右走 O(n) 格。块一共有 `n/B` 个，`r` 总共走 O(n · n/B)。

两部分相加：`q · B + n² / B`，在 `B = n / √q` 时取到最小，得到 O(n√q)。

## 实现

### 区间不同数的个数

给定数组，多次询问区间内有多少种不同的数。维护 `cnt[v]`（窗口内值 `v` 出现几次）和 `cur`（不同数的个数）。加入一个元素时，若它的计数从 0 变 1，`cur++`；删除时，若计数从 1 变 0，`cur--`。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
int n, q, B;
int a[N], cnt[N], cur;
struct Query { int l, r, id; } qs[N];
int ans[N];

void add(int i) { if (cnt[a[i]]++ == 0) cur++; }
void del(int i) { if (--cnt[a[i]] == 0) cur--; }

int main() {
    n = 6;
    int init[] = {1, 2, 3, 1, 2, 4};
    copy(init, init + n, a);
    vector<pair<int, int>> in = {{0, 2}, {1, 4}, {0, 5}, {3, 3}};   // 闭区间，0 起
    q = in.size();
    for (int i = 0; i < q; i++) qs[i] = {in[i].first, in[i].second, i};
    B = max(1, (int)(n / sqrt(q)));                 // 块长约 n / √q
    sort(qs, qs + q, [&](const Query& x, const Query& y) {
        int bx = x.l / B, by = y.l / B;
        if (bx != by) return bx < by;
        return (bx & 1) ? x.r > y.r : x.r < y.r;    // 奇偶优化：奇数块 r 倒着走
    });
    int l = 0, r = -1;                              // 当前窗口 [l, r]，初始为空
    for (int i = 0; i < q; i++) {
        while (l > qs[i].l) add(--l);               // 先扩张，再收缩，保证计数不为负
        while (r < qs[i].r) add(++r);
        while (l < qs[i].l) del(l++);
        while (r > qs[i].r) del(r--);
        ans[qs[i].id] = cur;
    }
    for (int i = 0; i < q; i++) printf("%d\n", ans[i]);   // 3 3 4 1
}
```

### 四个 while 的顺序

窗口 `[l, r]` 要变成 `[ql, qr]`。顺序必须是**先扩张（`l` 左移、`r` 右移），再收缩（`l` 右移、`r` 左移）**。反过来做，窗口可能在中途出现 `l > r + 1` 的“负长度”状态，删除了不在窗口里的元素，计数变成负数。

### 奇偶优化

块内右端点升序时，换到下一个块后 `r` 要从最右端一路跑回最左边。奇偶优化让奇数块 `r` 降序，偶数块升序，`r` 来回扫描，不用空跑，常数大约减半，写法只多一个三目运算符。

## 莫队的几个变体

| 变体 | 解决的问题 | 复杂度 |
| --- | --- | --- |
| 带修莫队 | 有单点修改，把“修改次数”当作时间维，排序按 `(l 块, r 块, 时间)`，块长取 `n^(2/3)` | O(n^(5/3)) |
| 回滚莫队 | 只能 O(1) 加入、删除很难（如区间最大值、最远相同数距离） | O(n√q) |
| 树上莫队 | 询问是树上的路径，用欧拉序把树展开成序列再做 | O(n√q) |
| 莫队二次离线 | 每次加入元素的代价是“统计它与窗口内其他元素的关系”，进一步离线 | 更低，较难 |

这几个变体都以普通莫队为基础，建议先把本篇的普通版本写熟。

## 适用与不适用

| 情况 | 建议 |
| --- | --- |
| 区间和、区间最值（静态） | 前缀和、ST 表，更快 |
| 区间不同数个数，且在线 | 主席树、树状数组加离线 |
| 区间不同数个数，离线，值域大 | 莫队，常数小，好写 |
| 统计量不支持 O(1) 的增删 | 莫队不适用，或改用回滚莫队 |
| 询问要求强制在线 | 不适用 |
| n、q 都到 10⁶ | O(n√q) 约 10⁹，通常太慢 |

## 常见坑

- 窗口初始 `[0, -1]` 表示空，而不是 `[0, 0]`。
- 四个 `while` 的顺序写反，计数出现负数。
- 块长为 0（`n < √q` 时 `n / √q` 取整为 0），用 `max(1, …)` 保护。
- 排序比较函数在奇偶优化里要保证严格弱序，`x.r > y.r` 与 `x.r < y.r` 不能写成 `>=`。
- 数据值域较大时 `cnt[a[i]]` 需要先离散化（2.2）。
- 答案类型：统计量可能是平方和之类，用 `long long`。
