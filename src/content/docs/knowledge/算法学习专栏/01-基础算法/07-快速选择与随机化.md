> 适用版本：C++17。前置：1.1（划分与分治思想）。什么时候需要学它：题目只要求第 k 小、中位数或前 k 个元素，不要求有序，且 n 在 10⁶ 以上、排序会超时或常数偏大时。多数情况下 `nth_element` 或 `sort` 已经够用。

## 要点

- 快速选择（quickselect）：快速排序的“只递归一边”版本。划分之后只进入包含第 k 小元素的那一段。
- 每次基准把数组平均分成两段，期望总工作量 `n + n/2 + n/4 + … = O(n)`；最坏 O(n²)，用随机基准避免被特殊数据卡。
- 三路划分（小于、等于、大于基准）能正确处理大量重复元素。
- 标准库 `nth_element(first, nth, last)` 就是快速选择的实现，平均 O(n)。
- 蓄水池抽样（reservoir sampling）：不知道总长度的数据流里等概率抽出一个或 k 个元素。

## 快速选择

![第 3 小：第一轮基准 4 把数组分成三段，只保留含第 3 小元素的左段](/qmx-Gameknowledge/assets/algo/c1-quickselect.svg)

做法：随机选一个基准 `p`，把数组三路划分成 `< p`、`= p`、`> p` 三段。设下标区间 `[l, r]`，划分后得到 `[l, lt-1]` 全部小于 `p`，`[lt, gt]` 全部等于 `p`，`[gt+1, r]` 全部大于 `p`。要找第 `k` 小（`k` 从 0 开始）：

- `k < lt`：答案在左段，`r = lt - 1`。
- `k > gt`：答案在右段，`l = gt + 1`。
- 否则：答案就是 `p`。

三路划分用三个下标一次扫描完成：`i` 是扫描位置，`lt` 之前的是小的，`gt` 之后的是大的，`[lt, i)` 是等于的。

```cpp
#include <bits/stdc++.h>
using namespace std;

mt19937 rng(chrono::steady_clock::now().time_since_epoch().count());

// 返回 a 中第 k 小（k 从 0 开始）的元素，会打乱 a
int quickselect(vector<int>& a, int k) {
    int l = 0, r = (int)a.size() - 1;
    while (true) {
        if (l == r) return a[l];
        int p = a[l + rng() % (r - l + 1)];       // 随机基准
        int lt = l, i = l, gt = r;
        while (i <= gt) {
            if (a[i] < p)      swap(a[lt++], a[i++]);
            else if (a[i] > p) swap(a[i], a[gt--]);
            else               i++;
        }
        if (k < lt)       r = lt - 1;
        else if (k > gt)  l = gt + 1;
        else              return p;
    }
}

int main() {
    vector<int> a = {7, 2, 9, 4, 1, 8, 3, 6};
    printf("%d\n", quickselect(a, 2));   // 第 3 小：3
}
```

复杂度：期望 O(n)，最坏 O(n²) 但随机基准下概率极低。若要求最坏也是 O(n)，有“中位数的中位数”（BFPRT）算法，常数很大，实际几乎不用。

## 例：数组中的第 K 个最大元素（LeetCode 215）

第 K 大等于升序下标为 `n - K` 的元素（下标从 0 开始），直接调用上面的函数：

```cpp
int findKthLargest(vector<int>& nums, int K) {
    return quickselect(nums, (int)nums.size() - K);
}
```

用标准库更简短，同样是平均 O(n)：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> a = {3, 2, 1, 5, 6, 4};
    int K = 2;
    nth_element(a.begin(), a.begin() + (a.size() - K), a.end());
    printf("%d\n", a[a.size() - K]);   // 5
}
```

`nth_element` 调用后，下标 `nth` 处恰好是排序后该位置的元素，左边的都不大于它，右边的都不小于它，但两边内部不保证有序。

## 为什么必须随机选基准

固定选第一个或最后一个元素当基准，遇到已经有序的输入，每次只能分出一个元素，退化成 O(n²)。出题人也会专门构造数据。用 `mt19937` 配合时间种子随机选基准，任何输入的期望复杂度都是 O(n)。不要用 `rand()`：它在不同平台上范围不同，质量也差。

## 蓄水池抽样

问题：数据一条条到来，总数事先不知道，要求在处理完之后等概率地选出 1 个（或 k 个），并且只能用 O(1)（或 O(k)）的内存。

做法：第 `i` 个元素（从 0 计）以 `1 / (i + 1)` 的概率替换当前选中的元素。

```cpp
#include <bits/stdc++.h>
using namespace std;

mt19937 rng(20240101);

int main() {
    int n = 5, cnt[5] = {0};
    for (int trial = 0; trial < 100000; trial++) {
        int pick = -1;
        for (int i = 0; i < n; i++)
            if (rng() % (i + 1) == 0) pick = i;      // 以 1/(i+1) 的概率换成第 i 个
        cnt[pick]++;
    }
    for (int i = 0; i < n; i++) printf("%d ", cnt[i]);   // 各约 20000
    puts("");
}
```

**为什么等概率：** 第 `i` 个元素被选中的概率是它在第 `i` 步被选中的 `1/(i+1)`，乘上之后每一步（第 `j` 步，`j > i`）都没有被替换的概率 `j/(j+1)`，连乘得 `1/(i+1) · (i+1)/n = 1/n`。

选 `k` 个的版本：先装入前 `k` 个，之后对第 `i` 个（`i ≥ k`）生成 `j = rng() % (i + 1)`，若 `j < k` 就替换结果数组的第 `j` 位。

## 适用与不适用

| 情况 | 建议 |
| --- | --- |
| 单次求第 k 小，n 很大 | `nth_element` 或快速选择 |
| 要反复查询不同的 k | 直接排序一次，O(n log n) 后每次 O(1) |
| 数组会动态增删 | 平衡树或权值线段树，不适合快速选择 |
| 要求前 k 小且有序 | `partial_sort`，或先 `nth_element` 再对前 k 个排序 |
| 数据流求中位数 | 对顶堆，不是快速选择 |

## 常见坑

- 第 `k` 小的 `k` 是从 0 还是从 1 计，没有统一，写之前约定好。
- 只做两路划分时，大量重复元素会让两段严重失衡。使用三路划分。
- `nth_element` 之后不要假设整个数组有序。
- 固定种子的随机数在被针对的在线评测上可能被卡，通常用时间作种子。
