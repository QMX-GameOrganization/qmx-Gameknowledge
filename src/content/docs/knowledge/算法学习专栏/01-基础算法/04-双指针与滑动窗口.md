> 适用版本：C++17。前置：1.3 的前缀和（用于对比）；会用 `unordered_map`、`sort`。

## 要点

- 双指针的核心是**单调性**：当左端点 `l` 向右移动时，满足条件的最小右端点 `r` 不会向左退。
- 同向（滑动窗口）：`l` 和 `r` 都从左往右走，维护窗口 `[l, r]` 的某个统计量，两个指针各走至多 n 步，总复杂度 O(n)。
- 相向：一个指针从左端出发，另一个从右端出发，向中间靠拢，常用于有序数组上找满足条件的二元组。
- 套路：右指针每次扩张一格，加入新元素；当窗口不再满足条件（或满足条件后想缩得更小）时，左指针收缩。
- 窗口统计量必须能在加入、移出一个元素时 O(1) 更新，比如和、计数数组。

## 滑动窗口模板

![求和 ≥ 7 的最短子数组：r 右移扩张，满足条件后 l 右移收缩](/qmx-Gameknowledge/assets/algo/c1-two-pointer.svg)

```cpp
int l = 0;
for (int r = 0; r < n; r++) {
    // 1. 把 a[r] 加入窗口，更新统计量
    while (窗口需要收缩) {
        // 2. 把 a[l] 移出窗口，更新统计量
        l++;
    }
    // 3. 此时窗口 [l, r] 满足约定的状态，用它更新答案
}
```

“窗口需要收缩”有两种常见含义：

- **求最短**：窗口已经满足条件，尽量缩短，所以 `while (满足条件)` 里记录答案并收缩。
- **求最长**：窗口不满足条件了，必须缩回去，所以 `while (不满足条件)` 收缩，循环结束后窗口合法，用它的长度更新答案。

## 例 1：长度最小的子数组（LeetCode 209）

给定正整数数组和目标值 `target`，求和不小于 `target` 的最短连续子数组长度，不存在输出 0。

数组全是正数，窗口越长和越大，满足单调性。窗口和 `≥ target` 时记录长度，同时收缩左端。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> a = {2, 3, 1, 2, 4, 3};
    int target = 7, n = a.size();
    int ans = INT_MAX, l = 0;
    long long sum = 0;
    for (int r = 0; r < n; r++) {
        sum += a[r];
        while (sum >= target) {               // 求最短：满足就记录并收缩
            ans = min(ans, r - l + 1);
            sum -= a[l++];
        }
    }
    printf("%d\n", ans == INT_MAX ? 0 : ans);   // 2：[4,3]
}
```

如果数组里有负数，窗口变长和不一定变大，这套单调性就不成立，要改用前缀和加其他结构（比如 LeetCode 862 用单调队列，见 2.1）。

## 例 2：无重复字符的最长子串（LeetCode 3）

求字符串中不含重复字符的最长连续子串长度。

求最长，所以“窗口出现重复”时收缩。用一个 256 大小的计数数组记录窗口内每个字符出现次数；加入 `s[r]` 后若它的计数大于 1，说明重复，收缩 `l` 直到计数回到 1。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s = "abcabcbb";
    int cnt[256] = {0};
    int ans = 0, l = 0;
    for (int r = 0; r < (int)s.size(); r++) {
        cnt[(unsigned char)s[r]]++;
        while (cnt[(unsigned char)s[r]] > 1)       // 出现重复，收缩
            cnt[(unsigned char)s[l++]]--;
        ans = max(ans, r - l + 1);                 // 窗口此时合法
    }
    printf("%d\n", ans);   // 3："abc"
}
```

## 相向双指针

数组有序时，两端各放一个指针。设要找两个数之和等于 `target`：

- 和太大：右指针左移，让和变小。
- 和太小：左指针右移，让和变大。
- 恰好相等：找到。

每次移动都排除了一批不可能的组合，所以总共不超过 n 步。

### 例 3：三数之和（LeetCode 15）

找出数组中所有和为 0 的不重复三元组。

先排序，枚举第一个数 `a[i]`，在 `i` 右侧用相向双指针找另外两个数。去重的关键是：`i` 遇到和前一个相同的值就跳过；找到答案后，`l` 和 `r` 也要跳过相同的值。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> a = {-1, 0, 1, 2, -1, -4};
    sort(a.begin(), a.end());
    int n = a.size();
    vector<array<int, 3>> res;
    for (int i = 0; i < n - 2; i++) {
        if (i > 0 && a[i] == a[i - 1]) continue;           // 第一个数去重
        int l = i + 1, r = n - 1;
        while (l < r) {
            int s = a[i] + a[l] + a[r];
            if (s < 0) l++;
            else if (s > 0) r--;
            else {
                res.push_back({a[i], a[l], a[r]});
                l++; r--;
                while (l < r && a[l] == a[l - 1]) l++;     // 第二个数去重
                while (l < r && a[r] == a[r + 1]) r--;     // 第三个数去重
            }
        }
    }
    for (auto& t : res) printf("%d %d %d\n", t[0], t[1], t[2]);
    // -1 -1 2
    // -1 0 1
}
```

复杂度：排序 O(n log n)，枚举加双指针 O(n²)，比暴力的 O(n³) 好很多。

## 技巧：数“最多包含 k 个”的子数组

“恰好满足条件”的子数组个数不一定能直接用滑动窗口数，但“最多满足”通常可以：窗口 `[l, r]` 合法时，以 `r` 结尾、左端点在 `[l, r]` 内的子数组都合法，共 `r - l + 1` 个。于是

恰好 k 个 = 最多 k 个 - 最多 k-1 个。

LeetCode 992 K 个不同整数的子数组就是这样做的。

## 常见坑

- 单调性不成立时硬套双指针。数组含负数、条件非单调时先想清楚，不要凭感觉。
- 收缩条件写成 `if` 而不是 `while`：一次加入可能需要收缩多步。
- 求最短时，记录答案要放在 `while` 内部；求最长时，记录答案放在 `while` 之后。放反会得到错误结果。
- 去重漏写。三数之和要对三个位置分别去重，且去重语句要在“找到答案并移动指针”之后。
- 字符计数数组下标是 `char`，负数下标会越界，转成 `unsigned char` 再用。
