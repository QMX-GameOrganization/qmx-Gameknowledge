> 适用版本：C++17。前置：1.2 二分与二分答案。什么时候需要学它：题目要在凸函数或单峰函数上找最值，或者要选出若干物品使 `Σa / Σb` 最大或最小。

## 要点

- 三分（ternary search）：在**严格单峰**的函数上找极值。取两个三等分点 `m1 < m2`，比较 `f(m1)` 与 `f(m2)`，丢掉不可能含极值的一侧三分之一。
- 三分对函数形状要求严格：峰值一侧严格递增、另一侧严格递减。有平台（一段相等的值）时，三分可能误删含最优解的一段。
- 整数域上的单峰函数，更稳妥的是二分“斜率”：比较 `f(mid)` 与 `f(mid + 1)`，只用一次比较。
- 01 分数规划（0-1 fractional programming）：选一些物品，使 `Σa / Σb` 最大。二分答案 λ：判断是否存在选法使 `Σ(a - λb) ≥ 0`，这个判断随 λ 单调。
- 精度题的循环次数固定（如 100 次），不要依赖 `hi - lo > eps` 作为循环条件。

## 三分

![f(m1) < f(m2) 时，最大值不在 [l, m1] 内，丢弃左边三分之一](/qmx-Gameknowledge/assets/algo/c1-ternary.svg)

求单峰函数的最大值（最小值只要把比较号反过来）：

- `f(m1) < f(m2)`：峰在 `m1` 右侧，令 `l = m1`。
- `f(m1) > f(m2)`：峰在 `m2` 左侧，令 `r = m2`。

每轮区间缩到原来的 2/3。实数域上循环 100 次足够。

```cpp
#include <bits/stdc++.h>
using namespace std;

double f(double x) { return -x * x + 4 * x + 3; }   // 在 x = 2 处取最大值 7

int main() {
    double l = -10, r = 10;
    for (int it = 0; it < 100; it++) {
        double m1 = l + (r - l) / 3, m2 = r - (r - l) / 3;
        if (f(m1) < f(m2)) l = m1;
        else r = m2;
    }
    printf("x = %.6f, f = %.6f\n", l, f(l));   // x = 2.000000, f = 7.000000
}
```

### 整数域：二分斜率

整数上的三分，区间缩小到长度为 2 时容易出现死循环，边界也复杂。改用二分：若 `f(mid) < f(mid + 1)`，峰在 `mid + 1` 及其右边；否则峰在 `mid` 及其左边。

```cpp
#include <bits/stdc++.h>
using namespace std;

long long f(long long x) { return -(x - 37) * (x - 37) + 100; }   // 峰在 37

int main() {
    long long lo = 0, hi = 100;
    while (lo < hi) {
        long long mid = lo + (hi - lo) / 2;
        if (f(mid) < f(mid + 1)) lo = mid + 1;
        else hi = mid;
    }
    printf("%lld %lld\n", lo, f(lo));   // 37 100
}
```

要求函数严格单峰：峰的两侧没有平台。如果有平台（如 `f` 在峰附近连续几个整数值相等），二分斜率同样会误判，要换思路。

## 01 分数规划

问题：有 `n` 个物品，每个有 `a[i]` 和 `b[i] > 0`。选出满足某种约束的一个子集 `S`，使 `Σa / Σb` 最大。

直接比较比值很难。转成判定问题：能否做到比值 `≥ λ`？

`Σa / Σb ≥ λ` 等价于 `Σa - λ·Σb ≥ 0`，即 `Σ(a[i] - λ·b[i]) ≥ 0`。记 `g(λ) = max_S Σ(a[i] - λ·b[i])`。由于 `b[i] > 0`，`λ` 越大每一项越小，`g(λ)` 单调递减。所以“存在一个选法比值 ≥ λ”（即 `g(λ) ≥ 0`）对 `λ` 是“真…真假…假”的，最优比值就是最后一个使 `g(λ) ≥ 0` 的 `λ`。这正好是 1.2 的二分答案。

每个物品现在有了独立的权值 `c[i] = a[i] - λ·b[i]`，`g(λ)` 就是在约束下选 `c` 之和最大的子集，通常用排序取前几大即可。

### 例：Dropping tests（POJ 2976）

`n` 次测验，第 `i` 次答对 `a[i]` 题、共 `b[i]` 题（`0 ≤ a[i] ≤ b[i]`，所以比值落在 `[0, 1]`）。去掉 `k` 次成绩，使剩下 `n - k` 次的总正确率 `Σa / Σb` 最大，输出该值乘以 100 四舍五入的整数。

对给定 `λ`：算出每次的 `c[i] = a[i] - λ·b[i]`，从大到小取 `n - k` 个，和 `≥ 0` 说明可以做到比值 `≥ λ`。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n = 3, k = 1;
    vector<double> a = {5, 0, 2}, b = {5, 1, 6};
    double lo = 0, hi = 1;                    // 正确率在 [0, 1]
    vector<double> c(n);
    for (int it = 0; it < 100; it++) {
        double mid = (lo + hi) / 2;
        for (int i = 0; i < n; i++) c[i] = a[i] - mid * b[i];
        sort(c.begin(), c.end(), greater<double>());
        double s = accumulate(c.begin(), c.begin() + (n - k), 0.0);
        if (s >= 0) lo = mid;                 // 可以做到 ≥ mid，答案在右边
        else hi = mid;
    }
    printf("%d\n", (int)(100 * lo + 0.5 + 1e-9));   // 83；lo 略小于真值，加一个极小量防止恰好 x.5 时少进一位
}
```

复杂度 O(100 · n log n)。

### 加速：Dinkelbach 迭代

二分需要固定的迭代次数。另一种做法：先取任意可行选法，用它的比值作为 `λ`，求出当前 `λ` 下的最优选法，再用新选法的比值作为新 `λ`，直到不再变化。收敛速度远快于二分，通常几次迭代就结束，但需要在求最优选法时记录选了哪些物品。

## 适用与不适用

| 问题特征 | 方法 |
| --- | --- |
| 单峰（凸或凹）连续函数求极值 | 三分，或者函数可导时直接求导 |
| 单峰整数函数 | 二分斜率 |
| 最大化或最小化 `Σa / Σb`，且 `b > 0` | 01 分数规划，二分或 Dinkelbach |
| 函数有平台或多个峰 | 不能三分，需要分段或别的方法 |
| 最优比值生成树、最优比率环 | 同样转成 `Σ(a - λb)`，再套最小生成树（5.3）或判负环（5.2） |

## 常见坑

- 三分的比较在有平台时失效。题目没保证严格单峰，先画图或证明。
- 实数二分、三分的迭代次数不够会影响精度；次数过多可能超时，通常 50 到 100 次足够。
- 01 分数规划里 `b[i]` 可能为 0 或负数，此时 `g(λ)` 不再单调递减，不能直接套用。
- 比值最大化与最小化相反，判定条件要同步翻转。
- 输出要求取整或保留位数时，别把 `eps` 带进最终判断。
