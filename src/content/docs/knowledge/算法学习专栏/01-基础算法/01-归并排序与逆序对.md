## 要点

- 归并排序把数组拆成两半，分别排序，再把两个有序数组合并成一个有序数组。拆分共 log n 层，每层合并总耗时 O(n)，总复杂度 O(n log n)，且稳定。
- 合并两个有序数组只需要两个指针，每个元素只被扫描一次。
- 合并发生的时刻，左半和右半都已经有序。这个“已有序”的条件可以拿来批量统计跨左右两半的元素对。
- 逆序对（inversion）：下标 i < j 且 a[i] > a[j] 的数对。归并排序可以在 O(n log n) 内数出全部逆序对，朴素做法是 O(n²)。
- 逆序对个数等于冒泡排序需要的交换次数，也就是只能交换相邻元素时把数组排成升序的最少交换次数。

## 归并排序的结构

![归并排序先把数组一路拆到单个元素，再两两合并成有序段](/qmx-Gameknowledge/assets/algo/c1-merge-tree.svg)

递归函数 `msort(l, r)` 负责把区间 `[l, r)` 排好序，约定左闭右开，区间长度 `r - l`：

1. 长度不超过 1，已经有序，直接返回。
2. 取 `m = (l + r) / 2`，递归排序 `[l, m)` 和 `[m, r)`。
3. 把两个有序的半区合并到临时数组 `tmp`，再复制回 `a`。

合并时用三个下标：`i` 指向左半当前元素，`j` 指向右半当前元素，`k` 是写入位置。每步取较小的那个。两元素相等时先取左边的，这就是归并排序稳定的原因。

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> tmp;

// 把 a[l, r) 排成升序
void msort(vector<int>& a, int l, int r) {
    if (r - l <= 1) return;
    int m = (l + r) / 2;
    msort(a, l, m);
    msort(a, m, r);
    int i = l, j = m, k = l;
    while (i < m && j < r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];   // 相等取左边，保证稳定
        else              tmp[k++] = a[j++];
    }
    while (i < m) tmp[k++] = a[i++];
    while (j < r) tmp[k++] = a[j++];
    copy(tmp.begin() + l, tmp.begin() + r, a.begin() + l);
}

int main() {
    vector<int> a = {6, 2, 5, 1, 8, 3, 7, 4};
    tmp.resize(a.size());
    msort(a, 0, a.size());
    for (int x : a) printf("%d ", x);   // 1 2 3 4 5 6 7 8
    puts("");
}
```

复杂度：递归深度 ⌈log₂n⌉，每层所有合并加起来扫描 n 个元素，时间 O(n log n)；临时数组 O(n) 额外空间。

提示：`tmp` 开成全局并在 `msort` 外一次性分配，不要在递归里反复 `vector` 构造，否则常数会明显变大。实际写题直接用 `sort` 即可，手写归并排序的价值在下面的“合并时统计”。

## 用归并数逆序对

直接枚举所有 (i, j) 是 O(n²)。归并排序给了一个更好的视角：把全部逆序对按“i 和 j 在递归的哪一层第一次被分到不同半区”分类。每个逆序对恰好属于一次合并，只要在每次合并时，把“左半元素大于右半元素”的对数数出来，累加即可。

合并时左右两半各自已经有序。当右半的 `a[j]` 比左半的 `a[i]` 小时，因为左半升序，`a[i..m-1]` 都比 `a[j]` 大，它们都和 `a[j]` 构成逆序对，一次加上 `m - i` 个。

![左 [3,5,8]、右 [2,4,9] 合并时，每次右侧元素先出队就加上左侧剩余个数，共 5 个逆序对](/qmx-Gameknowledge/assets/algo/c1-merge-count.svg)

对照图手算一遍：右半的 2 先出队，左半还剩 3、5、8，加 3；右半的 4 出队时左半剩 5、8，加 2；其余步骤都是左半先出队，不加。总数 5，对应 (3,2)、(5,2)、(8,2)、(5,4)、(8,4)。

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> tmp;
long long inv = 0;   // 逆序对最多约 n²/2，必须用 long long

void msort(vector<int>& a, int l, int r) {
    if (r - l <= 1) return;
    int m = (l + r) / 2;
    msort(a, l, m);
    msort(a, m, r);
    int i = l, j = m, k = l;
    while (i < m && j < r) {
        if (a[i] <= a[j]) {
            tmp[k++] = a[i++];
        } else {
            inv += m - i;            // a[i..m-1] 都比 a[j] 大
            tmp[k++] = a[j++];
        }
    }
    while (i < m) tmp[k++] = a[i++];
    while (j < r) tmp[k++] = a[j++];
    copy(tmp.begin() + l, tmp.begin() + r, a.begin() + l);
}

int main() {
    vector<int> a = {3, 5, 8, 2, 4, 9};
    tmp.resize(a.size());
    msort(a, 0, a.size());
    printf("%lld\n", inv);   // 5
}
```

判断条件写 `a[i] <= a[j]` 而不是 `<`：相等的两个数不构成逆序对，必须让左边的先出队，才不会把相等的数算进去。

## 例题

### 例 1：翻转对（LeetCode 493）

原题是[LeetCode 493 翻转对](https://leetcode.cn/problems/reverse-pairs/)（困难）：给定数组，统计满足 `i < j` 且 `a[i] > 2 * a[j]` 的数对个数。

条件不是“相邻两数的大小”，不能边合并边统计。做法是合并之前单独扫一遍：此时左右两半各自有序，对左半每个 `a[i]`，右半中满足 `a[i] > 2 * a[j]` 的 `j` 是一个前缀，而且 `i` 增大时这个前缀只会变长，所以右半指针 `j` 单调右移，一趟 O(n) 即可统计，然后再正常合并。

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> tmp;
long long cnt = 0;

void msort(vector<int>& a, int l, int r) {
    if (r - l <= 1) return;
    int m = (l + r) / 2;
    msort(a, l, m);
    msort(a, m, r);
    // 先统计：左半、右半此刻各自有序
    int j = m;
    for (int i = l; i < m; i++) {
        while (j < r && (long long)a[i] > 2LL * a[j]) j++;   // 用 long long 防止 2*a[j] 溢出
        cnt += j - m;
    }
    // 再合并
    inplace_merge(a.begin() + l, a.begin() + m, a.begin() + r);
}

int main() {
    vector<int> a = {1, 3, 2, 3, 1};
    msort(a, 0, a.size());
    printf("%lld\n", cnt);   // 2：(3,1) 和 (3,1)
}
```

这里合并直接用了标准库的 `inplace_merge`。关键是理解“统计”和“合并”可以分开写，统计只依赖两半各自有序。

### 例 2：最少相邻交换次数

只允许交换相邻两个元素，把序列排成升序，最少需要几次？答案就是逆序对个数：每次相邻交换最多消除一个逆序对，而冒泡排序恰好每次消除一个。所以直接套用上面的逆序对程序。POJ 2299 Ultra-QuickSort 就是这个题。

## 常见坑

- 逆序对个数最大约 n²/2，n = 10⁵ 时超过 int，用 `long long`。
- 合并条件写成 `a[i] < a[j]`，相等时先取右边，会把相等元素误算成逆序对，同时破坏稳定性。
- 区间约定要统一。本文一律用左闭右开 `[l, r)`，`m = (l + r) / 2`，递归 `[l, m)` 和 `[m, r)`；混用闭区间时 `m + 1` 很容易写错。
- 统计和合并交错写时，要保证统计发生在两半已经排好序之后、合并之前。
- 数据里有负数或很大的值时，翻转对类的乘法判断要用 `long long`。
