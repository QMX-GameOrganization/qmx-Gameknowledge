> 适用版本：C++17。前置知识：3.1 DFS 与回溯。剪枝没有固定模板，本篇用三道题展示思路，需要配合做题才能熟练。

## 要点

- 剪枝（pruning）：搜索到某个节点时，如果能判定它下面不可能出现答案（或不可能出现更好的答案），就直接返回，整棵子树都不用再看。
- 剪枝不改变答案，只减少访问的节点数。写错的剪枝会漏掉解，所以先写出正确的暴力，再一个一个加，每加一个都与暴力对拍。
- 好的剪枝要"便宜且有效"：判断本身要比被省掉的搜索便宜得多，并且能砍到足够多的分支。
- 搜索顺序也是剪枝：先试最可能成功的选项，或先处理候选最少的位置，失败得更早。

## 五类常用剪枝

| 类型 | 判断依据 | 例子 |
| --- | --- | --- |
| 可行性剪枝 | 当前状态已经不满足约束 | 组合总和里 `rest < 0`；N 皇后里同列已有皇后 |
| 最优性剪枝 | 当前状态再好也超不过已找到的最优解 | 背包里"剩余物品全拿也追不上当前最优" |
| 去重剪枝 | 这个状态等价于已经搜过的 | 含重复元素时同层跳过相同的数 |
| 顺序剪枝 | 调整搜索顺序，让失败早出现 | 数独先填候选数最少的格子 |
| 对称剪枝 | 两个分支互为镜像，只搜一个 | N 皇后第一行只搜左半边，结果乘 2 |

## 可行性剪枝与去重剪枝：组合总和 II

每个数最多用一次，从数组里选出若干数使和为 `target`，结果不能重复（LeetCode 40）。

做法：先**排序**，再用 3.1 的 `start` 写法。排序带来两个剪枝：

- 可行性：`a[i] > rest` 时，后面的数更大，一定也不行，直接 `break` 结束这一层，不是 `continue`。
- 去重：同一层里 `a[i] == a[i-1]`（`i > start`）时，跳过。

![排序后，两种剪枝在第一层的作用](/qmx-Gameknowledge/assets/algo/c3-prune-array.svg)

```cpp
#include <bits/stdc++.h>
using namespace std;

// 每个数最多用一次，找出和为 target 的所有组合，结果不能重复（LeetCode 40）
vector<int> a = {10, 1, 2, 7, 6, 1, 5};
int target = 8;
vector<int> path;

void dfs(int start, int rest) {
    if (rest == 0) {
        for (int x : path) cout << x << ' ';
        cout << '\n';
        return;
    }
    for (int i = start; i < (int)a.size(); i++) {
        if (a[i] > rest) break;                         // 可行性剪枝：排序后，后面的更大，直接结束这一层
        if (i > start && a[i] == a[i - 1]) continue;    // 去重剪枝：同一层里相同的数只试一次
        path.push_back(a[i]);
        dfs(i + 1, rest - a[i]);
        path.pop_back();
    }
}

int main() {
    sort(a.begin(), a.end());                           // 排序是两种剪枝的前提
    dfs(0, target);
}
```

```text
1 1 6 
1 2 5 
1 7 
2 6 
```

输出的 4 个组合：1+1+6、1+2+5、1+7、2+6，和都是 8，且没有重复。

## 最优性剪枝：0-1 背包

n 件物品，每件有重量和价值，容量有限，求最大总价值。暴力 DFS 对每件物品"拿或不拿"，共 2^n 种方案。

最优性剪枝的想法：维护全局最优 `best`。走到某个状态时，估计"从这里往后最多还能得到多少价值"，称为**上界（upper bound）**。如果当前价值加上界还追不上 `best`，这个状态下面不可能出现更好的解，直接返回。

上界必须**不小于**真实的最大值，否则会误砍。常用的上界是"可拆分背包"：允许把最后一件物品按比例拿一部分，用贪心（按性价比 `v/w` 从高到低）就能 O(n) 算出来。可拆分的价值一定不小于不可拆分的真实价值。

![最优性剪枝：上界追不上当前最优，整棵子树被砍掉](/qmx-Gameknowledge/assets/algo/c3-prune-tree.svg)

另一个配合手段是**排序**：先按性价比从高到低排序，好的方案会更早出现，`best` 很快变大，后面的剪枝就更有力。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n = 26, cap;
vector<int> w, v;           // 已按性价比 v/w 从高到低排序
long long nodes;
int best;

// 上界：剩余容量 rest 用物品 i.. 以"可拆分"的方式装，得到的价值一定不小于真实最优
double bound(int i, int rest) {
    double res = 0;
    for (; i < n && w[i] <= rest; i++) { rest -= w[i]; res += v[i]; }
    if (i < n) res += (double)v[i] * rest / w[i];       // 最后一件按比例拿一部分
    return res;
}

void dfs(int i, int weight, int value, bool prune) {
    nodes++;
    best = max(best, value);
    if (i == n) return;
    if (prune && value + bound(i, cap - weight) <= best) return;    // 最优性剪枝：上界都追不上当前最优
    if (weight + w[i] <= cap) dfs(i + 1, weight + w[i], value + v[i], prune);   // 拿（可行性：不超重）
    dfs(i + 1, weight, value, prune);                   // 不拿
}

int main() {
    mt19937 rng(12345);
    vector<int> w0(n), v0(n);
    int total = 0;
    for (int i = 0; i < n; i++) {
        w0[i] = rng() % 20 + 5;
        v0[i] = w0[i] * 2 + rng() % 40;                 // 价值与重量有关联但带噪声
        total += w0[i];
    }
    cap = total / 3;
    vector<int> id(n);
    iota(id.begin(), id.end(), 0);
    sort(id.begin(), id.end(), [&](int x, int y) { return (long long)v0[x] * w0[y] > (long long)v0[y] * w0[x]; });
    for (int i : id) { w.push_back(w0[i]); v.push_back(v0[i]); }

    for (bool prune : {false, true}) {
        nodes = 0; best = 0;
        dfs(0, 0, 0, prune);
        cout << (prune ? "有剪枝" : "无剪枝") << ": 最优价值 " << best << "，搜索节点数 " << nodes << '\n';
    }
}
```

```text
无剪枝: 最优价值 546，搜索节点数 14546360
有剪枝: 最优价值 546，搜索节点数 109
```

两种方式得到相同的最优价值 546，节点数从约 1455 万降到 109。这个数据（26 件物品，随机生成）是为了展示差距选的，实际效果取决于数据，但思路是通用的。

## 搜索顺序：数独

数独的 DFS 是"找一个空格，试填 1 到 9"。直接按从上到下、从左到右的顺序，分支很多。**改成每次选候选数最少的空格**，分支最少，还常常出现"候选数为 0"的格子，让死路更早暴露。这个策略叫"最小剩余值（minimum remaining values）"。

实现上用位运算加速：`row[i]`、`colm[j]`、`box[k]` 是 9 位掩码，第 d 位为 1 表示数字 d 已被用。某个格子的候选集合就是三个掩码的并集取反，`__builtin_popcount` 数出候选个数。

```cpp
#include <bits/stdc++.h>
using namespace std;

int g[9][9];
int row[9], colm[9], box[9];            // 每行/列/宫已用数字的位掩码，第 d 位为 1 表示数字 d 已用

bool dfs() {
    int bx = -1, by = -1, bestCnt = 10, bestMask = 0;
    for (int i = 0; i < 9; i++)
        for (int j = 0; j < 9; j++) {
            if (g[i][j]) continue;
            int mask = ~(row[i] | colm[j] | box[i / 3 * 3 + j / 3]) & 0x3FE;   // 可填数字集合（第 1..9 位）
            int cnt = __builtin_popcount(mask);
            if (cnt < bestCnt) { bestCnt = cnt; bx = i; by = j; bestMask = mask; }
        }
    if (bx == -1) return true;                          // 没有空格了：解出来了
    if (bestCnt == 0) return false;                     // 有空格无数可填：这条路死了
    // 选候选数最少的空格先填，分支最少，剪枝效果最好
    for (int d = 1; d <= 9; d++) {
        if (!(bestMask >> d & 1)) continue;
        g[bx][by] = d;
        row[bx] |= 1 << d; colm[by] |= 1 << d; box[bx / 3 * 3 + by / 3] |= 1 << d;
        if (dfs()) return true;
        row[bx] ^= 1 << d; colm[by] ^= 1 << d; box[bx / 3 * 3 + by / 3] ^= 1 << d;
        g[bx][by] = 0;
    }
    return false;
}

int main() {
    string s = "530070000600195000098000060800060003400803001700020006060000280000419005000080079";
    for (int i = 0; i < 81; i++) {
        int d = s[i] - '0', r = i / 9, c = i % 9;
        g[r][c] = d;
        if (d) { row[r] |= 1 << d; colm[c] |= 1 << d; box[r / 3 * 3 + c / 3] |= 1 << d; }
    }
    if (dfs())
        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) cout << g[i][j];
            cout << '\n';
        }
}
```

## 怎么设计一个剪枝

1. **先写暴力**，确认答案正确。
2. 问自己：搜到当前状态时，我知道哪些信息可以说明"这里没救了"？约束已违反、目标已不可能达到、已经搜过等价的状态。
3. 写成 `if (条件) return;`，放在**递归入口或进入下一层之前**，越早越好。
4. 用随机小数据与暴力对拍，答案必须一致。
5. 统计节点数，确认真的有效。判断的开销大于节省的开销，就是负收益。

## 常见坑

- **最优性剪枝用 `<` 还是 `<=`**：只要求"严格更好"的解时，上界等于 `best` 也可以砍；如果要求输出所有最优方案，则不能用 `<=`。
- **上界估小了**：比如用"剩余物品价值之和"当上界是安全的，但用贪心的不可拆分值当上界会误砍。
- **排序后下标对应关系丢失**：排序后如果还要输出原来的编号，需要保存原下标。
- **去重剪枝把 `break` 写成 `continue`**：可行性剪枝用 `break`（后面都不行），去重用 `continue`（只跳过这一个）。
- **剪枝依赖全局变量，但回溯时没恢复**：全局的 `best`、`used` 要么只增不减（`best`），要么随 `path` 严格撤销。
