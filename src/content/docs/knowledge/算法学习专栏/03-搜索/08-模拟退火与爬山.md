> 适用版本：C++17。前置知识：概率的基本概念（0 到 1 的随机数、`exp`）。什么时候需要学：问题很难精确求解（如 NP 难的旅行商），但**任何一个候选解的好坏都容易计算**，并且你只需要一个足够好的近似解。需要证明最优、需要精确答案时不适用。

## 要点

- 局部搜索：从一个解出发，每次对它做一点随机的小改动（邻域，neighborhood），比较新旧解的优劣，决定是否换过去。
- 爬山（hill climbing）：只接受更好的解。简单，但会停在**局部最优**，走不出去。
- 模拟退火（simulated annealing）：更差的解也以一定概率接受，概率随“温度”降低而变小。早期敢乱走，后期趋于稳定。
- 求最大值时，变差幅度为 Δ（Δ < 0）的解以概率 `exp(Δ / T)` 接受；求最小值时，变差幅度为 Δ（Δ > 0）以概率 `exp(-Δ / T)` 接受。
- 结果是随机的、不保证最优，要多次运行取最好，并**始终记录出现过的最好解**。

## 爬山为什么会卡住

函数 f(x) = x·sin(5x) + 0.3x 在 [0, 10] 上有许多起伏。从随机起点用爬山，只要附近有更高的点就往上走，走到附近最高点就停。

![爬山停在局部最高点，退火可以越过山谷](/qmx-Gameknowledge/assets/algo/c3-sa-landscape.svg)

一个起点如果在某个小山丘的山脚，爬山一路走上去，就停在这个小山丘的山顶，永远到不了更高的山。

## 模拟退火

名字来自金属退火：先加热到高温，原子能自由移动，再缓慢降温，最终排成能量最低的规整结构。

```text
T = T0                      // 初始温度，要足够高
当 T > T_min：
    重复若干次：
        y = 对当前解 x 做一次随机小改动
        Δ = 新旧解的优劣差
        如果 y 更好：接受
        否则以概率 exp(-|Δ| / T) 接受
        更新历史最优
    T = T * α               // 降温，α 通常取 0.95 到 0.9999
```

接受概率随 Δ 增大而减小，随 T 增大而增大：

![不同温度下的接受概率曲线](/qmx-Gameknowledge/assets/algo/c3-sa-accept.svg)

- T 很大：曲线几乎是平的，所有改动都接受，等价于随机游走，在整个空间里探索。
- T 变小：只接受变差很少的改动。
- T 很小：几乎只接受更好的，退化成爬山，在附近精修。

### 例 1：函数最大值

下面的代码同时实现了爬山和模拟退火，对同一批 200 个随机起点各跑一次，统计各自找到全局最大值的次数。步长也随温度缩小：高温时步子大，低温时步子小。

```cpp
#include <bits/stdc++.h>
using namespace std;

mt19937 rng(2024);
double rnd() { return uniform_real_distribution<double>(0, 1)(rng); }   // [0,1) 的随机数

// 在 [0, 10] 上有很多局部最大值的函数，全局最大值在 x ≈ 9.1 附近
double f(double x) { return x * sin(5 * x) + 0.3 * x; }
const double LO = 0, HI = 10;

// 爬山：只接受更好的解。步长随迭代缩小，每次从起点爬到附近最高点就停
double hillClimb(double x) {
    for (double step = 1.0; step > 1e-6; step *= 0.999) {
        double y = min(HI, max(LO, x + (rnd() * 2 - 1) * step));
        if (f(y) > f(x)) x = y;
    }
    return x;
}

// 模拟退火：更差的解也以概率 exp((f(y)-f(x))/T) 接受；T 随时间降低，越到后期越保守
double anneal(double x) {
    double bestX = x;
    for (double T = 5.0; T > 1e-4; T *= 0.995) {
        for (int it = 0; it < 20; it++) {
            double y = min(HI, max(LO, x + (rnd() * 2 - 1) * T));       // 步长也和温度成正比
            double delta = f(y) - f(x);
            if (delta > 0 || rnd() < exp(delta / T)) x = y;              // 好解必收，差解按概率收
            if (f(x) > f(bestX)) bestX = x;                              // 额外记录出现过的最好解
        }
    }
    return bestX;
}

int main() {
    // 暴力扫描得到近似的真实最大值，用来对照
    double truth = -1e9, tx = 0;
    for (double x = LO; x <= HI; x += 1e-5)
        if (f(x) > truth) { truth = f(x); tx = x; }
    printf("真实最大值: f(%.4f) = %.4f\n", tx, truth);

    int hillHit = 0, saHit = 0, runs = 200;
    for (int i = 0; i < runs; i++) {
        double x0 = rnd() * (HI - LO) + LO;
        if (f(hillClimb(x0)) > truth - 1e-3) hillHit++;
        if (f(anneal(x0)) > truth - 1e-3) saHit++;
    }
    printf("%d 次随机起点: 爬山找到全局最大 %d 次，模拟退火找到 %d 次\n", runs, hillHit, saHit);
}
```

```text
真实最大值: f(9.1163) = 11.8475
200 次随机起点: 爬山找到全局最大 30 次，模拟退火找到 200 次
```

爬山只有 30 次找到全局最大，模拟退火 200 次全部找到。注意：C++ 标准没有规定 `uniform_real_distribution` 的具体算法，换编译器后随机序列不同，具体数字会有出入，但“退火明显优于爬山”的结论不变。

### 例 2：旅行商问题（TSP）

n 个点，求一条经过每个点恰好一次并回到起点的最短回路。n 大时没有高效的精确算法。

- **解**：点的访问顺序 `p`。
- **邻域**：2-opt，随机选两个位置 i < j，把 `p[i..j]` 这段**反转**。效果是拆掉两条边、接上另外两条边。
- **Δ**：只和那四条边有关，O(1) 算出来，不需要重新计算整条路径。
- **目标**：最小化，所以变长的解以 `exp(-Δ / T)` 接受。

为了能检验结果，下面的例子把 40 个点均匀放在单位圆上，这时最优路径就是按圆周顺序走一圈，长度已知。

```cpp
#include <bits/stdc++.h>
using namespace std;

mt19937 rng(7);
double rnd() { return uniform_real_distribution<double>(0, 1)(rng); }

int n = 40;
vector<double> X, Y;
double dist(int a, int b) { return hypot(X[a] - X[b], Y[a] - Y[b]); }
double tourLen(const vector<int>& p) {
    double s = 0;
    for (int i = 0; i < n; i++) s += dist(p[i], p[(i + 1) % n]);
    return s;
}

int main() {
    // 构造一个已知最优解的实例：点均匀分布在单位圆上，最优路线就是按圆周顺序走一圈
    const double PI = acos(-1.0);
    X.resize(n); Y.resize(n);
    for (int i = 0; i < n; i++) { X[i] = cos(2 * PI * i / n); Y[i] = sin(2 * PI * i / n); }
    double optimal = 0;
    for (int i = 0; i < n; i++) optimal += dist(i, (i + 1) % n);

    vector<int> p(n);
    iota(p.begin(), p.end(), 0);
    shuffle(p.begin(), p.end(), rng);                   // 随机初始路线
    double cur = tourLen(p), best = cur;
    printf("初始路线长度: %.4f\n", cur);

    for (double T = 1.0; T > 1e-5; T *= 0.9995) {
        int i = rng() % n, j = rng() % n;
        if (i > j) swap(i, j);
        if (i == j || (i == 0 && j == n - 1)) continue;     // 反转整条路线不改变长度，跳过
        // 2-opt 邻域：把 p[i..j] 这一段反转，等价于换掉两条边。只需要算这两条边的变化
        int a = p[(i + n - 1) % n], b = p[i], c = p[j], d = p[(j + 1) % n];
        double delta = dist(a, c) + dist(b, d) - dist(a, b) - dist(c, d);
        if (delta < 0 || rnd() < exp(-delta / T)) {     // 求最小值：变短必收，变长按概率收
            reverse(p.begin() + i, p.begin() + j + 1);
            cur += delta;
            best = min(best, cur);
        }
    }
    printf("退火后路线长度: %.4f（最优 %.4f）\n", best, optimal);
}
```

```text
初始路线长度: 51.7714
退火后路线长度: 6.2767（最优 6.2767）
```

从随机顺序的 51.77 出发，退火后得到 6.2767，等于最优值。真实的非圆周点集，通常得到的是接近最优的解，而不一定恰好等于最优。

## 参数怎么调

| 参数 | 作用 | 经验 |
| --- | --- | --- |
| 初始温度 T0 | 决定一开始敢不敢乱走 | 取与 Δ 典型值同量级或略大 |
| 终止温度 T_min | 何时停止 | 取远小于最小的 Δ |
| 降温系数 α | 降温速度，越接近 1 越慢越好 | 0.99 到 0.9999，取决于时间限制 |
| 每个温度的迭代次数 | 每个温度“停留”多久 | 与问题规模成正比 |

时间足够就把 α 调大、迭代次数调多；时间有限就缩小，并多跑几次取最优。

## 适用与不适用

| 情况 | 建议 |
| --- | --- |
| 解空间大，局部最优很多，不要求最优 | 模拟退火 |
| 目标函数是单峰（只有一个山顶） | 爬山或二分/三分，不必退火 |
| 需要可证明的最优解 | 精确算法（DP、搜索加剪枝） |
| 评估一个解很慢 | 退火要几十万次评估，不合适 |

## 常见坑

- **只返回最后的解**：退火末期可能刚好接受了一个差解，应该记录并返回出现过的最好解。
- **接受概率的符号写反**：求最大值和求最小值，`exp` 里 Δ 的符号相反，写完要用一个小例子验证。
- **温度降得太快**：还没探索就变成了爬山。
- **步长不随温度缩小**：低温时依然大步乱跳，无法精修。
- **随机数质量**：反复构造 `mt19937` 对象会很慢，也可能给出相同序列；用一个全局的生成器。
- **反转整条路径**：2-opt 里 `i = 0, j = n-1` 反转后路线长度不变，Δ 的公式也会算错，要跳过。
