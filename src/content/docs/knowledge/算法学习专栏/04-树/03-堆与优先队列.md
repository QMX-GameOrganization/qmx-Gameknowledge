> 适用版本：C++17。前置知识：会用数组、比较器和 `vector`。堆是树专题中的基础容器，也是贪心和图算法的常用工具。

## 本篇属于哪一部分

堆和二叉搜索树都使用树形结构，但维护的性质不同。二叉搜索树适合沿大小关系查找，堆只保证堆顶是当前最大值或最小值，适合反复取出最优元素。

## 要点

- 堆是一棵完全二叉树，通常用数组保存，不需要真的创建节点。
- 小根堆满足父节点不大于孩子，大根堆满足父节点不小于孩子。
- 下标从 1 开始时，节点 `i` 的父亲是 `i / 2`，左孩子是 `2 * i`，右孩子是 `2 * i + 1`。
- 插入元素后向上调整，删除堆顶后把最后一个元素放到根，再向下调整。
- 从任意数组建堆可以在线性时间完成，逐个插入则是 O(n log n)。
- `priority_queue` 默认是大根堆，传入 `greater` 或自定义比较器可以得到小根堆。

## 堆的结构和不变量

![完全二叉树堆的数组下标与父子关系](/qmx-Gameknowledge/assets/algo/c4-heap-structure.svg)

堆的“有序”只发生在父子之间。例如小根堆中，根节点一定是全树最小值，但左右两个子树之间没有整体的大小顺序。因此不能像二叉搜索树一样根据目标值决定向左还是向右。

数组下标的关系是堆最重要的记忆点：

```text
parent(i) = i / 2
left(i)   = 2 * i
right(i)  = 2 * i + 1
```

使用 0 下标时要改成：

```text
parent(i) = (i - 1) / 2
left(i)   = 2 * i + 1
right(i)  = 2 * i + 2
```

## 上浮，插入一个元素

以小根堆为例，新元素先放到数组末尾。它可能小于父节点，于是不断和父节点交换，直到父节点更小，或者已经到达根。

![向上调整，把新加入的 2 沿父链交换到正确位置](/qmx-Gameknowledge/assets/algo/c4-heap-sift-up.svg)

```cpp
void push(int x) {
    heap.push_back(x);
    int i = (int)heap.size() - 1;
    while (i > 1 && heap[i] < heap[i / 2]) {
        swap(heap[i], heap[i / 2]);
        i /= 2;
    }
}
```

每次交换都会让节点向根移动一层，堆高是 O(log n)，所以插入复杂度是 O(log n)。

## 下沉，删除堆顶

删除堆顶时，不能直接把根删掉后留下空位。把最后一个元素移到根，再和两个孩子中更小的那个交换，直到它不大于孩子或到达叶子。

```cpp
void pop() {
    heap[1] = heap.back();
    heap.pop_back();

    for (int i = 1;;) {
        int best = i;
        int l = i * 2, r = i * 2 + 1;
        if (l < (int)heap.size() && heap[l] < heap[best]) best = l;
        if (r < (int)heap.size() && heap[r] < heap[best]) best = r;
        if (best == i) break;
        swap(heap[i], heap[best]);
        i = best;
    }
}
```

选择两个孩子中较小的一个非常重要。只和左孩子或任意一个孩子交换，不能保证交换后仍然满足堆序。

## 从零实现一个小根堆

这里使用 1 下标，`heap[0]` 不参与堆内数据。实际题目中如果使用 `priority_queue`，一般不需要手写这段代码。手写的目的，是看清楚堆序如何在局部交换中恢复。

```cpp
#include <bits/stdc++.h>
using namespace std;

struct MinHeap {
    vector<int> a = {0};

    bool empty() const { return a.size() == 1; }
    int top() const { return a[1]; }

    void push(int x) {
        a.push_back(x);
        int i = (int)a.size() - 1;
        while (i > 1 && a[i] < a[i / 2]) {
            swap(a[i], a[i / 2]);
            i /= 2;
        }
    }

    void pop() {
        a[1] = a.back();
        a.pop_back();
        for (int i = 1;;) {
            int best = i;
            int l = i * 2, r = i * 2 + 1;
            if (l < (int)a.size() && a[l] < a[best]) best = l;
            if (r < (int)a.size() && a[r] < a[best]) best = r;
            if (best == i) break;
            swap(a[i], a[best]);
            i = best;
        }
    }
};

int main() {
    MinHeap h;
    for (int x : {5, 2, 8, 1, 4}) h.push(x);
    while (!h.empty()) {
        cout << h.top() << ' ';
        h.pop();
    }
}
```

```output
1 2 4 5 8
```

## 建堆为什么是 O(n)

如果把 n 个元素逐个插入，复杂度是 O(n log n)。建堆可以从最后一个非叶子节点开始，依次向下调整。靠近叶子的节点高度很小，真正需要移动很多层的节点数量很少，所以总复杂度是 O(n)。

```cpp
void siftDown(vector<int>& a, int i) {
    for (;;) {
        int best = i;
        int l = i * 2, r = i * 2 + 1;
        if (l < (int)a.size() && a[l] < a[best]) best = l;
        if (r < (int)a.size() && a[r] < a[best]) best = r;
        if (best == i) break;
        swap(a[i], a[best]);
        i = best;
    }
}

// a[0] 作为占位，真正的数据从 a[1] 开始。
void buildHeap(vector<int>& a) {
    for (int i = (int)a.size() / 2; i >= 1; i--)
        siftDown(a, i);
}
```

也可以直接使用 `make_heap`，但刷题时更常见的是 `priority_queue`。

## C++ 优先队列

```cpp
priority_queue<int> maxHeap;
priority_queue<int, vector<int>, greater<int>> minHeap;
```

维护二元组时，常用 `pair` 的默认字典序比较：先比较第一关键字，再比较第二关键字。

```cpp
using PII = pair<int, int>;
priority_queue<PII, vector<PII>, greater<PII>> pq;
```

自定义结构体时，比较器返回“谁的优先级更低”。写之前先用两个元素手算，确认堆顶是谁，再写比较器。

## 堆的常见题型

### Top K

要找第 k 大，可以维护一个大小不超过 k 的小根堆。堆顶是当前保留下来的最小值，遇到更大的数就替换堆顶。最终堆顶就是第 k 大。

要找第 k 小则反过来维护大根堆。

### 反复取当前最优值

任务调度、合并果子、每次选择最短或最便宜的对象，都可以把候选项放进优先队列。取出后如果状态发生变化，再把新状态放回去。

### 延迟删除

当优先队列不支持删除任意元素时，可以把“当前版本”一起放进堆里。弹出时检查这个状态是否仍然有效，无效就丢弃并继续弹出。这种做法在滑动窗口和懒删除模拟中很常见。

## 常见坑

- 以为堆可以二分查找任意值。堆只保证堆顶正确。
- 删除堆顶后忘记下沉，或者下沉时没有选择更优的孩子。
- `priority_queue` 默认是大根堆，最小值堆需要显式使用 `greater`。
- 自定义比较器写成普通的“是否小于”，结果堆顶方向反了。
- Top K 中堆的方向弄反。第 k 大通常用大小为 k 的小根堆。
- 把堆的高度误认为 n。完全二叉树的高度是 O(log n)。
