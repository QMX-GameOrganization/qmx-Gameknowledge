## 本章怎么学

第 4 章是全专栏的核心，按“结构从简单到复杂”排列：先学二叉树的遍历和二叉搜索树（4.1、4.2），再学前缀树、一般树和 LCA（4.3 到 4.5），然后是两个区间数据结构，树状数组和线段树（4.6、4.7），最后用树形 DP 把递归思路串起来（4.8）。4.9 以后带 ⭐ 的篇目是进阶内容，不影响主线，可以等做过一批题再回来补。

学习上有三点建议。第一，树上的绝大多数题都是递归，写之前先想清楚“这个函数对一棵子树返回什么”。第二，树状数组和线段树是本章难点，每个至少做 8 道题再往后走。第三，红黑树、Splay 这类平衡树只需要理解思想，竞赛里直接用 `set` 和 `map`，不要求手写。

## 要点

- 二叉树遍历有四种：前序、中序、后序（都是深度优先），层序（广度优先）。区别只在“什么时候访问根”。
- 递归写法三行就能写完；迭代写法用显式的栈，目的是避开递归过深导致栈溢出。
- 已知前序和中序，或者中序和后序，可以唯一重建一棵二叉树；只有前序和后序则不行。
- 重建的核心是：前序（或后序）的一端确定根，中序用根把左右子树分开，然后递归。

## 二叉树怎么存

做题时最常用的是用两个数组存左右孩子，节点编号 `1..n`，`0` 表示空：

```cpp
const int N = 100005;
int lc[N], rc[N];   // lc[u]、rc[u]：u 的左、右孩子编号，0 表示没有
```

用指针的 `struct TreeNode { int val; TreeNode *left, *right; }` 在 LeetCode 里是标准给法，逻辑完全相同。本篇用数组写法，后面的代码也都沿用，因为它输入输出更方便，也不需要释放内存。

下文统一使用这棵树，节点值就是编号：

```text
        1
       / \
      2   3
     / \  /
    4  5 6
```

## 四种遍历顺序

![同一棵树的四种遍历：前序根左右，中序左根右，后序左右根，层序逐层从左到右](/qmx-Gameknowledge/assets/algo/c4-01-traversal.svg)

三种深度优先遍历的递归框架相同，只是 `visit(u)` 放的位置不同：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
int lc[N], rc[N];

void pre(int u)  { if (!u) return; printf("%d ", u); pre(lc[u]);  pre(rc[u]); }
void in(int u)   { if (!u) return; in(lc[u]);  printf("%d ", u); in(rc[u]);  }
void post(int u) { if (!u) return; post(lc[u]); post(rc[u]); printf("%d ", u); }

void level(int root) {              // 层序：用队列，先进先出
    queue<int> q;
    q.push(root);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        printf("%d ", u);
        if (lc[u]) q.push(lc[u]);
        if (rc[u]) q.push(rc[u]);
    }
}

int main() {
    lc[1] = 2; rc[1] = 3; lc[2] = 4; rc[2] = 5; lc[3] = 6;   // 上面那棵树
    pre(1);   puts("");
    in(1);    puts("");
    post(1);  puts("");
    level(1); puts("");
}
```

```output
1 2 4 5 3 6
4 2 5 1 6 3
4 5 2 6 3 1
1 2 3 4 5 6
```

每个节点恰好访问一次，时间 O(n)。递归深度等于树高：平衡时约 log n，退化成链时是 n。

层序遍历和第 3 章的 BFS 是同一个算法，只是树不会走回头路，所以不需要 `vis` 数组。

## 迭代写法：自己管理栈

递归的本质是系统帮你维护一个调用栈。树退化成链且有 10^5 个节点时，递归可能爆栈，这时要把栈显式写出来。

![迭代中序遍历的栈变化：一路向左入栈，弹出时访问，再转向右子树](/qmx-Gameknowledge/assets/algo/c4-01-iter-stack.svg)

中序遍历的迭代写法是最典型的模板：沿左链一路入栈，到头后弹出一个节点访问，再转向它的右孩子，重复。前序只要把“访问”提前到入栈的时候。后序稍微绕一点：把前序的“根、左、右”改成“根、右、左”，再整体倒过来，就是“左、右、根”。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
int lc[N], rc[N];

vector<int> preorder(int root) {
    vector<int> ans;
    stack<int> st;
    for (int u = root; u || !st.empty();) {
        while (u) {                    // 一路向左，入栈前就访问
            ans.push_back(u);
            st.push(u);
            u = lc[u];
        }
        u = rc[st.top()];              // 转向右子树
        st.pop();
    }
    return ans;
}

vector<int> inorder(int root) {
    vector<int> ans;
    stack<int> st;
    for (int u = root; u || !st.empty();) {
        while (u) { st.push(u); u = lc[u]; }
        u = st.top(); st.pop();
        ans.push_back(u);              // 左子树全部处理完，访问自己
        u = rc[u];
    }
    return ans;
}

vector<int> postorder(int root) {      // 根右左，再整体反转
    vector<int> ans;
    stack<int> st;
    if (root) st.push(root);
    while (!st.empty()) {
        int u = st.top(); st.pop();
        ans.push_back(u);
        if (lc[u]) st.push(lc[u]);     // 先压左，后弹出时右先出来
        if (rc[u]) st.push(rc[u]);
    }
    reverse(ans.begin(), ans.end());
    return ans;
}

void show(const vector<int>& v) { for (int x : v) printf("%d ", x); puts(""); }

int main() {
    lc[1] = 2; rc[1] = 3; lc[2] = 4; rc[2] = 5; lc[3] = 6;
    show(preorder(1));
    show(inorder(1));
    show(postorder(1));
}
```

```output
1 2 4 5 3 6
4 2 5 1 6 3
4 5 2 6 3 1
```

三个函数的时间都是 O(n)，栈的最大深度等于树高。

## 由遍历序列重建二叉树

只给你一个序列，树通常不唯一。但**前序加中序**，或者**中序加后序**，能唯一确定一棵树（节点值互不相同的前提下）。

![前序第一个数是根；在中序里找到根，左边是左子树，右边是右子树；按长度切分前序，递归](/qmx-Gameknowledge/assets/algo/c4-01-rebuild.svg)

以前序加中序为例，步骤如下：

1. 前序的第一个数是根。
2. 在中序里找到根的位置 `k`。根左边的 `k - il` 个数是左子树，右边是右子树。
3. 左子树的大小已知，所以前序里“根后面连续 `leftSize` 个数”是左子树的前序，剩下的是右子树的前序。
4. 对左右子树各递归一次。

中序加后序同理，只是根在后序的最后一个，其余步骤一样。为了 O(1) 找到根在中序中的位置，预先用数组 `posIn[值]` 记下每个值的下标，整个重建是 O(n)。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
int lc[N], rc[N], posIn[N];            // posIn[v]：值 v 在中序中的下标
int preA[N], inA[N], postA[N];

// 前序 preA[pl..pr]，中序 inA[il..ir]，返回子树的根（0 表示空树）
int buildPI(int pl, int pr, int il, int ir) {
    if (pl > pr) return 0;
    int root = preA[pl];
    int k = posIn[root];
    int leftSize = k - il;
    lc[root] = buildPI(pl + 1, pl + leftSize, il, k - 1);
    rc[root] = buildPI(pl + leftSize + 1, pr, k + 1, ir);
    return root;
}

// 中序 inA[il..ir]，后序 postA[ql..qr]
int buildIP(int il, int ir, int ql, int qr) {
    if (il > ir) return 0;
    int root = postA[qr];
    int k = posIn[root];
    int leftSize = k - il;
    lc[root] = buildIP(il, k - 1, ql, ql + leftSize - 1);
    rc[root] = buildIP(k + 1, ir, ql + leftSize, qr - 1);
    return root;
}

void pre(int u)  { if (!u) return; printf("%d ", u); pre(lc[u]); pre(rc[u]); }
void post(int u) { if (!u) return; post(lc[u]); post(rc[u]); printf("%d ", u); }

int main() {
    int n = 6;
    int p[] = {1, 2, 4, 5, 3, 6}, i_[] = {4, 2, 5, 1, 6, 3}, q[] = {4, 5, 2, 6, 3, 1};
    copy(p, p + n, preA); copy(i_, i_ + n, inA); copy(q, q + n, postA);
    for (int i = 0; i < n; i++) posIn[inA[i]] = i;

    int root = buildPI(0, n - 1, 0, n - 1);   // 前序 + 中序
    post(root); puts("");                     // 输出这棵树的后序

    memset(lc, 0, sizeof lc); memset(rc, 0, sizeof rc);
    root = buildIP(0, n - 1, 0, n - 1);       // 中序 + 后序
    pre(root); puts("");                      // 输出这棵树的前序
}
```

```output
4 5 2 6 3 1
1 2 4 5 3 6
```

**为什么前序加后序不行？** 一个节点只有一个孩子时，它是左孩子还是右孩子，前序和后序都看不出来。例如根 1 只有孩子 2，前序是 `1 2`，后序是 `2 1`，2 在左边或右边都得到同样的两个序列。中序序列则会把左右子树明确地分开在根的两侧。

## 例题

### 例 1：高度、节点数、叶子数

这是“函数对一棵子树返回一个值”的典型写法：空树返回边界值，非空树用左右子树的返回值组合出自己的答案。后面的树形 DP（4.8）就是这个模式的推广。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
int lc[N], rc[N];

int height(int u) { return u ? 1 + max(height(lc[u]), height(rc[u])) : 0; }
int cnt(int u)    { return u ? 1 + cnt(lc[u]) + cnt(rc[u]) : 0; }
int leaves(int u) {
    if (!u) return 0;
    if (!lc[u] && !rc[u]) return 1;      // 没有孩子才是叶子
    return leaves(lc[u]) + leaves(rc[u]);
}

int main() {
    lc[1] = 2; rc[1] = 3; lc[2] = 4; rc[2] = 5; lc[3] = 6;
    printf("%d %d %d\n", height(1), cnt(1), leaves(1));
}
```

```output
3 6 3
```

### 例 2：按层输出（LeetCode 102）

层序遍历时，每一轮开始先记下队列里的元素个数 `sz`，这 `sz` 个元素正好是同一层：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
int lc[N], rc[N];

int main() {
    lc[1] = 2; rc[1] = 3; lc[2] = 4; rc[2] = 5; lc[3] = 6;
    queue<int> q;
    q.push(1);
    while (!q.empty()) {
        int sz = q.size();                // 当前层的节点数
        for (int i = 0; i < sz; i++) {
            int u = q.front(); q.pop();
            printf("%d ", u);
            if (lc[u]) q.push(lc[u]);
            if (rc[u]) q.push(rc[u]);
        }
        puts("");                         // 一层结束换行
    }
}
```

```output
1
2 3
4 5 6
```

### 例 3：已知前序和中序，求后序（洛谷 P1827）

不必真的建树。把上一节的 `buildPI` 稍作改动，递归时直接先处理左右子树再输出根，就能直接得到后序。题目里节点是字母时，把 `posIn` 的下标换成字符的 ASCII 码即可。

## 常见坑

- 重建时左子树大小算错一位，导致前序区间下标偏移。写完先用一棵三个节点的树手算验证。
- 节点值有重复时，`posIn` 无法定位根，重建的前提是值互不相同。
- 多组数据时忘记清空 `lc`、`rc`，上一组的孩子会残留。
- 递归遍历在退化成链的大数据上会爆栈，这时改用迭代写法。
- 迭代中序里 `while (u)` 之后要先弹栈再访问，访问写在入栈处就变成了前序。
