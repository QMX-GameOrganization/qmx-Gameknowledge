> 适用版本：C++17。前置知识：4.1 二叉树遍历、递归；建议先学 4.6 树状数组，便于对比。

## 要点

- 线段树把数组区间 `[1, n]` 递归地一分为二，每个节点管理一段区间并保存这段区间的信息（和、最小值、最大值……）。
- 单点修改、区间查询都是 O(log n)。查询时把目标区间拆成 O(log n) 个“完整节点”，直接取它们保存的信息。
- **懒标记**（lazy tag）让区间修改也做到 O(log n)：修改时在被完整覆盖的节点上打标记，不再往下走；等以后需要进入这个节点的孩子时，再把标记下推。
- 写任何线段树只需要想清楚三件事：节点保存什么信息；两个孩子的信息怎么合并（`pushup`）；标记对节点信息的作用和下推方式（`apply`、`pushdown`）。
- 能用树状数组解决的“单点修改、区间求和”问题，树状数组更短更快；区间最值、区间赋值、复杂可合并信息只能用线段树。

## 线段树的结构

![线段树：每个节点管一段区间，节点 i 的孩子是 2i 和 2i+1，叶子是单个元素](/qmx-Gameknowledge/assets/algo/c4-07-seg-structure.svg)

对数组 `[5,3,8,6,2,7,4,1]`，根节点 1 管理 `[1,8]`，和为 36。把区间从中间一分为二：左孩子管理 `[1,4]`，右孩子管理 `[5,8]`；继续分到区间长度为 1 为止，这些就是叶子。

用堆式编号存储：根是 1，节点 `o` 的左孩子是 `2o`，右孩子是 `2o + 1`，不需要指针。区间 `[l, r]` 的中点是 `mid = (l + r) / 2`，左孩子管 `[l, mid]`，右孩子管 `[mid + 1, r]`。

**数组要开多大？** 树最深约 `⌈log₂ n⌉ + 1` 层，节点编号最大不超过 `4n`，所以数组开 `4 * N`。这是最常见的写法，记住即可。

## 建树、单点修改、区间查询

**建树**：递归到叶子时直接放入数组元素，回溯时用 `pushup` 把两个孩子的信息合并成父亲的信息。

**单点修改**：从根往下找到那个叶子，改完后沿原路回溯，逐层重新 `pushup`。

**区间查询** `[ql, qr]`：对每个节点 `[l, r]` 分三种情况。

1. `[l, r]` 与 `[ql, qr]` 没有交集：返回“空值”（求和是 0）。
2. `[l, r]` 完全落在 `[ql, qr]` 内：直接返回这个节点保存的信息，不再往下。
3. 部分重叠：递归左右孩子，把结果合并。

![查询 [2,6]：[2,2]、[3,4]、[5,6] 三个节点被完整覆盖，结果 3+14+9=26](/qmx-Gameknowledge/assets/algo/c4-07-query-decompose.svg)

图里查询 `[2,6]`，只有三个节点被完整覆盖（橙色），和为 `3 + 14 + 9 = 26`。每一层最多有两个节点是“部分重叠”（蓝色），所以总共访问的节点数是 O(log n)。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
int n, a[N];
long long sum[4 * N];                  // sum[o]：节点 o 所管区间的和

void pushup(int o) { sum[o] = sum[2 * o] + sum[2 * o + 1]; }

void build(int o, int l, int r) {      // 节点 o 管理 [l, r]
    if (l == r) { sum[o] = a[l]; return; }
    int mid = (l + r) / 2;
    build(2 * o, l, mid);
    build(2 * o + 1, mid + 1, r);
    pushup(o);
}

void update(int o, int l, int r, int pos, int val) {      // a[pos] = val
    if (l == r) { sum[o] = val; return; }
    int mid = (l + r) / 2;
    if (pos <= mid) update(2 * o, l, mid, pos, val);
    else update(2 * o + 1, mid + 1, r, pos, val);
    pushup(o);
}

long long query(int o, int l, int r, int ql, int qr) {    // [ql, qr] 的和
    if (qr < l || r < ql) return 0;                       // 无交集
    if (ql <= l && r <= qr) return sum[o];                // 完全覆盖
    int mid = (l + r) / 2;
    return query(2 * o, l, mid, ql, qr) + query(2 * o + 1, mid + 1, r, ql, qr);
}

int main() {
    n = 8;
    int init[] = {0, 5, 3, 8, 6, 2, 7, 4, 1};
    copy(init, init + 9, a);
    build(1, 1, n);
    printf("%lld\n", query(1, 1, n, 2, 6));
    update(1, 1, n, 3, 18);                               // a[3] 从 8 改成 18
    printf("%lld %lld\n", query(1, 1, n, 2, 6), query(1, 1, n, 1, 8));
}
```

```output
26
36 46
```

四个函数的参数 `(o, l, r)` 始终一起传递：当前节点编号及其区间。熟悉后可以把 `o, l, r` 当作一个整体来读。

## 区间修改与懒标记

现在加一种操作：给区间 `[l, r]` 的每个数都加上 `v`。如果逐个叶子修改，是 O(n)。

观察：对被完整覆盖的节点，它下面的所有叶子都要加 `v`，但我们此刻并不需要知道叶子的值，只需要让这个节点自己的和正确（`sum += v * 区间长度`）。把“孩子们还欠着一次加 v”记在这个节点的**懒标记** `tag` 里，等以后真的要进入孩子时再还。

![区间 [1,4] 加 3：只修改节点 [1,4] 并记下标记；之后查询需要进入孩子时，才把标记下推给孩子](/qmx-Gameknowledge/assets/algo/c4-07-lazy.svg)

涉及两个操作：

- `applyAdd(o, l, r, v)`：对节点 o 整段加 v。自己的和增加 `v * (r - l + 1)`，标记累加 `v`。
- `pushdown(o, l, r)`：把 o 的标记交给两个孩子（各自调用 `applyAdd`），然后清零。

**什么时候必须下推？** 凡是要从节点 o 走进它的孩子之前，都必须先 `pushdown(o)`：修改和查询都一样。否则孩子拿到的信息是过时的。

下面是洛谷 P3372 风格的完整程序：输入 n 个数和 m 个操作，`1 x y k` 表示区间 `[x, y]` 每个数加 k，`2 x y` 表示查询区间和。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
int n, m, a[N];
long long sum[4 * N], tag[4 * N];      // tag[o]：o 的整段还欠子树“每个数加 tag”

void pushup(int o) { sum[o] = sum[2 * o] + sum[2 * o + 1]; }

void applyAdd(int o, int l, int r, long long v) {
    sum[o] += v * (r - l + 1);
    tag[o] += v;
}

void pushdown(int o, int l, int r) {
    if (!tag[o]) return;
    int mid = (l + r) / 2;
    applyAdd(2 * o, l, mid, tag[o]);
    applyAdd(2 * o + 1, mid + 1, r, tag[o]);
    tag[o] = 0;
}

void build(int o, int l, int r) {
    if (l == r) { sum[o] = a[l]; return; }
    int mid = (l + r) / 2;
    build(2 * o, l, mid);
    build(2 * o + 1, mid + 1, r);
    pushup(o);
}

void add(int o, int l, int r, int ql, int qr, long long v) {
    if (qr < l || r < ql) return;
    if (ql <= l && r <= qr) { applyAdd(o, l, r, v); return; }   // 完全覆盖：打标记就停
    pushdown(o, l, r);                                         // 要往下走了，先还债
    int mid = (l + r) / 2;
    add(2 * o, l, mid, ql, qr, v);
    add(2 * o + 1, mid + 1, r, ql, qr, v);
    pushup(o);
}

long long query(int o, int l, int r, int ql, int qr) {
    if (qr < l || r < ql) return 0;
    if (ql <= l && r <= qr) return sum[o];
    pushdown(o, l, r);
    int mid = (l + r) / 2;
    return query(2 * o, l, mid, ql, qr) + query(2 * o + 1, mid + 1, r, ql, qr);
}

int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> a[i];
    build(1, 1, n);
    while (m--) {
        int op, x, y;
        cin >> op >> x >> y;
        if (op == 1) { long long k; cin >> k; add(1, 1, n, x, y, k); }
        else cout << query(1, 1, n, x, y) << "\n";
    }
}
```

```input
8 7
5 3 8 6 2 7 4 1
1 1 4 3
2 1 2
2 1 8
1 3 8 -1
2 1 8
2 5 6
2 3 4
```

```output
14
48
42
7
18
```

手算验证：原数组加 3 到 `[1,4]` 后是 `8 6 11 9 2 7 4 1`，`[1,2]` 的和是 14，全部是 48；再对 `[3,8]` 减 1，得到 `8 6 10 8 1 6 3 0`，总和 42，`[5,6]` 是 7，`[3,4]` 是 18。

加标记的节点 `tag` 不会被“推到底”：被完整覆盖的节点打完标记就返回，所以每次修改和查询仍然只访问 O(log n) 个节点，区间修改是 O(log n)，不是 O(n)。

## 换个问题怎么改：三件事

线段树的框架（建树、递归下降、回溯合并）几乎不变，换问题只改三处：

1. **节点信息**：求和存和；求最小值存最小值；最大子段和要存四个量（见下文）。
2. **`pushup`**：怎么由两个孩子的信息得到父亲的信息。
3. **标记**：标记的含义，标记作用在节点信息上的效果（`apply`），以及标记怎么合并。

几个常见组合：

| 问题 | 节点信息 | 标记 | `apply` 对节点的效果 |
| --- | --- | --- | --- |
| 区间加，区间求和 | `sum` | `add` | `sum += v * 长度`，`add += v` |
| 区间加，区间最小值 | `mn` | `add` | `mn += v`（与长度无关），`add += v` |
| 区间赋值，区间求和 | `sum` | `set`（需要“无标记”的特殊值） | `sum = v * 长度`，`set = v`，同时丢掉自己身上更早的 `add` |
| 区间乘，区间加，区间求和 | `sum` | `mul`、`add` | 先乘后加：`sum = sum * m + add * 长度` |

写区间最小值时，`pushup` 变成 `mn[o] = min(mn[2*o], mn[2*o+1])`，`applyAdd` 变成 `mn[o] += v; tag[o] += v;`，其余代码与上面的区间求和一致。

两个标记并存时（例如洛谷 P3373 的乘和加），要明确**标记的顺序**：约定“先乘后加”后，新来的加法直接累加到 `add`，新来的乘法要把已有的 `mul` 和 `add` 都乘上这个数。

## 可合并的信息：最大子段和

线段树的真正威力是：只要区间信息能由两个相邻小区间的信息**合并**出来，就能用线段树维护。最大子段和是经典例子，节点保存四个量：

- `sum`：区间和。
- `pre`：最大前缀和（至少一个数）。
- `suf`：最大后缀和。
- `best`：最大子段和。

合并左区间 L 和右区间 R：

- `sum = L.sum + R.sum`
- `pre = max(L.pre, L.sum + R.pre)`：最大前缀要么只在左边，要么吃下整个左区间再延伸到右边。
- `suf = max(R.suf, R.sum + L.suf)`：对称。
- `best = max(L.best, R.best, L.suf + R.pre)`：最优子段在左边、在右边，或者横跨中点。

查询时，如果区间跨过中点，就把左右两部分的查询结果用同样的合并函数拼起来。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
struct Info { long long sum, pre, suf, best; };

Info combine(const Info& L, const Info& R) {
    return {L.sum + R.sum,
            max(L.pre, L.sum + R.pre),
            max(R.suf, R.sum + L.suf),
            max({L.best, R.best, L.suf + R.pre})};
}

int n, a[N];
Info t[4 * N];

void build(int o, int l, int r) {
    if (l == r) { t[o] = {a[l], a[l], a[l], a[l]}; return; }
    int mid = (l + r) / 2;
    build(2 * o, l, mid);
    build(2 * o + 1, mid + 1, r);
    t[o] = combine(t[2 * o], t[2 * o + 1]);
}

void update(int o, int l, int r, int pos, int val) {
    if (l == r) { t[o] = {val, val, val, val}; return; }
    int mid = (l + r) / 2;
    if (pos <= mid) update(2 * o, l, mid, pos, val);
    else update(2 * o + 1, mid + 1, r, pos, val);
    t[o] = combine(t[2 * o], t[2 * o + 1]);
}

Info query(int o, int l, int r, int ql, int qr) {     // 另一种写法：按中点分流，不返回空值
    if (ql <= l && r <= qr) return t[o];
    int mid = (l + r) / 2;
    if (qr <= mid) return query(2 * o, l, mid, ql, qr);
    if (ql > mid) return query(2 * o + 1, mid + 1, r, ql, qr);
    return combine(query(2 * o, l, mid, ql, qr), query(2 * o + 1, mid + 1, r, ql, qr));
}

int main() {
    n = 8;
    int init[] = {0, 5, -3, 8, -6, 2, 7, -4, 1};
    copy(init, init + 9, a);
    build(1, 1, n);
    printf("%lld %lld\n", query(1, 1, n, 1, 8).best, query(1, 1, n, 3, 6).best);
    update(1, 1, n, 4, 6);                            // a[4] 从 -6 改成 6
    printf("%lld %lld\n", query(1, 1, n, 1, 8).best, query(1, 1, n, 3, 6).best);
}
```

```output
13 11
25 23
```

这里的 `query` 用了另一种常见写法：先判断区间是否完全落在一侧，只往有交集的孩子走，这样就不需要“空值”，对没有单位元的信息（如最大值、四元组）特别方便。

## 线段树与树状数组怎么选

| | 树状数组 | 线段树 |
| --- | --- | --- |
| 代码量 | 十几行 | 三四十行，带标记更多 |
| 常数 | 小，非递归 | 较大，递归 |
| 单点修改、区间求和 | 适合 | 可以 |
| 区间加、区间求和 | 两个树状数组 | 懒标记，标准做法 |
| 区间最值、区间赋值 | 不能 | 适合 |
| 复杂的可合并信息 | 不能 | 适合 |

经验是：只要是“单点改、区间和”或“区间加、单点查”，用树状数组；其他情况直接用线段树。

## 常见坑

- 数组开 `4 * N`，开 `2 * N` 会在 n 不是 2 的幂时越界。
- 进入孩子之前忘记 `pushdown`：修改和查询里都要写，漏一处就会出现偶发的错误结果。
- 标记用 `=` 而不是 `+=`：连续两次区间加时，第二次会覆盖第一次。（区间赋值的标记则正好相反，要覆盖。）
- 区间长度乘法溢出：`sum` 和 `tag` 用 `long long`，计算 `v * (r - l + 1)` 时 `v` 要是 `long long`。
- 区间赋值的标记需要一个“没有标记”的特殊值，赋值为 0 是合法操作时，不能用 0 当作“没有”。
- 建树时叶子的下标必须与查询下标一致（都从 1 开始，或都从 0 开始），混用会整体偏移一位。
- 多组数据时，`sum` 和 `tag` 要重新清空，`build` 会覆盖所有用到的 `sum`，但不会清 `tag`。
