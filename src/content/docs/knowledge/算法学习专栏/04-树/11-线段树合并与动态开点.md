> 适用版本：C++17。前置：4.7 线段树（建树、单点修改、区间查询），4.4 一般树（dfs 序、子树）。什么时候需要学它：值域达到 10^9，数组开不下；或者要对树上每个结点分别维护一个"值域上的统计"，并且父亲的统计由孩子的统计合并得到。

## 要点

- **动态开点**：不预先建好整棵树，只在修改经过的位置创建结点。空指针 0 表示"这一段什么都没有"，查询时遇到 0 直接返回。空间是 O(修改次数 × log 值域)。
- 每个结点用两个孩子下标 `lc`、`rc` 表示，不再用 `o*2` 和 `o*2+1`。
- **线段树合并**：把两棵动态开点线段树逐位置相加。一边为空时直接复用另一边的整棵子树，两边都有时递归合并并回溯重算。
- 合并的总代价不超过创建过的结点总数，所以 n 个单点线段树合并成一棵是 O(n log n)。
- 合并是**破坏性**的：合并后原来的两棵树不能再单独使用。

## 动态开点

普通线段树按下标直接建满：值域 [1, 10^9] 需要几十亿个结点。但如果一共只有 m 次单点修改，真正被碰到的位置最多 m 个，每个位置对应从根到叶的一条路径，只有 log(10^9) ≈ 30 个结点。把这些路径上的结点按需创建，其余位置不建。

![值域 [1,8] 的动态开点：插入位置 3 和 6 后只创建了 7 个结点，其余 8 个结点不存在](/qmx-Gameknowledge/assets/algo/c4-11-dynamic-nodes.svg)

做法上有两点和普通线段树不同：

1. 修改函数的结点参数用**引用**（`int& o`）：如果 `o` 是 0，就新建一个结点并让调用方的 `lc[o]` 或 `rc[o]` 指向它。
2. 查询遇到 `o == 0` 直接返回 0，不创建结点。

下面是值域 [1, 10^9] 的单点加、区间求和：

```cpp
#include <bits/stdc++.h>
using namespace std;

// 动态开点线段树：值域 [1, 1e9]，单点加、区间求和。只在用到的路径上创建结点。
const int MAXN = 4000000;                // 结点池：每次修改最多新建 ~31 个结点
int lc[MAXN], rc[MAXN], tot, root;
long long sum[MAXN];

void add(int& o, int l, int r, int p, long long v) {   // o 传引用：为空时就地新建
    if (!o) o = ++tot;
    sum[o] += v;
    if (l == r) return;
    int mid = l + (r - l) / 2;
    if (p <= mid) add(lc[o], l, mid, p, v);
    else add(rc[o], mid + 1, r, p, v);
}
long long query(int o, int l, int r, int ql, int qr) {
    if (!o || qr < l || r < ql) return 0;              // 空结点代表"这一段全是 0"
    if (ql <= l && r <= qr) return sum[o];
    int mid = l + (r - l) / 2;
    return query(lc[o], l, mid, ql, qr) + query(rc[o], mid + 1, r, ql, qr);
}

int main() {
    const int R = 1000000000;
    add(root, 1, R, 5, 3);
    add(root, 1, R, 999999999, 4);
    add(root, 1, R, 5, 2);
    printf("sum[1,10] = %lld\n", query(root, 1, R, 1, 10));        // 5
    printf("sum[6,1e9] = %lld\n", query(root, 1, R, 6, R));        // 4
    printf("用了 %d 个结点\n", tot);
    return 0;
}
```

输出：

```text
sum[1,10] = 5
sum[6,1e9] = 4
用了 61 个结点
```

两个位置各占一条 31 层的路径，它们共用了根，所以是 31 + 31 - 1 = 61 个结点。结点池的大小要按 `修改次数 × (log2(值域) + 1)` 估算，比如 10^5 次修改、值域 10^9 需要约 3.1×10^6 个结点，题目内存限制紧时要提前算好。

## 线段树合并

### 问题

一棵树，每个结点有一个颜色。对每个结点 v 求它的子树里**出现次数最多的颜色**（并列时把这些颜色编号加起来）。

对每个结点建一棵值域线段树（下标是颜色，值是出现次数），结点 v 的树由 v 自己的颜色和所有孩子的树合并得到。如果每次合并都逐个颜色相加，会是 O(n²)；线段树合并让总代价降到 O(n log n)。

### 合并过程

![两棵值域线段树合并：只有一边有的结点整棵复用，两边都有的结点递归相加](/qmx-Gameknowledge/assets/algo/c4-11-merge.svg)

`merge(a, b, l, r)` 把 b 并入 a，返回合并后的根：

1. 若 a 为空返回 b，若 b 为空返回 a。这一步直接复用了整棵子树，不再往下走。
2. 若是叶子（`l == r`），把次数相加。
3. 否则递归合并左右孩子，再用孩子信息重算当前结点。

### 复杂度

每次递归进入"两个结点都非空"的情形，合并完之后 a 和 b 变成了一个结点，等于**销毁了一个结点**。结点总数最多是创建出来的 n × (log n + 1) 个，所以所有合并加起来最多这么多步。这个论证和"并查集按秩合并"类似，是均摊的。

### 维护"出现次数最多的颜色"

每个结点存两个值：本段内的最大出现次数 `mx`，以及取到该最大次数的颜色编号之和 `best`。`pull` 比较左右孩子：谁的 `mx` 大就取谁，相等就把 `best` 相加。空结点（编号 0）的 `mx` 为 0，自动参与比较。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 例题：树的每个结点有一个颜色，对每个结点 v 求其子树中"出现次数最多的颜色"的编号之和
// （若有多种颜色并列最多，把它们的编号都加起来）。
// 做法：每个结点一棵动态开点线段树（下标 = 颜色，值 = 出现次数），子树向上合并。
const int N = 100005;
int n, col[N];
vector<int> g[N];

int lc[N * 20], rc[N * 20], mx[N * 20], tot;     // mx：本段内最大出现次数
long long best[N * 20];                           // best：本段内取到最大次数的颜色编号之和

void pull(int o) {
    int a = lc[o], b = rc[o];
    if (mx[a] > mx[b]) mx[o] = mx[a], best[o] = best[a];
    else if (mx[a] < mx[b]) mx[o] = mx[b], best[o] = best[b];
    else mx[o] = mx[a], best[o] = best[a] + best[b];   // 注意 mx[0] = 0，空结点自动参与比较
}
int insert(int l, int r, int c) {                 // 新建一条只含颜色 c（次数 1）的链
    int o = ++tot;
    if (l == r) { mx[o] = 1; best[o] = l; return o; }
    int mid = (l + r) / 2;
    if (c <= mid) lc[o] = insert(l, mid, c);
    else rc[o] = insert(mid + 1, r, c);
    pull(o);
    return o;
}
// 合并 a、b 两棵线段树：同一位置的次数相加；其中一边为空就直接用另一边（整棵子树复用）
int merge(int a, int b, int l, int r) {
    if (!a || !b) return a | b;
    if (l == r) { mx[a] += mx[b]; best[a] = l; return a; }
    int mid = (l + r) / 2;
    lc[a] = merge(lc[a], lc[b], l, mid);
    rc[a] = merge(rc[a], rc[b], mid + 1, r);
    pull(a);
    return a;
}

int rt[N];
long long ans[N];
void dfs(int v, int p) {
    rt[v] = insert(1, n, col[v]);
    for (int u : g[v]) {
        if (u == p) continue;
        dfs(u, v);
        rt[v] = merge(rt[v], rt[u], 1, n);
    }
    ans[v] = best[rt[v]];                         // 根结点的 best 就是整段的答案
}

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> col[i];
    for (int i = 1; i < n; i++) {
        int a, b;
        cin >> a >> b;
        g[a].push_back(b);
        g[b].push_back(a);
    }
    dfs(1, 0);
    for (int i = 1; i <= n; i++) cout << ans[i] << " ";
    cout << "\n";
    return 0;
}
```

用样例输入：

```text
4
1 2 3 4
1 2
2 3
2 4
```

输出：

```text
10 9 3 4 
```

结点 1 的子树里四种颜色各出现一次，并列最多，编号之和是 1+2+3+4 = 10；结点 2 的子树是颜色 2、3、4，和为 9；叶子 3、4 各自就是它自己的颜色。

注意 `dfs` 是递归的，树退化成一条链且 n = 10^5 时可能爆栈，竞赛里要么开大栈，要么改成迭代。

## 其他典型用法

- **子树内比自己大的数的个数**：每个结点的树以权值为下标，合并后在线段树上查区间和。洛谷 P3605 就是这类。
- **树上差分 + 合并**：在路径端点打标记，再自底向上合并，每个结点查众数。洛谷 P4556 雨天的尾巴。
- **动态开点的另一类用法**：二维或高维问题里把"一维线段树套线段树"的内层改为动态开点（线段树套线段树），内存更省。

## 常见坑

- 结点池开小了。线段树合并的值域是离散化后的大小 n，结点数约 n × (log2 n + 1)；值域 10^9 时要乘 31。
- `merge` 里忘记 `return a | b`，或叶子处理时把 `best` 直接相加（应该是 `best[a] = l`，叶子的编号是位置本身）。
- 合并完忘了 `pull`，上层信息过期。
- 合并后继续使用被并入的树（破坏性）。如果后面还要用，合并时要新建结点而不是修改原结点。
- 多组数据时没有清空 `lc`、`rc`、`mx`。结点复用时要把孩子指针清零。
- 查询时在空结点上创建了新结点，造成空间膨胀。
