> 适用版本：C++17。前置：4.7 线段树，2.2 离散化，4.11 中的动态开点。什么时候需要学它：要在**静态数组**上多次询问"区间 [l, r] 里第 k 小是多少"，或者需要访问数据结构的某个历史版本。

## 要点

- **可持久化**：每次修改都保留旧版本。线段树的一次修改只会改变从根到叶的一条路径，所以只需要复制这条路径上的 O(log n) 个结点，其余子树和旧版本共用。
- **主席树**（可持久化权值线段树）：按下标 i 从 1 到 n，依次把 a[i] 插入，得到 n+1 个版本，`root[i]` 表示"只含 a[1..i]"的权值线段树。
- 线段树的每个结点存"落在这一段值域里的数的个数"，所以 `root[r]` 与 `root[l-1]` 对应结点的**个数相减**，就是 a[l..r] 的权值分布。
- 查询第 k 小时，两个版本同时往下走，用差值比较 k，复杂度 O(log n)。预处理和空间都是 O(n log n)。
- 新建的结点越多，数组要开得越大。请在写代码前算好结点数。

## 权值线段树回顾

普通线段树按**下标**（数组位置）建树。权值线段树按**值**建树：下标是离散化后的值，结点里存这一段值域内的数一共出现了几次。

在整个数组上，第 k 小就是在这棵树上"二分"：设左半边的计数是 x，若 k <= x 就进左孩子，否则 k 减去 x 进右孩子，直到叶子。

问题是区间 [l, r] 要的是**这一段**的分布，不是整个数组的。

## 路径复制

![版本 i 的树只新建一条根到叶的链，其余子树指向版本 i-1 的同一批结点](/qmx-Gameknowledge/assets/algo/c4-12-persistent.svg)

在版本 i-1 上把值 p 的计数加 1：

- 复制根，计数加 1，然后看 p 在左半还是右半。
- 沿着包含 p 的那一侧继续复制孩子，另一侧的孩子**直接沿用旧指针**。
- 到叶子时复制叶子，计数加 1。

这样新版本只多出 log K + 1 个结点（K 是离散化后的值域大小），旧版本的结点没有被改动，所以旧版本仍然有效。

## 两个版本相减

![表格显示各版本中每个值的出现次数，root[4] 减 root[1] 得到 a[2..4] 的分布](/qmx-Gameknowledge/assets/algo/c4-12-kth-diff.svg)

数组 a = [3, 1, 4, 1, 5]。`root[4]` 里值 1、3、4、5 的个数是 2、1、1、0，`root[1]` 里是 0、1、0、0，相减得到 2、0、1、0，正好是 a[2..4] = [1, 4, 1] 中各个值的个数。

线段树上不需要真的把差构造出来：查询时同时持有 `u = root[r]`、`v = root[l-1]`，任意结点的区间计数就是 `cnt[u] - cnt[v]`。

## 代码：静态区间第 k 小

输入格式：第一行 n、m，第二行 n 个数，之后 m 行每行 l、r、k，输出 a[l..r] 中第 k 小的数。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 主席树（可持久化权值线段树）：静态区间第 k 小
// root[i] 是"只插入 a[1..i]"之后的权值线段树，root[r] 减去 root[l-1] 就是 a[l..r] 的权值分布
const int N = 100005;
int n, m, a[N];
vector<int> vals;                        // 离散化后的值表

int lc[N * 20], rc[N * 20], cnt[N * 20], tot;
int root[N];

// 在 old 版本的基础上，把值 p 的个数加 1，返回新版本的根。
// 只新建从根到叶的一条链（约 log n 个结点），其余子树与旧版本共用
int update(int old, int l, int r, int p) {
    int o = ++tot;
    lc[o] = lc[old];
    rc[o] = rc[old];
    cnt[o] = cnt[old] + 1;
    if (l == r) return o;
    int mid = (l + r) / 2;
    if (p <= mid) lc[o] = update(lc[old], l, mid, p);
    else rc[o] = update(rc[old], mid + 1, r, p);
    return o;
}
// 两个版本同时下降：差值 = 区间内落在左半边的个数
int kth(int u, int v, int l, int r, int k) {   // u = root[r]，v = root[l-1]
    if (l == r) return l;
    int mid = (l + r) / 2;
    int x = cnt[lc[u]] - cnt[lc[v]];
    if (k <= x) return kth(lc[u], lc[v], l, mid, k);
    return kth(rc[u], rc[v], mid + 1, r, k - x);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> a[i], vals.push_back(a[i]);
    sort(vals.begin(), vals.end());
    vals.erase(unique(vals.begin(), vals.end()), vals.end());
    int K = vals.size();
    for (int i = 1; i <= n; i++) {
        int p = lower_bound(vals.begin(), vals.end(), a[i]) - vals.begin() + 1;
        root[i] = update(root[i - 1], 1, K, p);        // root[0] = 0 是空树
    }
    while (m--) {
        int l, r, k;
        cin >> l >> r >> k;
        cout << vals[kth(root[r], root[l - 1], 1, K, k) - 1] << "\n";
    }
    return 0;
}
```

输入：

```text
5 3
25957 6405 15770 26287 26465
2 2 1
3 4 1
4 5 1
```

输出：

```text
6405
15770
26287
```

逐项核对：a[2..2] 只有 6405；a[3..4] = [15770, 26287]，最小是 15770；a[4..5] = [26287, 26465]，最小是 26287。

### 空间

每次 `update` 新建 `ceil(log2 K) + 1` 个结点。n = 10^5、K <= 10^5 时每次最多 18 个，总共约 1.8×10^6，所以数组开到 `N * 20` 够用。通用的写法是开 `n * (ceil(log2 n) + 2)`，或者保险起见开 `n << 5`。

## 变形：区间内不超过 x 的个数

用同样的两个版本相减，只需要把"沿着 k 往下走"换成"统计整段都 <= x 的结点"。下面这个函数加在上面程序的 `update` 之后：

```cpp
// 加在 pst.cpp 的 update 之后：区间 [l, r] 内离散化编号 <= p 的个数（u = root[r]，v = root[l-1]）
int countLE(int u, int v, int l, int r, int p) {
    if (p < l) return 0;
    if (r <= p) return cnt[u] - cnt[v];  // 整段都 <= p
    int mid = (l + r) / 2;
    return countLE(lc[u], lc[v], l, mid, p) + countLE(rc[u], rc[v], mid + 1, r, p);
}
```

使用时先用 `upper_bound` 算出 <= x 的离散化值有 p 种（编号 1..p），再调用 `countLE(root[r], root[l-1], 1, K, p)`。它沿一条路径走，遇到整段都被包含的结点就直接取差，复杂度 O(log K)。

## 还可以做什么

- **树上路径第 k 小**：把"版本"换成树上父子关系，`root[v]` 在 `root[fa[v]]` 的基础上插入 v 的权值。路径 u 到 v 的分布是 `root[u] + root[v] - root[lca] - root[fa[lca]]`，同样四个版本一起往下走。
- **可持久化数组 / 线段树**：用同样的路径复制，每次修改得到新版本，历史版本随时可以回溯。区间修改配懒标记时要用"标记永久化"，不要下放，否则会修改共用的旧结点。
- **区间不同数个数**：从左往右扫，每个位置只在该数最后一次出现处记 1，用版本做查询，也有主席树做法（但通常用树状数组离线更简单）。

## 常见坑

- 忘记离散化，或者离散化后用原值当下标，值域不是 [1, K] 导致越界。
- `update` 里忘记复制孩子指针 `lc[o] = lc[old]; rc[o] = rc[old];`，新版本丢失整棵旧子树。
- `root[0]` 应该是空树（0 号结点，`cnt[0] = 0`，孩子都是 0）。
- 查询时 `k` 超出区间大小，函数会走到错误的叶子。题目通常保证合法，自己写对拍时要生成合法数据。
- 递归写法在 K 很大时仍然只有 log 层深，不会爆栈；但结点数估算错会越界，是最常见的运行错误。
