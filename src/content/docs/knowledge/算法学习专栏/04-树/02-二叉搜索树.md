> 适用版本：C++17。前置知识：4.1 二叉树遍历。

## 要点

- 二叉搜索树（Binary Search Tree，BST）的性质：任意节点的**左子树所有值都小于它，右子树所有值都大于它**。
- 对 BST 做中序遍历，得到的恰好是从小到大的有序序列。
- 查找、插入、删除的时间都是 O(树高)。树高平均是 O(log n)，但按有序顺序插入会退化成一条链，树高变成 n。
- 删除是难点，分三种情况：叶子、一个孩子、两个孩子。两个孩子时用右子树的最小值（中序后继）顶替。
- STL 的 `set` 和 `map` 底层是红黑树，是自动保持平衡的 BST。本篇手写 BST 是为了理解它们的原理。

## 性质与查找

![在 BST 里查找 7：和根比较，小了往左，大了往右，只走一条路径](/qmx-Gameknowledge/assets/algo/c4-02-bst-search.svg)

查找一个值 `k`：从根出发，`k` 比当前节点小就进左子树，大就进右子树，相等就找到，走到空节点说明不存在。每步都排除了一半以上的候选（树平衡时），和二分查找是同一个思想。

```cpp
// 片段：查找，返回节点指针，找不到返回 nullptr
Node* find(Node* t, int k) {
    while (t && t->key != k)
        t = k < t->key ? t->l : t->r;
    return t;
}
```

## 插入

插入先按查找的路线走，走到空位就挂上新节点。新节点一定成为叶子，不会改动已有节点的相对位置。

```cpp
// 片段：插入，返回子树的新根；k 已存在时什么也不做
Node* insert(Node* t, int k) {
    if (!t) return new Node(k);
    if (k < t->key) t->l = insert(t->l, k);
    else if (k > t->key) t->r = insert(t->r, k);
    return t;
}
```

这里用“返回子树新根”的写法：每层递归把孩子指针重新接上，空位挂上新节点时自然就接好了，不需要单独维护父指针。

## 删除

![删除的三种情况：叶子直接删；一个孩子由孩子顶上；两个孩子用右子树最小值顶替](/qmx-Gameknowledge/assets/algo/c4-02-bst-delete.svg)

先查找到要删除的节点 `t`，再按它的孩子数分类：

1. **叶子**：直接删掉，父亲指向空。
2. **只有一个孩子**：让这个孩子顶替 `t` 的位置。左右子树的大小关系不会被破坏。
3. **有两个孩子**：不能直接删。找右子树中最小的节点 `s`（一路向左走到头），它是 `t` 的**中序后继**，值恰好比 `t` 的所有左子树节点大、比其余右子树节点小。把 `t` 的值改成 `s` 的值，再在右子树里删掉 `s`。`s` 没有左孩子，所以这次删除只会落入情况 1 或 2。

用左子树最大值（中序前驱）顶替也可以，是对称的写法。

## 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int key;
    Node *l = nullptr, *r = nullptr;
    explicit Node(int k) : key(k) {}
};

Node* insert(Node* t, int k) {
    if (!t) return new Node(k);
    if (k < t->key) t->l = insert(t->l, k);
    else if (k > t->key) t->r = insert(t->r, k);
    return t;
}

Node* findMin(Node* t) { while (t->l) t = t->l; return t; }

Node* erase(Node* t, int k) {
    if (!t) return nullptr;                       // 要删的值不存在
    if (k < t->key) t->l = erase(t->l, k);
    else if (k > t->key) t->r = erase(t->r, k);
    else {
        if (!t->l || !t->r) {                     // 叶子或只有一个孩子
            Node* c = t->l ? t->l : t->r;
            delete t;
            return c;
        }
        Node* s = findMin(t->r);                  // 两个孩子：找中序后继
        t->key = s->key;
        t->r = erase(t->r, s->key);               // 在右子树里删掉后继
    }
    return t;
}

bool contains(Node* t, int k) {
    while (t && t->key != k) t = k < t->key ? t->l : t->r;
    return t != nullptr;
}

int height(Node* t) { return t ? 1 + max(height(t->l), height(t->r)) : 0; }
void inorder(Node* t) { if (t) { inorder(t->l); printf("%d ", t->key); inorder(t->r); } }
void preorder(Node* t) { if (t) { printf("%d ", t->key); preorder(t->l); preorder(t->r); } }
void destroy(Node* t) { if (t) { destroy(t->l); destroy(t->r); delete t; } }

int main() {
    Node* root = nullptr;
    for (int k : {8, 3, 10, 1, 6, 14, 4, 7, 13}) root = insert(root, k);
    inorder(root); puts("");                     // 中序是有序的
    preorder(root); puts("");
    printf("%d %d\n", contains(root, 7), contains(root, 5));

    root = erase(root, 4);  preorder(root); puts("");   // 叶子
    root = erase(root, 14); preorder(root); puts("");   // 一个孩子
    root = erase(root, 3);  preorder(root); puts("");   // 两个孩子
    printf("%d\n", height(root));
    destroy(root);

    Node* chain = nullptr;                       // 有序插入：退化成链
    for (int i = 1; i <= 1000; i++) chain = insert(chain, i);
    printf("%d\n", height(chain));
    destroy(chain);

    vector<int> a(1000);
    iota(a.begin(), a.end(), 1);
    mt19937 rng(7);
    for (int i = 999; i > 0; i--) swap(a[i], a[rng() % (i + 1)]);   // 洗牌后再插入
    Node* rnd = nullptr;
    for (int x : a) rnd = insert(rnd, x);
    printf("%d\n", height(rnd));
    destroy(rnd);
}
```

```output
1 3 4 6 7 8 10 13 14
8 3 1 6 4 7 10 14 13
1 0
8 3 1 6 7 10 14 13
8 3 1 6 7 10 13
8 6 1 7 10 13
3
1000
24
```

最后两行对比了两种插入顺序：1 到 1000 按顺序插入，树高是 1000；同样 1000 个数打乱后插入，树高是 24（log₂1000 约为 10，随机树高大约是它的两倍多）。这就是“平衡”的价值。

## 退化与平衡

![有序插入时 BST 退化成链，随机顺序则接近完全二叉树](/qmx-Gameknowledge/assets/algo/c4-02-degenerate.svg)

BST 的所有操作都是 O(树高)。数据随机时期望树高是 O(log n)，但如果输入本身有序或接近有序，就会退化成链表，一次操作 O(n)。解决办法是**平衡树**：每次插入删除后通过旋转保持树高为 O(log n)，如 AVL、红黑树、Treap、Splay，这些在 4.9、4.10 中介绍。

做题时不需要手写：

- 需要有序集合、按值查找、求前驱后继，用 `set`、`multiset`、`map`，它们的操作都是 O(log n)。`lower_bound` 就是在平衡 BST 上找第一个不小于 k 的位置。
- 需要“第 k 小”或“某个值的排名”，`set` 做不到（迭代器不能随机访问），要么用 4.6 的树状数组、4.7 的线段树，要么用平衡树（4.10）。

## 例题

### 例 1：验证二叉搜索树（LeetCode 98）

最常见的错误是只比较节点和它的两个孩子：左孩子小、右孩子大并不够，整棵左子树都必须小于该节点。正确做法是递归时带着一个**开区间 (lo, hi)**，当前节点必须落在区间内，进入左子树时上界收紧为当前值，进入右子树时下界收紧为当前值。

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int key;
    Node *l = nullptr, *r = nullptr;
    explicit Node(int k) : key(k) {}
};

bool valid(Node* t, long long lo, long long hi) {    // 用 long long，避免 key 恰好是 INT_MIN
    if (!t) return true;
    if (t->key <= lo || t->key >= hi) return false;
    return valid(t->l, lo, t->key) && valid(t->r, t->key, hi);
}

int main() {
    // a：5 的右子树里有个 3，比 5 小，不是 BST（但每个节点都比自己的孩子“看起来对”）
    Node* a = new Node(5);
    a->l = new Node(1); a->r = new Node(4);
    a->r->l = new Node(3); a->r->r = new Node(6);
    Node* b = new Node(5);
    b->l = new Node(1); b->r = new Node(7);
    b->r->l = new Node(6); b->r->r = new Node(8);
    printf("%s %s\n", valid(a, LLONG_MIN, LLONG_MAX) ? "true" : "false",
                      valid(b, LLONG_MIN, LLONG_MAX) ? "true" : "false");
}
```

```output
false true
```

另一个等价做法：中序遍历，检查序列是否严格递增。

### 例 2：第 k 小的元素（LeetCode 230）

中序遍历是升序，所以第 k 个被访问的节点就是第 k 小。用 4.1 的迭代中序，数到 k 就停：

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int key;
    Node *l = nullptr, *r = nullptr;
    explicit Node(int k) : key(k) {}
};

Node* insert(Node* t, int k) {
    if (!t) return new Node(k);
    if (k < t->key) t->l = insert(t->l, k);
    else if (k > t->key) t->r = insert(t->r, k);
    return t;
}

int kth(Node* root, int k) {
    stack<Node*> st;
    Node* u = root;
    while (u || !st.empty()) {
        while (u) { st.push(u); u = u->l; }
        u = st.top(); st.pop();
        if (--k == 0) return u->key;                 // 第 k 个被访问的
        u = u->r;
    }
    return -1;                                       // k 超出范围
}

int main() {
    Node* root = nullptr;
    for (int x : {8, 3, 10, 1, 6, 14, 4, 7, 13}) root = insert(root, x);
    printf("%d %d %d\n", kth(root, 1), kth(root, 3), kth(root, 9));
}
```

```output
1 4 14
```

时间 O(树高 + k)。如果要在频繁插入删除的同时反复查询第 k 小，可以给每个节点多存一个 `size`（子树节点数），查询时看左子树大小决定往哪边走，单次 O(树高)，这就是平衡树求排名的基本做法。

### 例 3：有序数组转平衡 BST（LeetCode 108）

要得到矮的树，每次取区间中点做根，左右两半分别递归：

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int key;
    Node *l = nullptr, *r = nullptr;
    explicit Node(int k) : key(k) {}
};

Node* build(const vector<int>& a, int lo, int hi) {   // 闭区间 [lo, hi]
    if (lo > hi) return nullptr;
    int mid = (lo + hi) / 2;
    Node* t = new Node(a[mid]);
    t->l = build(a, lo, mid - 1);
    t->r = build(a, mid + 1, hi);
    return t;
}

void preorder(Node* t) { if (t) { printf("%d ", t->key); preorder(t->l); preorder(t->r); } }
int height(Node* t) { return t ? 1 + max(height(t->l), height(t->r)) : 0; }

int main() {
    vector<int> a = {1, 2, 3, 4, 5, 6, 7};
    Node* root = build(a, 0, 6);
    preorder(root); puts("");
    printf("%d\n", height(root));
}
```

```output
4 2 1 3 6 5 7
3
```

## 常见坑

- 验证 BST 时只和父亲比较，漏掉了“整个左子树都要小于祖先”的约束。
- 删除两个孩子的节点时，应该先把值换成后继的值，再到右子树里删后继，而不是在原位置重复删除。
- 重复元素没有统一约定。本篇忽略重复值；需要计数时在节点里加 `cnt` 字段。
- 用 `INT_MIN`、`INT_MAX` 当作边界，遇到恰好等于边界的测试数据就会判错，改用 `long long`。
- 数据有序时手写 BST 会退化，需要平衡时用 `set`/`map`。
