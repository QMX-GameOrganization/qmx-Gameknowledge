> 适用版本：C++17。前置：4.4 一般树（子树大小、dfs 序），4.5 LCA（倍增），4.13 中的重儿子概念。什么时候需要学它：n 达到 10^5，朴素的"对每个结点暴力统计子树 / 路径"是 O(n²)，而题目的统计量具有"可以加入、可以撤销"或"可以合并"的性质。

## 要点

- **树上启发式合并**（DSU on tree，也叫 sack）：处理完轻儿子后清空，处理重儿子后保留，再把轻子树的点逐个加入。每个点最多被加入 log n 次，总复杂度 O(n log n)。适合"子树内统计"。
- **点分治**：每次找树的重心，统计所有经过重心的路径，删掉重心后对每个子块递归。重心使子块大小至少减半，递归深度 O(log n)。适合"树上路径统计"。
- **虚树**：只保留询问涉及的 k 个关键点和它们的 LCA，最多 2k - 1 个点，把树压缩成规模 O(k) 的小树。适合"多组询问、每组只涉及少量点"。
- 这三个技巧的共同点：用结构性质（重儿子 / 重心 / 关键点的 dfn 序）把总工作量从 O(n²) 或 O(nq) 降下来。

## 一、树上启发式合并

### 问题

和 4.11 同一道题：树的每个结点有颜色，对每个结点求它子树里出现次数最多的颜色编号之和（并列时全部相加）。

### 思路

用一个全局数组 `cnt[颜色]` 统计当前"在桶里"的点。对每个结点 u 的处理 `dfs(u, keep)` 分四步：

![dfs(u, keep) 的四步：处理轻儿子并清空，处理重儿子并保留，加入 u 和轻子树，记录答案](/qmx-Gameknowledge/assets/algo/c4-14-sack-steps.svg)

1. 递归处理所有**轻儿子**，处理完立刻清空（`keep = false`）。
2. 递归处理**重儿子**，处理完**保留**它的统计（`keep = true`）。此时桶里正好是重儿子子树的信息。
3. 加入 u 本身，并把每个轻儿子子树里的点逐个加进桶（借助 dfs 序区间遍历）。此时桶里是 u 整棵子树的信息。
4. 记录 u 的答案。若 `keep = false`（u 是轻儿子），把 u 子树里的点逐个从桶里删除。

### 为什么是 O(n log n)

一个点 x 被重新加入桶的次数，等于从 x 往根走时经过的**轻边**条数：每经过一条轻边，x 就要在父亲那一层被"逐个加入"一次。而每过一条轻边，子树大小至少翻倍（因为轻儿子的子树不大于重儿子的），所以轻边不超过 log2 n 条。每个点被加入 O(log n) 次，每次 O(1)，总共 O(n log n)。

### 代码

用 dfs 序遍历子树（`dfn[u]..en[u]`）代替递归遍历，常数更小。`add` 同时维护当前最大次数 `mx` 和对应颜色编号和 `cur`。清空时因为整棵 u 子树都被删光，直接把 `mx` 和 `cur` 置零。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 树上启发式合并（DSU on tree / sack）
// 同一道题：每个结点求子树内出现次数最多的颜色编号之和
const int N = 100005;
int n, col[N];
vector<int> g[N];
int sz[N], son[N], dfn[N], rk[N], en[N], timer;     // en[u]：u 子树 dfn 区间的右端点
int cnt[N], mx;
long long cur, ans[N];                              // cur：当前达到最大次数的颜色编号之和

void dfs1(int u, int f) {
    sz[u] = 1;
    dfn[u] = ++timer;
    rk[timer] = u;
    for (int v : g[u]) {
        if (v == f) continue;
        dfs1(v, u);
        sz[u] += sz[v];
        if (sz[v] > sz[son[u]]) son[u] = v;
    }
    en[u] = timer;
}
void add(int c) {
    cnt[c]++;
    if (cnt[c] > mx) mx = cnt[c], cur = c;
    else if (cnt[c] == mx) cur += c;
}
// keep = true：处理完后保留 u 子树的统计（它是父亲的重儿子）；false：清空
void dfs2(int u, int f, bool keep) {
    for (int v : g[u])
        if (v != f && v != son[u]) dfs2(v, u, false);   // 先处理轻儿子，处理完清空
    if (son[u]) dfs2(son[u], u, true);                  // 再处理重儿子，保留它的统计
    add(col[u]);
    for (int v : g[u]) {                                // 把轻儿子子树的结点逐个加进来
        if (v == f || v == son[u]) continue;
        for (int i = dfn[v]; i <= en[v]; i++) add(col[rk[i]]);
    }
    ans[u] = cur;
    if (!keep) {                                        // 整棵 u 子树清零
        for (int i = dfn[u]; i <= en[u]; i++) cnt[col[rk[i]]]--;
        mx = 0;
        cur = 0;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> col[i];
    for (int i = 1; i < n; i++) {
        int a, b;
        cin >> a >> b;
        g[a].push_back(b);
        g[b].push_back(a);
    }
    dfs1(1, 0);
    dfs2(1, 0, true);
    for (int i = 1; i <= n; i++) cout << ans[i] << " ";
    cout << "\n";
    return 0;
}
```

输入：

```text
4
1 2 3 4
1 2
2 3
2 4
```

输出：

```text
10 9 3 4 
```

结果与 4.11 中线段树合并的版本一致。

### 和线段树合并比较

| 项目 | 启发式合并 | 线段树合并 |
| --- | --- | --- |
| 时间 | O(n log n) | O(n log n) |
| 空间 | O(n) | O(n log n) |
| 要求 | 统计量能"加入"和"撤销" | 统计量能在值域上"合并" |
| 能否在线回答任意子树 | 不能（按 dfs 顺序一次性算完） | 能（每个结点的树都保留着） |
| 代码 | 短、容易套模板 | 稍长 |

如果统计量只能加入、不能撤销（比如求最大值），启发式合并不好用，可以改成"把小集合插入大集合"：每次把较小的 `set` 或 `map` 的元素逐个加到较大的里面，每个元素被移动 O(log n) 次，总复杂度 O(n log² n)（`set` 插入多一个 log）。

## 二、点分治

### 重心

树的**重心**是这样的结点：删掉它之后，剩下的每个连通块大小都不超过 n/2。任意一棵树至少有一个重心，求法是随便选一个根算出子树大小，从根往下走，每次走向大小超过 n/2 的孩子，走不动时当前结点就是重心。

### 分治流程

问题：统计树上距离不超过 K 的无序点对个数（边带权）。

任意一条路径要么经过重心 c，要么完全落在删掉 c 之后的某个子块里。所以：

1. 找当前块的重心 c。
2. 统计所有**经过 c** 的合法点对：求出块内每个点到 c 的距离 d，数满足 `d[i] + d[j] <= K` 的点对。
3. 把 c 标记为已删除，对 c 的每个邻居所在的子块递归。

步骤 2 里数点对时，同一子块内的两点 i、j 的距离其实小于 `d[i] + d[j]`（路径不经过 c），不应该被统计。处理办法是**容斥**：先对整块（包括 c 自己，距离 0）统计一遍，再对每个子块（距离从 c 算起，即边权加上子块内距离）单独统计一遍并减掉。

数点对本身：把距离数组排序后用双指针，O(m log m)。

![原树与重心树：每一层选出的重心颜色相同，重心树的深度不超过 log n](/qmx-Gameknowledge/assets/algo/c4-14-centroid.svg)

### 复杂度

递归层数不超过 log2 n（每层块大小至少减半），每一层所有块的总点数是 n，每层排序一次，所以总复杂度是 O(n log² n)。如果统计的是固定长度的路径（用桶代替排序）可以做到 O(n log n)。

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 点分治：统计树上距离 <= K 的无序点对个数（边带权）
const int N = 100005;
int n, K;
vector<pair<int, int>> g[N];
bool vis[N];                             // 已被选作重心（已删除）的结点
int sz[N];
long long answer;

int calcSize(int u, int f) {
    sz[u] = 1;
    for (auto [v, w] : g[u])
        if (v != f && !vis[v]) sz[u] += calcSize(v, u);
    return sz[u];
}
// 在 u 所在连通块里找重心：最大子块 <= total/2 的结点
int findCentroid(int u, int f, int total) {
    for (auto [v, w] : g[u])
        if (v != f && !vis[v] && sz[v] * 2 > total) return findCentroid(v, u, total);
    return u;
}
void collect(int u, int f, int d, vector<int>& ds) {
    ds.push_back(d);
    for (auto [v, w] : g[u])
        if (v != f && !vis[v]) collect(v, u, d + w, ds);
}
// 在数组 ds 里数满足 ds[i] + ds[j] <= K 的无序对（i < j），排序加双指针
long long countPairs(vector<int>& ds) {
    sort(ds.begin(), ds.end());
    long long res = 0;
    int l = 0, r = (int)ds.size() - 1;
    while (l < r) {
        if (ds[l] + ds[r] <= K) res += r - l, l++;   // l 与 (l, r] 内每个都满足
        else r--;
    }
    return res;
}
void solve(int u) {
    int total = calcSize(u, 0);
    int c = findCentroid(u, 0, total);
    vis[c] = true;
    vector<int> all{0};                  // 重心自己，距离 0
    for (auto [v, w] : g[c]) {
        if (vis[v]) continue;
        vector<int> sub;
        collect(v, c, w, sub);
        answer -= countPairs(sub);       // 容斥：减去两端在同一个子树里的点对
        all.insert(all.end(), sub.begin(), sub.end());
    }
    answer += countPairs(all);           // 经过重心的路径（含两端同子树的，已在上面扣除）
    for (auto [v, w] : g[c])
        if (!vis[v]) solve(v);           // 对每个子块递归，规模至少减半
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> K;
    for (int i = 1; i < n; i++) {
        int a, b, w;
        cin >> a >> b >> w;
        g[a].push_back({b, w});
        g[b].push_back({a, w});
    }
    solve(1);
    cout << answer << "\n";
    return 0;
}
```

输入（5 个点，K = 4）：

```text
5 4
1 2 3
1 3 1
1 4 2
3 5 1
```

输出：

```text
8
```

手算核对：10 对点里，距离大于 4 的只有 (2,4) 距离 5 和 (2,5) 距离 5 两对，所以合法点对是 10 - 2 = 8。

### 重心树

把每次选出的重心 c 与其子块里选出的重心连边，得到的树叫**重心树**（点分树）。它的深度是 O(log n)，而且原树中任意两点 u、v 的路径必定经过它们在重心树上的 LCA。利用这点可以做"动态修改点权、询问到某点的距离和"一类问题（洛谷 P3345），这里不展开。

## 三、虚树

### 问题

多组询问，每组给出 k 个关键点，且所有询问的 k 之和不大，比如 Σk <= 5×10^5。要求某个只和关键点有关的量，例如"把这 k 个点连起来的最小子树的边权和"。如果每组都在整棵树 O(n) 上做，总共 O(nq) 太慢。

观察：关键点之间的路径只在少数**分叉点**拐弯。只需要保留关键点和分叉点，其余度为 2 的点沿路径压缩成一条边即可。

### 虚树的点集

设关键点集合为 S，按 dfn 排序后，**S 加上所有相邻两点的 LCA** 得到的集合 V 在"取 LCA"下是封闭的（任意两点的 LCA 仍在 V 中），|V| <= 2k - 1。这个 V 就是虚树的全部点。

### 建树

1. 关键点按 dfn 从小到大排序并去重。
2. 对每对相邻关键点求 LCA，加入点集。
3. 点集再次按 dfn 排序并去重。
4. 对排好序的点集，第 i 个点的**虚树父亲**是它与前一个点的 LCA：`parent = lca(a[i-1], a[i])`。

第 4 步成立的原因：l = lca(a[i-1], a[i]) 在点集里，并且是 a[i] 的祖先。如果点集里还有一个点 w 位于 l 和 a[i] 之间（w 是 a[i] 的祖先、l 的后代），那么 w 的 dfn 会落在 a[i-1] 和 a[i] 之间，与"它们相邻"矛盾。

虚树边 `parent → a[i]` 对应原树里 parent 到 a[i] 的整条路径，边权就是这段路径的距离，等于 `dist[a[i]] - dist[parent]`（`dist` 是到根的带权距离）。

![左图原树里关键点 6、8、9、11 为橙色，补上 LCA 1、2、5 后得到右图的虚树，边上标出原树里的路径长度](/qmx-Gameknowledge/assets/algo/c4-14-vtree.svg)

### 复杂度

排序 O(k log k)，LCA 查询 O(k log n)（倍增）或 O(k)（欧拉序 + ST 表）。总共 O(Σk · log n)。

### 代码

每次询问输出虚树的点数和边权和。边权和就是把 k 个点连起来的最小子树（Steiner 树）的总权值。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 虚树：每次询问给出 k 个关键点，求连通它们的最小子树的边权和
// 做法：关键点按 dfn 排序，加入相邻两点的 LCA，去重后再按 dfn 排序，
// 此时每个点的虚树父亲就是它与前一个点的 LCA
const int N = 100005, LOG = 17;
int n, q;
vector<pair<int, int>> g[N];
int up[LOG + 1][N], dep[N], dfn[N], timer;
long long dist[N];                       // 到根的带权距离

void dfs(int u, int f) {
    up[0][u] = f;
    dfn[u] = ++timer;
    for (int i = 1; i <= LOG; i++) up[i][u] = up[i - 1][up[i - 1][u]];
    for (auto [v, w] : g[u]) {
        if (v == f) continue;
        dep[v] = dep[u] + 1;
        dist[v] = dist[u] + w;
        dfs(v, u);
    }
}
int lca(int a, int b) {
    if (dep[a] < dep[b]) swap(a, b);
    for (int i = LOG; i >= 0; i--)
        if (dep[a] - (1 << i) >= dep[b]) a = up[i][a];
    if (a == b) return a;
    for (int i = LOG; i >= 0; i--)
        if (up[i][a] != up[i][b]) a = up[i][a], b = up[i][b];
    return up[0][a];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> q;
    for (int i = 1; i < n; i++) {
        int a, b, w;
        cin >> a >> b >> w;
        g[a].push_back({b, w});
        g[b].push_back({a, w});
    }
    dep[1] = 0;
    dfs(1, 0);
    auto byDfn = [&](int a, int b) { return dfn[a] < dfn[b]; };
    while (q--) {
        int k;
        cin >> k;
        vector<int> a(k);
        for (int& x : a) cin >> x;
        sort(a.begin(), a.end(), byDfn);
        a.erase(unique(a.begin(), a.end()), a.end());
        for (int i = (int)a.size() - 1; i > 0; i--) a.push_back(lca(a[i - 1], a[i]));
        sort(a.begin(), a.end(), byDfn);
        a.erase(unique(a.begin(), a.end()), a.end());
        long long total = 0;
        for (size_t i = 1; i < a.size(); i++) {
            int p = lca(a[i - 1], a[i]);          // a[i] 在虚树中的父亲
            total += dist[a[i]] - dist[p];        // 虚树边 = 原树上 p 到 a[i] 的那段路径
        }
        cout << a.size() << " " << total << "\n";   // 虚树点数、边权和
    }
    return 0;
}
```

输入：6 个点、2 次询问。

```text
6 2
1 2 1
1 3 2
2 4 3
2 5 4
3 6 5
3 4 5 6
2 4 5
```

输出：

```text
5 15
3 7
```

第一次询问关键点 {4, 5, 6}：虚树点集是 {4, 5, 6} 加上 LCA(4,5) = 2 和 LCA(5,6) = 1，共 5 个点；边权和 3 + 4 + 1 + 2 + 5 = 15。第二次询问 {4, 5}：点集是 {4, 5, 2}，边权和 3 + 4 = 7。

### 虚树上还能做什么

建好虚树之后，原来要在整棵树上做的树形 DP 可以改在虚树上做，复杂度只和 k 有关。例如"每次询问删掉一些边，使关键点与根不连通，求最小代价"（洛谷 P2495）：在虚树上自底向上，设 w 为虚树父亲到 v 这段原树路径上的最小边权：关键点 v 的代价就是 w，非关键点 v 的代价是 `min(w, 所有孩子代价之和)`。

## 三种技巧的选择

| 场景 | 技巧 | 关键性质 |
| --- | --- | --- |
| 每个结点要统计整棵子树，统计量可加可撤销 | 启发式合并 | 每个点被加入的次数 = 轻边数 <= log n |
| 统计树上满足条件的路径（长度、权值和等） | 点分治 | 重心使子块至少减半，路径必经某个重心 |
| 多次询问，每次只涉及少量关键点 | 虚树 | 关键点加相邻 LCA 封闭，点数 <= 2k - 1 |

## 常见坑

- 启发式合并清空时没有同时重置 `mx` 和 `cur`，下一棵子树的答案带着旧值。
- 启发式合并里遍历轻子树用的是 `dfn[v]..en[v]` 而不是 `dfn[u]..en[u]`，会重复加入重子树。
- 点分治忘了标记已删除的重心，递归时又走回去。
- 点分治的容斥里，子块的距离要从重心算起（带上重心到该子块根的边权），不是从子块根算起。
- 点分治里求大小的 `calcSize` 要在每次递归前重新算，不能沿用上一层的值。
- 虚树建好后，关键点中有重复点没去重，导致 LCA 退化成自己。
- 虚树排序用的是结点编号而不是 dfn。
- 树退化成链时三种递归写法都可能爆栈。
