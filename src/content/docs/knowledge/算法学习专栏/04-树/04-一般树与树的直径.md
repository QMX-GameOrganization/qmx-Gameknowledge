> 适用版本：C++17。前置知识：4.1 二叉树遍历；会用 `vector` 存邻接表。

## 要点

- 一般树的节点孩子数不限。做题时常见的是**无根树**给出 n-1 条边，用邻接表存，再选一个根做 DFS。
- 一次 DFS 就能求出每个点的父亲、深度和子树大小。DFS 递归过深时，改成 BFS 序后倒着累加。
- 树的重心：删掉它之后，剩下的每个连通块都不超过 n/2。重心到所有点的距离和最小。
- 树的直径：树中最长的一条路径。两次搜索法适用于边权非负；树形 DP 法对边权为负也成立。
- 两次搜索法的做法：从任意点出发找最远点 a，再从 a 出发找最远点 b，a 到 b 就是一条直径。

## 存树与基本量

![有根树的基本量：以 1 为根，每个节点标出深度 d 与子树大小 s](/qmx-Gameknowledge/assets/algo/c4-04-tree-info.svg)

给出 n-1 条无向边，用 `vector<int> g[N]` 存双向边。选定根 `root` 后，用 DFS 从根走下去。因为树没有环，**走回头路只会走回父亲**，所以只需要在递归时传入父亲 `p` 并跳过它，不需要 `vis` 数组。

- `par[u]`：u 的父亲，根的父亲记为 0。
- `dep[u]`：根到 u 的边数，根为 0。
- `sz[u]`：u 的子树里的节点数，`sz[u] = 1 + 所有孩子的 sz`。必须在孩子都处理完（回溯）之后才能累加。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
vector<int> g[N];
int par[N], dep[N], sz[N], n;

void dfs(int u, int p) {
    par[u] = p;
    dep[u] = p ? dep[p] + 1 : 0;       // 根的父亲是 0，深度为 0
    sz[u] = 1;
    for (int v : g[u])
        if (v != p) {
            dfs(v, u);
            sz[u] += sz[v];            // 回溯时累加
        }
}

int main() {
    n = 7;
    int e[][2] = {{1, 2}, {1, 3}, {2, 4}, {2, 5}, {3, 6}, {5, 7}};
    for (auto& x : e) { g[x[0]].push_back(x[1]); g[x[1]].push_back(x[0]); }
    dfs(1, 0);
    for (int i = 1; i <= n; i++) printf("%d ", dep[i]);
    puts("");
    for (int i = 1; i <= n; i++) printf("%d ", sz[i]);
    puts("");
    for (int i = 1; i <= n; i++) printf("%d ", par[i]);
    puts("");
    for (int u = 1; u <= n; u++) {     // 重心：最大的连通块不超过 n/2
        int mx = n - sz[u];            // 向上那一块
        for (int v : g[u]) if (v != par[u]) mx = max(mx, sz[v]);
        if (2 * mx <= n) printf("重心 %d\n", u);
    }
}
```

```output
0 1 1 2 2 2 3
7 4 2 1 2 1 1
0 1 1 2 2 3 5
重心 2
```

整个过程 O(n)。重心的判断条件是：删掉 u 之后，u 的每个孩子子树和“向上那一块”（大小 `n - sz[u]`）都不超过 n/2。图中的树删掉节点 2 后，剩下三块的大小分别是 1、2、3，都不超过 3.5，所以 2 是重心。重心至多有两个，有两个时它们相邻。

**重心的一个用途**：树上所有点到某个点的距离之和，在重心处取最小值。后面的例 2 会用到。

### 递归太深怎么办

树退化成一条链时，DFS 深度等于 n。n 达到 10^5 到 10^6 时，递归可能爆栈，具体深度上限取决于评测环境的栈大小。稳妥的做法是用 BFS 排出访问顺序，再**倒着**处理：倒序时每个点都排在它的孩子之后，正好等价于回溯。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
vector<int> g[N];
int par[N], dep[N], sz[N], n;

void build(int root) {
    vector<int> order = {root};        // BFS 序：父亲一定排在孩子前面
    par[root] = 0; dep[root] = 0;
    for (size_t i = 0; i < order.size(); i++) {
        int u = order[i];
        for (int v : g[u])
            if (v != par[u]) { par[v] = u; dep[v] = dep[u] + 1; order.push_back(v); }
    }
    for (int i = 1; i <= n; i++) sz[i] = 1;
    for (int i = (int)order.size() - 1; i > 0; i--)    // 倒序：孩子先于父亲
        sz[par[order[i]]] += sz[order[i]];
}

int main() {
    n = 7;
    int e[][2] = {{1, 2}, {1, 3}, {2, 4}, {2, 5}, {3, 6}, {5, 7}};
    for (auto& x : e) { g[x[0]].push_back(x[1]); g[x[1]].push_back(x[0]); }
    build(1);
    for (int i = 1; i <= n; i++) printf("%d ", dep[i]);
    puts("");
    for (int i = 1; i <= n; i++) printf("%d ", sz[i]);
    puts("");
}
```

```output
0 1 1 2 2 2 3
7 4 2 1 2 1 1
```

结果和递归版本完全相同。以后遇到“先算孩子再算父亲”的树上计算，都可以套这个倒序模板。

## 树的直径

直径是树里距离最远的两个点之间的路径。

### 方法一：两次搜索

![两次搜索求直径：从 1 出发找到最远点 5，再从 5 出发找到最远点 7，路径 7-6-2-3-4-5 即直径](/qmx-Gameknowledge/assets/algo/c4-04-diameter.svg)

1. 从任意点 s 出发，求出到每个点的距离，取最远的点 a。
2. 从 a 出发再求一次，取最远的点 b。
3. a 到 b 的路径就是一条直径。

**为什么对？** 依据是一条已知结论：树上任意点 s 的最远点，总可以取到某条直径的端点，条件是**边权非负**。证明要分“s 到最远点的路径是否与直径相交”两种情况讨论，这里略去。想自己确认的话，可以写一个枚举所有点对的暴力程序，在随机小树上对比。边权有负数时这个结论不成立，要用下面的树形 DP。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
vector<pair<int, int>> g[N];           // (邻点, 边权)
long long d[N];
int par[N], n;

void dfs(int u, int p) {
    par[u] = p;
    for (auto [v, w] : g[u])
        if (v != p) { d[v] = d[u] + w; dfs(v, u); }
}

int farthest(int s) {                  // 以 s 为根，返回最远的点
    d[s] = 0;
    dfs(s, 0);
    int best = s;
    for (int i = 1; i <= n; i++)
        if (d[i] > d[best]) best = i;
    return best;
}

int main() {
    n = 8;
    int e[][2] = {{1, 2}, {2, 3}, {3, 4}, {4, 5}, {2, 6}, {6, 7}, {4, 8}};
    for (auto& x : e) { g[x[0]].push_back({x[1], 1}); g[x[1]].push_back({x[0], 1}); }
    int a = farthest(1);               // 第一次：从任意点出发
    int b = farthest(a);               // 第二次：从 a 出发
    printf("%d %d %lld\n", a, b, d[b]);
    for (int u = b; u; u = par[u]) printf("%d ", u);   // 沿父亲回到 a，即直径路径
    puts("");
}
```

```output
5 7 5
7 6 2 3 4 5
```

### 方法二：树形 DP

对每个点 u，考虑“经过 u 的最长路径”：它由 u 往下走的两条最长的链拼成。所以 DFS 时让函数返回“从 u 向下的最长链”，同时用最长和次长两条链更新答案：

`ans = max(ans, 最长链 + 次长链)`

这个做法在边权为负时也成立，只要把每条链的贡献限制为非负（不够长的链就不取）。此时答案是**权值和最大的路径**，路径可以只含一个点（和为 0）。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
vector<pair<int, int>> g[N];
long long ans;

long long dfs(int u, int p) {          // 返回 u 向下的最长链（只含 u 时为 0）
    long long m1 = 0, m2 = 0;          // 最长、次长；负的链不取，所以从 0 开始
    for (auto [v, w] : g[u])
        if (v != p) {
            long long t = dfs(v, u) + w;
            if (t > m1) { m2 = m1; m1 = t; }
            else if (t > m2) m2 = t;
        }
    ans = max(ans, m1 + m2);           // 经过 u 的最好路径
    return m1;
}

long long solve(int n, vector<array<int, 3>> es) {
    for (int i = 1; i <= n; i++) g[i].clear();
    for (auto [a, b, w] : es) { g[a].push_back({b, w}); g[b].push_back({a, w}); }
    ans = 0;
    dfs(1, 0);
    return ans;
}

int main() {
    // 与上一节同一棵树，边权都是 1
    printf("%lld\n", solve(8, {{1, 2, 1}, {2, 3, 1}, {3, 4, 1}, {4, 5, 1}, {2, 6, 1}, {6, 7, 1}, {4, 8, 1}}));
    // 含负权边：1-2 权 5，2-3 权 -2，最好的路径只取 1-2
    printf("%lld\n", solve(3, {{1, 2, 5}, {2, 3, -2}}));
}
```

```output
5
5
```

两种方法都是 O(n)。边权非负时两次搜索更短也容易想到；有负权，或者题目要你顺便统计经过每个点的最长路径时，用 DP。[LeetCode 543 二叉树的直径](https://leetcode.cn/problems/diameter-of-binary-tree/)用的就是 DP 方法，只是它按**边数**计算，答案与本篇的“点数减一”一致。

## 例题

### 例 1：最小高度树（LeetCode 310）

题目链接：[LeetCode 310 最小高度树](https://leetcode.cn/problems/minimum-height-trees/)。给出一棵无根树，选一个根使得树高最小，返回所有这样的根。答案就是**树的中心**：直径中间的一个点（直径边数为偶数时）或两个点（奇数时）。用本篇的方法：两次搜索找到直径路径，取路径中间位置的点。

### 例 2：会议（洛谷 P1395 类型）

n 个点的树，选一个点使它到其他所有点的距离之和最小，输出编号最小的这样的点和距离和。由前面的结论，答案点就是重心。有两个重心时它们的距离和相等，所以取编号小的。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
vector<int> g[N];
int par[N], dep[N], sz[N], n;

void build(int root) {                 // BFS 序加倒序累加，避免递归过深
    vector<int> order = {root};
    par[root] = 0; dep[root] = 0;
    for (size_t i = 0; i < order.size(); i++) {
        int u = order[i];
        for (int v : g[u])
            if (v != par[u]) { par[v] = u; dep[v] = dep[u] + 1; order.push_back(v); }
    }
    for (int i = 1; i <= n; i++) sz[i] = 1;
    for (int i = (int)order.size() - 1; i > 0; i--) sz[par[order[i]]] += sz[order[i]];
}

int main() {
    cin >> n;
    for (int i = 1; i < n; i++) {
        int a, b; cin >> a >> b;
        g[a].push_back(b); g[b].push_back(a);
    }
    build(1);
    int c = 0;
    for (int u = 1; u <= n && !c; u++) {          // 从小到大扫，第一个重心编号最小
        int mx = n - sz[u];
        for (int v : g[u]) if (v != par[u]) mx = max(mx, sz[v]);
        if (2 * mx <= n) c = u;
    }
    build(c);                                      // 以重心为根，dep 就是到重心的距离
    long long sum = 0;
    for (int i = 1; i <= n; i++) sum += dep[i];
    printf("%d %lld\n", c, sum);
}
```

```input
7
1 2
1 3
2 4
2 5
3 6
5 7
```

```output
2 10
```

## 常见坑

- DFS 时没有跳过父亲，在无向图存法下会不停地来回走，最终栈溢出。
- 链状树上递归过深。n 超过 10^5 时优先考虑 BFS 序加倒序的写法。
- 两次搜索法只适用于边权非负。有负权用树形 DP。
- 直径的**长度**可能是边数，也可能是边权和，题目要求哪个就用哪个，别和点数混淆。
- 重心可能有两个，题目要求“编号最小”或“全部输出”时要处理。
- 题目给的是森林（多棵树）时，要对每个连通块分别求。
