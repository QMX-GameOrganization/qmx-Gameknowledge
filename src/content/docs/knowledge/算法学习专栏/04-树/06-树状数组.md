> 适用版本：C++17。前置知识：前缀和与差分（1.3）、二进制与位运算。

## 要点

- 树状数组（Binary Indexed Tree，Fenwick Tree）维护一个会被修改的数组，支持**单点修改**和**前缀和查询**，两者都是 O(log n)，代码只有十来行。
- 核心是 `lowbit(i) = i & -i`：数组 `c[i]` 保存原数组 `(i - lowbit(i), i]` 这一段的和。
- 查询前缀和时不断 `i -= lowbit(i)`，修改时不断 `i += lowbit(i)`。
- 配合差分，可以做**区间修改单点查询**；再用两个树状数组，可以做**区间修改区间查询**。
- 常见应用：动态前缀和、逆序对、统计“比它小的有几个”，以及在值域上二分求第 k 小。
- 限制：只能维护“可以抵消”的运算（加法、异或）。区间最大值带修改的问题用线段树（4.7）。

## 要解决的问题

数组 `a` 上有两种操作：把 `a[i]` 加上 `d`；询问 `a[1] + ... + a[x]`。

- 直接存数组：修改 O(1)，查询 O(n)。
- 存前缀和数组：查询 O(1)，修改要更新后面所有前缀和，O(n)。

两者的总代价都是 O(n)。树状数组把前缀和拆成不超过 log n 段，让修改和查询都是 O(log n)。

## lowbit 与结构

![树状数组：c[i] 管理 (i - lowbit(i), i]，长度恰好是 lowbit(i)](/qmx-Gameknowledge/assets/algo/c4-06-bit-structure.svg)

`lowbit(i)` 是 i 的二进制中最低位的 1 所代表的数。例如 `6 = (110)₂`，`lowbit(6) = 2`；`8 = (1000)₂`，`lowbit(8) = 8`。

`c[i]` 管理的区间是 `(i - lowbit(i), i]`，也就是以 i 结尾、长度为 `lowbit(i)` 的一段。看图：`c8` 管 `a1..a8`，`c4` 管 `a1..a4`，`c6` 管 `a5..a6`，`c7` 只管 `a7`。

**查询前缀和 `sum(x)`**：从 x 出发，取 `c[x]`，然后跳到 `x - lowbit(x)`，继续取，直到 0。每次跳跃去掉 x 二进制中最低位的 1，至多 log n 次。例如 `sum(7)`：7 → 6 → 4 → 0，取 `c7 + c6 + c4 = a7 + (a5+a6) + (a1..a4)`，正好拼出 `a1..a7`。

**修改 `add(i, d)`**：所有管辖区间包含 i 的 `c[j]` 都要加上 d。这些 j 是 i、`i + lowbit(i)`、再加 lowbit……直到超过 n。例如修改 `a3`：3 → 4 → 8，`c3`、`c4`、`c8` 都包含 `a3`。

![查询 7 沿 7→6→4 取三段；修改 3 沿 3→4→8 更新三个节点](/qmx-Gameknowledge/assets/algo/c4-06-query-update.svg)

## 基础模板

下标**必须从 1 开始**。如果 i 为 0，`i += lowbit(i)` 不会前进，程序会死循环。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
int n;
long long c[N];

int lowbit(int x) { return x & -x; }

void add(int i, long long d) {          // a[i] += d
    for (; i <= n; i += lowbit(i)) c[i] += d;
}

long long sum(int i) {                  // a[1] + ... + a[i]
    long long s = 0;
    for (; i > 0; i -= lowbit(i)) s += c[i];
    return s;
}

long long range(int l, int r) { return sum(r) - sum(l - 1); }

int main() {
    n = 8;
    int a[] = {0, 5, 3, 8, 6, 2, 7, 4, 1};         // 下标 1..8
    for (int i = 1; i <= n; i++) add(i, a[i]);
    for (int i = 1; i <= n; i++) printf("%lld ", c[i]);
    puts("");
    printf("%lld %lld\n", sum(7), range(2, 6));
    add(3, 10);                                    // a[3] 从 8 变成 18
    printf("%lld %lld\n", range(2, 6), sum(8));
}
```

```output
5 8 8 22 2 9 4 36
35 26
36 46
```

第一行打印的 `c` 数组和上面的图一一对应：`c4 = 5+3+8+6 = 22`，`c8 = 36` 是整个数组的和。查询和修改都至多循环 log n 次，所以都是 O(log n)。

**O(n) 建树**：逐个 `add` 建树是 O(n log n)。更快的办法是每个 `c[i]` 算好后，直接把它交给“管辖自己的父节点” `i + lowbit(i)`：

```cpp
// 片段：由原数组 a[1..n] 在 O(n) 时间里建出 c
for (int i = 1; i <= n; i++) {
    c[i] += a[i];
    int j = i + lowbit(i);
    if (j <= n) c[j] += c[i];
}
```

## 区间修改，单点查询

![区间 [3,6] 加 2，只改差分数组的两个位置，a 是 d 的前缀和](/qmx-Gameknowledge/assets/algo/c4-06-diff.svg)

如果操作变成“给区间 `[l, r]` 每个数加 `v`，询问某个位置的值”，借用差分的思想：设 `d[i] = a[i] - a[i-1]`，那么 `a[i] = d[1] + ... + d[i]`，即**单点查询是差分的前缀和**。区间加 `v` 只改变 `d[l]` 和 `d[r+1]` 两个位置：`d[l] += v`，`d[r+1] -= v`。所以用树状数组维护 `d`：

- `rangeAdd(l, r, v)`：`add(l, v)`，`add(r + 1, -v)`。
- `query(i)`：`sum(i)`。

## 区间修改，区间查询

要求同时支持“区间加”和“区间求和”时，只维护 `d` 不够。把前缀和 `S(x)` 用差分展开：

`S(x) = a[1] + ... + a[x] = Σ(i=1..x) Σ(j=1..i) d[j]`

每个 `d[j]` 在这个双重求和里被计入 `x - j + 1` 次，所以

`S(x) = Σ(j=1..x) d[j] * (x - j + 1) = (x + 1) * Σ d[j] - Σ j * d[j]`

于是用两个树状数组：`b1` 维护 `d[j]`，`b2` 维护 `j * d[j]`。区间加时两个都要改，查询前缀和时按公式组合，区间和用两个前缀和相减。

```cpp
#include <bits/stdc++.h>
using namespace std;

struct BIT {
    int n;
    vector<long long> t;
    explicit BIT(int n) : n(n), t(n + 1, 0) {}
    void add(int i, long long d) { for (; i <= n; i += i & -i) t[i] += d; }
    long long sum(int i) const { long long s = 0; for (; i > 0; i -= i & -i) s += t[i]; return s; }
};

struct RangeBIT {                      // 区间加，区间求和
    int n;
    BIT b1, b2;                        // b1 维护 d[i]，b2 维护 i * d[i]
    explicit RangeBIT(int n) : n(n), b1(n), b2(n) {}
    void rangeAdd(int l, int r, long long v) {
        b1.add(l, v);     b1.add(r + 1, -v);              // r + 1 > n 时 add 自动不执行
        b2.add(l, l * v); b2.add(r + 1, -(long long)(r + 1) * v);
    }
    long long prefix(int x) const { return (x + 1) * b1.sum(x) - b2.sum(x); }
    long long rangeSum(int l, int r) const { return prefix(r) - prefix(l - 1); }
};

int main() {
    RangeBIT t(8);
    t.rangeAdd(3, 6, 2);                              // a = 0 0 2 2 2 2 0 0
    printf("%lld %lld\n", t.rangeSum(1, 8), t.rangeSum(4, 7));
    t.rangeAdd(1, 8, 1);                              // a = 1 1 3 3 3 3 1 1
    printf("%lld %lld\n", t.rangeSum(4, 7), t.rangeSum(3, 3));
}
```

```output
8 6
10 3
```

四种常见需求和对应做法：

| 修改 | 查询 | 做法 |
| --- | --- | --- |
| 单点加 | 区间和 | 一个树状数组，直接存 `a` |
| 区间加 | 单点值 | 一个树状数组，存差分 `d` |
| 区间加 | 区间和 | 两个树状数组，存 `d` 和 `i * d[i]` |
| 单点加 | 区间最大值 | 树状数组做不了，用线段树（4.7） |

## 应用一：逆序对

逆序对是满足 `i < j` 且 `a[i] > a[j]` 的数对。从左到右处理每个 `a[j]`，需要知道“前面已经出现过的数里，有几个比它大”。把树状数组下标当作**值**，`c` 里存每个值出现的次数：处理完一个数就在它的值上加 1；统计时，前面共 j 个数，减去其中不超过 `a[j]` 的个数，剩下的就是严格大于它的个数。

值很大时先**离散化**（2.2）：把值映射为它在排序去重后的排名。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
int n, c[N];

void add(int i) { for (; i <= n; i += i & -i) c[i]++; }
int sum(int i) { int s = 0; for (; i > 0; i -= i & -i) s += c[i]; return s; }

int main() {
    vector<int> a = {5, 3, 8, 6, 2, 7, 4, 1};
    n = a.size();
    vector<int> b = a;                               // 离散化：值 -> 排名 1..m
    sort(b.begin(), b.end());
    b.erase(unique(b.begin(), b.end()), b.end());
    long long inv = 0;
    for (int i = 0; i < n; i++) {
        int r = lower_bound(b.begin(), b.end(), a[i]) - b.begin() + 1;
        inv += i - sum(r);                           // 前面 i 个数里严格大于 a[i] 的个数
        add(r);
    }
    printf("%lld\n", inv);
}
```

```output
18
```

总时间 O(n log n)，和 1.1 的归并排序做法相同，但代码短很多。[LeetCode 315 “计算右侧小于当前元素的个数”](https://leetcode.cn/problems/count-of-smaller-numbers-after-self/)是同一个模式，改成从右往左处理，每次查询 `sum(r - 1)` 即可。

## 应用二：在值域上求第 k 小

把值当下标，`c` 统计每个值出现的次数，则“第 k 小的数”就是最小的 `x` 使得 `sum(x) >= k`。普通二分要 O(log² n)，利用树状数组自己的结构可以直接 O(log n)：从高位到低位试探，每次判断“以 pos 为起点，向右跳 2^b 格能覆盖的那一段”是否还不够 k 个，不够就跳过去并扣掉这一段的个数。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 16, LOG = 3;             // 值域 1..8，2^3 = 8
int n = 8, c[N];

void add(int i, int d) { for (; i <= n; i += i & -i) c[i] += d; }

int kth(int k) {                       // 第 k 小的值，k 从 1 开始
    int pos = 0;
    for (int b = LOG; b >= 0; b--) {
        int np = pos + (1 << b);
        if (np <= n && c[np] < k) { pos = np; k -= c[np]; }
    }
    return pos + 1;
}

int main() {
    for (int x : {1, 3, 3, 5, 8}) add(x, 1);        // 多重集 {1,3,3,5,8}
    for (int k = 1; k <= 5; k++) printf("%d ", kth(k));
    puts("");
}
```

```output
1 3 3 5 8
```

这里 `c[pos + 2^b]` 恰好管理区间 `(pos, pos + 2^b]`，因为 pos 的二进制里比 b 低的位都是 0，这一点保证了跳跃时每个 `c` 都对得上。

## 例题：区域和检索，数组可修改（LeetCode 307）

题目链接：[LeetCode 307 区域和检索 - 数组可修改](https://leetcode.cn/problems/range-sum-query-mutable/)。题目要求把 `nums[index]` 改成 `val`，以及查询区间和。树状数组只支持“加”，所以把赋值转成加上差值：`add(index + 1, val - 旧值)`，同时要记录当前数组。LeetCode 的下标从 0 开始，树状数组从 1 开始，转换时统一加 1。

```cpp
#include <bits/stdc++.h>
using namespace std;

class NumArray {
    int n;
    vector<int> a;                    // 当前数组，下标从 0 起
    vector<long long> c;              // 树状数组，下标从 1 起
    void add(int i, long long d) { for (; i <= n; i += i & -i) c[i] += d; }
    long long sum(int i) const { long long s = 0; for (; i > 0; i -= i & -i) s += c[i]; return s; }
public:
    explicit NumArray(const vector<int>& nums) : n(nums.size()), a(nums), c(n + 1, 0) {
        for (int i = 1; i <= n; i++) {            // O(n) 建树
            c[i] += a[i - 1];
            int j = i + (i & -i);
            if (j <= n) c[j] += c[i];
        }
    }
    void update(int index, int val) { add(index + 1, val - a[index]); a[index] = val; }
    int sumRange(int l, int r) const { return sum(r + 1) - sum(l); }
};

int main() {
    NumArray na({1, 3, 5});
    printf("%d ", na.sumRange(0, 2));
    na.update(1, 2);
    printf("%d\n", na.sumRange(0, 2));
}
```

```output
9 8
```

## 常见坑

- 下标从 0 开始会死循环。读入时把下标统一加 1。
- 区间修改时 `r + 1` 可能等于 `n + 1`，`add` 里循环条件 `i <= n` 会自然跳过，如果手写时没有这个判断就会越界。
- 区间求和要用 `long long`。两个树状数组的乘积项 `i * d[i]` 容易溢出 `int`。
- 逆序对要先离散化，并且重复值不算逆序，所以统计“大于”时要用 `i - sum(r)`，其中 `sum(r)` 包含与自己相等的数。
- 多组数据要把 `c` 清零，只清到 `n` 为止即可。
- 树状数组做不了区间最大值带修改。强行套用会得到错误结果，这种需求换线段树。
