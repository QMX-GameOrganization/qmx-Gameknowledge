> 适用版本：C++17。前置：4.4 一般树（子树大小、dfs 序），4.5 LCA，4.7 线段树（区间加、区间求和，带懒标记）。什么时候需要学它：树上要反复做"路径上所有点加一个数、求路径上的和或最大值"这类操作，用 LCA 加差分处理不了（差分只能离线、且只支持加和）。

## 要点

- dfs 序能让**子树**变成一段连续区间，但**路径**不是连续的。树链剖分用重链把树切成若干条链，让每条链上的点 dfn 连续，路径就拆成 O(log n) 段区间。
- **重儿子**：孩子里子树最大的那个。重儿子与父亲之间的边叫重边，连续的重边组成**重链**，其余边叫轻边。
- 每经过一条轻边，子树大小至少翻倍，所以任意点到根的路径上轻边不超过 log2 n 条，路径经过的链数是 O(log n)。
- 做法是两遍 dfs：第一遍求父亲、深度、子树大小、重儿子；第二遍给每个点编号（dfn），**先走重儿子**，同时记录每个点所在链的链顶 `top`。
- 路径操作 O(log² n)（O(log n) 段，每段线段树 O(log n)），子树操作 O(log n)。
- 顺带得到一个不用倍增的 LCA 算法。

## 为什么要剖分

树上的两个点 u、v 之间的路径是 u 到 LCA 再到 v。如果把每个点按 dfs 序放进线段树：

- 子树 [dfn[u], dfn[u] + sz[u] - 1] 是连续区间，所以子树操作一次线段树操作就完成。
- 路径却散落在 dfn 序列的各处，没法用一次区间操作覆盖。

想让路径也尽量连续，就要在 dfs 时**把一条长链上的点编成连续的号**。而选哪条链最优？选子树最大的孩子（重儿子）继续往下，这样无论从哪个点出发，往上最多跳 log n 次就到根。

## 重链剖分

![11 个结点的树：粗线是重边，重链上的结点 dfn 连续，每个结点标出子树大小 sz 和 dfn](/qmx-Gameknowledge/assets/algo/c4-13-hld-tree.svg)

图中结点 1 的孩子 2、3、4 的子树大小是 5、4、1，所以重儿子是 2；结点 5 的两个孩子 8、9 大小相同，取先出现的 8。重链有 1-2-5-8 和 3-7-10-11，其余结点各自成一条只有一个点的链。

第二遍 dfs 先走重儿子，所以 1、2、5、8 的 dfn 是 1、2、3、4，3、7、10、11 的 dfn 是 7、8、9、10，链上编号连续。

## 路径操作：往上跳链

![路径 9 到 11：从两端轮流跳链顶，得到 dfn 区间 [5,5]、[7,10]、[1,3]](/qmx-Gameknowledge/assets/algo/c4-13-path-jump.svg)

对路径 u-v，反复做下面这件事，直到 u、v 的链顶相同：

1. 比较两点链顶的深度，取**链顶更深**的那一端（设为 u）。
2. 对区间 `[dfn[top[u]], dfn[u]]` 做线段树操作，这一段是 u 到它链顶的整条路径。
3. 令 `u = fa[top[u]]`，即跳到链顶的父亲，进入上面的另一条链。

两点在同一条链上之后，较浅的点到较深的点之间也是一段连续区间 `[dfn[浅], dfn[深]]`，做最后一次操作。

为什么取链顶更深的一端：如果跳了链顶更浅的那端，它可能跳过 LCA，把路径多算了。链顶更深者一定还没到 LCA 所在的链。

### 求 LCA

同样的跳法，不做区间操作，最后在同一条链上的两点里，较浅的那个就是 LCA。不需要倍增表，常数很小。

## 代码

操作：`1 x y z` 路径 x-y 上每个点加 z；`2 x y` 查路径 x-y 的点权和；`3 x z` 以 x 为根的子树每个点加 z；`4 x` 查子树点权和。线段树维护区间加、区间求和（带懒标记，见 4.7）。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 树链剖分（重链剖分）：支持 路径加、路径求和、子树加、子树求和
const int N = 100005;
int n, q, rt;
long long w[N];                          // 点权
vector<int> g[N];
int fa[N], dep[N], sz[N], son[N], top[N], dfn[N], rk[N], timer;

void dfs1(int u, int f) {                // 求父亲、深度、子树大小、重儿子
    fa[u] = f;
    dep[u] = dep[f] + 1;
    sz[u] = 1;
    son[u] = 0;
    for (int v : g[u]) {
        if (v == f) continue;
        dfs1(v, u);
        sz[u] += sz[v];
        if (sz[v] > sz[son[u]]) son[u] = v;
    }
}
void dfs2(int u, int tp) {               // 重儿子先走，保证每条重链的 dfn 连续
    top[u] = tp;
    dfn[u] = ++timer;
    rk[timer] = u;
    if (son[u]) dfs2(son[u], tp);
    for (int v : g[u]) {
        if (v == fa[u] || v == son[u]) continue;
        dfs2(v, v);                      // 轻儿子是新链的链顶
    }
}

// 线段树：区间加、区间求和（下标是 dfn）
long long sum[N * 4], tag[N * 4];
void pull(int o) { sum[o] = sum[o * 2] + sum[o * 2 + 1]; }
void apply(int o, int l, int r, long long v) { sum[o] += v * (r - l + 1); tag[o] += v; }
void push(int o, int l, int r) {
    if (!tag[o]) return;
    int mid = (l + r) / 2;
    apply(o * 2, l, mid, tag[o]);
    apply(o * 2 + 1, mid + 1, r, tag[o]);
    tag[o] = 0;
}
void build(int o, int l, int r) {
    tag[o] = 0;
    if (l == r) { sum[o] = w[rk[l]]; return; }
    int mid = (l + r) / 2;
    build(o * 2, l, mid);
    build(o * 2 + 1, mid + 1, r);
    pull(o);
}
void update(int o, int l, int r, int ql, int qr, long long v) {
    if (ql <= l && r <= qr) { apply(o, l, r, v); return; }
    push(o, l, r);
    int mid = (l + r) / 2;
    if (ql <= mid) update(o * 2, l, mid, ql, qr, v);
    if (qr > mid) update(o * 2 + 1, mid + 1, r, ql, qr, v);
    pull(o);
}
long long query(int o, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return sum[o];
    push(o, l, r);
    int mid = (l + r) / 2;
    long long res = 0;
    if (ql <= mid) res += query(o * 2, l, mid, ql, qr);
    if (qr > mid) res += query(o * 2 + 1, mid + 1, r, ql, qr);
    return res;
}

// 路径 u-v：每次让链顶更深的一端跳到链顶的父亲，直到两点同链
void pathAdd(int u, int v, long long val) {
    while (top[u] != top[v]) {
        if (dep[top[u]] < dep[top[v]]) swap(u, v);
        update(1, 1, n, dfn[top[u]], dfn[u], val);
        u = fa[top[u]];
    }
    if (dep[u] > dep[v]) swap(u, v);
    update(1, 1, n, dfn[u], dfn[v], val);
}
long long pathSum(int u, int v) {
    long long res = 0;
    while (top[u] != top[v]) {
        if (dep[top[u]] < dep[top[v]]) swap(u, v);
        res += query(1, 1, n, dfn[top[u]], dfn[u]);
        u = fa[top[u]];
    }
    if (dep[u] > dep[v]) swap(u, v);
    return res + query(1, 1, n, dfn[u], dfn[v]);
}
int lca(int u, int v) {                  // 顺手得到 LCA：最后在同一条链上，较浅的那个
    while (top[u] != top[v]) {
        if (dep[top[u]] < dep[top[v]]) swap(u, v);
        u = fa[top[u]];
    }
    return dep[u] < dep[v] ? u : v;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> q >> rt;
    for (int i = 1; i <= n; i++) cin >> w[i];
    for (int i = 1; i < n; i++) {
        int a, b;
        cin >> a >> b;
        g[a].push_back(b);
        g[b].push_back(a);
    }
    dfs1(rt, 0);
    dfs2(rt, rt);
    build(1, 1, n);
    while (q--) {
        int t, x, y;
        long long z;
        cin >> t >> x;
        if (t == 1) { cin >> y >> z; pathAdd(x, y, z); }
        else if (t == 2) { cin >> y; cout << pathSum(x, y) << "\n"; }
        else if (t == 3) { cin >> z; update(1, 1, n, dfn[x], dfn[x] + sz[x] - 1, z); }   // 子树 = 一段连续 dfn
        else cout << query(1, 1, n, dfn[x], dfn[x] + sz[x] - 1) << "\n";
    }
    return 0;
}
```

输入：

```text
5 5 2
7 3 4 2 5
1 2
1 5
3 1
4 1
2 3 4
3 2 2
4 5
1 3 4 1
2 1 5
```

第一行是点数 5、操作数 5、根 2；第二行是点权 7 3 4 2 5；之后 4 行是边；最后 5 行是操作。输出：

```text
13
7
17
```

手算核对：路径 3-1-4 的点权和是 4+7+2 = 13；整棵树每个点加 2 之后点权为 9 5 6 4 7，结点 5 的子树只有它自己，值 7；再把路径 3-1-4 每个点加 1，点权变成 1:10、3:7、4:5，所以路径 1-5 的和是 10 + 7 = 17。

## 复杂度

- 两遍 dfs：O(n)。
- 路径操作：最多 O(log n) 段，每段线段树 O(log n)，总共 O(log² n)。
- 子树操作：O(log n)。
- 实际常数很小，轻重链的数量通常远少于理论上界。

## 变化与扩展

- **边权**：把每条边的权放到它**较深端点**（儿子）上，路径查询时 LCA 这个点不能算进去，最后一段改为 `[dfn[浅] + 1, dfn[深]]`。
- **最大值**：线段树换成区间最大值，其他完全一样。
- **换根**：以 r 为根时，子树的询问要按 r 与 x 的位置关系分情形（r 在 x 的子树内时，答案是整棵树去掉含 r 的那个孩子的子树）。
- **结合其他结构**：重链上用 Splay、用 set 或其他数据结构，可以处理更复杂的链上操作；与 LCT 的区别是树形结构不变时用链剖分更简单。

## 常见坑

- 第二遍 dfs 没有先走重儿子，导致链上 dfn 不连续，整个算法失效。
- 路径操作时比较的是 `dep[top[u]]` 而不是 `dep[u]`。
- `son[0]` 的 `sz[0]` 必须为 0，否则 `sz[v] > sz[son[u]]` 在第一个孩子处判断出错。
- 树退化成链且 n 很大时，递归 dfs 会爆栈，需要改成迭代或增大栈空间。
- 子树区间是 `[dfn[x], dfn[x] + sz[x] - 1]`，容易写成 `dfn[x] + sz[x]`。
- 多组数据忘记清空邻接表和 `timer`。
