> 适用版本：C++17。前置知识：4.4 一般树（DFS、子树大小）；背包问题的基本思想（第 6 章 6.3 会系统讲解，这里只用到 01 背包）。

## 要点

- 树形 DP 是在树上定义状态：`f[u]` 描述“以 u 为根的子树”的某种最优值，由 u 的孩子们的状态推出。
- 因为 u 的状态依赖孩子，所以必须**先算孩子，再算父亲**，也就是在 DFS 回溯时计算（后序）。
- 最常见的状态设计是给每个点加一个“选或不选”的维度，用来表达相邻点不能同时选之类的约束。
- 当要求“选恰好 j 个点”时，状态多一维 `j`，把每个孩子的数组像背包一样合并进父亲，这叫树上背包，总复杂度是 O(nm)。
- 4.4 的树的直径 DP 就是树形 DP 的一个例子：每个点用最长链和次长链更新答案。

## 基本套路

树形 DP 的写法几乎固定：

1. 写出 `dfs(u, parent)`。
2. 对每个孩子 `v` 先递归 `dfs(v, u)`。
3. 孩子们的状态都已经算好，用它们更新 `f[u]`。

难点只在第一步之前：**状态怎么定义**，以及**转移时哪些孩子状态可以组合**。

![没有上司的舞会：f1[u] 表示 u 去，f0[u] 表示 u 不去，先算叶子，再算父亲](/qmx-Gameknowledge/assets/algo/c4-08-dp-order.svg)

下面通过三个典型问题看这几个步骤怎么落地。

## 例 1：没有上司的舞会（洛谷 P1352）

n 个人组成一棵上下级关系的树，每个人有快乐值 `r[i]`。一个人和他的**直接上司**不能同时参加舞会，求快乐值总和的最大值。

**状态**：

- `f1[u]`：u 参加时，u 的子树能得到的最大快乐值。
- `f0[u]`：u 不参加时，u 的子树能得到的最大快乐值。

**转移**：

- u 参加，则所有直接下属都不能参加：`f1[u] = r[u] + Σ f0[v]`。
- u 不参加，下属们各自随意，取各自更优的：`f0[u] = Σ max(f0[v], f1[v])`。

答案是 `max(f0[root], f1[root])`。图中的小例子：叶子 4 号 `f1=2, f0=0`；2 号有两个孩子 4 和 5，`f1 = 3 + 0 + 0 = 3`，`f0 = max(2,0) + max(6,0) = 8`；最终根的 `f1 = 5 + 8 + 1 = 14`，`f0 = 8 + 4 = 12`，答案 14。

输入格式：第一行 n，接着 n 个快乐值，然后若干行 `L K` 表示 K 是 L 的直接上司，以 `0 0` 结束。没有上司的人就是根。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 6005;
int n, r[N], f0[N], f1[N];
vector<int> son[N];
bool hasBoss[N];

void dfs(int u) {
    f1[u] = r[u];                        // u 参加：先算上自己
    f0[u] = 0;
    for (int v : son[u]) {
        dfs(v);                          // 孩子先算
        f1[u] += f0[v];                  // u 参加，下属都不能参加
        f0[u] += max(f0[v], f1[v]);      // u 不参加，下属随意
    }
}

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> r[i];
    int l, k;
    while (cin >> l >> k && (l || k)) { son[k].push_back(l); hasBoss[l] = true; }
    int root = 1;
    while (hasBoss[root]) root++;        // 找到没有上司的人
    dfs(root);
    cout << max(f0[root], f1[root]) << "\n";
}
```

```input
6
5 3 4 2 6 1
2 1
3 1
4 2
5 2
6 3
0 0
```

```output
14
```

这个程序的递归深度最多 6000，没有问题。深度可能达到 10^5 以上时，按 4.4 的方法用 BFS 序倒着处理，状态和转移完全不变。

## 例 2：打家劫舍 III（LeetCode 337）

同样的模式搬到二叉树上：不能偷相邻（父子）的两个节点，求能偷到的最大金额。让 `dfs` 直接返回两个值 `{不偷当前节点的最优, 偷当前节点的最优}`，用 `pair` 返回，不需要额外数组。

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int val;
    Node *l = nullptr, *r = nullptr;
    explicit Node(int v) : val(v) {}
};

pair<int, int> dfs(Node* t) {            // {不偷 t 的最优, 偷 t 的最优}
    if (!t) return {0, 0};
    auto [l0, l1] = dfs(t->l);
    auto [r0, r1] = dfs(t->r);
    int skip = max(l0, l1) + max(r0, r1);   // 不偷 t：孩子随意
    int take = t->val + l0 + r0;            // 偷 t：孩子都不能偷
    return {skip, take};
}

int rob(Node* root) {
    auto [a, b] = dfs(root);
    return max(a, b);
}

int main() {
    // 树 [3,2,3,null,3,null,1]
    Node* root = new Node(3);
    root->l = new Node(2); root->r = new Node(3);
    root->l->r = new Node(3); root->r->r = new Node(1);
    printf("%d\n", rob(root));
}
```

```output
7
```

偷根（3）、左孩子的右孩子（3）和右孩子的右孩子（1），共 7。

## 例 3：树上背包，选课（洛谷 P2014）

有 n 门课，每门课最多有一门先修课（先修课必须先选）。选出 m 门课，使学分之和最大。先修关系形成一片森林。

做法：增加一个**虚拟根 0**（学分 0，没有先修课的课都以它为先修），森林变成一棵树。在这棵树上，选一门课就必须选它的父亲，也就是“选出的点集是一个连通的、包含根的子树”。因为虚拟根也会占一个名额，所以要选 `m + 1` 个点。

**状态**：`dp[u][j]` 表示在 u 的子树里选恰好 j 个点，并且 u 必须被选（j ≥ 1）时的最大学分和。

**转移**：对 u 的每个孩子 v，把 v 的数组合并进 u 的数组。选 j 个点的 u，再从 v 的子树里选 k 个点（v 必须选），总共 `j + k` 个点：

`dp[u][j + k] = max(dp[u][j + k], dp[u][j] + dp[v][k])`

这就是“每个孩子是一个物品组，组内选 k 的代价是 k”的分组背包。和普通 01 背包一样，**j 要倒序枚举**，避免同一个孩子被重复合并。

![树上背包：把孩子的 dp 数组合并进父亲，new[k] = max(dp[u][i] + dp[v][k-i])](/qmx-Gameknowledge/assets/algo/c4-08-tree-knapsack.svg)

**为什么是 O(nm) 而不是 O(nm²)？** 合并时 j 只枚举到 `min(sz[u], m)`，k 只枚举到 `min(sz[v], m - j)`。可以证明所有合并的总代价是 O(nm)：每一对节点只会在它们的 LCA 处被“配对”一次（至多贡献一次循环），而超过 m 的部分被截断。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 305;
int n, m, score[N], sz[N], dp[N][N];
vector<int> son[N];

void dfs(int u) {
    sz[u] = 1;
    dp[u][1] = score[u];                       // 只选 u 自己
    for (int v : son[u]) {
        dfs(v);
        for (int j = min(sz[u], m); j >= 1; j--)           // j 倒序
            for (int k = 1; k <= sz[v] && j + k <= m; k++)
                dp[u][j + k] = max(dp[u][j + k], dp[u][j] + dp[v][k]);
        sz[u] += sz[v];
    }
}

int main() {
    cin >> n >> m;
    m++;                                       // 虚拟根 0 也占一个名额
    for (int i = 1; i <= n; i++) {
        int pre;
        cin >> pre >> score[i];                // pre 是先修课，0 表示没有
        son[pre].push_back(i);
    }
    dfs(0);
    cout << dp[0][m] << "\n";
}
```

```input
6 4
0 2
1 3
1 1
2 8
2 1
3 5
```

```output
14
```

输入里 6 门课的先修关系是：1 没有先修；2、3 的先修课是 1；4、5 的先修课是 2；6 的先修课是 3。学分依次为 2、3、1、8、1、5。选 4 门的最优方案之一是 {1, 2, 3, 4}：2 + 3 + 1 + 8 = 14。

## 小结

| 问题类型 | 状态 | 要点 |
| --- | --- | --- |
| 相邻不能同选 | `f0[u]`、`f1[u]` | 孩子的两个状态按 u 的选择分别组合 |
| 选恰好 j 个点 | `dp[u][j]` | 分组背包合并，j 倒序，注意上限 |
| 树上最长路径 | 向下最长链 | 在 u 处用最长和次长链更新答案（4.4） |

还有一类“换根 DP”：已知以某个点为根的答案，用 O(1) 推出以相邻点为根的答案，从而求出每个点为根时的答案，例如 [LeetCode 834](https://leetcode.cn/problems/sum-of-distances-in-tree/)。本篇不展开，练习里放了两道换根 DP 的题。

## 常见坑

- 状态定义不清就写转移。先用一句话写出 `f[u][...]` 的含义，再写转移。
- 在遍历孩子之前就用孩子的值，顺序反了。所有用到孩子的计算必须放在 `dfs(v)` 之后。
- 树上背包 j 正序枚举会让同一个孩子被合并多次。
- 数组 `dp[N][M]` 大小是 N×M 个 `int`，N、M 都是 10^3 级别时要注意内存。
- 忘记虚拟根占名额，答案少选一门。
- 初始状态没有处理“不选”：例如打家劫舍里空节点要返回 `{0, 0}`。
