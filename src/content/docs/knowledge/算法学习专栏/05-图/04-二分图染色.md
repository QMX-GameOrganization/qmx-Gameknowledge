> 适用版本:C++17。需要会写 BFS(3.2 篇)。

## 要点

- **二分图**:点可以分成两组,使得每条边的两个端点分别在两组。
- 等价说法:图里**没有奇数长度的环**。
- 判断方法是**二染色**:BFS 或 DFS 遍历,相邻点染成不同颜色,发现矛盾就不是二分图。时间 O(n + m)。
- 图可能不连通,每个连通分量单独染色,互不影响。
- 染色能做的题:判断能否分成两组、两组人数的选择、"把冲突最小化"的二分答案。

## 二分图与奇环

![BFS 按层染色:偶数层与奇数层分属两部分,边只出现在两部分之间](/qmx-Gameknowledge/assets/algo/c5-04-bfs-color.svg)

染色的规则只有一条:`color[v] = color[u] ^ 1`。起点染 0,它的邻居染 1,邻居的邻居染 0。这样同一个 BFS 层的点颜色相同,相邻层颜色不同。

什么时候会出现矛盾?当一条边连接的两个点**颜色已经相同**时。这条边和 BFS 树上两点到公共祖先的路径合起来,构成一个奇数长度的环(两条同层的树路径等长,加上这条边,总长为奇数)。

![偶环可以二染色,奇环必然冲突](/qmx-Gameknowledge/assets/algo/c5-04-odd-cycle.svg)

反过来,如果没有奇环,BFS 染色就不会遇到矛盾。所以"能二染色"和"没有奇环"是一回事。

## BFS 染色

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> g(n + 1);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    vector<int> color(n + 1, -1);  // -1 未染色,0/1 两种颜色
    for (int s = 1; s <= n; s++) {  // 图可能不连通,每个连通分量单独染
        if (color[s] != -1) continue;
        color[s] = 0;
        queue<int> q;
        q.push(s);
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (int v : g[u]) {
                if (color[v] == -1) {
                    color[v] = color[u] ^ 1;  // 邻居染成相反的颜色
                    q.push(v);
                } else if (color[v] == color[u]) {
                    cout << "不是二分图,冲突边 " << u << "-" << v << "\n";
                    return 0;
                }
            }
        }
    }
    cout << "是二分图\n";
    for (int i = 1; i <= n; i++) cout << color[i] << " ";
    cout << "\n";
    return 0;
}
```

输入(图中的 6 个点):

```text
6 6
1 2
2 3
3 4
4 1
4 5
5 6
```

输出:

```text
是二分图
0 1 0 1 0 1 
```

换成三角形(`3 3`,边 `1 2`、`2 3`、`3 1`),输出"不是二分图,冲突边 2-3"。

几点说明:

- 外层 `for s` 保证每个连通分量都被染到。
- 染色用 `-1` 表示未染色,所以判冲突时先看是否未染色,再比较颜色。
- DFS 也能染色,逻辑相同。但链状图递归深度可达 n,n 到 10^5 以上时容易爆栈,BFS 没有这个风险。

## 例题

### 例 1:判断二分图

LeetCode 785 判断二分图:给邻接表,直接用上面的染色。LeetCode 886 可能的二分法:把"互相不喜欢"的人连边,问能否分成两组,同样是判断二分图。

### 例 2:每条边恰有一个端点被选

洛谷 P1330 封锁阳光大学:选一些点,使每条边**恰有一个**端点被选,求最少选几个点,无解输出 `Impossible`。

每个连通分量内,如果可以二染色,就只有两种选法:选所有颜色 0 的点,或选所有颜色 1 的点。取点数少的一侧。各连通分量互相独立,答案是各块最小值的和。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 每条边恰有一个端点被选中,求最少选几个点
int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> g(n + 1);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    vector<int> color(n + 1, -1);
    int ans = 0;
    for (int s = 1; s <= n; s++) {
        if (color[s] != -1) continue;
        int cnt[2] = {0, 0};  // 这个连通分量里两种颜色各有多少个点
        color[s] = 0;
        cnt[0] = 1;
        queue<int> q;
        q.push(s);
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (int v : g[u]) {
                if (color[v] == -1) {
                    color[v] = color[u] ^ 1;
                    cnt[color[v]]++;
                    q.push(v);
                } else if (color[v] == color[u]) {
                    cout << "Impossible\n";
                    return 0;
                }
            }
        }
        ans += min(cnt[0], cnt[1]);  // 两种选法二选一,取点数少的那一侧
    }
    cout << ans << "\n";
    return 0;
}
```

输入一个星形图:

```text
4 3
1 2
1 3
1 4
```

输出 `1`:选中心点 1 即可。输入路径 `1-2-3-4` 输出 `2`。输入三角形则输出 `Impossible`。

### 例 3:二分答案加染色

洛谷 P1525 关押罪犯:n 个罪犯分到两个监狱,有些人之间有怨气值 c,同监狱的人之间会产生冲突事件,要使最大的冲突怨气值尽量小。

设答案不超过 x:那么所有怨气大于 x 的边,两端必须分到不同监狱,也就是这些边构成的图必须是二分图。x 越大保留的边越少,越容易满足,具有单调性,可以二分 x,每次只保留 `c > x` 的边做一次染色。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m;
vector<array<int, 3>> es;  // (a, b, c):a 和 b 之间的怨气值为 c

// 只保留怨气 > x 的边,这些边的两端必须分开关,检查是否能二染色
bool ok(int x) {
    vector<vector<int>> g(n + 1);
    for (auto& e : es)
        if (e[2] > x) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }
    vector<int> color(n + 1, -1);
    for (int s = 1; s <= n; s++) {
        if (color[s] != -1) continue;
        color[s] = 0;
        queue<int> q;
        q.push(s);
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (int v : g[u]) {
                if (color[v] == -1) {
                    color[v] = color[u] ^ 1;
                    q.push(v);
                } else if (color[v] == color[u]) {
                    return false;
                }
            }
        }
    }
    return true;
}

int main() {
    cin >> n >> m;
    es.resize(m);
    int hi = 0;
    for (auto& e : es) {
        cin >> e[0] >> e[1] >> e[2];
        hi = max(hi, e[2]);
    }
    int lo = 0;  // 答案在 [0, hi],ok 对 x 单调:x 越大保留的边越少,越容易二分
    while (lo < hi) {
        int mid = (lo + hi) / 2;
        if (ok(mid)) hi = mid;
        else lo = mid + 1;
    }
    cout << lo << "\n";
    return 0;
}
```

洛谷样例:

```text
4 6
1 4 2534
2 3 3512
1 2 28351
1 3 6618
2 4 1805
3 4 12884
```

输出 `3512`。这题还有并查集的做法(把"敌人的敌人是朋友"合并),速度更快,可以在学完并查集后对比。

## 常见坑

- 只从点 1 开始 BFS:漏掉其他连通分量,可能漏判矛盾。
- 自环(`u u`)一定不是二分图。上面的代码里,自环的邻居就是自己,颜色必然相同,会被判出来。
- 多组数据或二分答案时,颜色数组要重新初始化。上面例 3 在 `ok` 函数里每次新建。
- DFS 染色在大图上递归过深会栈溢出。
