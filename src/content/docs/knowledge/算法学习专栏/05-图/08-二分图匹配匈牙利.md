> 适用版本：C++17。前置知识：DFS、5.4 二分图染色（会判断一张图是不是二分图）。什么时候需要学：题目要把两类对象一一配对（任务和人、行和列、黑格和白格），或者要在"互相冲突"的两类点里选尽量多的点。

## 要点

- **匹配**：一组两两没有公共端点的边。边数最多的匹配叫**最大匹配**，所有点都被匹配的叫**完美匹配**。
- **增广路**：起点和终点都是未匹配点，路上"非匹配边、匹配边"交替出现的路径。沿增广路把两种边互换，匹配数恰好加 1；图里没有增广路时，当前匹配就是最大匹配。
- **匈牙利算法**：对左部每个点各做一次 DFS 找增广路。复杂度 O(VE)，V 到 1000 左右、E 到 10^5 级别够用。
- **Hopcroft–Karp**：每轮 BFS 分层、同时找多条最短增广路，复杂度 O(E√V)。
- **König 定理**：二分图中，最大匹配数 = 最小点覆盖数；最大独立集 = 总点数 - 最大匹配数。

## 增广路：为什么能一路改下去

设当前匹配里 a1 配 b1、a3 配 b3，现在要给 a2 找对象。a2 只认识 b1，而 b1 被 a1 占着。这时问 a1："能不能换一个？" a1 还认识 b2，b2 空闲，于是 a1 让出 b1 去配 b2，a2 配 b1。这个"问下去"的过程就是沿一条增广路走：a2 → b1（非匹配边）→ a1（匹配边）→ b2（非匹配边）。

![增广路：左边是增广前的匹配和那条路，右边是路上的边互换身份后的匹配](/qmx-Gameknowledge/assets/algo/c5-08-augment.svg)

增广路上非匹配边比匹配边多一条，互换之后匹配边多一条。算法保证的两件事：

1. 每找到一条增广路，匹配数加 1，且已匹配的点不会变成未匹配。
2. 没有增广路 ⟺ 当前匹配最大。这是 Berge 定理：如果存在更大的匹配 M'，把 M 与 M' 的对称差拿出来，里面必有一条路径，两端是 M 之外的点，它就是 M 的增广路。

匈牙利算法对每个左部点只尝试一次。已经尝试过又失败的点以后不用重试：之后图里的匹配只会变得更满，原来没找到路的点不会因此找到路。

## 模板

```cpp
const int N = 1005;
int nl, nr;
vector<int> g[N];            // 左部点 u 的邻居（右部编号）
int match_r[N];              // match_r[v]：右部 v 当前匹配的左部点，0 表示未匹配
int vis[N], stamp_;          // 用时间戳代替每轮 memset

bool dfs(int u) {            // 为左部点 u 找增广路
    for (int v : g[u]) {
        if (vis[v] == stamp_) continue;
        vis[v] = stamp_;
        if (!match_r[v] || dfs(match_r[v])) {   // v 空闲，或 v 的原配能换到别处
            match_r[v] = u;
            return true;
        }
    }
    return false;
}

// 主流程
int ans = 0;
for (int u = 1; u <= nl; u++) {
    ++stamp_;                // 每个左部点开始前，右部的"已访问"标记清空
    if (dfs(u)) ans++;
}
```

`vis` 只标右部点：一轮 DFS 里每个右部点最多被问一次，所以一轮是 O(E)，总共 O(VE)。

用图中的例子手走一遍：左部 3 个点，右部 3 个点，边 1-1、1-2、2-1、3-3（输入 `3 3 4`，后接这 4 条边）。

1. u=1：试 v=1，空闲，配 1-1。
2. u=2：试 v=1，已被 1 占；`dfs(1)` 试 v=1（本轮已访问，跳过）、v=2，空闲，于是 1 改配 2，2 配 1。
3. u=3：试 v=3，空闲，配 3-3。

程序输出 3，配对为 2-1、1-2、3-3，与手算一致。

## Hopcroft–Karp（更快的写法）

匈牙利每次只找一条增广路。Hopcroft–Karp 每一轮先用 BFS 从所有未匹配左点出发分层，再用 DFS 沿"层数加 1"的边同时找出一批互不相交的最短增广路。可以证明只需要 O(√V) 轮，总复杂度 O(E√V)。

```cpp
int nl, nr;
vector<int> g[N];
int match_l[N], match_r[N], dist_[N];

bool bfs() {
    queue<int> q;
    bool found = false;
    for (int u = 1; u <= nl; u++) {
        if (!match_l[u]) { dist_[u] = 0; q.push(u); }
        else dist_[u] = -1;
    }
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : g[u]) {
            int w = match_r[v];
            if (!w) found = true;                       // 到达空闲右点
            else if (dist_[w] < 0) { dist_[w] = dist_[u] + 1; q.push(w); }
        }
    }
    return found;
}

bool dfs(int u) {
    for (int v : g[u]) {
        int w = match_r[v];
        if (!w || (dist_[w] == dist_[u] + 1 && dfs(w))) {
            match_l[u] = v;
            match_r[v] = u;
            return true;
        }
    }
    dist_[u] = -1;                                      // 此点本轮已无路，剪掉
    return false;
}

// 主流程
int ans = 0;
while (bfs())
    for (int u = 1; u <= nl; u++)
        if (!match_l[u] && dfs(u)) ans++;
```

点数在几千以内时，匈牙利通常已经够快；到 10^5 级别再换 Hopcroft–Karp。

## König 定理：最小点覆盖与最大独立集

**点覆盖**是一组点，使每条边至少有一个端点在里面。König 定理说二分图里，最小点覆盖的大小等于最大匹配数。构造方法：

1. 求出最大匹配。
2. 从每个**未匹配的左部点**出发，沿"非匹配边走到右部，匹配边回到左部"的交错路遍历，记下访问到的点。
3. 最小点覆盖 = 左部**没被访问到**的点 + 右部**被访问到**的点。

![König 定理：从未匹配的左点 a3 走交错路，覆盖集是 a1、b2、b3](/qmx-Gameknowledge/assets/algo/c5-08-konig.svg)

图中最大匹配 3 条（粗绿线），a3 没有配上。从 a3 出发访问到 a3、a2、a4 和 b2、b3，所以覆盖集是左部没访问到的 a1，加上右部访问到的 b2、b3，共 3 个，恰好等于最大匹配数，并且图上六条边每条都至少有一端在里面。

**最大独立集**（互相没有边的最大点集）是点覆盖的补集，大小是总点数减去最大匹配数。这里 8 - 3 = 5，例如 a2、a3、a4、b1、b4。

```cpp
bool visL[N], visR[N];
void alt(int u) {            // 交错路遍历，从左部未匹配点出发
    visL[u] = true;
    for (int v : g[u]) {
        if (visR[v]) continue;
        visR[v] = true;
        if (match_r[v] && !visL[match_r[v]]) alt(match_r[v]);
    }
}
// 求完最大匹配后：
for (int u = 1; u <= nl; u++) if (!match_l[u]) alt(u);
// 覆盖集：左部 !visL[u] 的点 + 右部 visR[v] 的点
```

这里的 `match_l[u]` 需要在匈牙利的 `dfs` 成功时一并记录（`match_l[u] = v`）。

## 例题

### 例 1：骑士共存（洛谷 P3355）

n×n 棋盘上有若干障碍格，最多放多少个互相不会攻击的骑士。马走"日"字，一步一定换格子颜色，所以把格子按 (x+y) 的奇偶分成两部，互相能攻击的两格连边，得到二分图。要选的是互不相连的点，即**最大独立集**，答案是可用格数减去最大匹配。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 205;
int n;
bool bad[N][N];
int id[N][N];
vector<int> g[N * N];
int match_r[N * N], vis[N * N], stamp_;
const int dx[8] = {1, 2, 2, 1, -1, -2, -2, -1};
const int dy[8] = {2, 1, -1, -2, -2, -1, 1, 2};

bool dfs(int u) {
    for (int v : g[u]) {
        if (vis[v] == stamp_) continue;
        vis[v] = stamp_;
        if (!match_r[v] || dfs(match_r[v])) { match_r[v] = u; return true; }
    }
    return false;
}

int main() {
    int m;
    cin >> n >> m;
    while (m--) { int x, y; cin >> x >> y; bad[x][y] = true; }
    int cnt = 0, free_cells = 0;
    for (int x = 1; x <= n; x++)
        for (int y = 1; y <= n; y++)
            if (!bad[x][y]) { id[x][y] = ++cnt; free_cells++; }
    for (int x = 1; x <= n; x++)
        for (int y = 1; y <= n; y++) {
            if (bad[x][y] || (x + y) % 2) continue;      // 只从"偶"格往外连边
            for (int d = 0; d < 8; d++) {
                int nx = x + dx[d], ny = y + dy[d];
                if (nx < 1 || nx > n || ny < 1 || ny > n || bad[nx][ny]) continue;
                g[id[x][y]].push_back(id[nx][ny]);
            }
        }
    int match = 0;
    for (int x = 1; x <= n; x++)
        for (int y = 1; y <= n; y++)
            if (!bad[x][y] && (x + y) % 2 == 0) {
                ++stamp_;
                if (dfs(id[x][y])) match++;
            }
    cout << free_cells - match << "\n";
    return 0;
}
```

3×3 无障碍时输出 5：周围 8 格组成一个环，最多放 4 个，加上中心格共 5 个。程序对 4×4 以内的随机障碍做了暴力枚举对拍，结果一致。

### 例 2：多米诺骨牌覆盖

棋盘上有障碍格，每张骨牌盖相邻两格，最多放多少张。相邻两格颜色不同，按棋盘黑白染色分成两部，相邻的格子连边，答案就是最大匹配。如果要求"能否铺满"，就看最大匹配是否等于格子数的一半。

建模的通用套路：**把两类对象各放一边，"可以配对"连边，要找最多的配对数**。遇到"选尽量多的点使它们互不冲突"，先判断冲突关系是否构成二分图，再用总点数减最大匹配。

## 常见坑

- 匈牙利的 `vis` 每处理一个左部点就要重置。用时间戳比 `memset` 快得多。
- 两部点的编号要分开。如果左右部点编号重叠，要给右部点加偏移，否则 `vis` 会互相干扰。
- 最大独立集用在**二分图**上才成立，一般图的最大独立集是 NP 难题。先确认冲突图是二分图。
- 无向二分图建边时只从左部往右部存一份边，不要双向都存，否则匈牙利的 DFS 会走回左部。
- 点数较大时递归深度可能很深，必要时用 Hopcroft–Karp 或改成迭代。
