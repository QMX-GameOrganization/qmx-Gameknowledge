> 适用版本：C++17。前置知识：DFS、邻接表。什么时候需要学：题目要求"一笔画"——每条边恰好走一次；或者能把问题转成"每种转移恰好用一次"的序列，比如拼接字符串、安排行程、De Bruijn 序列。

## 要点

- **欧拉路径**：经过图中每条边恰好一次的路径。起点和终点相同时叫**欧拉回路**。点可以重复经过。
- 存在条件只看度数和连通性：
  - 无向图回路：所有点度数为偶数。无向图路径：恰有 0 或 2 个奇度点，有 2 个时必须从其中一个出发。
  - 有向图回路：所有点入度等于出度。有向图路径：要么回路，要么恰有一个点出度比入度大 1（起点）、恰有一个点入度比出度大 1（终点），其余点入度等于出度。
  - 另外所有**有边的点**必须互相连通（有向图看弱连通即可，结合度数条件就够用）。
- **Hierholzer 算法**：DFS 时一路沿未用的边走到走不动，回溯时才把点放进答案，最后把答案**反转**。复杂度 O(n + m)。
- 把邻接表按编号排序，同一套代码得到**字典序最小**的欧拉路径。

## 判定条件

欧拉路径的每个"中间点"都是"进来一次、出去一次"，所以无向图里除起点和终点外度数是偶数；起点多出一条出边，终点多出一条入边，度数就是奇数。起点等于终点时，所有点都是偶数。有向图把"度数"换成"入度和出度的差"。

![四种情形的判定条件：无向与有向，回路与路径](/qmx-Gameknowledge/assets/algo/c5-10-conditions.svg)

注意度数条件只保证"每个点可以配对进出"，不保证所有边在同一个连通块里。比如两个不相连的三角形，所有点度数都是 2，却没有一笔画的方式。所以算法最后要检查走过的边数是不是等于 m。

## Hierholzer 算法

直接从起点一路走，可能走进死胡同：已经回到起点、没有未用的边了，但图里还有别的边没走。Hierholzer 的做法是：

1. 从起点出发，每次沿一条未使用的边走，直到走不动为止。因为度数条件成立，走不动时一定停在起点（回路）或终点（路径）。
2. 回溯时，如果某个点还有未用的边，就从这个点再走一个圈，把这个圈**接到原来的路径中间**。
3. 具体实现不需要显式拼接：每个点在**所有边都走完之后**才压入答案栈。最后栈里的顺序是反的，翻转就是欧拉路径。

![Hierholzer 的过程：先走 1→2→3→1，回溯到 3 时发现还有未用的边，接上 3→4→5→3](/qmx-Gameknowledge/assets/algo/c5-10-hierholzer.svg)

这张图的例子有两个共用点 3 的三角形。从 1 出发，字典序最小的走法先走 1→2→3→1，到 1 时没有未用的边，1 先入栈。回溯到 3，3 还有边 3-4 没走，于是再走 3→4→5→3，圈走完，3、5、4 依次入栈，然后 3、2、1 入栈。入栈序列是 `1 3 5 4 3 2 1`，反转得到 `1 2 3 4 5 3 1`。

为什么对：一个点被压入栈的时刻，是它所有出边都被消耗完之后。在栈里，位于它下面的点（更早压入的）是"回溯途中还没处理完"的，位于它上面的点是它之后接上的圈。这个顺序保证了后一段圈的起点和终点都是同一个点（回路时）或终点（路径时），所以拼接后每条边恰好出现一次。

## 模板

下面的程序同时处理无向和有向图。输入第一行 `type n m`，`type = 1` 表示无向，`2` 表示有向，接着 m 条边。输出字典序最小的欧拉路径，不存在输出 `No`。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
vector<pair<int, int>> g[N];     // {邻点, 边编号}
bool used[N * 2];
int ptr_[N];                     // 当前弧：每个点下一条要尝试的边
vector<int> path;

void dfs(int u) {                // Hierholzer：走到走不动再回溯，回溯顺序倒过来就是路径
    while (ptr_[u] < (int)g[u].size()) {
        auto [v, id] = g[u][ptr_[u]++];
        if (used[id]) continue;  // 无向边的另一端已经走过
        used[id] = true;
        dfs(v);
    }
    path.push_back(u);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int type, n, m;
    cin >> type >> n >> m;
    vector<int> deg(n + 1, 0), in(n + 1, 0), out(n + 1, 0);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back({v, i});
        out[u]++; in[v]++;
        if (type == 1) {
            g[v].push_back({u, i});     // 无向边：两个方向共用一个编号
            deg[u]++; deg[v]++;
        }
    }
    for (int i = 1; i <= n; i++) sort(g[i].begin(), g[i].end());   // 字典序最小

    int start = -1;
    if (type == 1) {
        int odd = 0;
        for (int i = 1; i <= n; i++) if (deg[i] % 2) { odd++; if (start < 0) start = i; }
        if (odd != 0 && odd != 2) { cout << "No\n"; return 0; }
    } else {
        int s_cnt = 0, t_cnt = 0;
        for (int i = 1; i <= n; i++) {
            if (out[i] - in[i] == 1) { s_cnt++; start = i; }
            else if (in[i] - out[i] == 1) t_cnt++;
            else if (in[i] != out[i]) { cout << "No\n"; return 0; }
        }
        if (!((s_cnt == 0 && t_cnt == 0) || (s_cnt == 1 && t_cnt == 1))) { cout << "No\n"; return 0; }
    }
    if (start < 0) {                    // 回路：从编号最小且有边的点出发
        for (int i = 1; i <= n; i++) if (!g[i].empty()) { start = i; break; }
    }
    if (start < 0) { cout << "No\n"; return 0; }   // 没有边
    dfs(start);
    if ((int)path.size() != m + 1) { cout << "No\n"; return 0; }  // 边没走完：图不连通
    reverse(path.begin(), path.end());
    for (int i = 0; i <= m; i++) cout << path[i] << (i == m ? '\n' : ' ');
    return 0;
}
```

对图中的例子（`1 5 6`，边 1-2、2-3、3-1、3-4、4-5、5-3）输出 `1 2 3 4 5 3 1`，与手动回溯得到的结果一致。

几个实现细节：

- `ptr_[u]` 是每个点的当前弧。没有它，同一个点每次回来都要从头扫邻接表，退化成 O(m²)。
- 无向图两个方向的边要共用同一个编号，用 `used[id]` 保证一条边只用一次。有向图每条边只存一个方向，`used` 实际不起作用，但保留不影响正确性。
- 有向图选起点时优先选"出度比入度大 1"的点，没有就是回路，从任意有边的点开始。
- 递归深度可达 m，边数在 10^5 以上时要留意栈空间，必要时改成显式栈。
- 程序对 5 个点、7 条边以内的随机图与枚举所有欧拉路径的暴力解对拍，既测了存在的情形，也测了不存在的情形。

## 例题

### 例 1：重新安排行程（LeetCode 332）

给一组机票 `[from, to]`，从 `JFK` 出发用完所有机票，返回字典序最小的行程。机票是有向边，要求有向欧拉路径，同时字典序最小。用 `multiset` 存每个机场的出边，自动排序，每次取最小的邻居：

```cpp
class Solution {
    unordered_map<string, multiset<string>> adj;   // multiset 自带排序，取最小的邻居
    vector<string> path;
    void dfs(const string &u) {
        auto &s = adj[u];
        while (!s.empty()) {
            string v = *s.begin();
            s.erase(s.begin());                    // 用掉这张票
            dfs(v);
        }
        path.push_back(u);                         // 走不动了再入栈
    }
public:
    vector<string> findItinerary(vector<vector<string>> &tickets) {
        for (auto &t : tickets) adj[t[0]].insert(t[1]);
        dfs("JFK");
        reverse(path.begin(), path.end());
        return path;
    }
};
```

用题目的第二个示例 `[JFK,SFO] [JFK,ATL] [SFO,ATL] [ATL,JFK] [ATL,SFO]` 运行，得到 `JFK ATL JFK SFO ATL SFO`。程序对随机的小型机票集与枚举所有行程的暴力解对拍，结果一致。

这里没有先判断存不存在，因为题目保证有解。如果不保证，要在最后检查 `path.size() == 机票数 + 1`。

### 例 2：破解保险箱（LeetCode 753）

密码是长度 n、每位取 0 到 k-1 的数字串。输入错误时保险箱只保留最近输入的 n 位做检查，求一个最短的输入串，使所有可能的密码都是它的子串。

建图：点是长度 n-1 的数字串，边是"在点后面再输入一个数字"，从点 `abc` 输入 `d` 得到长度为 4 的串 `abcd`，走到点 `bcd`。这样每条边对应一个长度为 n 的密码，共 k^n 条边。每个点入度和出度都是 k，所以存在欧拉回路，走一圈就把所有密码都试了一遍。这样的串叫 De Bruijn 序列。

```cpp
class Solution {
    unordered_set<string> seen;     // 已经走过的边（长度 n 的串）
    string ans;
    int k;
    void dfs(const string &node) {
        for (int x = 0; x < k; x++) {
            string edge = node + char('0' + x);
            if (seen.count(edge)) continue;
            seen.insert(edge);
            dfs(edge.substr(1));
            ans += char('0' + x);   // 回溯时记录边上的数字
        }
    }
public:
    string crackSafe(int n, int k_) {
        k = k_;
        string start(n - 1, '0');
        dfs(start);
        return ans + start;
    }
};
```

这里回溯时记录边，最后补上起点串，得到的就是（反向的）欧拉回路，结果长度是 k^n + n - 1，是最短的。`n=2, k=2` 时输出 `01100`，四个密码 `00 01 11 10` 都在里面。程序对 n、k 不超过 4 且 k^n 不超过 2000 的组合，验证了结果长度和"所有密码都作为子串出现"。

### 例 3：骑马修栅栏（洛谷 P2731）

无向图，每条边是一段栅栏，求字典序最小的一笔画路径。直接用上面的模板：`type = 1`，邻接表排序，起点选编号最小的奇度点（没有奇度点就选编号最小的点）。

## 常见坑

- 先判存在性再 DFS。度数条件满足但图不连通时，DFS 走完后 `path.size()` 会小于 m + 1，要靠这个检查发现。
- 无向图的边要用编号去重，只看"邻点是否访问过"是错的，欧拉路径允许重复经过点。
- 有重边或自环时，邻接表里同一邻点会出现多次，排序按 `{邻点, 编号}` 即可，不要去重。
- 字典序最小要对**每个点的邻接表**升序排序，并且从最小的起点出发；有向图的起点由出入度差决定，无向图有两个奇度点时选编号小的那个。
- 输出是反转后的序列，忘了反转得到的是倒序。
- 点数很多但边很少时，初始化数组只清空用到的范围。
