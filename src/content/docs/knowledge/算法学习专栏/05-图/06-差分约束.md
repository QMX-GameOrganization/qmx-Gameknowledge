> 适用版本:C++17。前置:5.2 最短路(松弛、Bellman-Ford),5.5 的 SPFA 判负环。**什么时候需要它**:题目给出一组"两个变量之差不超过某个数"的限制,要求一组可行解,或要求某个量的最大、最小值。

## 要点

- 差分约束系统:若干条形如 `x_j - x_i <= c` 的不等式。每条不等式对应图上一条 `i -> j`、权为 `c` 的边。
- 从超级源点出发求最短路,`dist` 就是一组解;如果图里有负环,系统无解。
- 要求"最大解"用最短路,"最小解"把不等式反过来用最长路。
- 只有"两个变量的差"的约束才能用这个方法;出现和、积、三个变量的约束都不行。

## 从不等式到图

最短路有三角不等式:对每条边 `u -> v`(权 `w`),都有

```text
dist[v] <= dist[u] + w
```

把它和差分约束 `x_j <= x_i + c` 对比,形式完全一致。所以:**把每个变量当成一个点,把每条约束 `x_j - x_i <= c` 建成边 `i -> j`,权为 `c`**。在这张图上求出的最短距离 `dist`,自动满足所有约束,就是一组解。

![四条不等式如何变成约束图,以及从超源点出发的最短路给出的解](/qmx-Gameknowledge/assets/algo/c5-06-diff-graph.svg)

约束图不一定连通,有的点从任何点都到不了。为了统一处理,加一个**超级源点 0**,向每个变量连一条权为 0 的边。这相当于加了约束 `x_i <= x_0 + 0`,也就是所有变量都不大于 0。从 0 出发跑最短路,每个点都能被到达。

## 无解:负环

![两条不等式相加得到 0 ≤ -1,对应环权为负](/qmx-Gameknowledge/assets/algo/c5-06-diff-nosol.svg)

如果图里有一个环,把环上所有约束加起来,左边的变量互相抵消,变成 `0 <= 环的总权`。环权为负时,这是矛盾的,所以系统无解。反过来,没有负环时最短路存在,构造出的 `dist` 就是解。

所以:**有解 ⇔ 约束图没有负环**。求解的过程同时完成了判断,用 5.5 的 SPFA(或 Bellman-Ford)即可,遇到负环输出无解。

## 常见转换

| 约束 | 转成 `≤` 形式 | 建边 |
| --- | --- | --- |
| `x_j - x_i <= c` | 本身 | `i -> j`,权 `c` |
| `x_j - x_i >= c` | `x_i - x_j <= -c` | `j -> i`,权 `-c` |
| `x_j - x_i = c` | 两个不等式 | 两条边:`i -> j` 权 `c`,`j -> i` 权 `-c` |
| `x_j - x_i < c`(整数) | `x_j - x_i <= c - 1` | `i -> j`,权 `c - 1` |
| `x_i <= c`(常数) | `x_i - x_0 <= c`,令 `x_0 = 0` | `0 -> i`,权 `c` |
| `x_i >= c`(常数) | `x_0 - x_i <= -c` | `i -> 0`,权 `-c` |

用到常数约束时,`x_0` 代表数值 0,它是约束图里的一个普通点,要和超级源点分开:超级源点向所有点(包括 `x_0`)连权 0 的边做最短路,得到解之后,把每个 `dist[i]` 都减去 `dist[x_0]`,使 `x_0` 的值为 0。由于约束只涉及差,整体平移后仍然满足所有约束。

## 解的性质

最短路给出的解有一个很好的性质:在所有满足"每个 `x_i <= 0`"的解里,它的每个分量都是**最大的**。证明思路是归纳:任何这样的解 `x` 都满足 `x_i <= x_0 + 0 = 0`,并且沿最短路上每条边,`x_j <= x_i + c`,所以 `x_j <= dist[j]`。

这带来一个用法:

- 要求某个量的**最大值**(上界),用最短路。
- 要求某个量的**最小值**(下界),把约束写成 `x_j - x_i >= c`,建边 `i -> j` 权 `c`,求**最长路**。此时图里出现**正环**表示无解。

## 模板

输入格式采用洛谷 P5960:`n` 个变量,`m` 条约束,每行 `a b c` 表示 `x_a - x_b <= c`。有解输出任意一组解,无解输出 `NO`。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// 每条约束写成 x_a - x_b <= c;输出一组解,无解输出 NO
int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<pair<int, ll>>> g(n + 1);
    for (int i = 0; i < m; i++) {
        int a, b;
        ll c;
        cin >> a >> b >> c;
        g[b].push_back({a, c});  // x_a <= x_b + c  对应一条 b -> a、权为 c 的边
    }
    for (int i = 1; i <= n; i++) g[0].push_back({i, 0});  // 超级源点 0:到每个点的边权为 0

    const ll INF = LLONG_MAX / 4;
    vector<ll> dist(n + 1, INF);
    vector<int> len(n + 1, 0);
    vector<bool> inq(n + 1, false);
    queue<int> q;
    dist[0] = 0;
    q.push(0);
    inq[0] = true;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        inq[u] = false;
        for (auto [v, w] : g[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                len[v] = len[u] + 1;
                if (len[v] >= n + 1) {  // 图里一共 n+1 个点
                    cout << "NO\n";
                    return 0;
                }
                if (!inq[v]) {
                    q.push(v);
                    inq[v] = true;
                }
            }
        }
    }
    for (int i = 1; i <= n; i++) cout << dist[i] << " ";
    cout << "\n";
    return 0;
}
```

输入(图中的四条不等式):

```text
3 4
2 1 3
3 2 -2
1 3 0
3 1 4
```

输出:`-2 0 -2`。检查每条:`0-(-2)=2 <= 3`,`-2-0=-2 <= -2`,`-2-(-2)=0 <= 0`,`-2-(-2)=0 <= 4`,全部成立。

无解的例子:

```text
2 2
2 1 -1
1 2 0
```

输出 `NO`(环权 -1 + 0 = -1)。

代码里判负环的写法和 5.5 一样:`len[v] >= n + 1`,因为图里有 n + 1 个点(含超级源点),简单路径最多 n 条边。

## 例题:种树(最小值,求最长路)

洛谷 P1250:有 n 个位置排成一行,每个位置可以种一棵树或不种。给出 h 条要求,第 i 条要求区间 `[b, e]` 内至少种 `t` 棵。求最少种几棵。

设 `s[i]` 为前 i 个位置种的树数(`s[0] = 0`)。要求区间 `[b, e]` 至少 `t` 棵,等价于

```text
s[e] - s[b-1] >= t
```

每个位置最多一棵,所以还有

```text
s[i] - s[i-1] >= 0,  s[i] - s[i-1] <= 1
```

后一个写成 `s[i-1] - s[i] >= -1`。现在所有约束都是 `>=`,求 `s[n]` 的**最小值**,用最长路:`x_j - x_i >= c` 建边 `i -> j`,权 `c`,从 `s[0]` 出发求最长路,`dist[n]` 就是答案。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 种树:n 个位置,每个位置种一棵或不种。h 条要求:区间 [b, e] 内至少 t 棵。求最少种几棵。
// s[i] 为前 i 个位置种的棵数。求最小解 -> 用 >= 约束 + 最长路。
int main() {
    int n, h;
    cin >> n >> h;
    vector<vector<pair<int, int>>> g(n + 1);
    for (int i = 0; i < h; i++) {
        int b, e, t;
        cin >> b >> e >> t;
        g[b - 1].push_back({e, t});  // s[e] - s[b-1] >= t
    }
    for (int i = 1; i <= n; i++) {
        g[i - 1].push_back({i, 0});   // s[i] - s[i-1] >= 0
        g[i].push_back({i - 1, -1});  // s[i-1] - s[i] >= -1,即 s[i] - s[i-1] <= 1
    }
    const int NEG = INT_MIN / 2;
    vector<int> dist(n + 1, NEG), len(n + 1, 0);
    vector<bool> inq(n + 1, false);
    queue<int> q;
    dist[0] = 0;
    q.push(0);
    inq[0] = true;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        inq[u] = false;
        for (auto [v, w] : g[u]) {
            if (dist[u] + w > dist[v]) {  // 最长路:能变大才更新
                dist[v] = dist[u] + w;
                len[v] = len[u] + 1;
                if (len[v] > n) {  // 点数是 n+1,路径边数超过 n 说明有正环
                    cout << -1 << "\n";
                    return 0;
                }
                if (!inq[v]) {
                    q.push(v);
                    inq[v] = true;
                }
            }
        }
    }
    cout << dist[n] << "\n";
    return 0;
}
```

洛谷样例(原题的输入是先写 n,再另起一行写 h,程序用 `cin` 读入,两种换行方式都能处理):

```text
9
4
1 4 2
4 6 2
8 9 2
3 5 2
```

输出 `5`。如果有正环(例如要求某个区间种的棵数超过区间长度),输出 `-1`。

## 复杂度与注意

- 图有 n + 1 个点、m + n 条边(m 条约束加上超级源点的 n 条边),SPFA 和 Bellman-Ford 的最坏复杂度都是 O(nm)。数据较大时,SPFA 可能被卡。
- 约束图如果是**有向无环**的(比如所有约束都只指向更大的编号),可以直接用拓扑序 DP,复杂度 O(n + m)。
- 当约束图里有很多权为 0 的环,可以先用强连通分量(5.7)缩点,再在缩点后的 DAG 上做 DP,这是洛谷 P3275 糖果的标准做法。

## 常见坑

- 方向写反:`x_a - x_b <= c` 对应的边是 `b -> a`,不是 `a -> b`。动手前先写一个小例子验证。
- 判负环的阈值:点数是 n + 1,不是 n。
- 没有常数约束时,最短路给出的是满足 `x_i <= 0` 的最大解。题目带有"`x_i` 至少是某个正数"这类常数约束时,要按上面的方式引入 `x_0` 并平移,否则超级源点那组 `x_i <= 0` 的边会让本来有解的系统被判成无解。
- 严格不等号对整数要转成 `<= c - 1`。
- 并不是所有"变量加起来不超过"的题都能用。只有变量之间的**差**才能表示成边。
- SPFA 可能被卡,面对大数据考虑 Bellman-Ford 之外的转换(拓扑序、缩点)。
