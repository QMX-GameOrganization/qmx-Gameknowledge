> 适用版本：C++17。前置知识：DFS、5.1 拓扑排序（缩点后要在 DAG 上做 DP）。什么时候需要学：题目里出现"有向图里互相可达的一堆点"、"删掉一个点或一条边图会不会断开"，或者图里有环而你想按 DAG 处理时。

## 要点

- **强连通分量（SCC，strongly connected component）**：有向图里最大的一组点，组内任意两点互相可达。每个点恰属于一个 SCC。
- Tarjan 算法给每个点记两个数：`dfn[u]` 是第几个被访问的，`low[u]` 是 u 的子树能通过一条回边摸到的最小 `dfn`。`dfn[u] == low[u]` 说明 u 是所在 SCC 的根，此时把栈弹到 u 为止就得到这个 SCC。
- 缩点：把每个 SCC 缩成一个点，得到的图一定是 DAG。Tarjan 给出的分量编号恰好是逆拓扑序，缩点后的 DP 不用再做拓扑排序。
- 无向图用同一套 `dfn/low`：`low[v] > dfn[u]` 时边 (u,v) 是**桥**；`low[v] >= dfn[u]` 时 u 是**割点**（根要单独判断）。
- 复杂度都是 O(n + m)。

## 强连通分量：dfn 与 low 的含义

DFS 时，一个点的后代能走到的已访问点有三种：树边指向的孩子、指向栈外已完成 SCC 的点、指向栈内的点。只有第三种会让当前点和那个点处在同一个环里。所以：

- 遇到未访问的邻居 v：递归，递归结束后 `low[u] = min(low[u], low[v])`。
- 遇到已访问且**还在栈内**的邻居 v：`low[u] = min(low[u], dfn[v])`。
- 遇到已访问但**已不在栈内**的邻居：它属于一个已经确定的 SCC，什么也不做。

![Tarjan 在一张小图上的执行过程：圆旁是 dfn/low，右侧是八步执行过程](/qmx-Gameknowledge/assets/algo/c5-07-tarjan-trace.svg)

看图中的 `6→4`：4 在栈内，所以 `low[6] = dfn[4] = 4`，回溯时 5 和 4 的 low 也变成 4。回到 4 时 `dfn[4] == low[4]`，4 就是这个 SCC 的根，栈里 4 之上的 6、5 和 4 本身一起弹出。后面的 3 通过 `3→1` 得到 `low = 1`，一路传到 1，同理弹出 3、2、1。**先弹出的分量编号小**，所以这里 {4,5,6} 是分量 1。

为什么 `dfn[u] == low[u]` 就是根？若 u 的子树能摸到比 u 更早的栈内点，u 就在一个更早开始的环里，不是根；摸不到时，栈里在 u 之上的点都只能回到 u 的子树内，它们和 u 互相可达，而且 u 再往上无法和它们成环，所以它们恰好构成一个 SCC。

## 模板：求强连通分量

```cpp
const int N = 100005;
vector<int> g[N];          // 邻接表
int dfn[N], low[N], comp[N];
int stk[N], top_, timer_, scc_cnt;
bool in_stk[N];

void tarjan(int u) {
    dfn[u] = low[u] = ++timer_;
    stk[++top_] = u;
    in_stk[u] = true;
    for (int v : g[u]) {
        if (!dfn[v]) {                       // 树边：先递归，再用孩子的 low 更新
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (in_stk[v]) {              // 回到栈内：用 v 的 dfn 更新
            low[u] = min(low[u], dfn[v]);
        }                                    // 不在栈内的点属于已完成的 SCC，忽略
    }
    if (dfn[u] == low[u]) {                  // u 是这个 SCC 的根
        ++scc_cnt;
        while (true) {
            int v = stk[top_--];
            in_stk[v] = false;
            comp[v] = scc_cnt;
            if (v == u) break;
        }
    }
}
// 调用：for (int i = 1; i <= n; i++) if (!dfn[i]) tarjan(i);
```

注意两点。第一，更新 `low` 用 `dfn[v]` 而不是 `low[v]`，这对求 SCC 不影响结果，但写成 `low[v]` 在求割点时会出错，建议统一写 `dfn[v]`。第二，递归深度可能到 n，n 到 10^6 时要改成手写栈或加大系统栈。

## 缩点

每个 SCC 缩成一个点后，原来的跨分量边 u→v 变成分量之间的边。因为 SCC 是最大的，缩点图里不会再有环，是一张 DAG。

![缩点：左边是两个强连通分量，右边是缩点后的 DAG，点权累加，dp 从编号小的开始](/qmx-Gameknowledge/assets/algo/c5-07-condense.svg)

Tarjan 先弹出的是"出口方向"的分量，所以跨分量边 u→v 一定满足 `comp[u] > comp[v]`。在缩点图上做 DP 时，**按分量编号从小到大**处理，每个点依赖的后继都已经算完，不需要再跑拓扑排序。

## 无向图：割点与桥

**桥**是删掉后连通块数增加的边，**割点**是删掉后（连同它的边）连通块数增加的点。无向图的 DFS 只有树边和回边，没有横叉边，判断条件更简单：

- 树边 (u,v)，v 是 u 的孩子：若 `low[v] > dfn[u]`，v 的子树不经过 (u,v) 就回不到 u 或 u 的祖先，(u,v) 是桥。
- u 不是根：若存在孩子 v 满足 `low[v] >= dfn[u]`，v 的子树最多只能回到 u 本身，删掉 u 后这棵子树就被切开，u 是割点。
- u 是根：只要有至少两个孩子（两棵 DFS 子树），根就是割点。根没有祖先，`low[v] >= dfn[root]` 恒成立，所以必须单独判断。

![桥和割点：圆旁是 dfn/low，3-4 是桥，3 和 4 是割点](/qmx-Gameknowledge/assets/algo/c5-07-bridge-cut.svg)

点 2 的孩子 3 满足 `low[3] = 1 < dfn[2] = 2`，3 的子树能绕回 1，所以 2 不是割点。

```cpp
struct Edge { int to, id; };
vector<Edge> g[N];
int dfn[N], low[N], timer_;
bool is_bridge[N], is_cut[N];     // 边按编号标记，点按编号标记

void dfs(int u, int pe) {          // pe：进入 u 的那条边的编号，根为 -1
    dfn[u] = low[u] = ++timer_;
    int child = 0;
    for (auto [v, id] : g[u]) {
        if (id == pe) continue;    // 不能原路返回；用边号而不是父亲点，才能处理重边
        if (!dfn[v]) {
            dfs(v, id);
            child++;
            low[u] = min(low[u], low[v]);
            if (low[v] > dfn[u]) is_bridge[id] = true;
            if (pe != -1 && low[v] >= dfn[u]) is_cut[u] = true;
        } else {
            low[u] = min(low[u], dfn[v]);
        }
    }
    if (pe == -1 && child >= 2) is_cut[u] = true;   // 根：至少两棵子树才是割点
}
```

"跳过父边"要按**边的编号**跳过，而不是按"邻居是不是父亲"跳过。图里有重边时，父子之间的第二条边是一条真正的回边，它让这两点不再有桥，按点跳过会漏掉它。

## 例题

### 例 1：有向图的最大点权路径（洛谷 P3387 缩点）

有向图，每个点有点权，求一条路径（点和边可以重复经过，权值只算一次）的最大点权和。环里的点可以全部走到，所以先缩点，再在 DAG 上求最长路。

下面是 `main` 的核心部分（片段，接在上面的 `tarjan` 模板之后，`g`、`comp`、`scc_cnt` 沿用模板里的定义）：

```cpp
// 读入：n 个点、m 条边，a[i] 是点权；edges 保存原图的边
for (int i = 1; i <= n; i++)
    if (!dfn[i]) tarjan(i);

vector<long long> w(scc_cnt + 1, 0), dp(scc_cnt + 1, 0);
vector<vector<int>> dag(scc_cnt + 1);
for (int i = 1; i <= n; i++) w[comp[i]] += a[i];
for (auto [u, v] : edges)
    if (comp[u] != comp[v]) dag[comp[u]].push_back(comp[v]);

long long ans = 0;
for (int c = 1; c <= scc_cnt; c++) {         // 编号从小到大，后继一定已算完
    long long best = 0;
    for (int d : dag[c]) best = max(best, dp[d]);
    dp[c] = w[c] + best;
    ans = max(ans, dp[c]);
}
```

用图里的小例子（点权 3 2 1 4 5 6，边 1→2、2→3、3→1、3→4、4→5、5→6、6→4）实际运行，输出分量数 2，`comp[1..3] = 2`，`comp[4..6] = 1`，最大点权路径 21，与手算 6 + 15 一致。

### 例 2：谁被所有人喜欢（洛谷 P2341 受欢迎的牛）

a 喜欢 b 是边 a→b，喜欢可以传递，求被所有牛喜欢的牛的数量。缩点后，被所有人喜欢的牛一定在**出度为 0 的分量**里：如果出度为 0 的分量有两个，两边互相不可达，没有牛被所有人喜欢，答案为 0；只有一个时，答案是这个分量的大小。

```cpp
vector<int> out(scc_cnt + 1, 0), sz(scc_cnt + 1, 0);
for (auto [a, b] : edges) if (comp[a] != comp[b]) out[comp[a]]++;
for (int i = 1; i <= n; i++) sz[comp[i]]++;
int sink = 0, ans = 0;
for (int c = 1; c <= scc_cnt; c++)
    if (out[c] == 0) { sink++; ans = sz[c]; }
cout << (sink == 1 ? ans : 0) << "\n";
```

对 `3 3 / 1 2 / 2 1 / 2 3` 输出 1：{1,2} 是一个分量并指向 3，3 单独是出度为 0 的分量。

## 常见坑

- 有向图求 SCC 时，判断"在栈内"必须用 `in_stk`，只看"是否访问过"会把已完成分量里的点混进来。
- 无向图求桥时按边号跳过父边，不要按点跳过，否则重边会被误判成桥。
- 割点的根要单独判断子树个数，不能用 `low[v] >= dfn[u]`。
- 多个连通块时要对每个未访问的点都启动一次 DFS，根的判断对每个连通块各做一次。
- 求割点时 `low` 的回边更新用 `dfn[v]`，写成 `low[v]` 会让结果偏小。
- 递归层数接近 n 时可能栈溢出，n 达到 10^5 到 10^6 要留意。
