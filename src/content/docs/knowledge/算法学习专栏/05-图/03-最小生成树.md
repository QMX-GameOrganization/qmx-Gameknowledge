> 适用版本:C++17。Kruskal 需要并查集(2.3 篇),Prim 需要优先队列,并建议先读 5.2 的 Dijkstra。

## 要点

- 一张 n 个点的**连通**无向图,选出 n - 1 条边把所有点连起来且不成环,得到生成树。边权和最小的叫最小生成树(MST)。
- 最小生成树不一定唯一,但**权和唯一**。
- 两条性质保证贪心正确:**切割性质**说明"选哪条边",**环性质**说明"丢哪条边"。
- **Kruskal**:边按权排序,从小到大,不成环就选,用并查集判环。O(m log m)。
- **Prim**:从一个点出发,每次把离当前树最近的点拉进来。堆优化 O(m log m),矩阵版 O(n²)。

## 两条性质

![切割性质:跨越两部分的最小边必可选;环性质:环中最大边可以丢](/qmx-Gameknowledge/assets/algo/c5-03-cut.svg)

**切割性质**:把点集分成 S 和 V \ S 两个非空部分,所有横跨两部分的边里,权最小的那一条(多条相等时任取一条)一定属于某棵最小生成树。

证明思路(交换法):假设某棵最小生成树 T 不含这条最小的横跨边 e。把 e 加进 T 会形成一个环。这个环要从 S 走到 V \ S,必然还穿过切割一次,即还有另一条横跨边 f。删掉 f 加上 e,仍是生成树,而 `w(e) <= w(f)`,权和不会变大。所以存在包含 e 的最小生成树。

**环性质**:图中任意一个环里,权最大的边(且唯一最大)不会出现在任何最小生成树里。因为环上其他边已经把这个环连通了,去掉最大的一条不损失连通性,还能省下权。

两种算法的每一步选边,都可以用切割性质证明:选出的边是某个切割上最小的横跨边。

## Kruskal

**步骤**:

1. 把所有边按权从小到大排序。
2. 依次看每条边 `(u, v, w)`:如果 u、v 还不在同一个连通块,选这条边,并合并两个块;否则跳过(选了会成环)。
3. 选够 n - 1 条边就结束。如果扫完所有边也没选够,图不连通。

判断"是否在同一个连通块"正是并查集擅长的事。

![Kruskal 在 5 个点 8 条边的图上逐边判断,绿色边被选中](/qmx-Gameknowledge/assets/algo/c5-03-kruskal-steps.svg)

为什么正确:当一条边 `(u, v)` 被检查到时,它前面所有更小的边都已处理。如果 u、v 不连通,把 u 所在的连通块当作 S,这条边就是从 S 出去的最小边(更小的边要么在块内,要么已经被选了),由切割性质它可选。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

struct Edge { int u, v, w; };

vector<int> fa;
int find(int x) {  // 路径压缩(迭代写法)
    while (fa[x] != x) {
        fa[x] = fa[fa[x]];
        x = fa[x];
    }
    return x;
}

int main() {
    int n, m;
    cin >> n >> m;
    vector<Edge> es(m);
    for (auto& e : es) cin >> e.u >> e.v >> e.w;
    sort(es.begin(), es.end(), [](const Edge& a, const Edge& b) { return a.w < b.w; });
    fa.resize(n + 1);
    iota(fa.begin(), fa.end(), 0);
    ll total = 0;
    int used = 0;
    for (auto& e : es) {
        int a = find(e.u), b = find(e.v);
        if (a == b) continue;  // 两端已连通,加这条边会成环
        fa[a] = b;
        total += e.w;
        if (++used == n - 1) break;  // 选够 n-1 条就结束
    }
    if (used < n - 1) cout << "orz\n";  // 图不连通,没有生成树
    else cout << total << "\n";
    return 0;
}
```

输入(图中的 5 个点 8 条边):

```text
5 8
1 3 1
3 5 2
1 5 3
2 4 4
3 4 5
2 3 6
1 2 7
4 5 8
```

输出:`12`,选中的边是权为 1、2、4、5 的四条(1-5 这条权 3 会成环,被跳过)。

**复杂度**:排序 O(m log m),并查集操作近似 O(m α(n)),总体 O(m log m)。适合稀疏图。

## Prim

**步骤**:把点分成"树内"和"树外"两部分。起点先放入树。每一轮,在所有连接树内点和树外点的边里选权最小的一条,把它连着的树外点加进树。重复 n - 1 轮。

这和 Dijkstra 非常像,区别只有一点:Dijkstra 的 `dist[v]` 是起点到 v 的**路径总长**,Prim 的 `key[v]` 只是 v 连到树的**单条边权**。

![Prim 从点 1 出发,绿色圆点是各条边被选中的轮次](/qmx-Gameknowledge/assets/algo/c5-03-prim-steps.svg)

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<pair<int, int>>> g(n + 1);
    for (int i = 0; i < m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        g[u].push_back({v, w});
        g[v].push_back({u, w});
    }
    const int INF = INT_MAX;
    vector<int> key(n + 1, INF);  // key[v]:v 连到当前树的最便宜的边
    vector<bool> inTree(n + 1, false);
    priority_queue<pair<int, int>, vector<pair<int, int>>, greater<>> pq;
    key[1] = 0;
    pq.push({0, 1});
    ll total = 0;
    int cnt = 0;
    while (!pq.empty()) {
        auto [k, u] = pq.top();
        pq.pop();
        if (inTree[u]) continue;  // 过期元素
        inTree[u] = true;
        total += k;
        cnt++;
        for (auto [v, w] : g[u]) {
            if (!inTree[v] && w < key[v]) {  // 注意:比较的是边权 w,不是 dist
                key[v] = w;
                pq.push({w, v});
            }
        }
    }
    if (cnt < n) cout << "orz\n";
    else cout << total << "\n";
    return 0;
}
```

同样的输入输出 `12`。选边顺序和 Kruskal 不同:Prim 依次选 1-3、3-5、3-4、2-4,但权和一样。

### 稠密图的 O(n²) 写法

n 小、m 接近 n² 时,用邻接矩阵,不用堆,每轮线性找 `key` 最小的树外点:

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// 稠密图 Prim:邻接矩阵,O(n^2),不需要堆
int main() {
    int n, m;
    cin >> n >> m;
    const int INF = INT_MAX;
    vector<vector<int>> w(n + 1, vector<int>(n + 1, INF));
    for (int i = 0; i < m; i++) {
        int u, v, c;
        cin >> u >> v >> c;
        w[u][v] = w[v][u] = min(w[u][v], c);  // 重边取最小
    }
    vector<int> key(n + 1, INF);
    vector<bool> inTree(n + 1, false);
    key[1] = 0;
    ll total = 0;
    for (int it = 0; it < n; it++) {
        int u = -1;
        for (int v = 1; v <= n; v++)  // 在树外的点里找 key 最小的
            if (!inTree[v] && (u == -1 || key[v] < key[u])) u = v;
        if (key[u] == INF) {
            cout << "orz\n";  // 剩下的点都连不上树
            return 0;
        }
        inTree[u] = true;
        total += key[u];
        for (int v = 1; v <= n; v++)
            if (!inTree[v] && w[u][v] < key[v]) key[v] = w[u][v];
    }
    cout << total << "\n";
    return 0;
}
```

n = 5000 时,n² = 2.5 × 10^7,可行;堆版本的 m 约为 10^7 级,会慢得多。

### 怎么选

| | Kruskal | Prim(堆) | Prim(矩阵) |
| --- | --- | --- | --- |
| 复杂度 | O(m log m) | O(m log m) | O(n²) |
| 需要的结构 | 边数组加并查集 | 邻接表加堆 | 邻接矩阵 |
| 适合 | 稀疏图,边已成列表 | 一般 | 稠密图 |
| 能处理不连通图 | 能,得到最小生成森林 | 只处理起点所在块 | 同左 |

多数题用 Kruskal 就够了,写法最短。

## 变形

- **最大生成树**:边按权从大到小排序,其余不变。
- **瓶颈生成树**:让生成树里最大的那条边尽量小。最小生成树天然满足这个条件(Kruskal 最后加入的那条边就是最大边)。
- **最小生成森林**:图不连通时,对每个连通块分别求生成树。Kruskal 跑完所有边即可。
- **分成 k 个块**:要把点划分成 k 个连通块且总权最小,Kruskal 在选了 n - k 条边时提前停止。
- **次小生成树**:思路是枚举一条非树边去替换树上的边,需要 LCA(4.5 篇),放在练习的挑战档。

## 例题

### 例 1:模板

洛谷 P3366:无向图,求最小生成树的权和,图不连通输出 `orz`。直接使用 Kruskal 程序。

### 例 2:瓶颈

洛谷 P2330 繁忙的都市:选出尽量少的边使图连通(即生成树),并使其中最长的边尽量短。输出边数和最大边权。

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Edge { int u, v, w; };

vector<int> fa;
int find(int x) {
    while (fa[x] != x) {
        fa[x] = fa[fa[x]];
        x = fa[x];
    }
    return x;
}

// 瓶颈生成树:让生成树里最大的边尽量小。最小生成树天然满足。
int main() {
    int n, m;
    cin >> n >> m;
    vector<Edge> es(m);
    for (auto& e : es) cin >> e.u >> e.v >> e.w;
    sort(es.begin(), es.end(), [](const Edge& a, const Edge& b) { return a.w < b.w; });
    fa.resize(n + 1);
    iota(fa.begin(), fa.end(), 0);
    int used = 0, mx = 0;
    for (auto& e : es) {
        int a = find(e.u), b = find(e.v);
        if (a == b) continue;
        fa[a] = b;
        used++;
        mx = e.w;  // 边按权从小到大加入,最后一条被选中的边最大
    }
    if (used < n - 1) cout << "不连通\n";
    else cout << used << " " << mx << "\n";
    return 0;
}
```

对上面的输入,输出 `4 5`:需要 4 条边,最大边权为 5。输出格式以题面为准。

### 例 3:稠密图

洛谷 P1546 最短网络:n ≤ 100 的邻接矩阵给出完全图,求最小生成树。用上面的 O(n²) Prim 或 Kruskal 都可以。

### 例 4:提前停止

洛谷 P1195 口袋的天空:要连成恰好 k 棵"云",求最小花费。Kruskal 在选到 n - k 条边时停止,如果边用完仍不足,输出无解。

## 常见坑

- 判断连通:选够 n - 1 条边才是生成树,图不连通时不能输出一个部分和。
- 并查集 `find` 要路径压缩,否则退化到 O(n) 一次。
- Prim 堆里比较的是**单条边权**,不要写成 `key[u] + w`(那是 Dijkstra)。
- 重边和自环:Kruskal 自然处理(自环两端同块被跳过)。矩阵版 Prim 里重边要取最小。
- 总权和可能超过 `int`,用 `long long`。
- 排序用的比较函数要严格弱序,写 `a.w < b.w`,不要写 `<=`。
