> 适用版本：C++17。前置知识：5.2 最短路（Dijkstra、Floyd、BFS 求最短路）、优先队列。什么时候需要学：题目问"第二短"、"第 k 短"，或者"图里最短的环有多长"。

## 要点

- **严格次短路**：长度严格大于最短路的所有路径中最短的一条。做法是给每个点记两个值：最短距离 `d1` 和严格次短距离 `d2`，仍然用 Dijkstra。
- **k 短路**：用反图 Dijkstra 得到每个点到终点的最短距离 `h`，再用 A*（`f = g + h`）按 f 从小到大出队；终点第 j 次出队时的 g 就是第 j 短路。每个点最多出队 k 次。
- **最小环**：无向带权图用 Floyd 的"先枚举环上编号最大的点 k，再合并"的过程；无向无权图对每个点做一次 BFS，遇到非树边就闭合出一个环。
- 复杂度：次短路 O(m log n)；k 短路约 O(k·m log)；Floyd 最小环 O(n³)；BFS 最小环 O(n·(n+m))。

## 严格次短路

这里的路径可以重复经过点和边：沿一条边走过去再折返也算。所以无向图里只要起点能到终点，次短路就一定存在，不要求图里有第二条简单路径。有向图没有折返，次短路可能不存在。

每个点记两个值：`d1[v]` 是 1 到 v 的最短距离，`d2[v]` 是严格大于 `d1[v]` 的最短距离。Dijkstra 松弛 `nd = d + w` 时：

1. 若 `nd < d1[v]`：这是新的最短距离，原来的最短距离降级成次短，`d2[v] = d1[v]`，`d1[v] = nd`。
2. 否则若 `d1[v] < nd < d2[v]`：这是新的次短距离，更新 `d2[v]`。
3. 其他情况（`nd` 等于 `d1` 或不比 `d2` 小）丢弃。

两个值更新后都要入堆，因为它们都可能继续向外扩展出更长一点的路。出队时若 `d > d2[u]`，说明这条记录已经没有价值，直接跳过。

![严格次短路：左边是图和最短、次短两条路径，右边是每个点的 (d1, d2) 与更新规则](/qmx-Gameknowledge/assets/algo/c5-12-second.svg)

图里 1 到 4 的最短路是 1-2-4，长度 5；次短路是 1-3-4，长度 6。注意点 1 自己的 `d2` 是 4，来自 1-2-1：先去 2 再回来也是一条合法的路径。这种折返路径恰好让 `d2` 总有定义，也是为什么算法不需要单独考虑"有没有第二条路"。

```cpp
// 无向图，求 1 到 n 的最短路与严格次短路
vector<ll> d1(n + 1, INF), d2(n + 1, INF);           // 最短、严格次短
priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<>> pq;
d1[1] = 0;
pq.push({0, 1});
while (!pq.empty()) {
    auto [d, u] = pq.top(); pq.pop();
    if (d > d2[u]) continue;                         // 比次短还长的状态没有价值
    for (auto [v, w] : g[u]) {
        ll nd = d + w;
        if (nd < d1[v]) {                            // 新最短：旧最短降级为次短
            d2[v] = d1[v];
            d1[v] = nd;
            pq.push({d1[v], v});
        } else if (nd > d1[v] && nd < d2[v]) {       // 严格大于最短，且比现有次短更小
            d2[v] = nd;
            pq.push({d2[v], v});
        }
    }
}
// 答案：d1[n] 和 d2[n]（INF 表示不存在）
```

用图中的例子（`4 4`，边 `1 2 2`、`2 4 3`、`1 3 4`、`3 4 2`）运行，输出 `5 6`。程序对随机小图与"枚举所有长度不超过 80 的路径"的暴力解对拍，结果一致。

如果题目问的是**非严格次短路**（次短路长度可以等于最短路，只要是不同的路径），松弛的第二个分支改成 `nd < d2[v]`，并允许 `nd == d1[v]` 进入 `d2`。区别只在于有没有"严格"，读题时要先确认是哪一种。

## k 短路：A* 搜索

k 短路要求按长度从小到大列出从 s 到 t 的前 k 条路径（可以重复经过点）。直接用没有估价的优先队列搜索也能做，但会展开大量远离终点的状态。A* 的想法是给每个状态一个估价 `f = g + h`：

- `g`：从 s 走到当前点已经花的距离。
- `h`：当前点到 t 的**真实最短距离**，在反图上从 t 跑一次 Dijkstra 得到。

`h` 是真实值（不低估也不高估），所以按 `f` 出队时，到达终点的状态一定是按路径长度递增的顺序出现的。终点第 1 次出队是最短路，第 2 次是次短路，……第 k 次是第 k 短路。每个点最多出队 k 次：超过 k 次的出队不可能再产生前 k 短的路径，丢弃即可。

![k 短路的例子：左边是带 h 值的图，右边是 A* 的出队顺序，终点三次出队得到 3、3、4](/qmx-Gameknowledge/assets/algo/c5-12-kth.svg)

图里的例子：边 1→2 (1)、1→3 (2)、2→4 (3)、3→4 (1)、2→3 (1)。反图 Dijkstra 得到 h：4 是 0，3 是 1，2 是 2，1 是 3。起点 `f = 0 + 3 = 3`。出队顺序是 `(3,0,点1)`、`(3,1,点2)`、`(3,2,点3)`、`(3,2,点3)`，后两次都是点 3，一次来自 1→3，一次来自 1→2→3。它们各自展开出终点 4，于是点 4 以 f=3 出队两次，得到第 1 短和第 2 短都是 3；最后 1→2→4（`g = 4`）出队，第 3 短是 4。三条路径长度依次是 3、3、4，其中 1→3→4 和 1→2→3→4 长度相同，算两条不同的路径。

```cpp
// 有向图 s->t 的前 k 短路径长度（路径允许重复经过点和边，s != t）
vector<ll> h(n + 1, INF);                       // 估价函数：真实的剩余最短距离
{
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<>> pq;
    h[t] = 0;
    pq.push({0, t});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > h[u]) continue;
        for (auto [v, w] : rg[u])               // rg 是反图：原图 u->v 存成 rg[v] 里的 {u, w}
            if (d + w < h[v]) { h[v] = d + w; pq.push({h[v], v}); }
    }
}
vector<ll> ans;
if (h[s] < INF) {
    vector<int> cnt(n + 1, 0);                  // 每个点最多出队 k 次
    // 元素：{g + h, g, u}
    priority_queue<tuple<ll, ll, int>, vector<tuple<ll, ll, int>>, greater<>> pq;
    pq.push({h[s], 0, s});
    while (!pq.empty() && (int)ans.size() < k) {
        auto [f, d, u] = pq.top(); pq.pop();
        if (++cnt[u] > k) continue;
        if (u == t) ans.push_back(d);
        for (auto [v, w] : g[u])
            if (h[v] < INF && cnt[v] < k) pq.push({d + w + h[v], d + w, v});
    }
}
// ans 里是前 k 短（不足 k 条时更少）
```

对 `4 5 1 4 3`，边 `1 2 1`、`1 3 2`、`2 4 3`、`3 4 1`、`2 3 1`，输出 `3 3 4`。程序对随机小图，与"统计恰好长度为 L 的路径条数，再取最小的 k 个"的暴力解对拍，前 k 项一致；路径不足 k 条时输出 -1 补齐。

两点说明。第一，`h[v] == INF` 的点到不了终点，不要入堆。第二，这里的"路径"允许重复经过点，所以只要起点能走到一个包含环的区域再回到终点，k 短路总是存在。要求路径是**简单路径**（不重复点）时，A* 不再适用，需要 Yen 算法或可持久化堆，见下面的挑战题。

复杂度：每个点最多出队 k 次，每次出队扫描它的所有出边，总共 O(k·m) 次入堆，加上堆的 log，约 O(k·m·log(k·m))。k 在几百到几千、m 在 10^5 以内时可行。

## 最小环

**环**指起点终点相同、中间点互不重复的闭合路径，无向图里至少要有 3 个不同的点。最小环就是总权值最小的环。

### Floyd 法（带权，n 在几百以内）

Floyd 的外层循环按 k 从小到大把点加入"可用中转点"。在处理 k 之前，`d[i][j]` 只经过编号小于 k 的中转点。环上编号最大的点设为 k，环上与 k 相邻的两个点设为 i、j，那么这个环就是 `i → … → j`（只经过编号小于 k 的点，长度 `d[i][j]`）加上 `j → k → i` 两条边。所以在更新 `d` 之前，先用 `d[i][j] + w[i][k] + w[k][j]` 更新答案。

![Floyd 求最小环：k=4 时取 i=1、j=3，d[1][3]=4，环长 4+1+1=6](/qmx-Gameknowledge/assets/algo/c5-12-mincycle.svg)

图里最小环是 1-2-3-4-1，长度 6。环上编号最大的是 4，所以在 k=4 这一轮被发现：此时 `d[1][3] = min(5, 2+2) = 4`（对角线边权 5 比走 1-2-3 的 4 更长），加上 `w[1][4] = 1` 和 `w[4][3] = 1`，得 6。

```cpp
// 无向带权图，w[i][j] 是直接边权（没有边为 INF），d 初始等于 w
ll ans = INF;
for (int k = 1; k <= n; k++) {
    // 此时 d[i][j] 只经过编号 < k 的中转点，环上编号最大的点就是 k
    for (int i = 1; i < k; i++)
        for (int j = i + 1; j < k; j++)       // i != j 保证环至少三个点
            if (d[i][j] < INF && w[i][k] < INF && w[k][j] < INF)
                ans = min(ans, d[i][j] + w[i][k] + w[k][j]);
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            if (d[i][k] < INF && d[k][j] < INF)
                d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
}
// ans 为 INF 表示图中无环
```

`i < j < k` 的限制保证了环上三个点互不相同。直接边要取 `w`，不能用 `d`：`d[i][k]` 可能是绕过别的点的路径，会让环重复经过点。输入 `4 5 / 1 2 2 / 2 3 2 / 1 3 5 / 3 4 1 / 4 1 1` 输出 6。程序对 7 个点以内的随机图与枚举所有简单环的暴力解对拍，结果一致。

有向图的最小环更简单：Floyd 结束后，把对角线初始设为 INF，则 `d[i][i]` 就是经过 i 的最短环，取所有 i 的最小值。

### BFS 法（无权，点数更多）

无向无权图（简单图，没有重边和自环）里，对每个点 s 做一次 BFS。遍历时遇到一个已经访问过、且不是父亲的邻居 v，说明 s 出发的 BFS 树上，u 和 v 通过这条非树边闭合出一个环，长度不超过 `dist[u] + dist[v] + 1`。对所有起点取最小值，最小环一定会被某个起点准确找到（起点取在最小环上时，这个上界是精确的）。

```cpp
// 无向无权简单图，点编号 0..n-1
int ans = INT_MAX;
for (int s = 0; s < n; s++) {
    vector<int> dist(n, -1), par(n, -1);
    queue<int> q;
    dist[s] = 0; q.push(s);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : g[u]) {
            if (dist[v] < 0) { dist[v] = dist[u] + 1; par[v] = u; q.push(v); }
            else if (v != par[u])                       // 非树边：闭合出一个环
                ans = min(ans, dist[u] + dist[v] + 1);
        }
    }
}
// ans == INT_MAX 表示无环
```

复杂度 O(n·(n+m))，比 Floyd 的 O(n³) 更适合 n 到几千、边数不大的情形。LeetCode 2608 就是这个模型。对 7 个点以内的随机简单图与暴力枚举环对拍，结果一致。

## 常见坑

- 严格次短路里，等于最短路的长度不能当次短路。第二个分支必须带 `nd > d1[v]`。
- 次短路松弛后两个值都要入堆，否则漏掉由次短值扩展出的更长路径。
- k 短路的 `h` 要用反图 Dijkstra；用原图跑会得到起点到各点的距离，方向反了。
- k 短路的出队次数限制是每个点最多 k 次，不是全局 k 次。
- Floyd 最小环的答案更新必须放在 `d` 被 k 更新**之前**，否则 `d[i][j]` 已经包含 k，环会重复经过 k。
- 带权最小环用的是边权 `w` 而不是 `d` 去连接 k，否则可能得到非简单环。
- BFS 法只适用于简单图，有重边时要按边编号去重，而不是按父亲点。
