> 适用版本:C++17。需要会存图(5.1 篇)和使用 `priority_queue`。

## 要点

- 最短路的所有算法都建立在**松弛**上:如果 `dist[u] + w < dist[v]`,就把 `dist[v]` 改小。各算法只是松弛的顺序不同。
- **Dijkstra**:边权非负时用。每次取出距离最小的点,用它松弛邻居,堆优化后 O((n + m) log n)。
- **Bellman-Ford**:能处理负边权,能发现负环。把所有边松弛 n - 1 轮,O(nm)。
- **Floyd**:求任意两点之间的最短路,O(n³),代码只有三层循环。
- 选择顺序:边权全相等用 BFS;非负用 Dijkstra;有负边用 Bellman-Ford(或 5.5 的 SPFA);要所有点对且 n 不大用 Floyd。

## 问题分类

| 问题 | 条件 | 首选算法 | 复杂度 |
| --- | --- | --- | --- |
| 单源,边权全为 1(或全相等) | 无 | BFS | O(n + m) |
| 单源,边权非负 | 无负边 | Dijkstra(堆) | O(m log m) |
| 单源,有负边 | 可能有负环 | Bellman-Ford | O(nm) |
| 多源(所有点对) | n 约 400 以内 | Floyd | O(n³) |
| 有向无环图 | 任意边权 | 拓扑序 DP(5.1) | O(n + m) |

"最短路"在有负环时没有意义:沿着负环绕一圈就能让距离更小,可以无限缩短。所以有负边的图要先问有没有负环。

## 松弛

设 `dist[v]` 是目前已知的从起点到 v 的最短距离(起点为 0,其他点为无穷大)。对一条边 `u -> v`,权为 `w`,先经过 u 再走这条边,总长度是 `dist[u] + w`。如果它比当前的 `dist[v]` 小,就找到了一条更短的路,更新它。这个动作叫**松弛**(relaxation)。

![松弛成功与失败的两种情形,以及收敛条件](/qmx-Gameknowledge/assets/algo/c5-02-relax.svg)

```cpp
if (dist[u] + w < dist[v]) dist[v] = dist[u] + w;
```

所有边都不能再被松弛时,对每条边都有 `dist[v] <= dist[u] + w`,这就是最短路的三角不等式,此时 `dist` 就是正确答案。三种算法回答的是同一个问题:怎样用尽量少的松弛次数达到这个状态。

两个性质会反复用到:

- **最短路的前缀也是最短路**:如果 s 到 t 的最短路经过 x,那么这条路中从 s 到 x 的一段,也是 s 到 x 的最短路。否则换成更短的一段,整条路会更短。
- **没有负环时,最短路是简单路径**(不重复经过点),所以最多有 n - 1 条边。

## Dijkstra

**想法**:所有边权非负时,假设当前未确定的点里 `dist` 最小的是 u。任何其他方式到达 u 都要先经过某个未确定的点,那些点的距离已经不小于 `dist[u]`,再加上非负的边权,不可能更短。所以 `dist[u]` 已经是最终答案,可以确定它,并用它去松弛邻居。重复 n 次。

用小根堆取"当前距离最小的点"。堆里存 `(距离, 点)`。一个点的距离可能被改多次,每次改都会往堆里插一份新记录,旧记录留在堆里。取出时如果记录里的距离大于当前 `dist`,说明它已经过期,直接跳过。

![Dijkstra 在一张 5 个点的无向图上的逐步执行](/qmx-Gameknowledge/assets/algo/c5-02-dijkstra-steps.svg)

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const ll INF = LLONG_MAX / 4;

int main() {
    int n, m, s;
    cin >> n >> m >> s;
    vector<vector<pair<int, ll>>> g(n + 1);
    for (int i = 0; i < m; i++) {
        int u, v;
        ll w;
        cin >> u >> v >> w;
        g[u].push_back({v, w});  // 有向边;无向图就再加一条反向边
    }
    vector<ll> dist(n + 1, INF);
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<>> pq;  // 小根堆:(距离, 点)
    dist[s] = 0;
    pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();
        if (d > dist[u]) continue;  // 过期的堆元素:u 已经有更短的记录了
        for (auto [v, w] : g[u]) {
            if (dist[u] + w < dist[v]) {  // 松弛
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    for (int i = 1; i <= n; i++) {
        if (dist[i] == INF) cout << "INF ";
        else cout << dist[i] << " ";
    }
    cout << "\n";
    return 0;
}
```

输入(上图的无向图,每条边写成两条有向边,起点为 1):

```text
5 14 1
1 2 2
2 1 2
1 3 5
3 1 5
2 3 1
3 2 1
2 4 4
4 2 4
3 4 1
4 3 1
3 5 6
5 3 6
4 5 2
5 4 2
```

输出:`0 2 3 4 6`。

**复杂度**:每条边最多让一个点入堆一次,堆里最多 m 条记录,每次操作 O(log m),总时间 O(m log m),也写成 O(m log n)。

**为什么不能有负边**:Dijkstra 的证明依赖"确定的点不会再变小"。有负边时,先确定的点之后可能被一条负边改小。这里的写法没有"已确定"标记,发现更短的路就重新入堆,碰巧能在小数据上得到正确结果,但已知存在构造让它的运行时间变成指数级。不要依赖它,有负边就换 Bellman-Ford。

**稠密图**:当 m 接近 n² 时,可以不用堆,每轮线性扫描找最小的未确定点,总复杂度 O(n²),常数更小。写法见 5.3 的稠密图 Prim,两者结构几乎相同。

### 路径还原

在松弛成功时记录 `pre[v] = u`,表示 v 是从 u 走过来的。从终点沿 `pre` 一路回溯到起点,再反转就是路径。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const ll INF = LLONG_MAX / 4;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<pair<int, ll>>> g(n + 1);
    for (int i = 0; i < m; i++) {
        int a, b;
        ll w;
        cin >> a >> b >> w;
        g[a].push_back({b, w});
        g[b].push_back({a, w});  // 无向图
    }
    vector<ll> dist(n + 1, INF);
    vector<int> pre(n + 1, 0);  // pre[v]:最短路上 v 的前一个点
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<>> pq;
    dist[1] = 0;
    pq.push({0, 1});
    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();
        if (d > dist[u]) continue;
        for (auto [v, w] : g[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pre[v] = u;  // 记录是从谁松弛过来的
                pq.push({dist[v], v});
            }
        }
    }
    if (dist[n] == INF) {
        cout << -1 << "\n";
        return 0;
    }
    vector<int> path;
    for (int v = n; v != 0; v = pre[v]) path.push_back(v);  // 从终点沿 pre 倒着走
    reverse(path.begin(), path.end());
    for (int v : path) cout << v << " ";
    cout << "\n";
    return 0;
}
```

输入(无向边只写一次,代码里自己加了两个方向):

```text
5 7
1 2 2
1 3 5
2 3 1
2 4 4
3 4 1
3 5 6
4 5 2
```

输出:`1 2 3 4 5`,总长 2 + 1 + 1 + 2 = 6。

### 最短路计数

如果要统计有多少条不同的最短路,在松弛时分两种情形:找到**更短**的路,条数重置为 `ways[u]`;找到**一样短**的路,条数累加 `ways[u]`。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const ll INF = LLONG_MAX / 4;
const int MOD = 100003;

// 统计从 1 出发到每个点的最短路条数(边权必须为正)
int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<pair<int, ll>>> g(n + 1);
    for (int i = 0; i < m; i++) {
        int u, v;
        ll w;
        cin >> u >> v >> w;
        g[u].push_back({v, w});
        g[v].push_back({u, w});
    }
    vector<ll> dist(n + 1, INF);
    vector<int> ways(n + 1, 0);
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<>> pq;
    dist[1] = 0;
    ways[1] = 1;
    pq.push({0, 1});
    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();
        if (d > dist[u]) continue;
        for (auto [v, w] : g[u]) {
            if (dist[u] + w < dist[v]) {  // 找到更短的路:条数重置为 u 的条数
                dist[v] = dist[u] + w;
                ways[v] = ways[u];
                pq.push({dist[v], v});
            } else if (dist[u] + w == dist[v]) {  // 同样短:条数累加
                ways[v] = (ways[v] + ways[u]) % MOD;
            }
        }
    }
    for (int i = 1; i <= n; i++) cout << ways[i] << "\n";
    return 0;
}
```

输入一个菱形:

```text
4 4
1 2 1
1 3 1
2 4 1
3 4 1
```

输出 `1 1 1 2`:到点 4 有 1-2-4 和 1-3-4 两条最短路。

这个做法要求**边权为正**。如果有权为 0 的边,`ways[u]` 还没算完整时可能已经被用来更新别的点,结果会漏算。

## Bellman-Ford

**想法**:不要求边权非负,方法也很朴素,把所有边都松弛一遍,这样的"一轮"重复进行。

- 第 1 轮之后,所有"最多 1 条边"的最短路都已经正确。
- 第 k 轮之后,所有"最多 k 条边"的最短路都已经正确。
- 没有负环时,最短路最多 n - 1 条边,所以 n - 1 轮后一定收敛。

如果做完 n - 1 轮后,还能松弛成功,说明存在一条边数超过 n - 1 的"最短路",只能是在绕负环。第 n 轮仍有更新,就是发现了从起点可达的负环。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const ll INF = LLONG_MAX / 4;

struct Edge { int u, v; ll w; };

int main() {
    int n, m, s;
    cin >> n >> m >> s;
    vector<Edge> es(m);
    for (auto& e : es) cin >> e.u >> e.v >> e.w;
    vector<ll> dist(n + 1, INF);
    dist[s] = 0;
    bool changed = false;
    for (int round = 1; round <= n; round++) {  // 最多 n-1 轮就应该收敛,第 n 轮用来判负环
        changed = false;
        for (auto& e : es) {
            if (dist[e.u] < INF && dist[e.u] + e.w < dist[e.v]) {
                dist[e.v] = dist[e.u] + e.w;
                changed = true;
            }
        }
        if (!changed) break;  // 一整轮都没更新,提前结束
    }
    if (changed) {
        cout << "存在从 s 可达的负环\n";
        return 0;
    }
    for (int i = 1; i <= n; i++) {
        if (dist[i] == INF) cout << "INF ";
        else cout << dist[i] << " ";
    }
    cout << "\n";
    return 0;
}
```

输入(一个含负环 2→3→4→2 的小图,环权 -1 + -1 + 1 = -1):

```text
4 4 1
1 2 1
2 3 -1
3 4 -1
4 2 1
```

输出:`存在从 s 可达的负环`。如果把最后一条边的权改成 3,环权为 1,没有负环,输出 `0 1 0 -1`。

要点:

- 松弛前检查 `dist[e.u] < INF`。INF 加上负权会变成一个看起来很小的数,不跳过会产生错误的更新。
- 一整轮没有任何更新就可以提前结束,实际常常远小于 n 轮。
- 只有从起点**可达**的负环才会被发现。

### 限制边数的最短路

Bellman-Ford 的"第 k 轮"恰好对应"最多走 k 条边",所以限制边数的题可以直接做 k 轮。注意每一轮要用**上一轮**的结果去松弛,否则一轮里可能连续走多条边:

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const ll INF = LLONG_MAX / 4;

struct Edge { int u, v; ll w; };

// 最多经过 K 个中间站(即最多 K+1 条边)的最便宜路线
int main() {
    int n, m;
    cin >> n >> m;
    vector<Edge> es(m);
    for (auto& e : es) cin >> e.u >> e.v >> e.w;
    int src, dst, K;
    cin >> src >> dst >> K;
    vector<ll> dist(n, INF);
    dist[src] = 0;
    for (int round = 0; round < K + 1; round++) {  // 恰好做 K+1 轮,每轮多走一条边
        vector<ll> nd = dist;                       // 必须用上一轮的结果去松弛,否则一轮可能走多条边
        for (auto& e : es)
            if (dist[e.u] < INF) nd[e.v] = min(nd[e.v], dist[e.u] + e.w);
        dist = nd;
    }
    cout << (dist[dst] >= INF ? -1 : dist[dst]) << "\n";
    return 0;
}
```

输入(LeetCode 787 的样例:从 0 到 3,最多经过 1 个中转站):

```text
4 5
0 1 100
1 2 100
2 0 100
1 3 600
2 3 200
0 3 1
```

注意最后一行 `0 3 1` 是 `src dst K`,不是边。输出 `700`:路线 0→1→3,票价 100 + 600。

## Floyd

**想法**:用动态规划。设 `d[k][i][j]` 为只允许经过编号 ≤ k 的点作中转时,i 到 j 的最短距离。第 k 个点要么不用,要么用:

```text
d[k][i][j] = min(d[k-1][i][j], d[k-1][i][k] + d[k-1][k][j])
```

第一维可以滚掉,得到三层循环。**k 必须是最外层**:这样处理第 k 轮时,`d[i][k]` 和 `d[k][j]` 都只用到编号 < k 的中转点,和公式一致。

![三个点的例子:每轮允许多一个中转点,矩阵中变化的格子被标出](/qmx-Gameknowledge/assets/algo/c5-02-floyd.svg)

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const ll INF = LLONG_MAX / 4;

int main() {
    int n, m, q;
    cin >> n >> m >> q;
    vector<vector<ll>> d(n + 1, vector<ll>(n + 1, INF));
    for (int i = 1; i <= n; i++) d[i][i] = 0;
    for (int i = 0; i < m; i++) {
        int u, v;
        ll w;
        cin >> u >> v >> w;
        d[u][v] = min(d[u][v], w);  // 重边取最小
    }
    for (int k = 1; k <= n; k++)           // 阶段:允许使用的中转点 1..k,k 必须在最外层
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                if (d[i][k] < INF && d[k][j] < INF)
                    d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
    while (q--) {
        int a, b;
        cin >> a >> b;
        if (d[a][b] == INF) cout << "INF\n";
        else cout << d[a][b] << "\n";
    }
    return 0;
}
```

输入(4 个点,5 条边,5 个询问):

```text
4 5 5
1 2 1
2 3 1
3 4 1
1 3 5
2 4 5
1 4
1 3
4 1
2 4
3 3
```

输出依次是 `3`、`2`、`INF`、`2`、`0`。

**复杂度**:时间 O(n³),空间 O(n²)。n 到 400 左右还可以接受。

**其他用途**:

- 有负环时,某个点的 `d[i][i]` 会变成负数,可以用来检测。
- 把 `min`/`+` 换成 `||`/`&&`,就得到**传递闭包**(判断任意两点是否可达)。

## 选哪个

- 无权图:BFS,最简单最快。
- 边权非负,单个起点:Dijkstra。
- 有负边,或要检测负环:Bellman-Ford,数据大时用 5.5 的 SPFA。
- 要所有点对,点数几百:Floyd。
- 边数受限、层数很小的问题:Bellman-Ford 做 k 轮,或者把"已用边数"加进状态(分层图)。

## 常见坑

- INF 的取值:用 `LLONG_MAX / 4` 或 `1e18` 都可以,但在做加法前必须确认两个操作数都小于 INF。直接用 `INT_MAX` 加一个正数会溢出。
- 无向图要存两个方向的边。输入 `u v w`,需要 `g[u]` 和 `g[v]` 各加一条。
- 堆里的元素是 `(距离, 点)`,距离在前。如果写成 `(点, 距离)`,堆就按点编号排序,算法出错。
- 忘记写 `if (d > dist[u]) continue;`,正确性不受影响,但同一个点会被反复处理,可能超时。
- Floyd 的三层循环 k 一定在最外面。
- 重边取最小(`d[u][v] = min(d[u][v], w)`),自环对最短路没用。
- 路径还原时,不可达点的 `pre` 是 0,从终点回溯前先判断是否可达。
