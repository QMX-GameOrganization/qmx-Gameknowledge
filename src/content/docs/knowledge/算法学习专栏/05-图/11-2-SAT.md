> 适用版本：C++17。前置知识：5.7 强连通分量（Tarjan）。什么时候需要学：题目里每个对象只有两种状态（选或不选、左或右、开或关），约束都是"这两个对象的状态不能同时是某种组合"，要求判断是否存在方案并给出一个。

## 要点

- **2-SAT**：有 n 个布尔变量，若干条形如 `(x_i = a) 或 (x_j = b)` 的子句，问有没有一组赋值使所有子句成立。
- 每个变量拆成两个点：`x` 为真和 `x` 为假。一个子句 `(a ∨ b)` 转成两条蕴含边：`¬a → b` 和 `¬b → a`。
- 求蕴含图的强连通分量。若某个变量的"真"点和"假"点在同一个分量里，无解；否则一定有解。
- 构造解：对每个变量，取**拓扑序更靠后**的那个点为真。用 Tarjan 时编号小的分量拓扑序更靠后，所以取 `comp` 编号小的一侧。
- 复杂度 O(n + m)。

## 建模：把子句变成边

先看一个子句，比如 `(x1 ∨ x2)`，意思是"x1 和 x2 至少有一个为真"。反过来说：如果 x1 为假，x2 必须为真；如果 x2 为假，x1 必须为真。这就是两条"如果……那么……"：

- `¬x1 → x2`
- `¬x2 → x1`

一般地，子句 `(a ∨ b)` 对应边 `¬a → b` 和 `¬b → a`，两条边互为"逆否"。图里的点有 2n 个，每个变量两个点，分别表示"这个变量为真"和"这个变量为假"。

![蕴含图：三个子句拆成六条边，橙色和绿色是两个强连通分量](/qmx-Gameknowledge/assets/algo/c5-11-implication.svg)

例子里有三个子句 `(x1 ∨ x2)`、`(¬x1 ∨ x3)`、`(¬x2 ∨ ¬x3)`。它们给出六条边：`¬x1→x2`、`¬x2→x1`、`x1→x3`、`¬x3→¬x1`、`x2→¬x3`、`x3→¬x2`。

常见约束的转换方式：

| 约束 | 等价的子句 |
| --- | --- |
| a 或 b 至少一个为真 | `(a ∨ b)` |
| a 为真则 b 为真（a → b） | `(¬a ∨ b)` |
| a 必须为真 | `(a ∨ a)`，即边 `¬a → a` |
| a、b 不能同时为真 | `(¬a ∨ ¬b)` |
| a 与 b 相等 | `(¬a ∨ b)` 和 `(a ∨ ¬b)` |
| a 与 b 不同 | `(a ∨ b)` 和 `(¬a ∨ ¬b)` |

"最多选一个"这类涉及多个变量的约束，可以拆成两两之间的"不能同时为真"，变量个数大时边数是平方级，要用前缀优化建图，这是下一步的进阶内容。

## 判定与构造

**判定**：若 `x` 与 `¬x` 在同一个强连通分量里，说明 `x` 能推出 `¬x`，`¬x` 也能推出 `x`。无论 x 取真还是假都会矛盾，无解。

![x 与 ¬x 落进同一个分量就无解：两条边首尾相接成环](/qmx-Gameknowledge/assets/algo/c5-11-contradict.svg)

**可行时一定有解**：由对称性（每条边都有对应的逆否边），蕴含图是"斜对称"的，如果没有变量落在同一分量里，下面的构造就一定得到合法解。

**构造**：缩点后是 DAG。对每个变量 x，比较 `x` 和 `¬x` 的拓扑序，取**靠后**的那个为真。

为什么靠后的为真是对的：假设按这个规则赋值后有一条边 `a → b` 被违反，即 `a` 被选为真，`b` 被选为假（于是 `¬b` 被选为真）。用 `topo(·)` 表示拓扑序（越大越靠后），被选为真的点都比它的反面靠后，所以

- `topo(a) > topo(¬a)`，`topo(¬b) > topo(b)`；
- 边 `a → b` 给出 `topo(a) < topo(b)`；
- 它的逆否边 `¬b → ¬a` 也在图里，给出 `topo(¬b) < topo(¬a)`。

连起来是 `topo(a) < topo(b) < topo(¬b) < topo(¬a)`，即 `topo(a) < topo(¬a)`，与第一条矛盾。所以不会有边被违反，每个子句都成立。

## 模板

变量 `x_0 … x_{n-1}`。点 `2*i` 表示"x_i 为假"，点 `2*i+1` 表示"x_i 为真"，两者互为反面，取反就是 `^ 1`。输入第一行 `n m`，接着 m 行 `i a j b`，表示子句 `(x_i = a) 或 (x_j = b)`，`i`、`j` 从 1 开始，`a`、`b` 取 0 或 1。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 2000005;
vector<int> g[N];
int dfn[N], low[N], comp[N], stk[N], top_, timer_, scc_cnt;
bool in_stk[N];

void tarjan(int u) {
    dfn[u] = low[u] = ++timer_;
    stk[++top_] = u; in_stk[u] = true;
    for (int v : g[u]) {
        if (!dfn[v]) { tarjan(v); low[u] = min(low[u], low[v]); }
        else if (in_stk[v]) low[u] = min(low[u], dfn[v]);
    }
    if (dfn[u] == low[u]) {
        ++scc_cnt;
        while (true) {
            int v = stk[top_--];
            in_stk[v] = false;
            comp[v] = scc_cnt;
            if (v == u) break;
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    while (m--) {
        int i, a, j, b;
        cin >> i >> a >> j >> b;
        i--; j--;
        // (x_i=a) ∨ (x_j=b)：x_i≠a 则必须 x_j=b；x_j≠b 则必须 x_i=a
        g[2 * i + (a ^ 1)].push_back(2 * j + b);
        g[2 * j + (b ^ 1)].push_back(2 * i + a);
    }
    for (int u = 0; u < 2 * n; u++)
        if (!dfn[u]) tarjan(u);
    for (int i = 0; i < n; i++)
        if (comp[2 * i] == comp[2 * i + 1]) { cout << "IMPOSSIBLE\n"; return 0; }
    cout << "POSSIBLE\n";
    for (int i = 0; i < n; i++) {
        // Tarjan 的编号是逆拓扑序：编号小的更靠后。取靠后的那个为真
        cout << (comp[2 * i + 1] < comp[2 * i] ? 1 : 0) << (i == n - 1 ? '\n' : ' ');
    }
    return 0;
}
```

用图中的三个子句运行，输入

```text
3 3
1 1 2 1
1 0 3 1
2 0 3 0
```

输出 `POSSIBLE` 和 `0 1 0`，即 x1=0、x2=1、x3=0。代回检查：`(x1∨x2)` 有 x2 为真，`(¬x1∨x3)` 有 ¬x1 为真，`(¬x2∨¬x3)` 有 ¬x3 为真，三条全成立。

这个例子里蕴含图有两个强连通分量，`{¬x1, x2, ¬x3}` 编号 1，`{x1, ¬x2, x3}` 编号 2，没有变量的两个点落在同一分量里。取编号小的一侧为真，所以 x1 取假，x2 取真，x3 取假。

两个无解或边界情形：

- `1 2 / 1 1 1 1 / 1 0 1 0`，即 `(x1 ∨ x1)` 和 `(¬x1 ∨ ¬x1)`，输出 `IMPOSSIBLE`。
- `2 2 / 1 1 2 1 / 1 0 2 0`，即 `(x1 ∨ x2)` 和 `(¬x1 ∨ ¬x2)`，输出 `POSSIBLE` 和 `0 1`。

程序对 6 个变量以内的随机子句集与枚举全部 2^n 种赋值的暴力解对拍：判断结果一致，每个可行输出代回都满足所有子句。

## 例题：和平委员会（洛谷 P5782）

n 个党派，每个党派有 2 名代表，从每个党派恰好选一人组成委员会。给出若干对"不能同时入选"的代表，求一个合法委员会。

建模可以更省事：党派 i 的两名代表编号为 `2i` 和 `2i+1`，互为对立面（`^ 1`）。"选 p"就是变量取真，另一名代表就是它的反面，"每个党派恰好选一人"已经被点与反面的配对自动保证了。冲突 `(u, v)` 表示选了 u 就不能选 v，也就是选 u 只能选 v 的同党派伙伴，连边 `u → v^1` 和 `v → u^1`。

```cpp
// 片段：Tarjan 与上面的模板相同，点数是 2n
while (m--) {
    int u, v;
    cin >> u >> v;           // u、v 不能同时被选
    g[u].push_back(v ^ 1);   // 选 u 就不能选 v，只能选 v 的同党派伙伴
    g[v].push_back(u ^ 1);
}
for (int u = 0; u < 2 * n; u++) if (!dfn[u]) tarjan(u);
for (int i = 0; i < n; i++)
    if (comp[2 * i] == comp[2 * i + 1]) { cout << "NIE\n"; return 0; }
for (int p = 0; p < 2 * n; p++)
    if (comp[p] < comp[p ^ 1]) cout << p << "\n";   // 选编号小的一侧
```

这段程序对 6 个党派以内的随机冲突集，与枚举全部 2^n 种选法的暴力解对拍：有解的情形输出的 n 个人覆盖每个党派一次且没有冲突，无解的情形输出 `NIE`。

## 常见坑

- 点数是 2n，数组要开到变量数的两倍以上，边数是子句数的两倍。
- 判无解看的是 `x` 与 `¬x` 是否在同一分量，不是看有没有环。
- 构造解时取 `comp` 编号**小**的一侧为真，这是因为 Tarjan 的编号是逆拓扑序。如果你用的是 Kosaraju，顺序相反，写之前先确认自己的编号方向。
- 把"至多选一个"拆成两两不能同时为真时，边数是平方级，变量多时要换成前缀优化建图。
- 题目变成三个变量一条约束（3-SAT）就是 NP 完全问题，2-SAT 的方法不再适用。
- 递归深度可达 2n，变量数很大时要用显式栈。
