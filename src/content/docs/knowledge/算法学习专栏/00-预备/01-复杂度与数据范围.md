## 要点

- 复杂度描述“输入规模 n 变大时，操作次数怎么增长”，只保留增长最快的一项，忽略常数和低阶项。
- C++ 一秒大约能做 10^8 次简单运算，所以看到 n 就能估出可用的算法量级。
- 数复杂度的办法：嵌套循环相乘，顺序循环相加，每次折半的循环是 log n。
- 空间同样要估：一个 `int` 数组 10^6 个元素约 4 MB。
- 要警惕隐藏的复杂度：`vector` 头部插入、字符串反复拼接、`substr` 复制都不是 O(1)。

## 什么是 O(·)

设一段代码执行的基本操作数是 f(n)。如果存在常数 c，使得 n 足够大时 f(n) ≤ c · g(n)，就记作 f(n) = O(g(n))。例如 3n² + 100n + 7 = O(n²)。

写算法题时只关心最坏情况下的 O，这样才能保证任何数据都不超时。同阶的两个算法常数不同，实际速度可能差几倍，这一点在 1 秒的边界上会起作用。

## 常见的复杂度量级

![n = 10^5 时各复杂度的操作次数，O(n²) 已经远超一秒能完成的 10^8 次](/qmx-Gameknowledge/assets/algo/c0-growth.svg)

从快到慢依次是 O(1)、O(log n)、O(n)、O(n log n)、O(n√n)、O(n²)、O(n³)、O(2^n)、O(n!)。n = 10^5 时，O(n log n) 只要约 1.7×10^6 次操作，O(n²) 却要 10^10 次，差了四千多倍。

## 数循环：三个例子

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n = 1000;
    long long cntA = 0, cntB = 0, cntC = 0;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++) cntA++;          // 嵌套循环相乘：n * n
    for (int i = 1; i <= n; i++)
        for (int j = i; j <= n; j += i) cntB++;      // 内层执行 n/i 次
    for (int x = n; x > 1; x /= 2) cntC++;           // 每次折半
    printf("A=%lld B=%lld C=%lld\n", cntA, cntB, cntC);
    return 0;
}
```

输出：`A=1000000 B=7069 C=9`。

- A 是 n² = 10^6。
- B 的次数是 n/1 + n/2 + … + n/n，也就是 n 乘以调和级数，约为 n ln n。n = 1000 时是 7069，所以这种“步长随 i 增大”的双层循环是 O(n log n)，筛法里很常见。
- C 的次数是 ⌊log₂ 1000⌋ = 9，所以 O(log n)。

递归的复杂度怎么数，放到 0.2 篇。

## 由数据范围反推算法

![不同 n 对应的可用复杂度量级，从全排列到数学公式](/qmx-Gameknowledge/assets/algo/c0-range-table.svg)

做题时先读数据范围，再选算法。例如 n ≤ 10^5 时，O(n²) 一定超时，需要排序、二分、双指针、线段树这一类 O(n log n) 的做法。

几点修正：

- 表中是量级参考，不是硬规则。常数大的操作（`map`、`set`、`string` 比较、取模）会让可用的 n 变小，常数小的循环（连续访问数组）可以多跑几倍。
- 多组数据时，总数据量才是 n。如果有 T 组、每组 n，要看 T·n 是否在范围内。
- 时间限制不是 1 秒时，按比例调整。

## 空间复杂度

内存限制常见 256 MB。一个 `int` 占 4 字节，所以 `int a[10000000]`（10^7 个）是 40 MB，`long long` 的二维数组 `dp[5000][5000]` 是 200 MB，已经接近上限。开数组前先算一遍。

递归深度也占栈空间。深度 10^5 的递归在多数评测机上可能栈溢出，需要改成迭代或手动用栈（见 0.2）。

## 例题

### 例 1：判断素数，O(n) 与 O(√n)

n 最大到 10^9 时，从 2 枚举到 n−1 太慢。因子成对出现，若 n 有因子 d，则 n/d 也是因子，其中至少有一个不超过 √n，所以只需枚举到 √n。

```cpp
#include <bits/stdc++.h>
using namespace std;
bool slow(long long n) { if (n < 2) return false; for (long long d = 2; d < n; d++) if (n % d == 0) return false; return true; }
bool fast(long long n) { if (n < 2) return false; for (long long d = 2; d * d <= n; d++) if (n % d == 0) return false; return true; }
int main() {
    long long p = 1000000007;            // 一个素数
    printf("%d %d\n", (int)slow(p), (int)fast(p));
}
```

输出 `1 1`，两种写法结果一致。我在一台普通机器上测得 `slow` 约 1.4 秒，`fast` 约 0.04 毫秒，具体数值随机器不同，量级差距是稳定的。

### 例 2：两数之和，三种写法

在数组里找两个下标，使它们的值之和等于 target。

```cpp
#include <bits/stdc++.h>
using namespace std;
vector<int> bruteForce(const vector<int>& a, int target) {   // O(n^2)
    int n = a.size();
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)
            if (a[i] + a[j] == target) return {i, j};
    return {};
}
vector<int> twoPointers(const vector<int>& a, int target) {  // O(n log n)：排序下标 + 双指针
    int n = a.size();
    vector<int> id(n);
    iota(id.begin(), id.end(), 0);
    sort(id.begin(), id.end(), [&](int x, int y) { return a[x] < a[y]; });
    int l = 0, r = n - 1;
    while (l < r) {
        int s = a[id[l]] + a[id[r]];
        if (s == target) return {min(id[l], id[r]), max(id[l], id[r])};
        if (s < target) l++; else r--;
    }
    return {};
}
vector<int> hashed(const vector<int>& a, int target) {        // 期望 O(n)：哈希表
    unordered_map<int, int> pos;
    for (int i = 0; i < (int)a.size(); i++) {
        auto it = pos.find(target - a[i]);
        if (it != pos.end()) return {it->second, i};
        pos[a[i]] = i;
    }
    return {};
}
int main() {
    vector<int> a = {2, 7, 11, 15, 3, 6};
    for (auto f : {bruteForce, twoPointers, hashed}) {
        auto r = f(a, 9);
        printf("%d %d\n", r[0], r[1]);
    }
}
```

三行输出都是 `0 1`。n = 10^5 时，第一种约 5×10^9 次比较会超时，后两种都能通过。哈希表的 O(n) 是期望复杂度，最坏情况（大量冲突）会退化，竞赛里还可能被专门构造的数据卡。

## 常见坑

- 用 `int` 统计 n² 次的计数或求和，n = 10^5 时已溢出，改用 `long long`。
- `vector::insert(begin(), x)`、`erase(begin())` 是 O(n)，在循环里使用会变成 O(n²)。
- `s = s + "x"` 每次复制整个字符串，循环里用 `s += "x"`。
- 把 `string` 或 `vector` 按值传参会复制一份，数据大时用 `const &`。
- 只看单个测试的运行时间，不看最坏数据：快排遇到有序数组、哈希遇到冲突数据都会变慢。
