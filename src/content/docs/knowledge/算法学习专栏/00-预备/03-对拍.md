> 适用版本：C++17。以后每章写完算法，都建议用对拍验证一遍。

## 要点

- 对拍需要三个程序：数据生成器 `gen`、你的解法 `sol`、暴力解法 `brute`，再加一个反复运行并比较输出的脚本。
- 暴力解法追求“显然正确”，不在乎速度，通常直接按题意枚举。
- 数据要小（n 在 10 以内、数值范围也小），这样出错时的反例容易手算。
- 用循环编号做随机种子，出错后可以复现同一组数据。
- 对拍通过只说明没发现错误，并不是证明；数据覆盖不到的情况仍可能有 bug。

## 一个完整例子：最大子段和

题目：给定整数数组，求和最大的非空连续子数组。一个常见的 O(n) 写法是维护“以当前位置结尾的最大和”，我们故意写出一个有 bug 的版本，看对拍怎么抓到它。

**生成器 `gen.cpp`**：用命令行参数当种子。

```cpp
#include <bits/stdc++.h>
using namespace std;
int main(int argc, char* argv[]) {
    unsigned seed = argc > 1 ? atoi(argv[1]) : 1;   // 用编号做种子，保证可复现
    mt19937 rng(seed);
    int n = rng() % 8 + 1;                           // 数据小，出错时方便手算
    printf("%d\n", n);
    for (int i = 0; i < n; i++) printf("%d ", (int)(rng() % 21) - 10);
    printf("\n");
}
```

**暴力解 `brute.cpp`**：枚举所有区间，O(n²)。

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (auto& x : a) cin >> x;
    int best = INT_MIN;
    for (int l = 0; l < n; l++) {
        int s = 0;
        for (int r = l; r < n; r++) {      // 枚举所有区间 [l, r]
            s += a[r];
            best = max(best, s);
        }
    }
    cout << best << "\n";
}
```

**待测解 `sol.cpp`**（有 bug 的版本）：

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n;
    cin >> n;
    int best = 0, cur = 0;                 // 错误：全是负数时答案应是最大的那个负数
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        cur = max(cur + x, x);
        best = max(best, cur);
    }
    cout << best << "\n";
}
```

**对拍驱动 `check.cpp`**：编译好的三个程序放在同一目录，运行它即可。

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    for (int i = 1; i <= 1000; i++) {
        string g = "./gen " + to_string(i) + " > data.in";
        if (system(g.c_str()) != 0) return puts("gen 运行失败"), 1;
        if (system("./sol < data.in > sol.out") != 0) return printf("第 %d 组：sol 运行出错\n", i), 1;
        if (system("./brute < data.in > brute.out") != 0) return printf("第 %d 组：brute 运行出错\n", i), 1;
        if (system("diff -q sol.out brute.out > /dev/null") != 0) {
            printf("第 %d 组数据结果不一致，data.in 已保留\n", i);
            return 1;
        }
    }
    puts("1000 组全部一致");
}
```

这份驱动在 Linux 下验证过。在 Windows 上把 `./gen` 改成 `gen`，`diff -q ... > /dev/null` 改成 `fc sol.out brute.out > nul` 即可，我没有在 Windows 上运行过，请自行试一次。macOS 或 Linux 也可以用一个等价的 shell 循环：

```bash
for i in $(seq 1 1000); do
    ./gen $i > data.in
    ./sol < data.in > sol.out
    ./brute < data.in > brute.out
    if ! diff -q sol.out brute.out > /dev/null; then echo "第 $i 组不一致"; break; fi
done
```

运行结果：`第 2 组数据结果不一致，data.in 已保留`。打开 `data.in`：

```text
1
-7
```

`sol` 输出 0，`brute` 输出 −7。反例只有一个数，一眼就能看出 `best` 初值设成 0 是错的：全是负数时，答案不能是“空区间的 0”。

## 修复并再次验证

把 `best` 初始化为 `INT_MIN`，并把转移改成“前面的和为负就丢掉”：

```cpp
int best = INT_MIN, cur = 0;
for (int i = 0; i < n; i++) {
    int x;
    cin >> x;
    cur = max(cur, 0) + x;
    best = max(best, cur);
}
```

重新编译后再次运行 `check`，输出 `1000 组全部一致`。

## 怎样让对拍更有用

- **数据范围要小而集中**：n 取 1 到 8，数值取 −10 到 10，才容易撞上边界和重复值。
- **同时造“特殊数据”**：全相同、全负、已排序、n = 1 等，可以在生成器里按编号取模切换模式。
- **有时要换一种暴力**：如果题目的暴力本身难写，可以用另一种思路写两个暴力互相验证。
- **输出不唯一时**：比如题目答案有多种合法方案，不能直接 `diff`，需要写一个检查器（checker）来判断方案是否合法。
- **留着种子**：出错时记下编号 i，用 `./gen i` 可以随时重现。

## 常见坑

- 暴力解本身写错，对拍一直“不一致”或一直“一致”。写完暴力先手算两三个样例。
- 生成器的数据太大，暴力跑不动，也不方便定位。
- 生成器没有变化的种子，每次造出同一组数据。
- 忘了清空输出文件或重新编译，用了旧的可执行文件。
- 随机数用 `rand()`：不同平台的范围不同，推荐 `mt19937`。
