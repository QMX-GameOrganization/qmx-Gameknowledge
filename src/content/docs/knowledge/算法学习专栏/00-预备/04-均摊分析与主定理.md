> 适用版本：C++17。前置：0.1、0.2 篇。什么时候需要学：当你发现某个操作“单次可能很慢，但总体很快”（如 `vector` 扩容、单调栈、并查集），或者要分析自己设计的分治算法时。建议学完第 1 章、第 2 章再回头读。

## 要点

- 均摊复杂度是把 n 次操作的**总代价**除以 n，它不依赖输入是否随机，也不是平均情况。
- 聚合法：直接算总代价。记账法/势能法：给每次操作预付“信用”，用来支付以后的昂贵操作。
- 主定理解决 T(n) = a·T(n/b) + f(n) 这一类递推，核心是比较 f(n) 与 n^(log_b a)。
- 主定理有适用范围：子问题规模必须是 n/b、数量 a 为常数。不满足时回到递归树法。

## 均摊分析

### 例 1：动态数组的 push_back

`vector` 容量满了就申请两倍的新空间并搬运全部元素。连续 push_back 16 次，各次的实际代价如下：

![vector 连续 push_back 16 次的实际代价，扩容那几次特别高，平均不到 2](/qmx-Gameknowledge/assets/algo/c0-amortized.svg)

**聚合法**：n 次操作里，写入是 n 次，扩容时搬运的元素数是 1 + 2 + 4 + … + 2^k，不超过 2n（等比数列和小于最后一项的两倍）。总代价 ≤ 3n，所以每次均摊 O(1)。

### 例 2：二进制计数器自增

对一个 k 位二进制数连续加 1，一次自增可能翻转很多位（如 0111 → 1000 翻转 4 位），但**第 i 位每 2^i 次才翻转一次**。n 次自增总翻转位数小于 2n，均摊每次不超过 2 位。

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    // 动态数组：容量不够就翻倍，统计元素搬运次数
    long long n = 1000000, cap = 1, size = 0, moved = 0;
    for (long long i = 0; i < n; i++) {
        if (size == cap) { moved += size; cap *= 2; }
        size++;
    }
    printf("push %lld 次，搬运 %lld 次，平均每次 %.3f\n", n, moved, (double)(n + moved) / n);

    // 二进制计数器：每次加 1，统计翻转的位数
    unsigned long long x = 0, flips = 0;
    for (long long i = 0; i < n; i++) {
        unsigned long long y = x ^ (x + 1);      // 变化的位
        flips += __builtin_popcountll(y);
        x++;
    }
    printf("自增 %lld 次，翻转 %llu 位，平均每次 %.3f\n", n, flips, (double)flips / n);
}
```

输出：

```text
push 1000000 次，搬运 1048575 次，平均每次 2.049
自增 1000000 次，翻转 1999993 位，平均每次 2.000
```

### 势能法

给数据结构的状态定义一个势能 Φ，均摊代价 = 实际代价 + ΔΦ。选择 Φ 使得昂贵操作会大幅降低势能，把“欠账”还掉。

- 二进制计数器：Φ = 当前 1 的个数。一次自增把末尾 t 个 1 变成 0，再把一个 0 变成 1：实际代价 t + 1，Φ 变化 −t + 1，均摊代价 = (t + 1) + (−t + 1) = 2。
- 单调栈：Φ = 栈内元素个数。入栈代价 1、Φ 加 1；每次弹出代价 1、Φ 减 1，抵消。整个序列处理完总代价 ≤ 2n，这就是 2.1 篇里“每个元素最多进出一次”的严谨说法。

均摊分析在整本专栏里会反复出现：并查集的路径压缩、Splay 树、左偏树、双指针都用到它。

## 主定理

对 T(n) = a·T(n/b) + f(n)，其中 a ≥ 1、b > 1，令 c = log_b a（递归树的叶子数是 n^c 量级）：

![主定理的三种情形：叶子占主导、每层一样、根占主导](/qmx-Gameknowledge/assets/algo/c0-master-cases.svg)

| 情形 | 条件 | 结论 |
| --- | --- | --- |
| 1 | f(n) = O(n^(c−ε))，ε > 0 | T(n) = Θ(n^c) |
| 2 | f(n) = Θ(n^c) | T(n) = Θ(n^c · log n) |
| 3 | f(n) = Ω(n^(c+ε))，且 a·f(n/b) ≤ k·f(n)（k < 1） | T(n) = Θ(f(n)) |

使用步骤：先求 c = log_b a，再比较 f(n) 与 n^c。

| 递推式 | a, b, c | 情形 | 结果 |
| --- | --- | --- | --- |
| T(n) = 4T(n/2) + n | 4, 2, 2 | 1，f = n 远小于 n² | Θ(n²) |
| T(n) = 2T(n/2) + n | 2, 2, 1 | 2，f = n 与 n¹ 同阶 | Θ(n log n)（归并排序） |
| T(n) = T(n/2) + 1 | 1, 2, 0 | 2，f = 1 与 n⁰ 同阶 | Θ(log n)（二分） |
| T(n) = T(n/2) + n | 1, 2, 0 | 3，f = n 远大于 n⁰ | Θ(n) |
| T(n) = 8T(n/2) + n² | 8, 2, 3 | 1 | Θ(n³)（朴素矩阵分治） |

## 主定理不能用的情形

- 子问题规模不是 n/b：如 T(n) = T(n−1) + n，用递归树法得 O(n²)。
- 子问题数量不是常数：如 T(n) = n·T(n/2) + 1。
- f(n) 与 n^c 相差不是多项式倍：如 T(n) = 2T(n/2) + n/log n，落在情形 1 与 2 之间的缝里，需要用递归树或 Akra–Bazzi 公式。

## 例题

**线段树建树**：T(n) = 2T(n/2) + O(1)。c = 1，f = 1 = O(n^(1−ε))，是情形 1，T(n) = Θ(n)，建树共 O(n)。

**快速选择的期望复杂度**（1.7 篇）：每次期望把规模缩小一个常数比例，T(n) = T(3n/4) + n 一类，f 远大于 n^0，是情形 3，期望 Θ(n)。

## 常见坑

- 把均摊当成平均情况：均摊保证任意输入下 n 次操作的总代价，平均情况依赖输入分布。
- 均摊 O(1) 的操作单次可能很慢，对实时性要求高的场合（每次必须快速返回）不能依赖均摊。
- 套主定理前没把递推写成标准形式，如漏掉 f(n) 里的常数项或把 a 数错。
