## 要点

- `exgcd(a, b, x, y)` 在求出 `g = gcd(a, b)` 的同时，给出一组整数 `x, y` 满足 `a·x + b·y = g`。
- 模 m 下 a 的逆元存在，当且仅当 `gcd(a, m) = 1`；逆元就是方程 `a·x + m·y = 1` 里的 x。
- 求逆元有三种常用做法：扩展欧几里得（模数不必是质数）、费马小定理（模数是质数）、线性递推（一次求出 1 到 n 全部）。
- 同余方程 `a·x ≡ b (mod m)` 有解当且仅当 `gcd(a, m)` 整除 b，解之间相隔 `m / gcd(a, m)`。

## 为什么需要逆元

取模运算对加、减、乘封闭：`(a + b) mod m`、`(a - b) mod m`、`(a · b) mod m` 都可以分别取模后再算。除法不行：`6 / 2 mod 4` 不能写成 `(6 mod 4) / 2 = 1`，真实答案是 3 mod 4。

解决办法是把"除以 a"改成"乘以 a 的逆元"。逆元（modular inverse）定义为：满足 `a · x ≡ 1 (mod m)` 的整数 x，记作 `a⁻¹`。比如模 7 下 3 的逆元是 5，因为 `3 × 5 = 15 ≡ 1`。

## 裴蜀定理

**裴蜀定理（Bézout）**：对任意整数 a、b，方程 `a·x + b·y = c` 有整数解，当且仅当 `gcd(a, b)` 整除 c。

直观理由：左边 `a·x + b·y` 一定是 g = gcd(a, b) 的倍数，所以 c 不是 g 的倍数时无解。反方向的证明就是下面的扩展欧几里得算法，它直接构造出 `a·x + b·y = g` 的一组解，再把解乘以 `c / g` 即可。

## 扩展欧几里得的推导

辗转相除法依赖 `gcd(a, b) = gcd(b, a mod b)`。假设递归调用已经给出了 x'、y'：

```text
b·x' + (a mod b)·y' = g
```

把 `a mod b` 写成 `a - (a/b)·b`（这里 `a/b` 是整除），代入：

```text
b·x' + (a - (a/b)·b)·y' = g
a·y' + b·(x' - (a/b)·y') = g
```

和 `a·x + b·y = g` 对比，得到回溯公式：

```text
x = y'
y = x' - (a/b)·y'
```

递归边界是 `b = 0`：此时 `gcd = a`，取 `x = 1, y = 0`，因为 `a·1 + 0·0 = a`。

![以 exgcd(240, 46) 为例，先逐层下潜到 b=0，再自底向上用回溯公式算出每层的 x、y，最终得到 240×(-9)+46×47=2](/qmx-Gameknowledge/assets/algo/c8-exgcd-trace.svg)

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// 返回 g = gcd(a, b)，并求出一组 x, y 使 a*x + b*y = g
ll exgcd(ll a, ll b, ll &x, ll &y) {
    if (b == 0) { x = 1; y = 0; return a; }
    ll g = exgcd(b, a % b, y, x);   // 先把 x、y 交换位置传进去
    y -= a / b * x;                 // 回溯：y = x' - (a/b) * y'
    return g;
}

int main() {
    ll x, y;
    ll g = exgcd(240, 46, x, y);
    printf("gcd=%lld x=%lld y=%lld check=%lld\n", g, x, y, 240 * x + 46 * y);
    return 0;
}
```

运行结果：

```text
gcd=2 x=-9 y=47 check=2
```

`g = 2`，`240·(-9) + 46·47 = -2160 + 2162 = 2`，验算无误。

关于代码的几点说明：

- `exgcd(b, a % b, y, x)` 故意把 x、y 的位置交换传入。返回后 `y` 里装的是 x'，`x` 里装的是 y'，所以只需要 `y -= a / b * x` 这一行完成 `y = x' - (a/b)·y'`，`x = y'` 已经由换位置自动完成。
- 复杂度与辗转相除法相同，为 O(log min(a, b))。
- 求出的解满足 `|x| ≤ b`、`|y| ≤ a`，只要 a、b 本身在 `long long` 内就不会溢出。
- 解不唯一。通解为 `x + k·(b/g)`、`y - k·(a/g)`，k 为任意整数。

## 三种求逆元的方法

![三种求逆元方法的条件与复杂度对比：扩展欧几里得适用于任意互质模数，费马小定理要求模数是质数，线性递推一次求出1到n的全部逆元](/qmx-Gameknowledge/assets/algo/c8-inverse-compare.svg)

### 方法一：扩展欧几里得

`a·x ≡ 1 (mod m)` 等价于存在整数 y 使 `a·x + m·y = 1`。调用 `exgcd(a, m, x, y)`，若返回的 g 不是 1 则逆元不存在，否则 `(x mod m + m) mod m` 就是答案。这是最通用的方法，m 不必是质数。

### 方法二：费马小定理

若 p 是质数且 a 不是 p 的倍数，则 `a^(p-1) ≡ 1 (mod p)`。两边同时除以 a（也就是乘上 a 的逆元）：`a^(p-2) ≡ a⁻¹`。所以 `inv_fermat(a, p) = a^(p-2) mod p`，用快速幂 O(log p) 即可。

### 方法三：线性递推

需要一次性得到 `1, 2, …, n` 的全部逆元（n < p，p 是质数）时，用递推。设 `p = k·i + r`，其中 `k = p / i`（整除），`r = p mod i`。则：

```text
k·i + r ≡ 0 (mod p)
两边乘 i⁻¹ · r⁻¹：   k·r⁻¹ + i⁻¹ ≡ 0
所以：               i⁻¹ ≡ -k · r⁻¹ ≡ (p - p/i) · inv[p mod i]
```

由于 `r = p mod i < i`，`inv[r]` 在计算 `inv[i]` 之前已经算好，因此从小到大一次扫描就够，总复杂度 O(n)。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

ll exgcd(ll a, ll b, ll &x, ll &y) {
    if (b == 0) { x = 1; y = 0; return a; }
    ll g = exgcd(b, a % b, y, x);
    y -= a / b * x;
    return g;
}

// 方法一：扩展欧几里得。m 不必是质数，只要 gcd(a, m) = 1；不存在返回 -1
ll inv_exgcd(ll a, ll m) {
    ll x, y;
    if (exgcd(a, m, x, y) != 1) return -1;
    return (x % m + m) % m;
}

ll power(ll a, ll e, ll m) {
    ll r = 1 % m;
    for (a %= m; e > 0; e >>= 1, a = a * a % m)
        if (e & 1) r = r * a % m;
    return r;
}

// 方法二：费马小定理，要求 p 是质数且 a 不是 p 的倍数
ll inv_fermat(ll a, ll p) { return power(a, p - 2, p); }

// 方法三：线性递推，一次求出 1..n 的逆元，要求 p 是质数且 n < p
vector<ll> inv_table(int n, ll p) {
    vector<ll> inv(n + 1);
    inv[1] = 1;
    for (int i = 2; i <= n; i++)
        inv[i] = (p - p / i) * inv[p % i] % p;
    return inv;
}

// 解 a*x ≡ b (mod m)：无解返回 false；有解时 x0 是最小非负解，其余解为 x0 + k*(m/g)
bool solve_congruence(ll a, ll b, ll m, ll &x0, ll &step) {
    ll x, y;
    ll g = exgcd(a, m, x, y);
    if (b % g != 0) return false;
    step = m / g;
    x0 = (x % step + step) % step * ((b / g) % step) % step;
    return true;
}

int main() {
    const ll p = 1000000007;
    printf("3 在模 7 下的逆元: %lld\n", inv_exgcd(3, 7));
    printf("2 在模 1e9+7 下的逆元: %lld %lld\n", inv_exgcd(2, p), inv_fermat(2, p));
    printf("4 在模 8 下的逆元: %lld\n", inv_exgcd(4, 8));
    vector<ll> inv = inv_table(10, 13);
    for (int i = 1; i <= 10; i++) printf("%lld ", inv[i]);
    puts("");
    ll x0, step;
    if (solve_congruence(6, 4, 10, x0, step)) printf("6x≡4 (mod 10): x≡%lld (mod %lld)\n", x0, step);
    if (!solve_congruence(6, 5, 10, x0, step)) puts("6x≡5 (mod 10): 无解");
    return 0;
}
```

运行结果：

```text
3 在模 7 下的逆元: 5
2 在模 1e9+7 下的逆元: 500000004 500000004
4 在模 8 下的逆元: -1
1 7 9 10 8 11 2 5 3 4 
6x≡4 (mod 10): x≡4 (mod 5)
6x≡5 (mod 10): 无解
```

第三行 `4 在模 8 下` 返回 -1：`gcd(4, 8) = 4 ≠ 1`，逆元不存在。`inv_table(10, 13)` 打印的是 1 到 10 在模 13 下的逆元，例如 `2 × 7 = 14 ≡ 1`。

## 解同余方程 ax ≡ b (mod m)

令 `g = gcd(a, m)`。方程等价于 `a·x + m·y = b`，由裴蜀定理：

- `g` 不整除 `b` 时无解。
- 否则两边同除以 g，得到 `(a/g)·x ≡ b/g (mod m/g)`，此时 `a/g` 与 `m/g` 互质，可以直接用逆元求出模 `m/g` 下的唯一解 `x0`。
- 在原模数 m 下，一共有 g 个解：`x0, x0 + m/g, x0 + 2·m/g, …`。

![方程 6x≡4 (mod 10) 把x从0试到9，6x mod 10 在 x=4 与 x=9 时等于4，两个解相隔 5=m/g](/qmx-Gameknowledge/assets/algo/c8-linear-congruence.svg)

上面代码里的 `solve_congruence` 就是这个流程。示例中 `6x ≡ 4 (mod 10)` 得到 `x ≡ 4 (mod 5)`，即 x = 4 与 x = 9；而 `6x ≡ 5 (mod 10)` 无解，因为 `gcd(6, 10) = 2` 不整除 5。

## 例题

### 例 1：二元一次不定方程

求 `a·x + b·y = c` 的最小非负整数 x 和对应的 y。思路：先 `exgcd` 得到 `a·x + b·y = g`，若 `g ∤ c` 无解；否则把解乘上 `c/g`，再把 x 模到 `[0, b/g)` 内即为最小非负解，y 由方程反推。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

ll exgcd(ll a, ll b, ll &x, ll &y) {
    if (b == 0) { x = 1; y = 0; return a; }
    ll g = exgcd(b, a % b, y, x);
    y -= a / b * x;
    return g;
}

// 解 a*x + b*y = c（a, b > 0）：无解返回 false；
// 否则 x0 是最小非负的 x，对应 y0；通解为 x = x0 + k*(b/g)，y = y0 - k*(a/g)
bool diophantine(ll a, ll b, ll c, ll &x0, ll &y0) {
    ll x, y;
    ll g = exgcd(a, b, x, y);
    if (c % g != 0) return false;
    ll step = b / g;
    x0 = (x % step + step) % step * ((c / g) % step) % step;
    y0 = (c - a * x0) / b;
    return true;
}

int main() {
    ll x0, y0;
    if (diophantine(6, 10, 14, x0, y0))
        printf("6x + 10y = 14：最小非负 x = %lld，y = %lld\n", x0, y0);   // x=4, y=-1
    if (!diophantine(6, 10, 15, x0, y0))
        puts("6x + 10y = 15：无解（gcd = 2 不整除 15）");
    return 0;
}
```

运行结果：

```text
6x + 10y = 14：最小非负 x = 4，y = -1
6x + 10y = 15：无解（gcd = 2 不整除 15）
```

验算：`6×4 + 10×(-1) = 14`。

### 例 2：青蛙约会

环上周长为 L，两只青蛙起点为 x、y，每次分别跳 m、n 格，问最少跳几次相遇。设跳 t 次，相遇条件是 `x + m·t ≡ y + n·t (mod L)`，整理为同余方程 `(m - n)·t ≡ y - x (mod L)`，直接套用上一节的解法，取最小非负解。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

ll exgcd(ll a, ll b, ll &x, ll &y) {
    if (b == 0) { x = 1; y = 0; return a; }
    ll g = exgcd(b, a % b, y, x);
    y -= a / b * x;
    return g;
}

// 青蛙约会：两只青蛙在周长 L 的环上，起点 x、y，每次跳 m、n，问最少跳几次相遇
// x + m*t ≡ y + n*t (mod L)  →  (m - n)*t ≡ y - x (mod L)
ll frog(ll x, ll y, ll m, ll n, ll L) {
    ll a = ((m - n) % L + L) % L, b = ((y - x) % L + L) % L;
    ll p, q;
    ll g = exgcd(a, L, p, q);
    if (b % g != 0) return -1;
    ll step = L / g;
    return (p % step + step) % step * ((b / g) % step) % step;
}

int main() {
    printf("%lld\n", frog(1, 2, 3, 4, 5));    // 例：求最少次数
    printf("%lld\n", frog(1, 2, 4, 2, 6));    // 无解
    return 0;
}
```

运行结果：

```text
4
-1
```

第一行：`(3-4)·t ≡ 2-1 (mod 5)`，即 `4t ≡ 1 (mod 5)`，t = 4。第二行方程为 `2t ≡ 1 (mod 6)`，`gcd(2, 6) = 2` 不整除 1，永远不会相遇。

## 常见坑

- 逆元只在 `gcd(a, m) = 1` 时存在。模数是合数时不要用费马小定理。
- `exgcd` 返回的 x 可能是负数，使用前要做 `(x % m + m) % m`。
- 乘法前先模：m 接近 1e18 时 `a·b` 会超出 `long long`，需要 `__int128`（见 8.4 的 `merge`）。
- 线性递推求逆元要求 p 是质数；它依赖 `inv[p mod i]` 的存在。
- `inv[i]` 递推里的 `p / i` 是整数除法，注意 p 的类型，避免 `int` 溢出。
