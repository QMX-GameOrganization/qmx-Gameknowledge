> 适用版本：C++17。前置：8.3 组合计数；Burnside 部分用到 8.1 的 gcd。什么时候需要学：计数题里出现"至少满足某些条件"、"不能越过某条线"、"旋转或翻转后算同一种"这类描述时。

## 要点

- **容斥原理**：`|A₁ ∪ … ∪ Aₙ| = Σ|Aᵢ| - Σ|Aᵢ∩Aⱼ| + Σ|Aᵢ∩Aⱼ∩Aₖ| - …`，奇数个集合的交加，偶数个减。
- **卡特兰数** `Cₙ = C(2n, n) / (n+1)`：出栈序列、合法括号序列、二叉树形态、凸多边形三角剖分都是它。
- **Burnside 引理**：本质不同的方案数 = 所有"对称操作"下不动点个数的平均值。
- 三者可以和 8.3 的阶乘逆元结合，处理取模下的大数计数。

## 容斥原理

### 公式与直觉

两个集合：`|A ∪ B| = |A| + |B| - |A ∩ B|`，因为交集部分被 `|A|` 和 `|B|` 各数了一次，减掉一次。三个集合：

```text
|A ∪ B ∪ C| = |A| + |B| + |C| - |A∩B| - |A∩C| - |B∩C| + |A∩B∩C|
```

一般地，对 n 个集合，枚举 `2ⁿ - 1` 个非空子集，大小为 k 的子集交集前面的符号是 `(-1)^(k+1)`。

### 例：1 到 30 中与 30 互质的数

30 = 2·3·5。设 A、B、C 分别是 2、3、5 的倍数。"与 30 互质" 就是不在 A∪B∪C 里。

![三个圆分别表示2、3、5的倍数：只属于A的8个，只属于B的4个，只属于C的2个，A与B重叠4个，A与C重叠2个，B与C重叠1个，三者共有1个，总共22个；圈外的8个就是与30互质的数](/qmx-Gameknowledge/assets/algo/c8-inclusion-venn.svg)

`|A| = 15`，`|B| = 10`，`|C| = 6`，`|A∩B| = 5`（6 的倍数），`|A∩C| = 3`，`|B∩C| = 2`，`|A∩B∩C| = 1`。所以 `|A∪B∪C| = 15 + 10 + 6 - 5 - 3 - 2 + 1 = 22`，互质的有 `30 - 22 = 8` 个：1, 7, 11, 13, 17, 19, 23, 29。

这就是 φ(30) = 8，与 8.5 公式 `30·(1/2)(2/3)(4/5) = 8` 一致。

### 例：错位排列的另一个公式

设"第 i 个数在原位"为性质 Pᵢ。至少 k 个数在原位的排列数为 `C(n, k)·(n-k)!`（选出 k 个固定，其余随意排）。由容斥：

```text
D(n) = Σ_{k=0}^{n} (-1)^k · C(n, k) · (n-k)! = Σ_{k=0}^{n} (-1)^k · n!/k!
```

代码里 `derangement_ie` 用的是后一个形式，与 8.3 的递推结果一致（`D(5) = 44`，`D(8) = 14833`）。

## 卡特兰数

### 定义与通项

卡特兰数 `C₀, C₁, C₂, … = 1, 1, 2, 5, 14, 42, 132, …`，满足

```text
Cₙ = C(2n, n) / (n + 1) = C(2n, n) - C(2n, n+1)
递推：C_{n+1} = Σ_{i=0}^{n} Cᵢ · C_{n-i}      （C₀ = 1）
```

典型意义（含 n 对括号/n 个节点时的方案数）：

- 由 n 对括号组成的合法括号序列。
- 进栈顺序固定为 1 到 n 的合法出栈序列个数。
- n 个节点的不同形态的二叉树。
- n+2 边形的三角剖分数。

### 用网格路径推导（反射法）

把括号序列看作从 (0,0) 走到 (n,n)，"(" 是向右走一步，")" 是向上走一步。合法序列要求任何前缀里 "(" 的个数不少于 ")"，即路径始终不越过直线 `y = x`。

- 总路径数（不加限制）：`C(2n, n)`。
- 非法路径：它们会碰到直线 `y = x + 1`。把路径从第一次碰到该直线之后的部分沿这条直线对称，终点 (n,n) 变成 (n-1, n+1)，反过来也能还原。这是一一对应，所以非法路径数就是从 (0,0) 走到 (n-1, n+1) 的路径数 `C(2n, n-1)`。

所以 `Cₙ = C(2n, n) - C(2n, n-1)`。再化简：`C(2n, n-1) = C(2n, n)·n/(n+1)`，得 `Cₙ = C(2n, n)/(n+1)`。

![左图：n=3 时合法路径 RRURUU 始终不越过对角线；右图：非法路径 RUURRU 碰到直线 y=x+1，把碰线后的剩余部分沿这条线对称，终点从 (3,3) 变成 (2,4)，所以非法路径共 C(6,2)=15 条](/qmx-Gameknowledge/assets/algo/c8-catalan-paths.svg)

n = 3 时：`C(6,3) - C(6,2) = 20 - 15 = 5`。

### 递推式的含义

以括号序列为例，第一个 "(" 一定和某个 ")" 匹配，设它们之间包含 i 对括号，其后包含 `n - 1 - i` 对。两部分都是合法序列，数目相乘，再对 i 求和，就是递推式。

## Burnside 引理

### 问题

n 个珠子穿成项链，每颗珠子有 k 种颜色。旋转后相同的算同一种，问有多少种本质不同的项链。

直接去重很困难。Burnside 引理说：设群 G 是所有"对称操作"（这里是 n 种旋转），则

```text
本质不同的方案数 = (1 / |G|) · Σ_{g ∈ G} (在 g 作用下保持不变的方案数)
```

### 项链的不动点数

旋转 i 步（0 ≤ i < n），珠子位置分成 `gcd(i, n)` 个循环，每个循环内的珠子颜色必须相同才能在旋转后不变，所以不动点数是 `k^gcd(i, n)`。

```text
项链数 = (1/n) · Σ_{i=0}^{n-1} k^{gcd(i, n)}
```

n = 4、k = 2 的例子：

![4颗珠子的四种旋转：旋转0步有4个循环，不动点2的4次方等于16；旋转1步1个循环，不动点2；旋转2步2个循环，不动点4；旋转3步1个循环，不动点2；平均值为(16+2+4+2)/4=6](/qmx-Gameknowledge/assets/algo/c8-burnside-necklace.svg)

`(16 + 2 + 4 + 2) / 4 = 6`。

### 手链（旋转加翻转）

允许翻转时，群有 2n 个元素：n 个旋转，n 个翻转。翻转的不动点数：

- n 为奇数：每条对称轴过一个珠子，其余成对，循环数 `(n+1)/2`，共 n 条轴，不动点和 `n · k^((n+1)/2)`。
- n 为偶数：n/2 条轴过两个珠子，循环数 `n/2 + 1`；n/2 条轴过边的中点，循环数 `n/2`。

手链数 = (旋转不动点和 + 翻转不动点和) / (2n)。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// 1) 容斥：[1, n] 中与 m 互质的数的个数
ll count_coprime(ll n, ll m) {
    vector<ll> ps;
    for (ll p = 2; p * p <= m; p++)
        if (m % p == 0) {
            ps.push_back(p);
            while (m % p == 0) m /= p;
        }
    if (m > 1) ps.push_back(m);
    int k = ps.size();
    ll res = 0;
    for (int mask = 0; mask < (1 << k); mask++) {          // 枚举"被哪些质数整除"的子集
        ll prod = 1;
        int bits = 0;
        for (int i = 0; i < k; i++)
            if (mask >> i & 1) prod *= ps[i], bits++;
        res += (bits % 2 ? -1 : 1) * (n / prod);
    }
    return res;
}

// 2) 错位排列的容斥公式：D(n) = sum_{k=0..n} (-1)^k * n!/k!
ll derangement_ie(int n) {
    ll res = 0, fact_n = 1;
    for (int i = 2; i <= n; i++) fact_n *= i;
    ll term = fact_n;                                      // n!/0!
    for (int k = 0; k <= n; k++) {
        res += (k % 2 ? -1 : 1) * term;
        if (k + 1 <= n) term /= (k + 1);                   // n!/(k+1)!
    }
    return res;
}

// 3) 卡特兰数：C_n = C(2n, n) / (n + 1)，递推 C_{n+1} = C_n * 2(2n+1) / (n+2)
vector<ll> catalan(int n) {
    vector<ll> c(n + 1);
    c[0] = 1;
    for (int i = 0; i < n; i++) c[i + 1] = c[i] * 2 * (2 * i + 1) / (i + 2);
    return c;
}

// 4) Burnside：n 个珠子的项链，k 种颜色
ll power(ll a, int e) { ll r = 1; while (e--) r *= a; return r; }

ll necklaces(int n, int k) {                               // 只允许旋转
    ll sum = 0;
    for (int i = 0; i < n; i++) sum += power(k, __gcd(i, n)); // 旋转 i 步，有 gcd(i,n) 个循环
    return sum / n;
}

ll bracelets(int n, int k) {                               // 旋转 + 翻转
    ll rot = 0, refl = 0;
    for (int i = 0; i < n; i++) rot += power(k, __gcd(i, n));
    if (n % 2) refl = n * power(k, (n + 1) / 2);           // 每条对称轴过一颗珠子
    else refl = n / 2 * power(k, n / 2 + 1) + n / 2 * power(k, n / 2);
    return (rot + refl) / (2 * n);
}

int main() {
    printf("1..30 中与 30 互质的个数: %lld\n", count_coprime(30, 30));
    printf("D(5)=%lld  D(8)=%lld\n", derangement_ie(5), derangement_ie(8));
    auto c = catalan(10);
    for (int i = 0; i <= 10; i++) printf("%lld ", c[i]);
    puts("");
    printf("6 颗珠子 3 种颜色：项链 %lld 种，手链 %lld 种\n", necklaces(6, 3), bracelets(6, 3));
    return 0;
}
```

运行结果：

```text
1..30 中与 30 互质的个数: 8
D(5)=44  D(8)=14833
1 1 2 5 14 42 132 429 1430 4862 16796 
6 颗珠子 3 种颜色：项链 130 种，手链 92 种
```

- `1..30` 与 30 互质的有 8 个。
- `D(5) = 44`，`D(8) = 14833`。
- 卡特兰数 `1 1 2 5 14 42 132 429 1430 4862 16796`。
- 6 颗珠子 3 种颜色：项链 130 种，手链 92 种。

程序用暴力验证：`count_coprime` 与逐个 gcd 对拍，`derangement_ie` 与枚举全排列对拍，卡特兰数与枚举括号序列对拍，项链与手链数与"枚举所有染色并取字典序最小代表"对拍（n ≤ 9，k ≤ 3）。

## 例题

### 例 1：出栈序列

进栈顺序固定为 1, 2, …, n，问有多少种不同的出栈序列。答案是卡特兰数 `Cₙ`。n = 3 时共 5 种：123、132、213、321、231。

### 例 2：圆桌染色

用 3 种颜色给 6 个珠子的项链染色，旋转同构算同一种：`necklaces(6, 3) = 130`。若再允许翻转：`bracelets(6, 3) = 92`。

### 例 3：硬币购物（容斥与背包结合）

四种面值硬币各有数量限制，多次询问凑出金额 s 的方案数。先预处理"不限数量"的完全背包，再对每次询问用 16 个子集的容斥减去超出数量限制的方案。这一类 "容斥 + 背包" 的写法值得练习。

## 适用与不适用

容斥适合"集合个数 n 不大（约 20 以内）"的场合，因为要枚举 `2ⁿ` 个子集；n 大时需要找到子集和的结构化求法（如 8.5 的莫比乌斯函数）。Burnside 适合对称群很小的情形；对称群很大时，需要 Pólya 定理按循环节计数。

## 常见坑

- 容斥的符号：子集大小为奇数加、偶数减，别写反；空集那一项代表"全集"。
- 子集乘积溢出：这里的质因数互不相同，乘积不超过 m，不会溢出；但如果容斥的对象是任意的数（要取 lcm），乘积可能超过 `long long`，要在乘积大于 n 时提前剪枝。
- 卡特兰数用 `C(2n,n)/(n+1)` 取模时，除以 `n+1` 必须乘逆元，不能直接整除。
- Burnside 里最后的除法 `/n` 在整数上是精确除法；取模时换成乘 n 的逆元。
- 项链与手链公式里，翻转的两类（过珠子/过边）n 为奇偶不同，不能合并写。
