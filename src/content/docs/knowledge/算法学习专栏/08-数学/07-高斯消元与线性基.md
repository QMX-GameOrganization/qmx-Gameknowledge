> 适用版本：C++17。前置：8.1 的逆元（模意义下的消元要用）。什么时候需要学：题目是多元一次方程组，或者要从一组数里选子集使异或值最大、判断某个数能否被异或凑出。

## 要点

- 高斯消元的核心是三种初等行变换：交换两行、一行乘非零常数、一行加上另一行的倍数。它们不改变方程组的解。
- 先消成上三角，再回代；统计秩可以判断无解、唯一解、无穷多解。复杂度 O(n³)。
- 实数消元要选绝对值最大的主元并用 `eps` 比较；模质数消元用逆元，没有精度问题。
- 异或线性基是"异或意义下的高斯消元"：用 O(63) 的数组维护一组基，支持插入、判断是否可表示、求最大异或和。

## 高斯消元

### 过程

方程组写成增广矩阵（系数加常数列）。第 `col` 列作为"主元列"：

1. 在 `row` 行及以下找该列的主元（非零元素），交换到 `row` 行。
2. 用 `row` 行把其它行这一列消成 0。
3. `row++`，处理下一列。

下图是 `x + y + z = 6`、`y + 2z = 8`、`2x + 5y − z = 9` 的上三角化过程：

![增广矩阵经过两次行变换（R3 减去 2 倍 R1，再减去 3 倍 R2）变成上三角，再从最后一行回代得到 z=3、y=2、x=1](/qmx-Gameknowledge/assets/algo/c8-gauss-steps.svg)

### 三种结果

消元结束后，主元数 `row`（即矩阵的秩）与方程数 n 比较：

- 存在全为 0 的系数行但常数不为 0（`0 = 非零`）：**无解**。
- 没有矛盾，且秩小于未知数个数：**无穷多解**，没有主元的列对应自由元。
- 秩等于未知数个数：**唯一解**。

### 实数版：选最大主元

浮点数做除法时，主元很小会放大误差。每列选**绝对值最大**的行作主元（部分选主元），并用 `eps` 判断是否为 0。

### 模质数版

在模 p 下，把"除以主元"换成"乘主元的逆元"。精确无误差。若方程组在模 p 下有 f 个自由元，则解的个数是 p^f。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const double EPS = 1e-9;

// 实数高斯消元：n 个方程 n 个未知数，a 是 n 行 n+1 列的增广矩阵
// 返回 0：唯一解（存在 a[i][n]）；1：无穷多解；2：无解
int gauss_double(vector<vector<double>> &a, int n) {
    int row = 0;
    for (int col = 0; col < n && row < n; col++) {
        int pivot = row;                                   // 选绝对值最大的做主元，减小误差
        for (int i = row + 1; i < n; i++)
            if (fabs(a[i][col]) > fabs(a[pivot][col])) pivot = i;
        if (fabs(a[pivot][col]) < EPS) continue;           // 这一列没有主元，是自由元
        swap(a[row], a[pivot]);
        for (int i = 0; i < n; i++) {                      // 高斯-约当：把其他行这一列也消成 0
            if (i == row) continue;
            double f = a[i][col] / a[row][col];
            for (int j = col; j <= n; j++) a[i][j] -= f * a[row][j];
        }
        row++;
    }
    for (int i = row; i < n; i++)
        if (fabs(a[i][n]) > EPS) return 2;                 // 出现 0 = 非零
    if (row < n) return 1;
    for (int i = 0; i < n; i++) a[i][n] /= a[i][i];
    return 0;
}

// 模 p 高斯消元（p 为质数）：n 个方程 m 个未知数，a 是 n 行 m+1 列
// 返回自由元个数；无解返回 -1。解的个数为 p^自由元个数
ll power(ll a, ll e, ll p) {
    ll r = 1;
    for (a %= p; e; e >>= 1, a = a * a % p)
        if (e & 1) r = r * a % p;
    return r;
}

int gauss_mod(vector<vector<ll>> &a, int n, int m, ll p) {
    int row = 0;
    for (int col = 0; col < m && row < n; col++) {
        int pivot = -1;
        for (int i = row; i < n; i++)
            if (a[i][col] % p != 0) { pivot = i; break; }
        if (pivot < 0) continue;
        swap(a[row], a[pivot]);
        ll inv = power(a[row][col], p - 2, p);
        for (int j = col; j <= m; j++) a[row][j] = a[row][j] * inv % p;   // 主元化为 1
        for (int i = 0; i < n; i++) {
            if (i == row || a[i][col] == 0) continue;
            ll f = a[i][col];
            for (int j = col; j <= m; j++) a[i][j] = ((a[i][j] - f * a[row][j]) % p + p) % p;
        }
        row++;
    }
    for (int i = row; i < n; i++)
        if (a[i][m] != 0) return -1;
    return m - row;
}

int main() {
    // x + y = 3, x - y = 1 → x=2, y=1
    vector<vector<double>> a = {{1, 1, 3}, {1, -1, 1}};
    int st = gauss_double(a, 2);
    printf("状态=%d x=%.3f y=%.3f\n", st, a[0][2], a[1][2]);
    vector<vector<double>> b = {{1, 1, 2}, {2, 2, 4}};
    printf("重复方程: 状态=%d\n", gauss_double(b, 2));
    vector<vector<double>> c = {{1, 1, 2}, {2, 2, 5}};
    printf("矛盾方程: 状态=%d\n", gauss_double(c, 2));
    // 模 7：x + y ≡ 3，2x + 3y ≡ 1
    vector<vector<ll>> d = {{1, 1, 3}, {2, 3, 1}};
    int fr = gauss_mod(d, 2, 2, 7);
    printf("模 7: 自由元=%d x=%lld y=%lld\n", fr, d[0][2], d[1][2]);
    return 0;
}
```

运行结果：

```text
状态=0 x=2.000 y=1.000
重复方程: 状态=1
矛盾方程: 状态=2
模 7: 自由元=0 x=1 y=2
```

- 第一个方程组解为 `x = 2, y = 1`。
- `x + y = 2`、`2x + 2y = 4` 是重复方程，秩 1 小于 2，无穷多解。
- `x + y = 2`、`2x + 2y = 5` 矛盾，无解。
- 模 7 的方程组 `x + y ≡ 3`、`2x + 3y ≡ 1` 解为 `x = 1, y = 2`，代入验算：`1+2 = 3`，`2+6 = 8 ≡ 1`。

代码写成了 Gauss-Jordan 形式（每次把整列的其它行也消成 0），省去回代，结果直接在最后一列。

## 异或线性基

### 问题

给 n 个非负整数，选出一些数，使它们的异或和最大。或者问：某个数能否由若干个数异或得到。

### 思路

把每个数看作二进制向量，异或相当于模 2 的向量加法。像高斯消元一样，用 `b[i]` 保存"最高位恰好是第 i 位"的一个基向量：

- **插入 x**：从高位到低位扫描，遇到 x 的第 i 位是 1：若 `b[i]` 为空，把 x 放进去并结束；否则 `x ^= b[i]` 继续。如果最后 x 变成 0，说明它已经能被现有基向量异或表示，不加入。
- **能否表示**：用同样的过程消去，最后为 0 则可以。
- **最大异或和**：从高位到低位，若 `r ^ b[i] > r` 就取。

最多 63 个基向量，每次插入 O(63)。基的大小为 k 时，能凑出的不同异或值恰好有 2^k 个。

![依次插入5、3、6、1：5和3占据最高位2和1；6等于5异或3，被消成0，插入失败；1占据最高位0；最大异或和从高位到低位依次异或得到111即7](/qmx-Gameknowledge/assets/algo/c8-xor-basis.svg)

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef unsigned long long ull;

// 异或线性基：最多 63 个基向量，b[i] 的最高位恰好是第 i 位
struct XorBasis {
    ull b[64] = {};
    int cnt = 0;

    bool insert(ull x) {                       // 插入成功（x 原本不在张成空间内）返回 true
        for (int i = 63; i >= 0; i--) {
            if (!(x >> i & 1)) continue;
            if (!b[i]) { b[i] = x; cnt++; return true; }
            x ^= b[i];
        }
        return false;
    }
    bool contains(ull x) const {
        for (int i = 63; i >= 0 && x; i--)
            if ((x >> i & 1) && b[i]) x ^= b[i];
        return x == 0;
    }
    ull max_xor() const {
        ull r = 0;
        for (int i = 63; i >= 0; i--)
            if ((r ^ b[i]) > r) r ^= b[i];
        return r;
    }
};

int main() {
    XorBasis lb;
    for (ull x : {5, 3, 6, 1}) printf("插入 %llu: %d\n", x, (int)lb.insert(x));
    printf("基大小=%d  最大异或和=%llu  能凑出 7: %d  能凑出 9: %d\n",
           lb.cnt, lb.max_xor(), (int)lb.contains(7), (int)lb.contains(9));
    return 0;
}
```

运行结果：

```text
插入 5: 1
插入 3: 1
插入 6: 0
插入 1: 1
基大小=3  最大异或和=7  能凑出 7: 1  能凑出 9: 0
```

基里有 3 个向量 `101, 011, 001`，能凑出 8 个值，最大是 `111 = 7`；9 = `1001` 的最高位 3 没有基向量，无法凑出。

## 例题

### 例 1：球形空间产生器

n 维空间里给出 n+1 个球面上的点，求球心坐标。球面上点到球心距离相等，相邻两点的方程相减后，平方项消去，得到 n 个关于球心坐标的线性方程，用实数高斯消元解出。这是实数版的典型题。

### 例 2：外星千足虫

每个方程是若干个未知数（取 0 或 1）的异或等于 0 或 1，要求出每个未知数。这是模 2 的方程组，可以用 `bitset` 把一行压成一个整数，消元的行加法变成 `^=`，复杂度降到 O(n³/64)。

### 例 3：最大异或和

n 个数选任意子集，求最大异或和：全部插入线性基，调用 `max_xor()`。

## 适用与不适用

适用：n 在几百到一两千的稠密线性方程组；异或类问题。不适用：稀疏的大方程组（需要其它方法）；未知数个数很大时 O(n³) 过慢。

## 常见坑

- 实数版用 `a == 0` 判零会出错，要用 `fabs(a) < eps`；`eps` 通常取 1e-9 左右，具体依数据范围调整。
- 实数版不选最大主元，当主元接近 0 时误差会爆炸。
- 模 p 版里，减法后要 `+ p` 再取模，避免出现负数。
- 判断无解必须在消元结束后检查"系数全 0 而常数非 0"的行，不能只看秩。
- 异或线性基里 `b[i]` 的下标是最高位，写成"最低位"会让最大值的贪心失效。
