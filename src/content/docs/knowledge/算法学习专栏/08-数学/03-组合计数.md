> 适用版本：C++17。需要先学 8.1 的逆元和快速幂。

## 要点

- 乘法原理（分步）和加法原理（分类）是所有计数题的出发点。
- `C(n, m)` 可以用杨辉三角递推 O(n²) 预处理，也可以用"阶乘 + 阶乘逆元"在 O(n) 预处理后每次 O(1) 查询。
- 模数是小质数、n 又很大时，用 Lucas 定理把 n、m 按 p 进制拆开。
- 隔板法解"把相同的球放进不同盒子"，错位排列用递推 `D(n) = (n-1)(D(n-1) + D(n-2))`。

## 基本概念

- **排列**：从 n 个不同元素中取 m 个并排成一列，数目 `A(n, m) = n! / (n-m)!`。
- **组合**：从 n 个不同元素中取 m 个，不计顺序，数目 `C(n, m) = n! / (m!·(n-m)!)`。
- 对称性：`C(n, m) = C(n, n-m)`。约定 m < 0 或 m > n 时 `C(n, m) = 0`。

选 m 个元素就是"选"和"不选"的二分类，这给出最重要的递推。看第 n 个元素：选它，则从前 n-1 个里再选 m-1 个；不选它，则从前 n-1 个里选 m 个。

```text
C(n, m) = C(n-1, m-1) + C(n-1, m)
```

把它按行排开就是杨辉三角。

![杨辉三角前7行，C(4,2)=6 等于肩上的 C(3,1)=3 与 C(3,2)=3 之和；每行的和是 2 的 n 次方](/qmx-Gameknowledge/assets/algo/c8-pascal.svg)

用二维数组递推，预处理 O(n²)，适合 n 不超过几千的场合；模数可以是任意数，因为只用加法。

## 阶乘与阶乘逆元

n 到 10⁶ 级、模数 p 是大质数（如 10⁹+7）时，用公式 `C(n, m) = n! · (m!)⁻¹ · ((n-m)!)⁻¹`。

1. 预处理 `fact[i] = i! mod p`，O(n)。
2. 阶乘的逆元 `ifact[i] = (i!)⁻¹`：只对最大的 `ifact[N]` 做一次快速幂（费马小定理），然后反推。
3. 反推依据：`(i-1)!⁻¹ = i · (i!)⁻¹`，所以 `ifact[i-1] = ifact[i] · i`。

![先用快速幂求出 ifact[N]，再用 ifact[i-1]=ifact[i]×i 从大到小反推出所有阶乘逆元](/qmx-Gameknowledge/assets/algo/c8-fact-inverse.svg)

这样预处理 O(n + log p)，每次 `C(n, m)` 只要三次乘法。如果对每个 i 都单独做一次快速幂，预处理会变成 O(n log p)，慢很多。

## Lucas 定理

当 n 很大（如 10¹⁸）而模数 p 是不大的质数时，阶乘预处理装不下，且 n ≥ p 时 `n!` 本身是 p 的倍数，没有逆元。这时用 **Lucas 定理**：

```text
C(n, m) ≡ C(n mod p, m mod p) · C(n / p, m / p)   (mod p)
```

其中 `n / p` 是整除。推导思路：在模 p 下 `(1 + x)^p ≡ 1 + x^p`（二项式系数 `C(p, k)` 在 0 < k < p 时是 p 的倍数）。把 n 写成 `n = n1·p + n0`（0 ≤ n0 < p），有

```text
(1+x)^n = (1+x)^(n0) · ((1+x)^p)^(n1) ≡ (1+x)^(n0) · (1 + x^p)^(n1)
```

比较两边 `x^m` 的系数（把 m 写成 `m1·p + m0`），因为 `(1+x)^(n0)` 的次数小于 p，所以 `x^m` 只能由 `x^(m0)` 与 `x^(m1·p)` 相乘得到，即 `C(n0, m0) · C(n1, m1)`。递归下去，层数是 `log_p n`。

每一层的小组合数 `C(n0, m0)` 用 O(p) 的乘法和一次快速幂求出，总复杂度 O(p · log_p n)。代码见下，`lucas` 复用了 `power(·, ·, p)`。

## 隔板法

把 n 个相同的球放进 k 个不同的盒子：

- 每盒至少 1 个：在 n 个球的 n-1 个空隙里选 k-1 个放隔板，`C(n-1, k-1)`。
- 每盒可以为空：先每盒"借"1 个球，变成 n+k 个球再要求每盒至少 1 个，`C(n+k-1, k-1)`。

![10个球之间有9个空隙，选其中3个放隔板，把球分成4段，对应4个盒子里的球数 3、2、4、1，方案数是 C(9,3)=84](/qmx-Gameknowledge/assets/algo/c8-stars-bars.svg)

## 错位排列

`D(n)`：把 1 到 n 排成一列，要求第 i 个位置上不是 i，这样的排列数。

递推：考虑位置 n 上放的数 k（k ≠ n，有 n-1 种选法）。再看数 n 放在哪：

- n 放在位置 k：剩下 n-2 个数的错位排列，`D(n-2)` 种。
- n 不放在位置 k：把 n 看作"位置 k 的原位数"，其余 n-1 个数的错位排列，`D(n-1)` 种。

所以 `D(n) = (n-1)·(D(n-1) + D(n-2))`，`D(0) = 1`，`D(1) = 0`。前几项：1, 0, 1, 2, 9, 44, 265。（8.10 会给出容斥原理的另一种推导。）

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const int MOD = 1000000007;
const int N = 1000000;
ll fact[N + 1], ifact[N + 1];

ll power(ll a, ll e, ll m = MOD) {
    ll r = 1;
    for (a %= m; e > 0; e >>= 1, a = a * a % m)
        if (e & 1) r = r * a % m;
    return r;
}

void init() {
    fact[0] = 1;
    for (int i = 1; i <= N; i++) fact[i] = fact[i - 1] * i % MOD;
    ifact[N] = power(fact[N], MOD - 2);           // 只做一次快速幂
    for (int i = N; i >= 1; i--) ifact[i - 1] = ifact[i] * i % MOD;
}

ll C(int n, int m) {
    if (m < 0 || m > n) return 0;
    return fact[n] * ifact[m] % MOD * ifact[n - m] % MOD;
}

// Lucas：模数 p 是小质数（p 可以远小于 n）时求 C(n, m) mod p
// 每一层用 O(p) 次乘法算小组合数的分子分母，再用快速幂（模 p）求分母的逆元
ll lucas(ll n, ll m, int p) {
    if (m == 0) return 1;
    ll ni = n % p, mi = m % p;
    if (mi > ni) return 0;
    ll a = 1, b = 1;
    for (ll i = 0; i < mi; i++) a = a * ((ni - i) % p) % p, b = b * ((i + 1) % p) % p;
    return a * power(b, p - 2, p) % p * lucas(n / p, m / p, p) % p;
}

// 错位排列 D(n)：n 个元素都不在原位的排列数
ll derangement(int n) {
    vector<ll> d(n + 2);
    d[0] = 1; d[1] = 0;
    for (int i = 2; i <= n; i++) d[i] = (ll)(i - 1) * (d[i - 1] + d[i - 2]) % MOD;
    return d[n];
}

int main() {
    init();
    printf("C(5,2)=%lld C(10,3)=%lld C(1000000,500000)=%lld\n", C(5, 2), C(10, 3), C(1000000, 500000));
    // 隔板法：把 10 个相同的球放进 4 个盒子，每盒至少 1 个 → C(9,3)
    printf("隔板法: %lld\n", C(9, 3));
    printf("Lucas: C(100,50) mod 7 = %lld\n", lucas(100, 50, 7));
    printf("D(4)=%lld D(5)=%lld\n", derangement(4), derangement(5));
    return 0;
}
```

运行结果：

```text
C(5,2)=10 C(10,3)=120 C(1000000,500000)=996692777
隔板法: 84
Lucas: C(100,50) mod 7 = 4
D(4)=9 D(5)=44
```

- `C(5,2) = 10`、`C(10,3) = 120` 可以口算验证。
- `C(1000000, 500000) mod (10⁹+7) = 996692777` 与 Python 的 `math.comb` 对照一致。
- 隔板法：10 个球 4 个盒子每盒至少 1 个，`C(9, 3) = 84`，与图相符。
- `C(100, 50) mod 7 = 4`：用 Lucas 展开，100 = 2·49 + 0·7 + 2，50 = 1·49 + 0·7 + 1，即 `C(2,1)·C(0,0)·C(2,1) = 2·1·2 = 4`。
- `D(4) = 9`、`D(5) = 44`。

## 例题

### 例 1：网格路径计数

从 m×n 方格的左上角走到右下角，每次只能向右或向下，路径条数。总共走 `(m-1) + (n-1)` 步，其中 `n-1` 步向右，只需要决定哪些步向右：`C(m+n-2, n-1)`。LeetCode 62 的 `m = 3, n = 7` 给出 `C(8, 2) = 28`。

### 例 2：把 10 件相同的奖品分给 4 个人

每人至少一件，是 `C(9, 3) = 84`；允许有人一件也没有，是 `C(13, 3) = 286`。公式见隔板法一节。

### 例 3：信封问题

n 封信装进 n 个信封，全装错的方案数就是 `D(n)`，直接套递推；程序里的 `derangement` 已经实现。

## 常见坑

- 模数是质数 p，但 n ≥ p 时 `fact[n]` 已经是 p 的倍数，`ifact` 不存在，必须用 Lucas。
- 阶乘数组开小了：`C(n+m, n)` 需要预处理到 `n+m`，而不是 n。
- `fact`、`ifact` 用 `int` 存会在乘法时溢出，乘之前转成 `long long`。
- 减法后再取模要写 `(x % p + p) % p`，否则可能出现负数。
- 反推 `ifact` 时必须从 N 往下推（`ifact[i-1] = ifact[i]·i`），写反方向会得到错误结果。
