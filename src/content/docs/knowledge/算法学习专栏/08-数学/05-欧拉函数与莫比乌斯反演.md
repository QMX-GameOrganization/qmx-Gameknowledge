> 适用版本：C++17。前置：8.2 线性筛（会用 `lp` 和积性函数的递推），8.1 快速幂与取模。什么时候需要学：题目要对大量 `(i, j)` 求 `gcd(i, j) = 1` 的个数，或求 `gcd` 的和；或者指数特别大（如 `a^(10^18)`）需要降幂时。

## 要点

- **欧拉函数** `φ(n)`：1 到 n 中与 n 互质的数的个数。`φ(n) = n·∏(1 - 1/p)`（对 n 的每个质因子 p）。
- **欧拉定理**：`gcd(a, m) = 1` 时 `a^φ(m) ≡ 1 (mod m)`。扩展欧拉定理处理不互质的情形，用于指数降幂。
- **莫比乌斯函数** `μ(n)`：n 含平方因子时为 0，否则为 `(-1)^(质因子个数)`。核心性质 `Σ_{d|n} μ(d) = [n = 1]`。
- **整除分块**：`⌊n/d⌋` 只有 O(√n) 种取值，把相同的 d 合并成一段，每次求和 O(√n)。
- 两个套路：`[gcd(i,j) = 1] = Σ_{d | gcd} μ(d)`；`gcd(i,j) = Σ_{d | gcd} φ(d)`。

## 欧拉函数

先看质数的幂 `p^k`：1 到 `p^k` 里与它不互质的数就是 p 的倍数，共 `p^(k-1)` 个，所以

```text
φ(p^k) = p^k - p^(k-1) = p^k · (1 - 1/p)
```

`φ` 是**积性函数**：`gcd(a, b) = 1` 时 `φ(a·b) = φ(a)·φ(b)`（可由 8.4 的中国剩余定理得到：模 `ab` 的剩余类与 `(模 a, 模 b)` 的剩余类一一对应，互质的对应互质的）。对 `n = p1^k1 · p2^k2 · …`：

```text
φ(n) = n · (1 - 1/p1) · (1 - 1/p2) · …
```

单个数用试除求 `φ`，O(√n)；批量用线性筛，规则（8.2 已给出）：

- `p` 整除 `i`：`φ(i·p) = φ(i)·p`。因为 `i·p` 与 `i` 的质因子集合相同，公式里的乘积项不变，只是 n 乘了 p。
- `p` 不整除 `i`：`φ(i·p) = φ(i)·φ(p) = φ(i)·(p-1)`，由积性。

### 欧拉定理与指数降幂

**欧拉定理**：`gcd(a, m) = 1` 时 `a^φ(m) ≡ 1 (mod m)`。质数 p 时 `φ(p) = p - 1`，就是费马小定理。

当指数 b 很大（比如 `10^18`，甚至要用字符串存），可以对 `a` 和 `m` 不要求互质，用**扩展欧拉定理**：

```text
b < φ(m) 时：   a^b mod m 直接算
b ≥ φ(m) 时：   a^b ≡ a^(b mod φ(m) + φ(m))   (mod m)
```

## 莫比乌斯函数与反演

定义：`μ(1) = 1`；n 含平方因子时 `μ(n) = 0`；否则 n 是 k 个不同质数之积，`μ(n) = (-1)^k`。

核心性质：

```text
Σ_{d | n} μ(d) = [n = 1]     （n = 1 时为 1，否则为 0）
```

理由：设 n 有 k 个不同质因子，只有"无平方因子"的 d（即这 k 个质数的子集乘积）才有非零的 μ。子集大小为 j 的有 `C(k, j)` 个，贡献 `(-1)^j`，总和 `Σ C(k,j)(-1)^j = (1-1)^k`，k ≥ 1 时为 0。

这个性质的用处是：**把"gcd 恰好是 1"这个条件，改写成对所有公约数 d 求和**：

```text
[gcd(i, j) = 1] = Σ_{d | gcd(i,j)} μ(d)
```

## 整除分块

求 `Σ_{d=1}^{n} f(d)·⌊n/d⌋` 这种和式时，d 从 1 到 n 逐个算是 O(n)。观察 `⌊n/d⌋`：

- d ≤ √n 时，最多 √n 个不同的 d，取值至多 √n 种。
- d > √n 时，商 ≤ √n，取值也最多 √n 种。

总共不超过 `2√n` 种商值，而相同商值的 d 是连续的一段。对一段的起点 l，商 `q = ⌊n/l⌋`，这一段的终点 `r = ⌊n/q⌋`。

![n=12 时 d 从1到12的商是12、6、4、3、2、2、1、1、1、1、1、1，相同商值的 d 连成一段：[1]、[2]、[3]、[4]、[5,6]、[7,12]](/qmx-Gameknowledge/assets/algo/c8-block-division.svg)

同时处理两个数 n、m 时，终点取 `min(n/(n/l), m/(m/l))`。有了前缀和 `Σ f`，每一段的贡献就是"前缀和之差 × 商 × 商"。

## 两个经典问题

**问题 1**：`1 ≤ i ≤ n`，`1 ≤ j ≤ m`，求 `gcd(i, j) = 1` 的 `(i, j)` 对数。

```text
Σ_i Σ_j [gcd(i,j) = 1] = Σ_i Σ_j Σ_{d | i, d | j} μ(d) = Σ_d μ(d)·⌊n/d⌋·⌊m/d⌋
```

交换求和顺序时用到：满足 `d | i` 的 i 有 `⌊n/d⌋` 个，满足 `d | j` 的 j 有 `⌊m/d⌋` 个。再用 μ 的前缀和和整除分块，O(√n)。

**问题 2**：求 `Σ_{i ≤ n} Σ_{j ≤ m} gcd(i, j)`。

利用恒等式 `Σ_{d | n} φ(d) = n`（把 1 到 n 按 `gcd(k, n)` 分类，gcd 为 `n/d` 的数恰有 `φ(d)` 个）。取 `n = gcd(i, j)`：

```text
gcd(i, j) = Σ_{d | gcd(i,j)} φ(d)
所以 Σ Σ gcd(i,j) = Σ_d φ(d)·⌊n/d⌋·⌊m/d⌋
```

同样用 φ 的前缀和和整除分块。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const int N = 100000;
int lp[N + 1], phi[N + 1], mu[N + 1];
ll sphi[N + 1];       // phi 的前缀和
int smu[N + 1];       // mu 的前缀和
vector<int> primes;

void init() {
    phi[1] = mu[1] = 1;
    for (int i = 2; i <= N; i++) {
        if (!lp[i]) { lp[i] = i; primes.push_back(i); phi[i] = i - 1; mu[i] = -1; }
        for (int p : primes) {
            if (p > lp[i] || (ll)i * p > N) break;
            lp[i * p] = p;
            if (p == lp[i]) phi[i * p] = phi[i] * p, mu[i * p] = 0;
            else phi[i * p] = phi[i] * (p - 1), mu[i * p] = -mu[i];
        }
    }
    for (int i = 1; i <= N; i++) sphi[i] = sphi[i - 1] + phi[i], smu[i] = smu[i - 1] + mu[i];
}

// 单个数的欧拉函数：试除，O(sqrt n)
ll euler_phi(ll n) {
    ll res = n;
    for (ll p = 2; p * p <= n; p++)
        if (n % p == 0) {
            while (n % p == 0) n /= p;
            res = res / p * (p - 1);
        }
    if (n > 1) res = res / n * (n - 1);
    return res;
}

// 整除分块：对 [1, n] 内的 d，把 floor(n/d) 相同的 d 合成一段
// 例 1：1<=i<=n, 1<=j<=m 中 gcd(i,j)=1 的对数 = sum mu(d) * floor(n/d) * floor(m/d)
ll coprime_pairs(int n, int m) {
    ll res = 0;
    for (int l = 1, r; l <= min(n, m); l = r + 1) {
        r = min(n / (n / l), m / (m / l));
        res += (ll)(smu[r] - smu[l - 1]) * (n / l) * (m / l);
    }
    return res;
}

// 例 2：sum_{i<=n, j<=m} gcd(i,j) = sum_d phi(d) * floor(n/d) * floor(m/d)
ll sum_gcd(int n, int m) {
    ll res = 0;
    for (int l = 1, r; l <= min(n, m); l = r + 1) {
        r = min(n / (n / l), m / (m / l));
        res += (sphi[r] - sphi[l - 1]) * (n / l) * (m / l);
    }
    return res;
}

ll power(ll a, ll e, ll m) {
    ll r = 1 % m;
    for (a %= m; e > 0; e >>= 1, a = a * a % m)
        if (e & 1) r = r * a % m;
    return r;
}

// 扩展欧拉定理：a^b mod m，b 可以非常大（用字符串或 ll 表示均可，这里用 ll 演示）
ll power_big(ll a, ll b, ll m) {
    ll ph = euler_phi(m);
    if (b < ph) return power(a, b, m);
    return power(a, b % ph + ph, m);
}

int main() {
    init();
    printf("phi(36)=%lld  phi 前缀和 sphi[10]=%lld\n", euler_phi(36), sphi[10]);
    printf("coprime_pairs(10,10)=%lld  sum_gcd(10,10)=%lld\n", coprime_pairs(10, 10), sum_gcd(10, 10));
    printf("2^(10^18) mod 12 = %lld\n", power_big(2, 1000000000000000000LL, 12));
    return 0;
}
```

运行结果：

```text
phi(36)=12  phi 前缀和 sphi[10]=32
coprime_pairs(10,10)=63  sum_gcd(10,10)=189
2^(10^18) mod 12 = 4
```

- `φ(36) = 12`：36 = 2²·3²，`36·(1/2)·(2/3) = 12`。
- `sphi[10] = 32`：`φ(1..10) = 1,1,2,2,4,2,6,4,6,4`，和为 32。
- `coprime_pairs(10, 10) = 63`：与公式 `2·Σφ(1..10) - 1 = 63` 一致（互质对按 `i < j`、`i = j = 1`、`i > j` 划分）。
- `2^(10^18) mod 12 = 4`：用扩展欧拉定理降幂：`φ(12) = 4`，指数变成 `10^18 mod 4 + 4 = 4`，`2^4 = 16 ≡ 4`。

代码里两个求和函数都用整除分块，单次查询 O(√n)；程序通过随机数据与 O(nm) 暴力对拍。

## 例题

### 例 1：仪仗队

n×n 的方阵，从左下角能看到多少个人（同一方向上只能看到最近的一个）。除了 `(0,1)`、`(1,0)` 两个特殊方向，能看到的点就是坐标 `(x, y)` 满足 `gcd(x, y) = 1`，用 `φ` 的前缀和直接得到答案，即 `coprime_pairs` 的变形。

### 例 2：求 gcd(x, y) 为质数的对数

`Σ_{p 为质数} (满足 gcd(x,y) = p 的对数) = Σ_p (满足 gcd(x/p, y/p) = 1 的对数)`，即 `Σ_p coprime_pairs(n/p, m/p)`。质数个数 O(n/ln n)，每次 O(√n)，总复杂度不够快时需要继续化简成 `Σ_T (Σ_{p|T} μ(T/p))·⌊n/T⌋⌊m/T⌋` 再预处理前缀和，这是莫比乌斯反演的经典进阶。

## 适用与不适用

适用：求和式里出现 `gcd` 或"互质"条件，n、m 达到 10⁷ 以内可以预处理 μ、φ 的前缀和。n 达到 10⁹ 以上需要杜教筛等更强的方法，不在本篇范围内。

## 常见坑

- 整除分块的终点 `r = min(n/(n/l), m/(m/l))`，忘记 `min` 会越界；`n/l` 为 0 时不能除，所以循环上界要写 `l ≤ min(n, m)`。
- `φ` 和 `μ` 的前缀和别忘了 `d = 0`、`d = 1` 的边界。
- 求和函数返回值要用 `long long`，`(sphi[r] - sphi[l - 1]) * (n/l) * (m/l)` 乘积较大时也别用 `int`。
- 扩展欧拉定理的条件是 `b ≥ φ(m)`；`b` 很小时直接降幂会出错。
