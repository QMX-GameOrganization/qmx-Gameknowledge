> 适用版本：C++17。前置：2.3 并查集。什么时候需要学：题目里元素之间有“差、比、距离、奇偶”这类**关系**要判断是否矛盾（带权并查集），或者需要**撤销**最近几次合并（可撤销并查集，常与离线分治配合）。

## 要点

- 带权并查集在每个点上多记一个 `d[x]`，表示 x 相对父亲的某种量（差值、距离、奇偶等），`find` 压缩路径时把权值累加。
- 权值必须能“沿路径叠加”，常见的是加法（差值、距离）和异或（奇偶、分类）。
- 可撤销并查集不做路径压缩，只按大小合并，每次合并把 `(被挂的根, 挂到的根)` 压栈，撤销时弹栈还原。
- 没有路径压缩，单次操作是 O(log n)，但可以精确回退。

## 带权并查集

定义 `d[x]` = x 的值 − parent[x] 的值（任何可加的量，如重量、坐标、时间）。`find` 回溯时把路径上的权累加，压缩后 `d[x]` 就是 x 到根的总差值。

![带权并查集：压缩前每条边记录到父亲的距离，find 之后直接记录到根的总距离](/qmx-Gameknowledge/assets/algo/c2-wdsu.svg)

**合并**：要建立关系 val[a] − val[b] = w。先找根 ra、rb。

- 根相同：已有 d 可以算出 val[a] − val[b] = d[a] − d[b]，与 w 比较，不等就是矛盾。
- 根不同：把 ra 挂到 rb 下。因为 val[a] = d[a] + val[ra]，val[b] = d[b] + val[rb]，代入 val[a] − val[b] = w，得 `d[ra] = w − d[a] + d[b]`。

```cpp
#include <bits/stdc++.h>
using namespace std;
struct WDSU {
    vector<int> p;
    vector<long long> d;                          // d[x] = val[x] - val[p[x]]
    WDSU(int n) : p(n + 1), d(n + 1, 0) { iota(p.begin(), p.end(), 0); }
    int find(int x) {
        if (p[x] == x) return x;
        int r = find(p[x]);
        d[x] += d[p[x]];                          // p[x] 此时已指向根，d[p[x]] 是它到根的距离
        return p[x] = r;
    }
    // 加入条件 val[a] - val[b] = w；与已有条件矛盾返回 false
    bool add(int a, int b, long long w) {
        int ra = find(a), rb = find(b);
        if (ra == rb) return d[a] - d[b] == w;
        p[ra] = rb;
        d[ra] = w - d[a] + d[b];
        return true;
    }
    // 查询 val[a] - val[b]，不连通返回 false
    bool query(int a, int b, long long& out) {
        if (find(a) != find(b)) return false;
        out = d[a] - d[b];
        return true;
    }
};
int main() {
    WDSU u(5);
    printf("%d\n", u.add(1, 2, 3));               // 1 比 2 大 3
    printf("%d\n", u.add(2, 3, 2));               // 2 比 3 大 2
    printf("%d\n", u.add(1, 3, 5));               // 与已知一致
    printf("%d\n", u.add(1, 3, 4));               // 矛盾
    long long r;
    if (u.query(1, 3, r)) printf("val1 - val3 = %lld\n", r);
    printf("1 和 4 能比较吗 %d\n", u.query(1, 4, r));
}
```

输出：

```text
1
1
1
0
val1 - val3 = 5
1 和 4 能比较吗 0
```

对于“奇偶 / 分类”关系（如食物链：同类、吃、被吃），把加法换成模 3 的加法或异或即可，推导方法一样。

## 可撤销并查集

做**离线**的动态连通性（加边、删边、查询按时间展开）时，常把每条边存在的时间段挂到线段树的节点上，对线段树做 DFS：进入节点时加这个节点上的边，离开时撤销。这就要求并查集能回退。

回退的前提是树的形状只被最近一次合并改过，所以**不能路径压缩**，只用按大小合并。

![可撤销并查集：用栈记录每次合并，撤销时弹出栈顶并还原 parent 和 size](/qmx-Gameknowledge/assets/algo/c2-rollback.svg)

```cpp
#include <bits/stdc++.h>
using namespace std;
struct RollbackDSU {
    vector<int> p, sz;
    vector<pair<int, int>> st;                    // (被挂的根 b, 挂到的根 a)；b = -1 表示没有发生合并
    RollbackDSU(int n) : p(n), sz(n, 1) { iota(p.begin(), p.end(), 0); }
    int find(int x) { while (p[x] != x) x = p[x]; return x; }          // 不压缩
    bool unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) { st.push_back({-1, -1}); return false; }
        if (sz[a] < sz[b]) swap(a, b);
        p[b] = a; sz[a] += sz[b];
        st.push_back({b, a});
        return true;
    }
    int snapshot() { return st.size(); }
    void rollback(int to) {                       // 回退到栈大小为 to 的状态
        while ((int)st.size() > to) {
            auto [b, a] = st.back(); st.pop_back();
            if (b < 0) continue;
            sz[a] -= sz[b]; p[b] = b;
        }
    }
};
int main() {
    RollbackDSU d(4);
    d.unite(0, 1); d.unite(2, 3);
    int mark = d.snapshot();                      // 记下当前状态
    d.unite(1, 2);
    printf("合并后 0 和 3：%d\n", d.find(0) == d.find(3));
    d.rollback(mark);
    printf("撤销后 0 和 3：%d\n", d.find(0) == d.find(3));
    printf("0 和 1 仍相连：%d\n", d.find(0) == d.find(1));
}
```

输出 `合并后 0 和 3：1`、`撤销后 0 和 3：0`、`0 和 1 仍相连：1`。`unite` 失败时也压一个占位记录，是为了让“栈大小”始终等于“操作次数”，快照和回退更好写。

复杂度：单次 `find` 为 O(log n)，线段树分治总复杂度约 O((n + m) log m log n)。

## 适用与不适用

| | 带权并查集 | 可撤销并查集 |
| --- | --- | --- |
| 解决 | 元素间的数量关系是否矛盾、求差值 | 按时间回退合并 |
| 路径压缩 | 要，且要累加权值 | 不能 |
| 单次复杂度 | 近似 O(1) | O(log n) |
| 不能做 | 回退 | 在线任意删边 |

## 常见坑

- 带权 `find` 里先改 `p[x]` 再累加 `d[x]`：必须先递归，累加用的是 `p[x]` 压缩前的父亲，顺序错了会多加或漏加。
- 合并公式里 a、b 的方向写反：先把 `val[a] − val[b] = w` 的定义写清楚，再推导。
- 用 `int` 存权值，累加后溢出：用 `long long`。
- 可撤销并查集里偷偷加了路径压缩，回退后树形状不对，结果错误。
- 忘记 `rollback` 要按栈的 LIFO 顺序，不能跳着撤销。
