## 要点

- 单调栈：栈内元素保持单调，新元素进来时先弹出破坏单调性的元素，再入栈。
- 每个元素最多入栈一次、出栈一次，所以整体是 O(n)。
- 典型问题：每个元素右边（或左边）第一个更大（或更小）的元素在哪。
- 单调队列：用 `deque` 保持队内单调，队首永远是当前窗口的最值，过期的元素从队首出，被淘汰的从队尾出。
- 典型问题：滑动窗口最大值、带长度限制的区间最值（常用于优化 DP，见 6.9）。

## 单调栈

**问题**：给定数组 a，对每个 i 求右边第一个比 a[i] 大的数，不存在则输出 −1。

暴力是对每个 i 向右扫，最坏 O(n²)。观察：如果 a[j] 比栈顶的元素大，那么 a[j] 就是栈顶元素要找的答案，这个栈顶元素以后不会再被用到，可以弹出。

![单调栈处理 [2,7,3,4,8,5]：新元素更大就弹出栈顶并给出答案](/qmx-Gameknowledge/assets/algo/c2-monostack.svg)

栈里从栈底到栈顶保持**递减**。看图中 i = 4 的一列：a[4] = 8 比栈顶 4 大，弹出 4；又比 7 大，弹出 7；然后 8 入栈。弹出的元素的答案就是当前的 8。

```cpp
#include <bits/stdc++.h>
using namespace std;
// 返回 ans[i]：i 右边第一个更大的元素的下标，不存在为 -1
vector<int> nextGreater(const vector<int>& a) {
    int n = a.size();
    vector<int> ans(n, -1);
    stack<int> st;                              // 存下标，对应的值从栈底到栈顶递减
    for (int i = 0; i < n; i++) {
        while (!st.empty() && a[st.top()] < a[i]) {
            ans[st.top()] = i;                  // 栈顶的答案就是当前 i
            st.pop();
        }
        st.push(i);
    }
    return ans;
}
int main() {
    vector<int> a = {2, 7, 3, 4, 8, 5};
    for (int i : nextGreater(a)) printf("%d ", i < 0 ? -1 : a[i]);
    printf("\n");
}
```

输出 `7 8 4 8 -1 -1`，与图中手算一致。

怎么变形：求“更小”就把比较反过来；求“左边第一个”就从右往左扫，或者弹出时同时记录栈里下面那个元素。栈里存下标比存值更通用，因为下标既能取值又能算距离。

### 例题：柱状图中最大的矩形

给定柱子高度 h，求能勾勒出的最大矩形面积。对每根柱子 i，以它的高度为矩形高，向左右尽量扩展，边界是左右两侧第一个比它矮的柱子。用单调栈求出这两个边界即可。

```cpp
#include <bits/stdc++.h>
using namespace std;
int largestRectangle(const vector<int>& h) {
    int n = h.size(), best = 0;
    vector<int> L(n), R(n);                     // L[i]：左边第一个更矮的下标，R[i]：右边第一个
    stack<int> st;
    for (int i = 0; i < n; i++) {
        while (!st.empty() && h[st.top()] >= h[i]) st.pop();
        L[i] = st.empty() ? -1 : st.top();
        st.push(i);
    }
    st = stack<int>();
    for (int i = n - 1; i >= 0; i--) {
        while (!st.empty() && h[st.top()] >= h[i]) st.pop();
        R[i] = st.empty() ? n : st.top();
        st.push(i);
    }
    for (int i = 0; i < n; i++) best = max(best, h[i] * (R[i] - L[i] - 1));
    return best;
}
int main() {
    printf("%d\n", largestRectangle({2, 1, 5, 6, 2, 3}));   // 10：高 5 宽 2
    printf("%d\n", largestRectangle({2, 4}));               // 4
}
```

输出 `10` 和 `4`。注意弹出条件用 `>=`：遇到等高的柱子也弹出，留在栈里的都是严格更矮的柱子，所以 `L`、`R` 是左右第一个**严格更矮**的位置，等高的柱子会被算进矩形的宽度里。如果两侧都改成 `>`，遇到等高柱子就停下，宽度会算小。

## 单调队列

**问题**：长度为 n 的数组，窗口大小 k，窗口每次右移一格，求每个窗口内的最大值。

暴力每个窗口扫 k 个，O(nk)。观察：如果新元素 a[i] 比队尾的元素大，那么队尾元素在 a[i] 还在窗口里时永远不会成为最大值（比它小且更早离开），可以删除。队内因此保持递减，队首就是最大值。队首下标 ≤ i − k 时说明已离开窗口，也要弹出。

![单调队列处理滑动窗口，队首（绿色）始终是窗口最大值](/qmx-Gameknowledge/assets/algo/c2-monoqueue.svg)

```cpp
#include <bits/stdc++.h>
using namespace std;
vector<int> slidingMax(const vector<int>& a, int k) {
    vector<int> res;
    deque<int> dq;                              // 存下标，对应值从队首到队尾递减
    for (int i = 0; i < (int)a.size(); i++) {
        while (!dq.empty() && a[dq.back()] <= a[i]) dq.pop_back();   // 淘汰更小的
        dq.push_back(i);
        if (dq.front() <= i - k) dq.pop_front();                    // 过期
        if (i >= k - 1) res.push_back(a[dq.front()]);
    }
    return res;
}
int main() {
    for (int x : slidingMax({1, 3, -1, -3, 5, 3, 6, 7}, 3)) printf("%d ", x);
    printf("\n");
}
```

输出 `3 3 5 5 6 7`，与图中右侧一列一致。复杂度同样是 O(n)：每个下标至多入队、出队各一次。

## 单调栈与单调队列的区别

| | 单调栈 | 单调队列 |
| --- | --- | --- |
| 结构 | `stack`，只在栈顶操作 | `deque`，队首、队尾都要操作 |
| 解决 | 左右第一个更大/更小 | 定长窗口的最值 |
| 弹出原因 | 被新元素“打败” | 被打败，或者离开窗口 |

## 常见坑

- 栈里存值还是存下标：几乎总是存下标，需要值时再取 `a[idx]`。
- 比较用 `<` 还是 `<=`：决定了遇到相等元素是否弹出，要根据题意选，上面最大矩形的例子里选错会算错面积。
- 单调队列的过期判断写成 `dq.front() < i - k`，窗口长度多出一格。
- 循环结束后栈里剩下的元素没有答案，别忘了它们的默认值（如 −1）。
