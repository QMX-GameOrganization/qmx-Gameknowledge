> 适用版本：C++17。前置：`sort`、`unique`、`lower_bound` 的用法。

## 要点

- 离散化（coordinate compression）：只保留数值的相对大小，把它们映射到 0 到 m−1 的编号，m 是不同数值的个数。
- 做法三步：复制、排序、去重，再用 `lower_bound` 找每个值的编号。时间 O(n log n)。
- 适用于“只关心大小关系或相等关系”的题：计数、前缀和、差分、树状数组、区间覆盖等。
- 不适用于需要数值差的场景，除非把差值另外存下来。
- 区间类问题要注意端点的开闭，以及相邻点之间的间隔是否被需要。

## 为什么需要

数据 a[i] 最大到 10^9，但只有 n = 10^5 个数。想用数组 `cnt[a[i]]` 计数要开 10^9 个元素，放不下。但真正出现的不同值最多 10^5 个，把它们按大小编号为 0 到 m−1，就能用 `cnt[0..m-1]`。

![a = [1000, 5, 99999, 5, 70] 先排序去重得到 v，再映射成 [2, 0, 3, 0, 1]](/qmx-Gameknowledge/assets/algo/c2-discretize-map.svg)

## 模板

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    vector<int> a = {1000, 5, 99999, 5, 70};
    vector<int> v = a;                                    // 1. 复制
    sort(v.begin(), v.end());                             // 2. 排序
    v.erase(unique(v.begin(), v.end()), v.end());         // 3. 去重
    auto id = [&](int x) { return int(lower_bound(v.begin(), v.end(), x) - v.begin()); };
    for (int x : a) printf("%d ", id(x));                 // 每个值的编号（0 开始）
    printf("\n不同的值有 %d 个\n", (int)v.size());
    printf("编号 3 对应原值 %d\n", v[3]);                  // 还原
}
```

输出：

```text
2 0 3 0 1
不同的值有 4 个
编号 3 对应原值 99999
```

`v[编号]` 可以还原出原值，`lower_bound` 保证编号保持原来的大小顺序。如果需要编号从 1 开始（树状数组常用），在 `id` 里加 1。

![离散化压缩的是间距：原数值轴上相隔很远的点，被映射成连续的编号](/qmx-Gameknowledge/assets/algo/c2-discretize-axis.svg)

## 它丢失了什么

离散化后，两点的大小顺序和是否相等都保留了，但**差值和比例丢了**。例如 5 和 70 的差是 65，1000 和 99999 的差是 98999，离散化后它们的编号差都是 1。所以只要题目里出现“距离”“长度”“个数差”，就要小心：

- 需要长度时，用原坐标 `v[i+1] - v[i]` 作为第 i 段的长度，而不是编号差。
- 需要“相邻的两个整数是否相连”（如 5 和 6）时，在离散化前把 x−1、x+1 也加入候选值。

## 例题：区间并的总长度

给定 n 个半开区间 [l, r)，求被至少一个区间覆盖的总长度。坐标范围到 10^9。

思路：把所有端点离散化为 xs，相邻两个端点之间是一段“基本段”，段内的覆盖状态相同。对每个区间在差分数组上 `+1` 和 `−1`，扫描一遍，凡是覆盖次数大于 0 的基本段，长度累加到答案。

```cpp
#include <bits/stdc++.h>
using namespace std;
long long unionLength(const vector<pair<int, int>>& seg) {
    vector<int> xs;
    for (auto [l, r] : seg) { xs.push_back(l); xs.push_back(r); }
    sort(xs.begin(), xs.end());
    xs.erase(unique(xs.begin(), xs.end()), xs.end());
    int m = xs.size();
    auto id = [&](int x) { return int(lower_bound(xs.begin(), xs.end(), x) - xs.begin()); };
    vector<int> diff(m + 1, 0);
    for (auto [l, r] : seg) { diff[id(l)]++; diff[id(r)]--; }   // 差分，见 1.3
    long long total = 0;
    int cnt = 0;
    for (int i = 0; i + 1 < m; i++) {
        cnt += diff[i];
        if (cnt > 0) total += xs[i + 1] - xs[i];                 // 用原坐标算长度
    }
    return total;
}
int main() {
    vector<pair<int, int>> seg = {{1, 5}, {3, 8}, {10, 12}, {11, 20}};
    printf("%lld\n", unionLength(seg));                          // [1,8) 与 [10,20)：7 + 10
}
```

输出 `17`。时间 O(n log n)，只与区间个数有关，与坐标范围无关。我用随机小数据和“逐点标记”的暴力解对拍过 3000 组，结果一致。

## 常见坑

- 忘记去重就直接用 `lower_bound`：重复值会得到第一个位置，编号有空洞但仍然单调，只是 m 不再是不同值的个数。
- `unique` 之后忘记 `erase`，多余的尾部元素会混进后续的查找。
- 离散化后又把编号当成原值参与加减运算。
- 对多个数组同时离散化时，要把所有数组的值放进同一个 `v`，否则同一个数在不同数组里编号不同。
- 区间问题没有区分开闭，导致端点处少算或多算一个单位长度。
