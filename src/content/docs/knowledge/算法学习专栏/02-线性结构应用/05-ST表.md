> 适用版本：C++17。前置：2.1 篇的区间最值问题，以及倍增的基本想法（把区间拆成 2 的幂长度的块）。什么时候需要学：数组**不修改**、查询次数很多（10^5 到 10^6）、每次问区间最大/最小/gcd 时。数组会被修改请用线段树（4.7）。

## 要点

- ST 表（sparse table）预处理 O(n log n)，每次查询 O(1)。
- `st[j][i]` 表示从 i 开始、长度为 2^j 的区间的最值，由两个长度 2^(j−1) 的区间合并得到。
- 查询 [l, r] 时取 k = ⌊log₂(r − l + 1)⌋，用两段长度 2^k 的区间覆盖它，它们可以重叠。
- 重叠不影响结果的运算才能用：最大值、最小值、gcd、按位与、按位或，这类运算叫幂等。
- 区间和、异或和不幂等，重叠会重复计算，要用前缀和或线段树。

## 原理

把区间 [i, i + 2^j) 分成左右各 2^(j−1) 的两半：`st[j][i] = min(st[j-1][i], st[j-1][i + 2^(j-1)])`。下图是 a = [3, 1, 4, 1, 5, 9, 2, 6] 的表，查询区间 [1, 6]（长度 6）：

![ST 表的各层，以及用 st[2][1] 和 st[2][3] 两段重叠区间覆盖查询区间 [1, 6]](/qmx-Gameknowledge/assets/algo/c2-sparse-table.svg)

长度 6 的最大 2 的幂不超过它的是 4（k = 2）。用 `st[2][1]`（覆盖 [1, 4]）和 `st[2][6 - 4 + 1] = st[2][3]`（覆盖 [3, 6]）合起来正好盖住 [1, 6]。中间的 [3, 4] 被算了两次，但取最小值时重复不影响。

因为查询只需两次访问，所以是 O(1)；预处理有 log n 层，每层 O(n)，所以是 O(n log n) 时间和空间。

## 模板

```cpp
#include <bits/stdc++.h>
using namespace std;
template <class Op>
struct SparseTable {
    vector<vector<int>> st;
    vector<int> lg;
    Op op;
    SparseTable(const vector<int>& a, Op op) : op(op) {
        int n = a.size();
        lg.assign(n + 1, 0);
        for (int i = 2; i <= n; i++) lg[i] = lg[i / 2] + 1;        // 预处理 floor(log2 i)
        int K = lg[n] + 1;
        st.assign(K, vector<int>(n));
        st[0] = a;
        for (int j = 1; j < K; j++)
            for (int i = 0; i + (1 << j) <= n; i++)
                st[j][i] = op(st[j - 1][i], st[j - 1][i + (1 << (j - 1))]);
    }
    int query(int l, int r) const {                                  // 闭区间 [l, r]
        int k = lg[r - l + 1];
        return op(st[k][l], st[k][r - (1 << k) + 1]);
    }
};
int main() {
    vector<int> a = {3, 1, 4, 1, 5, 9, 2, 6};
    SparseTable mn(a, [](int x, int y) { return min(x, y); });
    SparseTable mx(a, [](int x, int y) { return max(x, y); });
    printf("min[1,6] = %d\n", mn.query(1, 6));
    printf("min[4,7] = %d\n", mn.query(4, 7));
    printf("max[0,3] = %d\n", mx.query(0, 3));
    printf("min[5,5] = %d\n", mn.query(5, 5));
}
```

输出：

```text
min[1,6] = 1
min[4,7] = 2
max[0,3] = 4
min[5,5] = 9
```

`op` 换成 `__gcd` 就得到区间 gcd，换成 `&` 或 `|` 就得到区间与、或。C++17 的类模板参数推导让 `SparseTable mn(a, lambda)` 可以不写模板参数。

## 例题：极差不超过 limit 的最长子数组

求最长的连续子数组，使其中最大值与最小值之差不超过 limit。双指针扩展右端，窗口合法就继续，不合法就收缩左端；每次用两张 ST 表 O(1) 取窗口的最大值和最小值。

```cpp
#include <bits/stdc++.h>
using namespace std;
template <class Op>
struct SparseTable {
    vector<vector<int>> st; vector<int> lg; Op op;
    SparseTable(const vector<int>& a, Op op) : op(op) {
        int n = a.size(); lg.assign(n + 1, 0);
        for (int i = 2; i <= n; i++) lg[i] = lg[i / 2] + 1;
        int K = lg[n] + 1; st.assign(K, vector<int>(n)); st[0] = a;
        for (int j = 1; j < K; j++)
            for (int i = 0; i + (1 << j) <= n; i++)
                st[j][i] = op(st[j - 1][i], st[j - 1][i + (1 << (j - 1))]);
    }
    int query(int l, int r) const { int k = lg[r - l + 1]; return op(st[k][l], st[k][r - (1 << k) + 1]); }
};
int longest(const vector<int>& a, int limit) {
    SparseTable mn(a, [](int x, int y) { return min(x, y); });
    SparseTable mx(a, [](int x, int y) { return max(x, y); });
    int n = a.size(), best = 0, l = 0;
    for (int r = 0; r < n; r++) {
        while (mx.query(l, r) - mn.query(l, r) > limit) l++;
        best = max(best, r - l + 1);
    }
    return best;
}
int main() {
    printf("%d\n", longest({8, 2, 4, 7}, 4));               // 2：[2, 4] 或 [4, 7]
    printf("%d\n", longest({10, 1, 2, 4, 7, 2}, 5));        // 4：[2, 4, 7, 2]
}
```

输出 `2` 和 `4`。这道题也可以用 2.1 篇的两个单调队列做，空间只要 O(n)；ST 表的做法代码更直白，但占 O(n log n) 空间。

## 与线段树、前缀和的比较

| 方法 | 预处理 | 单次查询 | 支持修改 | 支持的运算 |
| --- | --- | --- | --- | --- |
| ST 表 | O(n log n) | O(1) | 否 | 幂等运算（最值、gcd、与、或） |
| 线段树 | O(n) | O(log n) | 是 | 任何满足结合律的运算 |
| 前缀和 | O(n) | O(1) | 否 | 可逆运算（和、异或） |

## 常见坑

- 下标范围：`st[j]` 只有 `n - 2^j + 1` 个有效位置，循环条件写成 `i + (1 << j) <= n`。
- `lg` 数组的大小要到 n，用 `log2()` 浮点函数会慢，也可能有误差，推荐预处理。
- 对和、异或使用 ST 表：重叠部分被重复计入，结果错误。
- 数组被修改后继续用旧表。
- 空间：n = 10^6 时 21 层 × 4 字节 × 10^6 ≈ 84 MB，要先算内存限制。
