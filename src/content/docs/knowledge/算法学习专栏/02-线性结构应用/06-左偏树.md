> 适用版本：C++17。前置：二叉堆（`priority_queue` 的原理）、2.3 并查集。什么时候需要学：题目要求把两个**堆合并**，并且还要继续取最小值/删除最小值。`priority_queue` 只能一个一个插入，合并是 O(n)。

## 要点

- 左偏树（leftist heap）是一棵满足堆性质的二叉树，额外要求“左边更深”：每个节点左儿子的 dist 不小于右儿子的 dist。
- dist(x) 表示从 x 往下走到最近的空节点需要经过的边数：空节点为 0，叶子为 1，其余节点为 `dist(右儿子) + 1`（左偏性质保证右儿子的 dist 较小）。
- 左偏保证**右链**（一直往右儿子走）的长度不超过 log₂(n+1)，所以沿右链合并只要 O(log n)。
- 所有操作都建立在 `merge` 上：插入 = 合并单点，删除最小 = 合并根的两个儿子。
- 需要知道“某个元素在哪个堆”，所以常与并查集一起用。

## 合并的做法

`merge(x, y)` 先让根更小的做新根（以小根堆为例），再把另一个堆并进它的**右子树**，递归下去。回来时如果右子树的 dist 变得比左子树大，就交换左右子树，最后更新 dist。

![左偏树合并：堆 B 并入 A 的右子树，右子树 dist 变大，交换左右子树](/qmx-Gameknowledge/assets/algo/c2-leftist-merge.svg)

图中堆 A 的根是 1（左儿子 6），堆 B 的根是 2（儿子 7、8，dist = 2）。1 < 2，所以 1 当根，B 并入 1 的右子树。此时右子树 dist = 2，左子树 6 的 dist = 1，违反左偏性质，于是交换，最终 1 的 dist = 右儿子 dist + 1 = 2。

为什么复杂度是 O(log n)：`merge` 只沿着两个堆的右链向下走，右链长度都是 O(log n)，每一层 O(1)。

## 模板

```cpp
#include <bits/stdc++.h>
using namespace std;
struct LeftistHeap {                              // 小根堆；节点编号 1..n，0 表示空
    vector<int> ls, rs, dist, val, fa;            // fa：并查集，指向所在堆的堆顶
    vector<char> dead;
    LeftistHeap(const vector<int>& a) {           // a 的下标 0 对应节点 1
        int n = a.size();
        ls.assign(n + 1, 0); rs.assign(n + 1, 0); dist.assign(n + 1, 1);
        val.assign(n + 1, 0); fa.resize(n + 1); dead.assign(n + 1, 0);
        dist[0] = 0;
        for (int i = 1; i <= n; i++) { val[i] = a[i - 1]; fa[i] = i; }
    }
    int find(int x) { while (fa[x] != x) { fa[x] = fa[fa[x]]; x = fa[x]; } return x; }
    int merge(int x, int y) {
        if (!x || !y) return x | y;
        if (val[x] > val[y] || (val[x] == val[y] && x > y)) swap(x, y);   // 值相同按编号，保证确定性
        rs[x] = merge(rs[x], y);
        if (dist[ls[x]] < dist[rs[x]]) swap(ls[x], rs[x]);                // 维持左偏
        dist[x] = dist[rs[x]] + 1;
        return x;
    }
    void unite(int x, int y) {                    // 合并 x、y 所在的堆
        if (dead[x] || dead[y]) return;
        int a = find(x), b = find(y);
        if (a == b) return;
        int r = merge(a, b);
        fa[a] = fa[b] = r;
        fa[r] = r;
    }
    int popMin(int x) {                           // 弹出 x 所在堆的最小值，已删除返回 -1
        if (dead[x]) return -1;
        int r = find(x), res = val[r];
        dead[r] = 1;
        int nr = merge(ls[r], rs[r]);
        fa[r] = nr;                               // 堆顶被删后，r 之后的查找都走到 nr
        if (nr) fa[nr] = nr;
        return res;
    }
};
int main() {
    LeftistHeap h({1, 5, 4, 2, 3});               // 节点 1..5 的初始值
    h.unite(1, 5);
    h.unite(2, 5);
    printf("%d\n", h.popMin(2));                  // 堆里有 {1, 3, 5}，弹出 1
    h.unite(4, 2);
    printf("%d\n", h.popMin(2));                  // 堆里有 {2, 3, 5}，弹出 2
}
```

输出 `1` 和 `2`。这个操作序列对应洛谷 P3377 的样例：节点 1 到 5 的值依次为 1、5、4、2、3；合并 1 和 5，再合并 2 和 5；弹出 2 所在堆的最小值得 1；合并 4 和 2；再弹出 2 所在堆的最小值得 2。

我用随机的“合并、弹出”序列与“每个堆放一个 `multiset`”的暴力解对拍了 3000 组，结果一致。

## 与其他堆比较

| 结构 | 插入 | 取最小 | 删除最小 | 合并 |
| --- | --- | --- | --- | --- |
| 二叉堆 `priority_queue` | O(log n) | O(1) | O(log n) | O(n) |
| 左偏树 | O(log n) | O(1) | O(log n) | O(log n) |
| 配对堆 | 均摊 O(1) | O(1) | 均摊 O(log n) | 均摊 O(1)，代码更短，复杂度的证明较复杂 |

## 常见坑

- `dist[0]` 必须是 0（空节点），叶子的 dist 是 1；若把空节点当 −1 要整体平移，不要混用。
- `merge` 比较根的大小时，值相同要有固定的次序，否则题目要求“值相同取编号小的”时会出错。
- 删除堆顶后，并查集里 `fa[r]` 必须改指新堆顶，否则以后查这个堆里的元素会找到已删除的节点。
- 左偏树是树形的**可合并**堆，不支持按值删除任意节点（需要额外的打标记或懒删除）。
- 以为“左偏”表示整棵树偏向左边：它只约束 dist，左子树的节点数不一定更多。
