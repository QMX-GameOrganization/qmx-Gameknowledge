## 要点

- 字符串哈希把一个字符串映射成一个整数，哈希值不同则字符串一定不同；哈希值相同时，字符串**几乎一定**相同。
- 预处理前缀哈希后，任意子串的哈希可以在 O(1) 内算出，比较两个子串从 O(长度) 降到 O(1)。
- 模数要用 2^61 - 1 这样的大素数，底数要随机；单个 10^9 级的模数在数据量大时会冲突。
- 哈希常与二分配合：长度满足单调性时，二分长度，每次用哈希判断“是否存在”。

## 为什么需要哈希

比较两个子串 `s[l1, r1)` 和 `s[l2, r2)` 是否相等，朴素做法逐字符比较，最坏 O(长度)。如果一道题要做 10^5 次这样的比较，每次比较 10^5 个字符，总共 10^10 次操作，超时。

哈希的想法是：给每个字符串算一个整数“指纹”，比较指纹只需要 O(1)。关键问题是指纹要能**快速得到任意子串的值**，下面的前缀哈希做到了这一点。

## 多项式哈希与前缀哈希

取一个底数 B 和模数 M，把字符串 `s[0..k)` 看成 B 进制的数：

```
H(s) = s[0]·B^(k-1) + s[1]·B^(k-2) + … + s[k-1]   (mod M)
```

定义前缀哈希 `h[i]` 为前 i 个字符的哈希，递推：`h[i+1] = h[i]·B + s[i]`。子串 `s[l, r)` 的哈希是

```
get(l, r) = h[r] - h[l]·B^(r-l)   (mod M)
```

理解这个公式：`h[r]` 是前 r 个字符组成的数，其中前 l 个字符组成的部分被乘了 B^(r-l)（后面又接了 r-l 个字符），减掉这部分就剩下 `s[l, r)` 自己。下图用十进制（B=10）演示，a=1, b=2, c=3：

![用 H[r] 减去 H[l] 乘 B 的 (r-l) 次方得到子串哈希，十进制例子 12312 - 12×1000 = 312](/qmx-Gameknowledge/assets/algo/c7-hash-prefix.svg)

预处理 `h` 和 `pw`（B 的幂）是 O(n)，之后每次 `get` 是 O(1)。

## 模数、底数与冲突

哈希不是精确比较，两个不同的串可能得到同一个值，叫**冲突**。冲突的概率怎么估算：

- 固定两个不同的、长度不超过 n 的串，它们的差是关于 B 的非零多项式，次数小于 n。模素数 M 时，这个多项式最多有 n - 1 个根。底数 B 在 [0, M) 里**随机**选，两个串冲突的概率不超过 (n - 1) / M。
- 如果一道题做 q 次比较，总出错概率不超过 q·n / M。取 M = 10^9 + 7，n = q = 10^5，上界是 10，没有保证意义；取 M = 2^61 - 1 ≈ 2.3×10^18，同样的数据上界约 4×10^-9，可以放心。
- 另一类风险是“生日冲突”：把 m 个不同字符串的哈希放进集合，出现两个相同值的概率约 m² / (2M)。M = 10^9 + 7、m = 10^5 时，期望的冲突对数约为 5，几乎一定会遇到冲突；M = 2^61 - 1、m = 10^6 时约 2×10^-7。

所以本文使用 **M = 2^61 - 1 加随机底数**。有两种常见的替代方案，需要知道它们的缺点：

| 方案 | 做法 | 问题 |
| --- | --- | --- |
| 单模数 10^9+7 | 简单，`long long` 即可 | 数据量大时冲突概率不可忽略 |
| 双模数 | 两个 10^9 级模数，一起比较 | 可用，常数是两倍 |
| 自然溢出（`unsigned long long`） | 不写取模 | 对 2^64 取模，存在 Thue–Morse 串使任意底数都冲突，容易被针对性数据卡掉 |

2^61 - 1 是梅森素数，乘法后可以用移位和加法代替取模，配合 `__uint128_t` 做乘法，既安全又快。

## 代码

完整的哈希模板，加上两个常用函数 `countOcc`（统计模式串出现次数）和 `longestRepeat`（最长重复子串）：

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef unsigned long long ull;
const ull MOD = (1ULL << 61) - 1;   // 梅森素数 2^61 - 1

// a * b % MOD，借助 128 位整数；利用 2^61 ≡ 1 (mod MOD) 做快速取模
ull mulmod(ull a, ull b) {
    __uint128_t t = (__uint128_t)a * b;
    ull r = (ull)(t >> 61) + (ull)(t & MOD);
    if (r >= MOD) r -= MOD;
    return r;
}

struct StrHash {
    vector<ull> h, pw;   // h[i] = 前 i 个字符的哈希；pw[i] = base^i
    StrHash(const string& s, ull base) : h(s.size() + 1, 0), pw(s.size() + 1, 1) {
        for (size_t i = 0; i < s.size(); i++) {
            pw[i + 1] = mulmod(pw[i], base);
            h[i + 1] = mulmod(h[i], base) + (unsigned char)s[i];
            if (h[i + 1] >= MOD) h[i + 1] -= MOD;
        }
    }
    // 子串 s[l, r) 的哈希，O(1)
    ull get(int l, int r) const {
        return (h[r] + MOD - mulmod(h[l], pw[r - l])) % MOD;
    }
};

ull randomBase() {
    static mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());
    return rng() % (MOD - 1000) + 500;   // 随机底数，防止被针对性卡
}

// 文本串 t 中模式串 p 出现的次数（允许重叠）
int countOcc(const string& t, const string& p) {
    int n = t.size(), m = p.size();
    if (m == 0 || m > n) return 0;
    ull base = randomBase();
    StrHash ht(t, base), hp(p, base);
    ull target = hp.get(0, m);
    int cnt = 0;
    for (int i = 0; i + m <= n; i++)
        if (ht.get(i, i + m) == target) cnt++;
    return cnt;
}

// 最长重复子串（出现至少两次，可重叠）。返回 {长度, 其中一次出现的起点}
pair<int, int> longestRepeat(const string& s) {
    int n = s.size();
    StrHash H(s, randomBase());
    auto check = [&](int len) -> int {          // 存在长度 len 的重复子串则返回起点，否则 -1
        unordered_map<ull, int> seen;
        for (int i = 0; i + len <= n; i++) {
            ull x = H.get(i, i + len);
            auto it = seen.find(x);
            if (it != seen.end()) return i;
            seen[x] = i;
        }
        return -1;
    };
    int lo = 0, hi = n - 1, pos = 0;            // 答案长度单调：长度 L 可行则 L-1 也可行
    while (lo < hi) {
        int mid = (lo + hi + 1) / 2;
        int p = check(mid);
        if (p >= 0) { lo = mid; pos = p; }
        else hi = mid - 1;
    }
    return {lo, lo ? pos : 0};
}

int main() {
    string s = "abracadabra";
    StrHash H(s, randomBase());
    // 比较 s[0,4) 与 s[7,11)：都是 "abra"
    cout << "abra == abra ? " << (H.get(0, 4) == H.get(7, 11)) << "\n";
    cout << "abra == brac ? " << (H.get(0, 4) == H.get(1, 5)) << "\n";

    cout << "countOcc(abracadabra, abra) = " << countOcc(s, "abra") << "\n";
    cout << "countOcc(aaaaa, aa) = " << countOcc("aaaaa", "aa") << "\n";

    auto [len, pos] = longestRepeat("banana");
    cout << "banana 最长重复子串: " << "banana"s.substr(pos, len) << " (长度 " << len << ")\n";
    return 0;
}
```

运行结果：

```text
abra == abra ? 1
abra == brac ? 0
countOcc(abracadabra, abra) = 2
countOcc(aaaaa, aa) = 4
banana 最长重复子串: ana (长度 3)
```

几处实现细节：

- `mulmod` 利用 2^61 ≡ 1 (mod 2^61 - 1)：128 位乘积 `t` 写成 `高位 · 2^61 + 低位`，等价于 `高位 + 低位`，再减一次 M 即可。
- 字符直接用它的 ASCII 值参与计算，**不要把 `'a'` 映射成 0**：若 a 映射成 0，则 `"a"`、`"aa"`、`"aaa"` 的哈希全是 0，会冲突。
- `get(l, r)` 的区间是半开的，`r - l` 就是长度。
- 减法先加 `MOD` 再取模，避免出现负数。
- `randomBase()` 用时间做种子。固定底数会被针对性数据卡，比赛中尤其要注意。

## 哈希加二分：最长重复子串

“最长的、在串中出现至少两次的子串”：如果长度 L 的重复子串存在，那么长度 L - 1 的也一定存在（把它截短一位即可），所以答案长度**单调**，可以对长度二分。对每个候选长度 L，用哈希把所有长度为 L 的子串放进哈希表，有重复就说明可行。

![banana 的最长重复子串：L=1,2,3 可行，L=4,5 不可行，二分两次探测得到答案 3](/qmx-Gameknowledge/assets/algo/c7-hash-binary.svg)

每次探测 O(n)，二分 O(log n) 次，总共 O(n log n)。这是哈希最常见的用法：**二分长度 + 哈希判断存在性**。

### 例 1：字符串去重计数（洛谷 P3370）

给 n 个字符串，求不同的字符串有多少个。把每个字符串的哈希值放进集合，集合大小就是答案。

```cpp

const ull MOD = (1ULL << 61) - 1;   // 梅森素数 2^61 - 1

// 洛谷 P3370：给 n 个字符串，求其中不同的字符串有多少个
```

### 例 2：最长公共子串

给两个字符串 a、b，求最长公共子串的长度。最长公共子串也满足长度单调：长度 L 的公共子串存在，则 L - 1 的也存在。二分 L，把 a 的所有长度为 L 的子串哈希放进集合，再检查 b 里有没有。

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef unsigned long long ull;
const ull MOD = (1ULL << 61) - 1;   // 梅森素数 2^61 - 1

// a * b % MOD，借助 128 位整数；利用 2^61 ≡ 1 (mod MOD) 做快速取模
ull mulmod(ull a, ull b) {
    __uint128_t t = (__uint128_t)a * b;
    ull r = (ull)(t >> 61) + (ull)(t & MOD);
    if (r >= MOD) r -= MOD;
    return r;
}

struct StrHash {
    vector<ull> h, pw;   // h[i] = 前 i 个字符的哈希；pw[i] = base^i
    StrHash(const string& s, ull base) : h(s.size() + 1, 0), pw(s.size() + 1, 1) {
        for (size_t i = 0; i < s.size(); i++) {
            pw[i + 1] = mulmod(pw[i], base);
            h[i + 1] = mulmod(h[i], base) + (unsigned char)s[i];
            if (h[i + 1] >= MOD) h[i + 1] -= MOD;
        }
    }
    // 子串 s[l, r) 的哈希，O(1)
    ull get(int l, int r) const {
        return (h[r] + MOD - mulmod(h[l], pw[r - l])) % MOD;
    }
};

ull randomBase() {
    static mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());
    return rng() % (MOD - 1000) + 500;   // 随机底数，防止被针对性卡
}

// 文本串 t 中模式串 p 出现的次数（允许重叠）
int countOcc(const string& t, const string& p) {
    int n = t.size(), m = p.size();
    if (m == 0 || m > n) return 0;
    ull base = randomBase();
    StrHash ht(t, base), hp(p, base);
    ull target = hp.get(0, m);
    int cnt = 0;
    for (int i = 0; i + m <= n; i++)
        if (ht.get(i, i + m) == target) cnt++;
    return cnt;
}

// 最长重复子串（出现至少两次，可重叠）。返回 {长度, 其中一次出现的起点}
pair<int, int> longestRepeat(const string& s) {
    int n = s.size();
    StrHash H(s, randomBase());
    auto check = [&](int len) -> int {          // 存在长度 len 的重复子串则返回起点，否则 -1
        unordered_map<ull, int> seen;
        for (int i = 0; i + len <= n; i++) {
            ull x = H.get(i, i + len);
            auto it = seen.find(x);
            if (it != seen.end()) return i;
            seen[x] = i;
        }
        return -1;
    };
    int lo = 0, hi = n - 1, pos = 0;            // 答案长度单调：长度 L 可行则 L-1 也可行
    while (lo < hi) {
        int mid = (lo + hi + 1) / 2;
        int p = check(mid);
        if (p >= 0) { lo = mid; pos = p; }
        else hi = mid - 1;
    }
    return {lo, lo ? pos : 0};
}

// 最长公共子串：二分长度 L，把 a 的所有长度 L 子串哈希放进集合，看 b 里有没有
int longestCommon(const string& a, const string& b) {
    ull base = randomBase();
    StrHash ha(a, base), hb(b, base);
    auto ok = [&](int L) {
        unordered_set<ull> st;
        for (int i = 0; i + L <= (int)a.size(); i++) st.insert(ha.get(i, i + L));
        for (int i = 0; i + L <= (int)b.size(); i++)
            if (st.count(hb.get(i, i + L))) return true;
        return false;
    };
    int lo = 0, hi = min(a.size(), b.size());
    while (lo < hi) {                              // 长度单调：L 可行则 L-1 可行
        int mid = (lo + hi + 1) / 2;
        if (ok(mid)) lo = mid;
        else hi = mid - 1;
    }
    return lo;
}

int main() {
    string a, b;
    cin >> a >> b;
    cout << longestCommon(a, b) << "\n";
    return 0;
}
```

示例（公共子串是 `cde`）：

输入：

```text
abcdefg
xcdeyz
```

输出：

```text

```

这题也可以用后缀数组或 DP 做（DP 是 O(nm)），哈希加二分是 O((n + m) log(min(n, m)))，写法最短。

## 常见坑

- **固定底数**：在有 hack 机制的平台上会被卡，坚持用随机底数。
- **单模数 10^9+7 加大数据量**：冲突概率不可忽略，改用 2^61 - 1 或双模数。
- **字符映射成 0**：会让不同长度的全 `a` 串冲突。
- **忘记加 `MOD` 就取模**：减法结果为负，`unsigned` 类型会回绕成巨大值，比较时出错。
- **`unordered_map` 以哈希值为键**：个别平台上有针对 `unordered_map` 的数据，必要时改成排序加去重，或给 `unordered_map` 换一个自定义的 hash。
- 哈希只能判断“相等”，不能比较大小；要比较字典序，用后缀数组（7.6）或哈希加二分求 LCP 再比下一个字符。
