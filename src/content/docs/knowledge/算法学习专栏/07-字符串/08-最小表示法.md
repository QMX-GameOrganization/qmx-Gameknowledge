> 适用版本：C++17。前置知识：双指针。**什么时候学**：题目涉及“环形字符串”“循环同构”“旋转之后字典序最小”时。这是本章最短、最好理解的一篇。

## 要点

- 把串首的若干字符移到串尾得到的串叫**循环同构串**（旋转）。长度为 n 的串最多有 n 个不同的旋转。
- **最小表示**：字典序最小的那个旋转。两个串循环同构，当且仅当它们的最小表示相同。
- 朴素做法逐个比较 n 个旋转，O(n²)。双指针法 O(n)。

## 双指针做法

维护两个候选起点 `i`、`j`（`i != j`），以及已经比较过的长度 `k`：旋转 i 和旋转 j 的前 k 个字符相同。每轮比较第 k+1 个字符 `a = s[(i+k) % n]`、`b = s[(j+k) % n]`：

- `a == b`：`k++`，继续。
- `a > b`：旋转 i 的第 k+1 个字符更大。不仅旋转 i 不可能最优，**起点 `i, i+1, …, i+k` 都不可能最优**：对 `0 ≤ x ≤ k`，旋转 `i+x` 和旋转 `j+x` 的前 `k−x` 个字符相同，而第 `k−x+1` 个字符分别是 `s[i+k]` 和 `s[j+k]`，前者更大，所以旋转 `i+x` 比旋转 `j+x` 大。因此令 `i += k + 1`。
- `a < b`：同理 `j += k + 1`。

淘汰之后 `k` 清零。如果 `i == j`，让 `j` 加 1 避开。当 `k` 增长到 n，说明两个候选旋转完全相同（串有周期），任意一个都是最小。最后答案是 `min(i, j)`。

![cabcab 的运行过程：i 从 0 到 1，j 依次淘汰 2、3，最后 i=1 与 j=4 比较 6 个字符全部相同，答案从下标 1 开始：abcabc](/qmx-Gameknowledge/assets/algo/c7-minrot-trace.svg)

**时间 O(n)**：每一轮要么 `k` 加 1，要么 `i` 或 `j` 增加 `k + 1` 并把 `k` 清零。两种情形下，`i + j + k` 每轮都至少增加 1；循环条件保证三个量都小于 n，所以最多 3n 轮。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 最小表示法：返回循环同构串中字典序最小的那个的起点，O(n)
int minRotation(const string& s) {
    int n = s.size();
    int i = 0, j = 1, k = 0;                     // i, j 是两个候选起点，k 是已比较的长度
    while (i < n && j < n && k < n) {
        char a = s[(i + k) % n], b = s[(j + k) % n];
        if (a == b) { k++; continue; }
        if (a > b) i += k + 1;                   // 以 i..i+k 为起点的旋转都不可能最小，直接淘汰
        else j += k + 1;
        if (i == j) j++;
        k = 0;
    }
    return min(i, j);
}

string rotate_(const string& s, int start) { return s.substr(start) + s.substr(0, start); }

// 两个串是否循环同构
bool isRotationOf(const string& a, const string& b) {
    if (a.size() != b.size()) return false;
    return rotate_(a, minRotation(a)) == rotate_(b, minRotation(b));
}

int main() {
    string s = "cabcab";
    int st = minRotation(s);
    cout << s << " 的最小表示从下标 " << st << " 开始: " << rotate_(s, st) << "\n";
    s = "bcaab";
    st = minRotation(s);
    cout << s << " 的最小表示从下标 " << st << " 开始: " << rotate_(s, st) << "\n";
    cout << "abcde 与 cdeab 循环同构? " << isRotationOf("abcde", "cdeab") << "\n";
    cout << "abcde 与 abced 循环同构? " << isRotationOf("abcde", "abced") << "\n";
    return 0;
}
```

运行结果：

```text
cabcab 的最小表示从下标 1 开始: abcabc
bcaab 的最小表示从下标 2 开始: aabbc
abcde 与 cdeab 循环同构? 1
abcde 与 abced 循环同构? 0
```

`isRotationOf` 把两个串都转成最小表示后比较，判断是否循环同构。

## 例题

### 洛谷 P1368（字符串版）

输出一个串所有循环同构串中字典序最小的一个。原题给的是整数序列，只需把 `string` 换成 `vector<int>`，比较的 `char` 换成 `int`，逻辑不变。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 最小表示法：返回循环同构串中字典序最小的那个的起点，O(n)
int minRotation(const string& s) {
    int n = s.size();
    int i = 0, j = 1, k = 0;                     // i, j 是两个候选起点，k 是已比较的长度
    while (i < n && j < n && k < n) {
        char a = s[(i + k) % n], b = s[(j + k) % n];
        if (a == b) { k++; continue; }
        if (a > b) i += k + 1;                   // 以 i..i+k 为起点的旋转都不可能最小，直接淘汰
        else j += k + 1;
        if (i == j) j++;
        k = 0;
    }
    return min(i, j);
}

string rotate_(const string& s, int start) { return s.substr(start) + s.substr(0, start); }

// 两个串是否循环同构
bool isRotationOf(const string& a, const string& b) {
    if (a.size() != b.size()) return false;
    return rotate_(a, minRotation(a)) == rotate_(b, minRotation(b));
}

// 洛谷 P1368 的字符串版：输出 s 的所有循环同构串中字典序最小的一个
int main() {
    string s;
    cin >> s;
    cout << rotate_(s, minRotation(s)) << "\n";
    return 0;
}
```

示例：

输入：

```text
cabcab
```

输出：

```text
abcabc
```

## 适用与不适用

- 适用：最小（最大）旋转、循环同构判定、给环形串规范化后做哈希或去重。
- 最大表示：把比较方向反过来（`a > b` 时淘汰 j，`a < b` 时淘汰 i）。
- 求“最小后缀”“最大后缀”或 Lyndon 分解，思路相近但算法不同（Duval 算法），不在本篇范围。
- 另一种思路：把 `s + s` 的所有长度 n 的子串排序，用后缀数组（7.6）也能得到最小表示，但复杂度更高，写起来也长。

## 常见坑

- **下标取模**：旋转 i 的第 k 个字符是 `s[(i + k) % n]`。
- **`i == j` 的处理**：淘汰某个候选后两者可能相等，必须让其中一个加 1，否则会无限循环。
- **答案取 `min(i, j)`**：循环结束时，较大的那个可能已经超过 n。
- **周期串**：当 k 增长到 n 就应该结束，否则 `i`、`j` 可能一直后移。
