> 适用版本：C++17。前置知识：Trie、DAG 的基本概念、7.2 的 border/后缀链接思想。**什么时候学**：需要统计“子串出现次数”“本质不同的子串/回文串”，且 n 达到 10^5 到 10^6 时。理解门槛是本章最高的一篇，建议读完 7.6 后再学。

## 要点

- **后缀自动机（SAM）**：接受且仅接受 s 的全部后缀的最小自动机，同时它的状态集合覆盖了 s 的全部子串。状态数不超过 2n − 1，转移数不超过 3n − 4。
- 每个状态对应一组**结束位置集合（endpos）**相同的子串；同一状态里的子串互为后缀，长度恰好覆盖一段连续区间。
- 每个状态 v 有 `len[v]`（最长子串长度）和 `link[v]`（后缀链接，指向去掉若干字符后换了 endpos 的状态），状态 v 含 `len[v] − len[link[v]]` 个子串。
- **回文自动机（PAM）**：节点是本质不同的回文串，每加一个字符最多新增一个节点，所以不同的回文子串不超过 n 个。

## 后缀自动机

### endpos 与状态

对 s 的一个子串 t，`endpos(t)` 是 t 在 s 中所有**结束位置**的集合。例如 s = abcbc：`endpos("bc") = {3, 5}`（下标从 1 开始），`endpos("c") = {3, 5}`，所以 `c` 和 `bc` 属于同一个状态；而 `endpos("b") = {2, 4}`，是另一个状态。

把 endpos 相同的子串归为一类，每类一个状态。同一类里的子串：

- 都是其中最长那个的后缀；
- 长度是一段连续区间 `[len[link[v]] + 1, len[v]]`。

`link[v]` 指向“去掉最短的若干字符后，endpos 变大”的那个状态，也就是最长后缀中 endpos 与 v 不同的那个。所有 link 构成一棵树，根是空串状态 0。

![abcbc 的后缀自动机：8 个状态，实线是转移，每个框内标出 len、包含的子串和 link](/qmx-Gameknowledge/assets/algo/c7-sam-abcbc.svg)

### 增量构造

按顺序加入字符 `c`，维护 `last`（整个当前串所在的状态）。

1. 新建状态 `cur`，`len[cur] = len[last] + 1`。
2. 从 `p = last` 沿 link 往上走，对每个还没有 `c` 转移的状态 p，加上转移 `p →c→ cur`。
3. 走到一个已经有 `c` 转移的状态 p，令 `q = next[p][c]`，分三种情形：
   - 没有这样的 p（走到了 -1）：`link[cur] = 0`。
   - `len[p] + 1 == len[q]`：q 里所有子串恰好都是以新字符结尾的合法后缀，`link[cur] = q`。
   - 否则 q 里混着“长度 ≤ len[p]+1”的和更长的两类子串，它们加入新字符后 endpos 不同，需要把 q **克隆**：新状态 `clone`，`len[clone] = len[p] + 1`，复制 q 的转移和 link，然后把沿 link 上所有指向 q 的 `c` 转移改成指向 clone，最后 `link[q] = link[cur] = clone`。
4. `last = cur`。

构造的总时间是均摊 O(n)（乘上字母表大小就是转移数组的初始化开销）。

### 应用

- **本质不同的子串个数**：每个状态 v（除根）含 `len[v] − len[link[v]]` 个子串，求和。abcbc 是 12。
- **子串出现次数**：新建的状态（非克隆）出现次数初值为 1，克隆状态为 0；按 `len` 从大到小，把计数累加给 `link`。状态 v 的计数就是它里面每个子串的出现次数。
- 判断子串：从根按字符走，走不通就不是子串。

## 回文自动机

### 结构

回文自动机（也叫回文树，eertree）的节点是**本质不同的回文串**。有两个根：

- 节点 0：奇根，`len = −1`；
- 节点 1：偶根，`len = 0`。

从节点 u 沿字符 c 到节点 v，表示 `v = c + u + c`，即 u 两侧各加一个 c。每个节点还有 `link`：它的最长**回文真后缀**所在节点。

![abaab 的回文自动机：5 个本质不同的回文串 a、b、aa、aba、baab，虚线是 link](/qmx-Gameknowledge/assets/algo/c7-pam-abaab.svg)

### 增量构造

维护 `last` = 当前整个串的最长回文后缀对应的节点。加入第 i 个字符 `c`：

1. 从 `last` 沿 link 往上，找到最长的回文后缀 `cur`，使得 `s[i − len[cur] − 1] == c`，也就是能在两侧补上 c。奇根满足条件（`i − (−1) − 1 = i`，自己等于自己），所以一定能停下来。
2. 如果 `cur` 没有 c 的转移，新建节点 v，`len[v] = len[cur] + 2`，求它的 link：若 `len[v] == 1`，link 为偶根；否则从 `link[cur]` 继续沿 link 往上，再找一次能补上 c 的位置 `w`，`link[v] = next[w][c]`。**先求 link，后挂边。**
3. `last = next[cur][c]`，并给它的计数加 1。

关键性质：加入一个字符，最多新增一个本质不同的回文串（新增的只可能是以这个字符结尾的最长回文后缀）。所以节点数 ≤ n + 2，构造均摊 O(n)。

出现次数的累加：节点按创建顺序，`link` 总是指向更早创建的节点，所以倒序遍历，`cnt[link[v]] += cnt[v]`。

## 代码

SAM 和 PAM 放在同一个程序里：

```cpp
#include <bits/stdc++.h>
using namespace std;

// ================= 后缀自动机 =================
struct SAM {
    struct State { int len, link; array<int, 26> next; };
    vector<State> st;
    vector<long long> cnt;                       // cnt[v]：状态 v 对应的子串在原串中的出现次数
    int last;

    int newState(int len, int link) {
        State x;
        x.len = len; x.link = link;
        x.next.fill(-1);
        st.push_back(x);
        cnt.push_back(0);
        return (int)st.size() - 1;
    }
    SAM() { last = newState(0, -1); }

    void extend(char ch) {
        int c = ch - 'a';
        int cur = newState(st[last].len + 1, 0);
        cnt[cur] = 1;                            // 新前缀结束于此：出现 1 次（克隆出来的状态初值为 0）
        int p = last;
        while (p != -1 && st[p].next[c] == -1) { st[p].next[c] = cur; p = st[p].link; }
        if (p == -1) st[cur].link = 0;
        else {
            int q = st[p].next[c];
            if (st[p].len + 1 == st[q].len) st[cur].link = q;
            else {                               // q 里混了长度不同、结束位置不同的子串：拆出克隆
                int clone = newState(st[p].len + 1, st[q].link);
                st[clone].next = st[q].next;
                while (p != -1 && st[p].next[c] == q) { st[p].next[c] = clone; p = st[p].link; }
                st[q].link = st[cur].link = clone;
            }
        }
        last = cur;
    }
    // 按 len 从大到小把出现次数沿 link 累加到父亲
    void calcCount() {
        vector<int> ord(st.size());
        iota(ord.begin(), ord.end(), 0);
        sort(ord.begin(), ord.end(), [&](int a, int b) { return st[a].len > st[b].len; });
        for (int v : ord) if (st[v].link >= 0) cnt[st[v].link] += cnt[v];
    }
    // 本质不同的子串个数：每个状态贡献 len[v] - len[link[v]] 个
    long long distinctSubstrings() const {
        long long total = 0;
        for (size_t v = 1; v < st.size(); v++) total += st[v].len - st[st[v].link].len;
        return total;
    }
    // 子串 t 的出现次数（需先 calcCount）
    long long occurrences(const string& t) const {
        int u = 0;
        for (char ch : t) {
            u = st[u].next[ch - 'a'];
            if (u < 0) return 0;
        }
        return cnt[u];
    }
};

// ================= 回文自动机（回文树） =================
struct PAM {
    vector<array<int, 26>> nx;
    vector<int> len, link;
    vector<long long> cnt;                       // cnt[v]：回文串 v 在原串中的出现次数（需先 calcCount）
    string s;
    int last;                                    // 当前整个串的最长回文后缀对应的节点

    int newNode(int l) {
        array<int, 26> a;
        a.fill(-1);
        nx.push_back(a);
        len.push_back(l);
        link.push_back(0);
        cnt.push_back(0);
        return (int)nx.size() - 1;
    }
    PAM() {
        newNode(-1);                             // 节点 0：奇根，len = -1
        newNode(0);                              // 节点 1：偶根，len = 0
        link[1] = 0;
        last = 1;
    }
    // 从 v 出发沿 link 找最长的、能在两侧补上 s[i] 的回文后缀
    int getLink(int v, int i) const {
        while (i - len[v] - 1 < 0 || s[i - len[v] - 1] != s[i]) v = link[v];
        return v;
    }
    void add(char ch) {
        s.push_back(ch);
        int i = (int)s.size() - 1, c = ch - 'a';
        int cur = getLink(last, i);
        if (nx[cur][c] < 0) {
            int v = newNode(len[cur] + 2);
            if (len[v] == 1) link[v] = 1;        // 单个字符，后缀回文是空串
            else link[v] = nx[getLink(link[cur], i)][c];
            nx[cur][c] = v;                      // 先算 link 再挂边，否则可能自己找到自己
        }
        last = nx[cur][c];
        cnt[last]++;
    }
    // 节点按创建顺序，link 指向的总是更早创建的节点：倒序累加即可
    void calcCount() {
        for (int v = (int)nx.size() - 1; v >= 2; v--) cnt[link[v]] += cnt[v];
    }
    int distinctPalindromes() const { return (int)nx.size() - 2; }
};

int main() {
    string s = "abcbc";
    SAM sam;
    for (char ch : s) sam.extend(ch);
    sam.calcCount();
    cout << "状态数 = " << sam.st.size() << "\n";
    cout << "abcbc 本质不同的子串个数 = " << sam.distinctSubstrings() << "\n";
    cout << "bc 出现 " << sam.occurrences("bc") << " 次, c 出现 " << sam.occurrences("c")
         << " 次, cb 出现 " << sam.occurrences("cb") << " 次, abd 出现 " << sam.occurrences("abd") << " 次\n";

    PAM pam;
    string t = "abaab";
    for (char ch : t) pam.add(ch);
    pam.calcCount();
    cout << t << " 本质不同的回文子串个数 = " << pam.distinctPalindromes() << "\n";
    long long total = 0;
    for (size_t v = 2; v < pam.nx.size(); v++) total += pam.cnt[v];
    cout << t << " 回文子串总个数（按位置）= " << total << "\n";
    return 0;
}
```

运行结果：

```text
状态数 = 8
abcbc 本质不同的子串个数 = 12
bc 出现 2 次, c 出现 2 次, cb 出现 1 次, abd 出现 0 次
abaab 本质不同的回文子串个数 = 5
abaab 回文子串总个数（按位置）= 8
```

abcbc 的 SAM 有 8 个状态（含根），12 个本质不同的子串。abaab 的 PAM 有 5 个本质不同的回文串：a、b、aa、aba、baab；回文子串按位置计共 8 个。

## 例题

### 洛谷 P3804：后缀自动机模板

求所有出现次数不少于 2 的子串中，（出现次数 × 长度）的最大值。状态 v 里最长的子串长度是 `len[v]`，它的出现次数是 `cnt[v]`，对每个状态取 `cnt[v] × len[v]` 的最大值即可（状态里更短的子串出现次数相同，长度更短，不会更优）。

```cpp
#include <bits/stdc++.h>
using namespace std;

// ================= 后缀自动机 =================
struct SAM {
    struct State { int len, link; array<int, 26> next; };
    vector<State> st;
    vector<long long> cnt;                       // cnt[v]：状态 v 对应的子串在原串中的出现次数
    int last;

    int newState(int len, int link) {
        State x;
        x.len = len; x.link = link;
        x.next.fill(-1);
        st.push_back(x);
        cnt.push_back(0);
        return (int)st.size() - 1;
    }
    SAM() { last = newState(0, -1); }

    void extend(char ch) {
        int c = ch - 'a';
        int cur = newState(st[last].len + 1, 0);
        cnt[cur] = 1;                            // 新前缀结束于此：出现 1 次（克隆出来的状态初值为 0）
        int p = last;
        while (p != -1 && st[p].next[c] == -1) { st[p].next[c] = cur; p = st[p].link; }
        if (p == -1) st[cur].link = 0;
        else {
            int q = st[p].next[c];
            if (st[p].len + 1 == st[q].len) st[cur].link = q;
            else {                               // q 里混了长度不同、结束位置不同的子串：拆出克隆
                int clone = newState(st[p].len + 1, st[q].link);
                st[clone].next = st[q].next;
                while (p != -1 && st[p].next[c] == q) { st[p].next[c] = clone; p = st[p].link; }
                st[q].link = st[cur].link = clone;
            }
        }
        last = cur;
    }
    // 按 len 从大到小把出现次数沿 link 累加到父亲
    void calcCount() {
        vector<int> ord(st.size());
        iota(ord.begin(), ord.end(), 0);
        sort(ord.begin(), ord.end(), [&](int a, int b) { return st[a].len > st[b].len; });
        for (int v : ord) if (st[v].link >= 0) cnt[st[v].link] += cnt[v];
    }
    // 本质不同的子串个数：每个状态贡献 len[v] - len[link[v]] 个
    long long distinctSubstrings() const {
        long long total = 0;
        for (size_t v = 1; v < st.size(); v++) total += st[v].len - st[st[v].link].len;
        return total;
    }
    // 子串 t 的出现次数（需先 calcCount）
    long long occurrences(const string& t) const {
        int u = 0;
        for (char ch : t) {
            u = st[u].next[ch - 'a'];
            if (u < 0) return 0;
        }
        return cnt[u];
    }
};

// ================= 回文自动机（回文树） =================
struct PAM {
    vector<array<int, 26>> nx;
    vector<int> len, link;
    vector<long long> cnt;                       // cnt[v]：回文串 v 在原串中的出现次数（需先 calcCount）
    string s;
    int last;                                    // 当前整个串的最长回文后缀对应的节点

    int newNode(int l) {
        array<int, 26> a;
        a.fill(-1);
        nx.push_back(a);
        len.push_back(l);
        link.push_back(0);
        cnt.push_back(0);
        return (int)nx.size() - 1;
    }
    PAM() {
        newNode(-1);                             // 节点 0：奇根，len = -1
        newNode(0);                              // 节点 1：偶根，len = 0
        link[1] = 0;
        last = 1;
    }
    // 从 v 出发沿 link 找最长的、能在两侧补上 s[i] 的回文后缀
    int getLink(int v, int i) const {
        while (i - len[v] - 1 < 0 || s[i - len[v] - 1] != s[i]) v = link[v];
        return v;
    }
    void add(char ch) {
        s.push_back(ch);
        int i = (int)s.size() - 1, c = ch - 'a';
        int cur = getLink(last, i);
        if (nx[cur][c] < 0) {
            int v = newNode(len[cur] + 2);
            if (len[v] == 1) link[v] = 1;        // 单个字符，后缀回文是空串
            else link[v] = nx[getLink(link[cur], i)][c];
            nx[cur][c] = v;                      // 先算 link 再挂边，否则可能自己找到自己
        }
        last = nx[cur][c];
        cnt[last]++;
    }
    // 节点按创建顺序，link 指向的总是更早创建的节点：倒序累加即可
    void calcCount() {
        for (int v = (int)nx.size() - 1; v >= 2; v--) cnt[link[v]] += cnt[v];
    }
    int distinctPalindromes() const { return (int)nx.size() - 2; }
};

// 洛谷 P3804：求所有出现次数不少于 2 的子串中，（出现次数 × 长度）的最大值
int main() {
    string s;
    cin >> s;
    SAM sam;
    for (char ch : s) sam.extend(ch);
    sam.calcCount();
    long long best = 0;
    for (size_t v = 1; v < sam.st.size(); v++)
        if (sam.cnt[v] > 1) best = max(best, sam.cnt[v] * sam.st[v].len);   // 状态里最长的子串 len[v] 最优
    cout << best << "\n";
    return 0;
}
```

示例（`abb` 出现 2 次，长度 3，乘积 6）：

输入：

```text
abbabb
```

输出：

```text
6
```

## 适用与不适用

- 适用：子串出现次数、本质不同的子串数、两个或多个串的最长公共子串（对一个串建 SAM，拿另一个串去走，或者用广义 SAM）、字典序第 k 小的子串、回文串的计数类问题。
- 空间：SAM 的转移表是 `2n × 字母表大小`。n = 10^6、字母表 26 时仅转移表就约 200 MB，需要换成 `map` 存边，或者改用后缀数组。
- 不要用 SAM 解决需要“按字典序直接枚举后缀”的问题，后缀数组更直接。

## 常见坑

- **克隆时忘了复制 `next`**：克隆状态要继承 q 的全部转移。
- **vector 引用失效**：`st.push_back(...)` 之后，之前取到的 `st[p]` 引用都可能失效，用下标反复访问，不要保存引用。
- **PAM 先挂边再求 link**：`link[v]` 查找时如果 `cur` 的 c 边已经指向 v，会找到自己，得到错误的 link。
- **出现次数的累加顺序**：SAM 按 `len` 降序，PAM 按创建顺序倒序，反了就会少加。
- SAM 的“出现次数”只对非克隆状态初始化为 1。
