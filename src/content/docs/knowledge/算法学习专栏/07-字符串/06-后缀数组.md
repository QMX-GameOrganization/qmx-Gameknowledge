> 适用版本：C++17。前置知识：排序、计数排序；7.1 哈希加二分可以对照着看。**什么时候学**：题目涉及“所有子串”“两个后缀的公共前缀”“第 k 小的子串”之类的整体性质，且不想写后缀自动机时。

## 要点

- 后缀数组 `sa[i]` 是字典序排名第 i 的后缀的起点；`rank[j]` 是起点为 j 的后缀的排名。
- 倍增法：按前 k 个字符排好序之后，用 `(rk[i], rk[i+k])` 这对排名作为键，就能得到按前 2k 个字符的排序。共 O(log n) 轮。
- `height[i]`：排名第 i 与第 i-1 的后缀的最长公共前缀（LCP）。Kasai 算法在 O(n) 内算出。
- 任意两个后缀的 LCP 等于 `height` 区间上的最小值（用 2.5 的 ST 表可以 O(1) 查询）。
- 本质不同的子串个数 = n(n+1)/2 − Σ height。

## 后缀数组与 height

把串 `banana` 的 6 个后缀按字典序排序：

![banana 的 6 个后缀排序后得到 sa = 5 3 1 0 4 2，height = 0 1 3 0 0 2](/qmx-Gameknowledge/assets/algo/c7-sa-banana.svg)

排名相邻的后缀，公共前缀往往很长；而一个子串一定是某个后缀的前缀。所以“有多少个不同的子串”“哪个子串出现最多”这类问题，可以转化成对排好序的后缀做扫描。

## 倍增法构造

直接对 n 个后缀做字符串比较排序，最坏 O(n² log n)。倍增法利用了一个事实：长度为 2k 的前缀可以看作两个长度为 k 的前缀拼起来，所以只要知道所有位置“前 k 个字符”的排名 `rk`，就能用二元组 `(rk[i], rk[i+k])` 比较“前 2k 个字符”，其中 `i+k >= n` 时第二项看作 -1（比任何排名都小）。

![banana 的倍增过程：首字符排名、首 2 个字符排名、首 4 个字符排名；第三行排名全不相同，结束](/qmx-Gameknowledge/assets/algo/c7-sa-doubling.svg)

每一轮用两次计数排序，实现双关键字排序：

1. **按第二关键字排序**：没有第二关键字（`i + k >= n`）的后缀最小，按下标放最前面；其余的按上一轮的 `sa` 顺序，每个下标减去 k 得到。这一步不需要比较，O(n)。
2. **按第一关键字稳定地计数排序**：对第一步得到的顺序，按 `rk` 做稳定的计数排序，相同 `rk` 的后缀保持第二关键字的顺序。
3. **重新编号**：扫描一遍，二元组相同的后缀得到相同的新排名。如果新排名个数等于 n，说明已经全部区分，结束。

一共 O(log n) 轮，每轮 O(n + m)（m 是排名取值个数，不超过 max(n, 256)），所以 **O(n log n)**。

## height 数组与 Kasai 算法

直接求每对相邻后缀的 LCP 最坏 O(n²)。Kasai 算法按**后缀起点** i = 0, 1, 2, … 的顺序处理，利用一个性质：

> 设 `h(i) = height[rank[i]]`，则 `h(i+1) >= h(i) - 1`。

直观理由：如果后缀 i 与它排名前一位的后缀 j 有长度为 h 的公共前缀，那么去掉首字母后，后缀 i+1 和后缀 j+1 的公共前缀长度为 h - 1，并且后缀 j+1 的排名一定在后缀 i+1 之前（不会在其之后）。所以 `h(i+1)` 至少是 h - 1，可以从 h - 1 开始比较，h 每步最多减 1、总共最多增加 2n，总比较次数 O(n)。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 倍增 + 计数排序构造后缀数组，O(n log n)。sa[i] = 排名第 i 的后缀的起点
vector<int> buildSA(const string& s) {
    int n = s.size(), m = 256;                   // m：当前排名（关键字）的取值个数
    vector<int> sa(n), rk(n), tmp(n), cnt(max(m, n) + 1);
    for (int i = 0; i < n; i++) { rk[i] = (unsigned char)s[i]; cnt[rk[i]]++; }
    for (int i = 1; i < m; i++) cnt[i] += cnt[i - 1];
    for (int i = n - 1; i >= 0; i--) sa[--cnt[rk[i]]] = i;      // 按首字符排序
    for (int k = 1; ; k <<= 1) {
        // 第二关键字排序：没有第二关键字（i+k>=n）的最小，排在最前；其余按 sa 的顺序平移 k
        int p = 0;
        for (int i = n - k; i < n; i++) tmp[p++] = i;
        for (int i = 0; i < n; i++) if (sa[i] >= k) tmp[p++] = sa[i] - k;
        // 第一关键字计数排序（稳定）
        fill(cnt.begin(), cnt.begin() + m, 0);
        for (int i = 0; i < n; i++) cnt[rk[i]]++;
        for (int i = 1; i < m; i++) cnt[i] += cnt[i - 1];
        for (int i = n - 1; i >= 0; i--) sa[--cnt[rk[tmp[i]]]] = tmp[i];
        // 重新编号：(rk[x], rk[x+k]) 相同的后缀排名相同
        auto second = [&](int x) { return x + k < n ? rk[x + k] : -1; };
        vector<int> nrk(n);
        p = 0;
        nrk[sa[0]] = 0;
        for (int i = 1; i < n; i++) {
            int a = sa[i - 1], b = sa[i];
            if (rk[a] != rk[b] || second(a) != second(b)) p++;
            nrk[b] = p;
        }
        rk = nrk;
        m = p + 1;
        if (m == n) break;                       // 排名全不相同，排序完成
    }
    return sa;
}

// Kasai 算法求 height：height[i] = LCP(sa[i-1], sa[i])，height[0] = 0，O(n)
vector<int> buildHeight(const string& s, const vector<int>& sa) {
    int n = s.size(), h = 0;
    vector<int> rank_(n), height(n, 0);
    for (int i = 0; i < n; i++) rank_[sa[i]] = i;
    for (int i = 0; i < n; i++) {
        if (rank_[i] == 0) { h = 0; continue; }
        int j = sa[rank_[i] - 1];                // 排在 i 前一名的后缀
        while (i + h < n && j + h < n && s[i + h] == s[j + h]) h++;
        height[rank_[i]] = h;
        if (h > 0) h--;                          // 关键性质：height[rank[i+1]] >= height[rank[i]] - 1
    }
    return height;
}

// 模式串 p 在 s 中的出现次数：在 sa 上二分出以 p 为前缀的后缀区间
int countBySA(const string& s, const vector<int>& sa, const string& p) {
    int m = p.size();
    auto lo = partition_point(sa.begin(), sa.end(), [&](int i) { return s.compare(i, m, p) < 0; });
    auto hi = partition_point(lo, sa.end(), [&](int i) { return s.compare(i, m, p) == 0; });
    return hi - lo;
}

int main() {
    string s = "banana";
    vector<int> sa = buildSA(s), height = buildHeight(s, sa);
    int n = s.size();
    cout << "排名 sa height 后缀\n";
    for (int i = 0; i < n; i++)
        cout << i << "    " << sa[i] << "  " << height[i] << "      " << s.substr(sa[i]) << "\n";

    long long distinct = (long long)n * (n + 1) / 2 - accumulate(height.begin(), height.end(), 0LL);
    cout << "本质不同的子串个数 = " << distinct << "\n";
    int best = max_element(height.begin(), height.end()) - height.begin();
    cout << "最长重复子串 = " << s.substr(sa[best], height[best]) << "\n";
    cout << "ana 出现 " << countBySA(s, sa, "ana") << " 次\n";
    return 0;
}
```

4    4  0      na

三个常用操作都从 `sa` 和 `height` 得到：

- 本质不同的子串个数：每个后缀 `sa[i]` 贡献 `n - sa[i]` 个前缀，其中前 `height[i]` 个已经被排名更靠前的后缀算过，所以总数 = Σ(n − sa[i]) − Σ height = n(n+1)/2 − Σ height。banana：21 − 6 = 15。
- 最长重复子串（至少出现两次）：`max(height)` 对应的公共前缀。banana 是 `ana`。
- 模式串出现次数：模式串是若干个后缀的前缀，这些后缀在 `sa` 里连续，用二分找到这段区间的两端，`countBySA` 用 `partition_point` 实现。

## 例题

### 洛谷 P3809 与 P2408

P3809：输出后缀排序结果（起点从 1 开始）。P2408：求本质不同的子串个数。一个程序同时给出两个答案。

## 适用与不适用

- 适用：不同子串个数、最长重复子串（可重叠/不可重叠，后者要二分加分组）、最长公共子串（两个串用分隔符拼起来）、按字典序第 k 小的子串。
- 与后缀自动机（7.7）相比：后缀数组的空间 O(n)，常数小，能直接得到字典序；后缀自动机更擅长“出现次数”“多个串的公共子串”等需要状态合并的问题。
- n 到 10^6 时，O(n log n) 的倍增法可能偏慢，可以换成 SA-IS 算法（线性），原理复杂，本篇不展开。

## 常见坑

- **计数排序的桶大小**：第一轮的排名取值最多 256（字符），之后最多 n，所以桶数组要开 `max(256, n) + 1`。
- **第二关键字排序**：忘记把 `i >= n - k` 的后缀放最前面，会漏掉短后缀。
- **终止条件**：排名全不同（`m == n`）就退出，而不是循环固定次数。
- **`height[0]` 的约定**：这里取 0。用公式 `n(n+1)/2 − Σ height` 时要确认 `height[0]` 没有被算进去其他值。
- **用 `string::substr` 比较后缀**：只能用于对拍，`substr` 会复制字符串。
