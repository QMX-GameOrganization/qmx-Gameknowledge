> 适用版本：C++17。前置知识：7.2 KMP（前缀函数、失配回退）、4.3 Trie、BFS。**什么时候学**：有多个模式串（几十个到几十万个）要在同一段文本里匹配时。只有一个模式串，KMP 就够了。

## 要点

- AC 自动机 = Trie + fail 指针。fail 指针对多个模式串的作用，等价于 KMP 里的前缀函数。
- 节点 u 的 `fail[u]`：u 所表示的串的**最长真后缀**中，同样存在于 Trie 里的那个节点。
- 用 BFS 按深度求 fail，同时把缺失的转移补全，得到一个确定的自动机，文本每个字符只走一步。
- 统计每个模式串的出现次数：先给文本走到的节点计数，再按 BFS 逆序沿 fail 累加。
- 时间 O(Σ|模式串| × 字母表大小 + |文本|)。

## 问题与想法

n 个模式串，一段文本，要找出每个模式串的出现。逐个跑 KMP 是 O(n × |文本|)，模式串很多时太慢。

想法：把所有模式串插入一棵 Trie，共享相同前缀。在文本上同时匹配所有模式串，匹配到某个节点时，当前文本末尾的若干字符等于这个节点代表的串。失配时，要回退到“当前文本末尾仍然匹配的、最长的 Trie 中的串”，这正是 fail 指针。

## Trie 与 fail 指针

![he、she、his、hers 的 Trie，以及 fail(sh)=h、fail(she)=he 两条 fail 指针](/qmx-Gameknowledge/assets/algo/c7-ac-trie.svg)

以 `she` 为例，它的真后缀有 `he`、`e`、空串。`he` 在 Trie 里，所以 `fail(she) = he`。这意味着：只要文本走到了 `she`，文本末尾也一定匹配了 `he`，所以到达 `she` 的同时也要算上 `he` 出现了一次。

**求 fail**：用 BFS 按深度从小到大处理。设 u 的父亲是 p，u 是 p 经字符 c 到达的孩子：

```
fail[u] = nx[ fail[p] ][c]
```

意思是：从 p 的 fail 节点出发，走同一个字符 c。因为 `fail[p]` 比 p 浅，已经处理完毕，并且它的转移已经被补全，所以 `nx[fail[p]][c]` 就是答案。深度为 1 的节点，fail 都是根。

**补全转移**：对于节点 u 没有字符 c 的边，令 `nx[u][c] = nx[fail[u]][c]`，即“沿 fail 链找到的第一个有 c 边的位置”。根上缺失的边指回根。补全之后，文本匹配时对每个字符只需要一次 `u = nx[u][c]`，没有任何回退循环，成为一个确定的自动机。

## 在文本上匹配与计数

![扫描 ushers：到达 she 的同时 he 也出现，最后到达 hers，合计 he、she、hers 各 1 次，his 为 0](/qmx-Gameknowledge/assets/algo/c7-ac-match.svg)

读文本的每个字符，转移到新节点 u。此时以这个字符结尾的、所有的模式串出现，包括 u 本身以及 fail 链 `fail[u], fail[fail[u]], …` 上的所有模式串结尾。逐个沿 fail 链数代价太高（链可能很长）。

改成两步：

1. 扫描文本，每次到达 u 就 `vis[u]++`。
2. 按 BFS 的**逆序**处理节点，执行 `vis[fail[v]] += vis[v]`。逆序保证 v 的计数在累加给 fail 父亲之前已经收齐（所有深度更大、fail 指向 v 的节点都在 v 之前处理过）。

最后，模式串 i 的出现次数就是 `vis[它的结尾节点]`。相同的模式串会落到同一个结尾节点，自然得到相同的答案。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct ACAutomaton {
    vector<array<int, 26>> nx;                   // nx[u][c]：建好后是完整的转移（含失配后的跳转）
    vector<int> fail, order;                     // fail 指针；order 是除根外节点的 BFS 顺序

    ACAutomaton() { newNode(); }
    int newNode() {
        array<int, 26> a;
        a.fill(-1);
        nx.push_back(a);
        return (int)nx.size() - 1;
    }
    // 插入模式串，返回它的结尾节点
    int insert(const string& s) {
        int u = 0;
        for (char ch : s) {
            int c = ch - 'a';
            if (nx[u][c] < 0) {
                int v = newNode();
                nx[u][c] = v;
            }
            u = nx[u][c];
        }
        return u;
    }
    void build() {
        fail.assign(nx.size(), 0);
        queue<int> q;
        for (int c = 0; c < 26; c++) {
            if (nx[0][c] < 0) nx[0][c] = 0;      // 根没有的边，回到根
            else q.push(nx[0][c]);               // 深度 1 的节点 fail 为根
        }
        while (!q.empty()) {
            int u = q.front(); q.pop();
            order.push_back(u);
            for (int c = 0; c < 26; c++) {
                int v = nx[u][c];
                if (v < 0) nx[u][c] = nx[fail[u]][c];          // 补全转移：沿 fail 链找到的第一个有 c 边的位置
                else { fail[v] = nx[fail[u]][c]; q.push(v); }  // v 的 fail = fail[u] 走 c 到达的节点
            }
        }
    }
};

// 对每个模式串，返回它在 text 中出现的次数（允许重叠、允许模式串重复）
vector<long long> countEach(const vector<string>& pats, const string& text) {
    ACAutomaton ac;
    vector<int> endNode;
    for (auto& p : pats) endNode.push_back(ac.insert(p));
    ac.build();
    vector<long long> vis(ac.nx.size(), 0);
    int u = 0;
    for (char ch : text) {
        u = ac.nx[u][ch - 'a'];
        vis[u]++;                                // 文本在 u 处“结束”了一次
    }
    // u 处结束意味着 fail 链上所有节点也都结束了一次：按 BFS 逆序把计数累加到 fail 父亲
    for (int i = (int)ac.order.size() - 1; i >= 0; i--) {
        int v = ac.order[i];
        vis[ac.fail[v]] += vis[v];
    }
    vector<long long> res;
    for (int e : endNode) res.push_back(vis[e]);
    return res;
}

int main() {
    vector<string> pats = {"he", "she", "his", "hers"};
    string text = "ushers";
    vector<long long> res = countEach(pats, text);
    for (size_t i = 0; i < pats.size(); i++)
        cout << pats[i] << " 出现 " << res[i] << " 次\n";
    return 0;
}
```

运行结果：

```text
he 出现 1 次
she 出现 1 次
his 出现 0 次
hers 出现 1 次
```

实现要点：

- `nx[u][c] = -1` 表示还没有这条边；`build` 之后所有 -1 都被替换成了有效节点。
- `order` 保存除根以外的节点的 BFS 顺序，供逆序累加使用。
- `vis` 用 `long long`，文本很长时出现次数会超过 `int`。
- `insert` 里每次调用 `newNode()` 后再给 `nx[u][c]` 赋值，避免 `push_back` 导致的引用失效。

## 例题

### 洛谷 P3808：AC 自动机（简单版）

给 n 个模式串和一个文本串，问有多少个**不同**的模式串在文本中出现过。直接复用 `countEach`，用集合去掉相同的模式串。

```cpp
#include <bits/stdc++.h>
using namespace std;

struct ACAutomaton {
    vector<array<int, 26>> nx;                   // nx[u][c]：建好后是完整的转移（含失配后的跳转）

    ACAutomaton() { newNode(); }
    int newNode() {
        array<int, 26> a;
        a.fill(-1);
        nx.push_back(a);
        return (int)nx.size() - 1;
    }
    // 插入模式串，返回它的结尾节点
    int insert(const string& s) {
        int u = 0;
        for (char ch : s) {
            int c = ch - 'a';
            if (nx[u][c] < 0) {
                int v = newNode();
                nx[u][c] = v;
            }
            u = nx[u][c];

            }
        }
    }

// 对每个模式串，返回它在 text 中出现的次数（允许重叠、允许模式串重复）
vector<long long> countEach(const vector<string>& pats, const string& text) {
    ACAutomaton ac;
    vector<int> endNode;

        vis[ac.fail[v]] += vis[v];
    }

    for (int e : endNode) res.push_back(vis[e]);
    return res;

// 洛谷 P3808：n 个模式串，一个文本串，问有多少个不同的模式串在文本中出现过
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<string> pats(n);
    for (auto& p : pats) cin >> p;
    string text;
    cin >> text;
    vector<long long> res = countEach(pats, text);
    set<string> counted;
    int ans = 0;
    for (int i = 0; i < n; i++)
        if (res[i] > 0 && counted.insert(pats[i]).second) ans++;   // 相同的模式串只算一次
    cout << ans << "\n";
    return 0;
}
```

示例（模式串 `a`、`aa`、`aa`，文本 `aaa`，不同的出现过的模式串是 `a` 和 `aa`）：

输入：

```text
3
a
aa
aa
aaa
```

输出：

```text
2
```

## 适用与不适用

- 适用：模式串集合固定，文本很长或有多段；需要统计每个模式串的出现次数；在 AC 自动机上做 DP（“长度为 L 的串中不含任何禁用词的个数”）。
- 字母表很大（如整数序列、Unicode）时，`array<int, 26>` 太占空间，改用 `map` 或哈希表存边，转移补全需要换成沿 fail 链回退的写法。
- 模式串需要动态增加或删除时，AC 自动机要重建，需要二进制分组之类的技巧，不在本篇范围。

## 常见坑

- **求 fail 和补全转移要在同一次 BFS 里按深度进行**：求 `fail[v]` 用到 `nx[fail[p]][c]`，要求 `fail[p]` 这一行已经补全；因为 `fail[p]` 比 p 浅，BFS 保证它先被处理。写成递归（DFS）会读到还是 -1 的边。
- **BFS 顺序错误**：fail 必须在比它浅的节点都处理完后才能求，所以必须 BFS，不能 DFS。
- **累加方向反了**：必须先累加深度大的节点，再累加深度小的。
- **重复模式串**：只按结尾节点记录“出现次数”会丢掉重复项，需要保存每个模式串各自的结尾节点。
- 多模式串里有一个是另一个的前缀（如 `he` 和 `hers`）完全正常，Trie 上它们共享路径。
