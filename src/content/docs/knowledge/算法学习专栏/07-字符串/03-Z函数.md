> 适用版本：C++17。前置知识：7.2 KMP 中 border 的概念会让这篇更好懂，但不是必需。

## 要点

- `z[i]`：字符串 `s` 与它的后缀 `s[i..]` 的最长公共前缀长度。约定 `z[0] = n`。
- 求 z 数组的关键是维护一个**窗口** `[l, r)`：它是目前已知的、最靠右的、与 `s` 的前缀相等的区间。窗口里的位置可以直接抄已算好的 z 值。
- 时间 O(n)，因为 r 只增不减。
- 模式匹配：对 `pat + '#' + text` 求 z 数组，`z[i] == |pat|` 的位置就是一次匹配。

## 定义

![s=aabxaab：从下标 4 开始的后缀 aab... 与 s 的前缀 aab 相同，所以 z[4]=3](/qmx-Gameknowledge/assets/algo/c7-z-def.svg)

`s = aabxaab` 时，`z = 7 1 0 0 3 1 0`：

- `z[1] = 1`：`s[1..] = abxaab`，与 `s = aabxaab` 的公共前缀是 `a`。
- `z[4] = 3`：`s[4..] = aab`，与 `s` 的前缀 `aab` 完全相同。

## 线性算法：窗口 [l, r)

朴素做法对每个 i 从头比较，最坏 O(n²)。优化思路和 Manacher（7.4）相似：利用已经算出的信息。

维护 `[l, r)`：所有 `j < i` 中使 `j + z[j]` 最大的那个 j 作为 l，r = l + z[l]。窗口的含义是 `s[l, r) == s[0, r - l)`。

处理新位置 i 时：

1. 如果 `i < r`：i 落在窗口里。窗口内 `s[i]` 对应前缀里的 `s[i - l]`，所以 `s[i..]` 与前缀的公共部分，至少和 `s[i-l..]` 与前缀的公共部分一样长，只是不能超出窗口右端。因此 `z[i]` 的初值是 `min(r - i, z[i - l])`。
2. 从初值开始往右继续比较，能扩就扩（`s[z[i]] == s[i + z[i]]`）。
3. 如果 `i + z[i] > r`，窗口右移：`l = i, r = i + z[i]`。

![s=aabaaab 求 z[4]：窗口 [3,5) 内 4 对应 1，抄 z[1]=1，再往右扩 2 位得到 3](/qmx-Gameknowledge/assets/algo/c7-z-window.svg)

**时间 O(n)**：分两种情形看步骤 2。若 `i < r` 且 `z[i - l] < r - i`，则 `z[i]` 恰好等于 `z[i - l]`，第一次比较就会失败，不产生成功的比较。其余情形下初值是 `r - i`（或 i 在窗口外时为 0），之后每成功比较一次，`i + z[i]` 就向右推进一格，循环结束时 `r` 被更新为这个值。所以成功比较的总次数不超过 `r` 的总增量，即 n。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// z[i] = s 与 s[i..] 的最长公共前缀长度（约定 z[0] = n）
vector<int> zFunction(const string& s) {
    int n = s.size();
    vector<int> z(n, 0);
    z[0] = n;
    int l = 0, r = 0;                            // [l, r) 是已知的、最靠右的“与前缀相等”的区间
    for (int i = 1; i < n; i++) {
        if (i < r) z[i] = min(r - i, z[i - l]);  // 利用 s[l..r) == s[0..r-l) 抄答案
        while (i + z[i] < n && s[z[i]] == s[i + z[i]]) z[i]++;   // 能往右扩就扩
        if (i + z[i] > r) { l = i; r = i + z[i]; }
    }
    return z;
}

// pat 在 text 中的所有出现位置：把 pat + '#' + text 拼起来，z 值等于 |pat| 的位置就是匹配
vector<int> zFind(const string& text, const string& pat) {
    int m = pat.size();
    vector<int> res;
    if (m == 0) return res;
    string s = pat + '#' + text;                 // '#' 不在字母表里，保证 z 值不会超过 m
    vector<int> z = zFunction(s);
    for (size_t i = m + 1; i < s.size(); i++)
        if (z[i] == m) res.push_back(i - m - 1);
    return res;
}

// 最小整周期：最小的 p 使得 p 整除 n 且 s 由长度 p 的串重复 n/p 次得到
int fullPeriod(const string& s) {
    int n = s.size();
    vector<int> z = zFunction(s);
    for (int p = 1; p < n; p++)
        if (n % p == 0 && z[p] == n - p) return p;
    return n;
}

int main() {
    string s = "aabxaabxcaabxaabxay";
    vector<int> z = zFunction(s);
    cout << "s = " << s << "\nz = ";
    for (int x : z) cout << x << ' ';
    cout << "\n";

    cout << "aab 在 aabaabcaab 中的起点: ";
    for (int p : zFind("aabaabcaab", "aab")) cout << p << ' ';
    cout << "\n";

    cout << "ababab 的最小整周期 = " << fullPeriod("ababab") << "\n";
    cout << "abcab 的最小整周期 = " << fullPeriod("abcab") << "\n";
    return 0;
}
```

运行结果：

```text
s = aabxaabxcaabxaabxay
z = 19 1 0 0 4 1 0 0 0 8 1 0 0 5 1 0 0 1 0 
aab 在 aabaabcaab 中的起点: 0 3 7 
ababab 的最小整周期 = 2
abcab 的最小整周期 = 5
```

输出的 `z = 19 1 0 0 4 1 0 0 0 8 …` 可以手验：`z[9] = 8`，因为 `s[9..]` 开头的 `aabxaabx` 与 `s` 的前 8 个字符完全相同。

## 用 Z 函数做匹配

把 `pat + '#' + text` 拼成一个串 `s` 再求 z。`#` 是不在字母表里的分隔符，保证任何位置的 z 值都不会超过 `|pat|`。`s` 中 text 部分的位置 `i` 满足 `z[i] == |pat|`，就说明 `text` 里从 `i - |pat| - 1` 开始有一次匹配。`zFind` 就是这样写的。

另外 `fullPeriod` 展示了 z 数组判断周期：长度为 p 的前缀是整周期，当且仅当 `n % p == 0` 且 `z[p] == n - p`（从下标 p 开始到串尾全部与前缀相同）。

## Z 函数与 KMP 的对比

| | Z 函数 | KMP（前缀函数） |
| --- | --- | --- |
| 数组含义 | 每个后缀与整串的公共前缀 | 每个前缀的最长 border |
| 匹配方式 | 拼接 `pat#text` 后看 z 值 | 直接扫描文本，在线处理 |
| 在线 | 否，需要先拿到全文 | 是，一个字符一个字符喂 |
| 更适合 | 需要“某个后缀与前缀多相似”的题 | 需要 border、周期、失配结构的题 |

两者互相转换是可行的，但没必要。遇到题目，哪个先想到就用哪个；需要在线处理字符流，或者后面要学 AC 自动机时，用 KMP。

## 例题

### 例 1：z 数组与总和

输出 z 数组以及所有 z 值之和。这是验证模板是否写对的最直接题目。

```cpp
#include <bits/stdc++.h>
using namespace std;

// z[i] = s 与 s[i..] 的最长公共前缀长度（约定 z[0] = n）
vector<int> zFunction(const string& s) {
    int n = s.size();

        if (i + z[i] > r) { l = i; r = i + z[i]; }
    }
    return z;
}

// 输出 z 数组，以及所有 z 值之和
int main() {
    string s;
    cin >> s;
    vector<int> z = zFunction(s);
    long long sum = 0;
    for (int x : z) { cout << x << " "; sum += x; }
    cout << "\n" << sum << "\n";
    return 0;
}
```

输入：

```text

```

输出：

```text

```

### 例 2：Tavas and Malekas（Codeforces 535D）

长度为 n 的小写字母串里，模式串 `p` 必须在给定的 m 个起点出现（这些起点升序给出）。问有多少种满足条件的字符串，答案模 10^9 + 7。

思路：相邻两个起点 `y[i-1]` 和 `y[i]` 相距 d。若 `d >= |p|`，两次出现互不重叠，没有约束。若 `d < |p|`，它们重叠了 `|p| - d` 个字符，要求 `p` 的后缀 `p[d..]` 等于 `p` 的前缀 `p[0, |p|-d)`，即 `z[d] == |p| - d`。任意相邻对满足，整体就一致。统计被覆盖的位置数，剩下的位置各有 26 种选择。

```cpp
#include <bits/stdc++.h>
using namespace std;

// z[i] = s 与 s[i..] 的最长公共前缀长度（约定 z[0] = n）
vector<int> zFunction(const string& s) {
    int n = s.size();
    vector<int> z(n, 0);
    z[0] = n;
    int l = 0, r = 0;                            // [l, r) 是已知的、最靠右的“与前缀相等”的区间
    for (int i = 1; i < n; i++) {
        if (i < r) z[i] = min(r - i, z[i - l]);  // 利用 s[l..r) == s[0..r-l) 抄答案
        while (i + z[i] < n && s[z[i]] == s[i + z[i]]) z[i]++;   // 能往右扩就扩
        if (i + z[i] > r) { l = i; r = i + z[i]; }
    }
    return z;
}

// pat 在 text 中的所有出现位置：把 pat + '#' + text 拼起来，z 值等于 |pat| 的位置就是匹配
vector<int> zFind(const string& text, const string& pat) {
    int m = pat.size();
    vector<int> res;
    if (m == 0) return res;
    string s = pat + '#' + text;                 // '#' 不在字母表里，保证 z 值不会超过 m
    vector<int> z = zFunction(s);
    for (size_t i = m + 1; i < s.size(); i++)
        if (z[i] == m) res.push_back(i - m - 1);
    return res;
}

// 最小整周期：最小的 p 使得 p 整除 n 且 s 由长度 p 的串重复 n/p 次得到
int fullPeriod(const string& s) {
    int n = s.size();
    vector<int> z = zFunction(s);
    for (int p = 1; p < n; p++)
        if (n % p == 0 && z[p] == n - p) return p;
    return n;
}

// Codeforces 535D：长度 n 的串里，模式串 p 必须出现在给定的 m 个起点，问有多少种合法的串（模 1e9+7）
int main() {
    int n, m;
    string p;
    cin >> n >> m >> p;
    int len = p.size();
    vector<int> y(m);
    for (int& x : y) cin >> x;
    vector<int> z = zFunction(p);
    long long covered = 0;
    for (int i = 0; i < m; i++) {
        if (i > 0) {
            int d = y[i] - y[i - 1];
            if (d < len) {                           // 相邻两次出现有重叠：p 必须以 d 为“周期”
                if (z[d] != len - d) { cout << 0 << "\n"; return 0; }
                covered += d;                        // 新增覆盖的位置数
            } else covered += len;
        } else covered += len;
    }
    long long ans = 1;
    for (long long i = 0; i < n - covered; i++) ans = ans * 26 % 1000000007;
    cout << ans << "\n";
    return 0;
}
```

示例：

输入：

```text
5 2
ioi
1 3
```

输出：

```text
1
```

## 常见坑

- **`z[0]`**：约定为 n 或 0 都可以，但要在使用处保持一致。本文取 n，所以匹配时只看 `i >= |pat| + 1` 的位置。
- **分隔符不能出现在原串里**：否则 z 值可能超过 `|pat|`，匹配判断出错。
- **窗口是半开区间 `[l, r)`**：`r - i` 是 i 到窗口右端的字符数。`i < r` 才在窗口内，等于 r 时不在。
