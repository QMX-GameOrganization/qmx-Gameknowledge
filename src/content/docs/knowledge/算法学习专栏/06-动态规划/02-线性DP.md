> 适用版本：C++17。前置知识：6.1 的四步设计方法；O(n log n) 的 LIS 需要会用 `lower_bound`（1.2 篇二分）。

## 要点

- 线性 DP 的状态沿着一个或两个序列的下标展开，转移只看「前面」的状态，填表顺序就是下标从小到大。
- LIS 的状态是「以 i 结尾」，朴素做法 O(n²)；换一种状态（长度为 k 的序列最小结尾）后可以二分，做到 O(n log n)。
- LCS 和编辑距离是两个序列的二维 DP：`dp[i][j]` 看两个串各自的前缀，核心是比较 `s[i-1]` 与 `t[j-1]` 是否相同。
- 要输出具体方案时，从终点沿着「这个值是怎么来的」往回走。

## 最长递增子序列（LIS）

给定数组 a，从中选出若干元素，保持原来的先后顺序，使它们严格递增，求最多能选多少个。例如 `10 9 2 5 3 7 101 18` 的 LIS 长度是 4，一个方案是 `2 5 7 101`。

注意「子序列」不要求连续，这一点和「子数组」不同。

### 状态与转移

状态：`dp[i]` 表示**以 `a[i]` 结尾**的最长递增子序列的长度。为什么要规定「以 a[i] 结尾」？因为接下来要判断能不能接上 a[i]，必须知道结尾元素是谁。

转移：枚举 i 前面的每个 j，只要 `a[j] < a[i]`，就可以把 a[i] 接在以 `a[j]` 结尾的序列后面：

```
dp[i] = max(dp[j] + 1)   对所有 j < i 且 a[j] < a[i]
dp[i] = 1                 如果没有这样的 j
```

答案不是 `dp[n-1]`，而是所有 `dp[i]` 的最大值，因为最长序列可以在任何位置结尾。

![LIS 的 O(n²) 做法：dp 数组为 1 1 1 2 2 3 4 4，橙色标出的一条最长序列 2 5 7 101](/qmx-Gameknowledge/assets/algo/c6-02-lis-n2.svg)

### O(n log n)：换一个状态

n 到 10^5 时 O(n²) 超时。观察：长度相同的递增子序列里，结尾越小越好，因为结尾越小，后面越容易接上别的数。于是换一个状态：

`tail[k]` = 长度为 k+1 的递增子序列中，结尾元素的**最小值**。

可以证明 `tail` 一直严格递增（长度更长的序列，其最小结尾不可能更小）。读入一个新元素 x 时：

- 如果 x 比 `tail` 里所有数都大，说明能接在最长的序列后面，`tail` 追加 x，LIS 长度加 1。
- 否则找到 `tail` 中第一个 `>= x` 的位置，用 x 替换它。长度没变，但这个长度的最小结尾变小了，对后面更有利。

找位置用二分，所以每个元素 O(log n)。

![tail 数组随读入元素的变化，橙色是本次写入的位置，最终长度 4](/qmx-Gameknowledge/assets/algo/c6-02-lis-tail.svg)

注意 `tail` 里存的**不是**一个真实的 LIS，只是「各长度的最小结尾」。例如数组 `3 4 1`：读完后 `tail=[1,4]`，但 `1 4` 并不是原数组的子序列（1 在 4 后面）。`tail` 只保证长度正确，所以这个版本不能直接还原方案；需要方案时用 O(n²) 的前驱数组，或在二分版本里额外记录每个元素落在哪个位置。

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// O(n^2)：dp[i] = 以 a[i] 结尾的最长严格递增子序列的长度
int lisN2(const vector<int> &a) {
    int n = a.size(), ans = 0;
    vector<int> dp(n, 1);                              // 至少可以只取 a[i] 自己
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < i; j++)
            if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1);
        ans = max(ans, dp[i]);
    }
    return ans;
}

// O(n log n)：tail[k] = 长度为 k+1 的递增子序列中，结尾元素的最小值
int lisNlogN(const vector<int> &a) {
    vector<int> tail;
    for (int x : a) {
        auto it = lower_bound(tail.begin(), tail.end(), x);   // 严格递增用 lower_bound
        if (it == tail.end()) tail.push_back(x);              // x 比所有结尾都大：接在最长的后面
        else *it = x;                                         // 否则让 x 替换第一个 >= x 的结尾
    }
    return tail.size();
}

// 还原一条最长序列：多记一个前驱 pre[i]
vector<int> lisPath(const vector<int> &a) {
    int n = a.size();
    if (n == 0) return {};
    vector<int> dp(n, 1), pre(n, -1);
    int end = 0;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < i; j++)
            if (a[j] < a[i] && dp[j] + 1 > dp[i]) dp[i] = dp[j] + 1, pre[i] = j;
        if (dp[i] > dp[end]) end = i;
    }
    vector<int> path;
    for (int i = end; i != -1; i = pre[i]) path.push_back(a[i]);
    reverse(path.begin(), path.end());
    return path;
}

int main() {
    vector<int> a = {10, 9, 2, 5, 3, 7, 101, 18};
    cout << lisN2(a) << " " << lisNlogN(a) << "\n";       // 4 4
    for (int x : lisPath(a)) cout << x << " ";             // 2 5 7 101
    cout << "\n";
}
```

**严格递增与不降的区别**：求严格递增用 `lower_bound`（替换第一个 `>= x`）；求非严格递增（允许相等）改用 `upper_bound`（替换第一个 `> x`）。这是最常见的写错点。

## 最长公共子序列（LCS）

给两个字符串 s 和 t，求它们最长的公共子序列（不要求连续）的长度。例如 `ABCBDAB` 和 `BDCABA` 的 LCS 长度是 4，一个方案是 `BCBA`。

状态：`dp[i][j]` 表示 s 的前 i 个字符与 t 的前 j 个字符的 LCS 长度。下标从 1 开始计「前缀长度」，这样 `dp[0][*]` 和 `dp[*][0]` 自然表示空串，值为 0，不用单独写边界。

转移看两个前缀的最后一个字符 `s[i-1]` 和 `t[j-1]`：

- 相同：它们可以作为公共子序列的最后一个字符，`dp[i][j] = dp[i-1][j-1] + 1`。
- 不同：至少有一个字符用不上，要么丢掉 s 的最后一个，要么丢掉 t 的最后一个，取较大者：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`。

顺序：i、j 都从小到大。

![LCS 表，橙色格子是回溯时字符相同的位置，依次取出得到 BCBA](/qmx-Gameknowledge/assets/algo/c6-02-lcs.svg)

### 回溯还原方案

从右下角 (n, m) 出发：如果两个字符相同，这个字符属于答案，斜着走到 (i-1, j-1)；否则看值来自上方还是左方，往那边走。走到边界结束，得到的字符串反过来就是方案。

```cpp
#include <bits/stdc++.h>
using namespace std;

// dp[i][j] = s 的前 i 个字符与 t 的前 j 个字符的 LCS 长度
string lcs(const string &s, const string &t) {
    int n = s.size(), m = t.size();
    vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));   // dp[0][*] = dp[*][0] = 0
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            dp[i][j] = s[i - 1] == t[j - 1] ? dp[i - 1][j - 1] + 1
                                            : max(dp[i - 1][j], dp[i][j - 1]);
    // 从 (n, m) 往回走，还原一个具体的公共子序列
    string res;
    int i = n, j = m;
    while (i > 0 && j > 0) {
        if (s[i - 1] == t[j - 1]) res += s[i - 1], i--, j--;        // 这个字符属于 LCS
        else if (dp[i - 1][j] >= dp[i][j - 1]) i--;                 // 来自上方
        else j--;                                                   // 来自左方
    }
    reverse(res.begin(), res.end());
    return res;
}

int main() {
    string r = lcs("ABCBDAB", "BDCABA");
    cout << r.size() << " " << r << "\n";            // 4 BCBA
}
```

复杂度 O(nm)。只要长度、不要方案时，每行只依赖上一行，可以用滚动数组把空间降到 O(m)。LCS 的方案不唯一，上面的回溯在不同时优先往上走，换成优先往左，可能得到另一个同样长的方案。

## 编辑距离

把字符串 s 变成 t，每次可以插入一个字符、删除一个字符或替换一个字符，最少要几次操作？`horse` 变成 `ros` 需要 3 次：horse → rorse（h 替换成 r）→ rose（删 r）→ ros（删 e）。

状态：`dp[i][j]` 表示把 s 的前 i 个字符变成 t 的前 j 个字符的最少操作数。

边界：`dp[i][0] = i`（s 的前 i 个字符删光），`dp[0][j] = j`（从空串插入 j 个字符）。

转移同样看最后一个字符：

- `s[i-1] == t[j-1]`：最后一个字符不用动，`dp[i][j] = dp[i-1][j-1]`。
- 不同：三种操作取最小再加 1。替换对应 `dp[i-1][j-1]`；删除 `s[i-1]` 对应 `dp[i-1][j]`；在 s 末尾插入 `t[j-1]` 对应 `dp[i][j-1]`。

![horse 到 ros 的编辑距离表，右下角为 3，说明框解释了橙色与蓝色格子的转移](/qmx-Gameknowledge/assets/algo/c6-02-edit.svg)

```cpp
#include <bits/stdc++.h>
using namespace std;

// 编辑距离：把 s 变成 t 的最少操作数（插入、删除、替换各算 1 次）
// dp[i][j] = s 的前 i 个字符变成 t 的前 j 个字符的最少操作数
int editDistance(const string &s, const string &t) {
    int n = s.size(), m = t.size();
    vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
    for (int i = 0; i <= n; i++) dp[i][0] = i;     // s 的前 i 个字符变成空串：全删
    for (int j = 0; j <= m; j++) dp[0][j] = j;     // 空串变成 t 的前 j 个字符：全插
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            if (s[i - 1] == t[j - 1]) dp[i][j] = dp[i - 1][j - 1];
            else dp[i][j] = 1 + min({dp[i - 1][j - 1],   // 替换
                                      dp[i - 1][j],       // 删除 s[i-1]
                                      dp[i][j - 1]});     // 在 s 末尾插入 t[j-1]
        }
    return dp[n][m];
}

int main() {
    cout << editDistance("horse", "ros") << "\n";           // 3
    cout << editDistance("intention", "execution") << "\n"; // 5
}
```

复杂度 O(nm)。

## 三道题的共同点

| | 状态 | 转移的来源 | 复杂度 |
| --- | --- | --- | --- |
| LIS | 以 i 结尾 | 前面所有 j（满足 a[j] < a[i]） | O(n²)，二分版 O(n log n) |
| LCS | 两个前缀 (i, j) | 左上、上、左 | O(nm) |
| 编辑距离 | 两个前缀 (i, j) | 左上、上、左 | O(nm) |

遇到序列问题时，先问自己：状态是「以 i 结尾」还是「前 i 个」？两个序列就用两个下标的前缀。看最后一个元素/字符怎么处理，转移基本就出来了。

## 常见坑

- **LIS 答案取了 `dp[n-1]`。** 应该是所有 `dp[i]` 的最大值。
- **LIS 的 `lower_bound` 与 `upper_bound` 用反。** 严格递增用 `lower_bound`，不降用 `upper_bound`。
- **把 `tail` 数组当成方案输出。** 它只保证长度，见上文。
- **字符串下标错位。** `dp[i][j]` 表示前 i、前 j 个字符，对应的字符是 `s[i-1]`、`t[j-1]`，写成 `s[i]` 会越界或错一位。
- **LCS 和最长公共子串混淆。** 子串要求连续，不同时直接令 `dp[i][j] = 0`，答案取表中的最大值。
- **编辑距离的边界忘了赋值。** `dp[i][0] = i`、`dp[0][j] = j` 不是 0。
