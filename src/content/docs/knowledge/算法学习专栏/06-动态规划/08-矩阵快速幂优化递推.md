> 适用版本：C++17。前置：会写快速幂，会写线性递推类的 DP（如斐波那契、爬楼梯）。什么时候需要学：递推项数 n 达到 10^9 到 10^18，O(n) 的递推已经跑不完。

## 要点

- 原始 DP 是 `f[i] = 若干个 f[i-1], f[i-2], ... 的线性组合`，逐项推需要 O(n)。
- 把「一步转移」写成固定的 d×d 矩阵 M，第 n 步的状态就是 M 的 n 次幂乘初始状态。
- 矩阵乘法满足结合律，所以可以像整数快速幂一样反复平方，总共 O(d³ log n)。
- 递推里有常数项、多项式项时，给状态向量多加几个分量即可。
- 条件：转移系数不随 i 变化，状态个数 d 小（通常不超过几十到一百）。

## 瓶颈在哪

斐波那契的 DP 是 `f[i] = f[i-1] + f[i-2]`，一个循环推到 n，时间 O(n)。当 n = 10^18 时，这个循环永远跑不完。

观察转移：每一步都是同一个操作，把「当前状态」变成「下一个状态」，并且新状态的每个分量都是旧状态分量的线性组合。这种「同一个线性操作重复 n 次」的结构，正是矩阵幂擅长的。

## 把一步转移写成矩阵

取状态向量 v(i) = (F(i+1), F(i))ᵀ，则

```
F(i+2) = F(i+1) + F(i)       对应矩阵第 1 行：1 1
F(i+1) = F(i+1)              对应矩阵第 2 行：1 0   （把旧的 F(i+1) 搬到第二个位置，F(i) 的系数是 0）
```

即 v(i+1) = M · v(i)，其中 M = [[1,1],[1,0]]。重复 n 次得到 v(n) = Mⁿ · v(0)。

![斐波那契的一步转移是 2×2 矩阵乘以状态向量，M 的 13 次幂只需要 3 次平方和 2 次相乘](/qmx-Gameknowledge/assets/algo/c6-08-matrix-fib.svg)

一般做法：

1. 确定状态向量，把递推里用到的「最近几项」全部放进去，设有 d 个分量。
2. 逐个写出新向量每个分量的表达式，系数填进 M 的对应行。矩阵第 r 行第 c 列 = 新状态第 r 个分量里，旧状态第 c 个分量的系数。
3. 答案 = Mⁿ⁻ˢ · v(s)，s 是已知初值对应的起点。

## 矩阵快速幂模板

乘法是普通的三重循环，幂用二进制拆分。注意 `mul(R, A)` 的顺序：矩阵乘法不满足交换律，这里 R 只会是 A 的若干次幂的乘积，同一个矩阵的幂彼此可交换，所以顺序不影响结果。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
typedef vector<vector<ll>> Mat;
const ll MOD = 1e9 + 7;

// 矩阵乘法：A 是 n×k，B 是 k×m，结果 n×m，全部对 MOD 取模
Mat mul(const Mat& A, const Mat& B) {
    int n = A.size(), k = B.size(), m = B[0].size();
    Mat C(n, vector<ll>(m, 0));
    for (int i = 0; i < n; i++)
        for (int t = 0; t < k; t++) {
            if (A[i][t] == 0) continue;
            for (int j = 0; j < m; j++)
                C[i][j] = (C[i][j] + A[i][t] * B[t][j]) % MOD;
        }
    return C;
}

// 矩阵快速幂：A 必须是方阵，返回 A^e
Mat mpow(Mat A, ll e) {
    int n = A.size();
    Mat R(n, vector<ll>(n, 0));
    for (int i = 0; i < n; i++) R[i][i] = 1;  // 单位矩阵
    while (e > 0) {
        if (e & 1) R = mul(R, A);
        A = mul(A, A);
        e >>= 1;
    }
    return R;
}

int main() {
    ll n;
    cin >> n;
    // [F(n+1), F(n)]^T = M^n * [F(1), F(0)]^T，其中 M = [[1,1],[1,0]]
    Mat M = {{1, 1}, {1, 0}};
    Mat P = mpow(M, n);
    cout << P[0][1] << "\n";  // M^n 的右上角就是 F(n)
    return 0;
}
```

- 输入 `10`，输出 `55`。
- 输入 `1000000000000000000`，输出 `209783453`（F(10^18) mod 1e9+7）。用快速倍增法单独算同一个值，结果一致。

复杂度：一次矩阵乘法 O(d³)，快速幂做约 2·log₂n 次，总共 O(d³ log n)。d = 2、n = 10^18 时只有 60 次左右的 2×2 乘法。

## 例题 1：带常数项的递推

题目：a(0) = a(1) = a(2) = 1，a(i) = a(i-1) + a(i-3) + 1，求 a(n) mod 1e9+7，n 可到 10^18。

常数项 +1 不是「旧分量的线性组合」，处理办法是在状态里加一个恒为 1 的分量。取 v(i) = (a(i), a(i-1), a(i-2), 1)ᵀ：

```
a(i+1)   = 1·a(i) + 0·a(i-1) + 1·a(i-2) + 1·1
a(i)     = 1·a(i) + 0 + 0 + 0
a(i-1)   = 0 + 1·a(i-1) + 0 + 0
1        = 0 + 0 + 0 + 1·1
```

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
typedef vector<vector<ll>> Mat;
const ll MOD = 1e9 + 7;

Mat mul(const Mat& A, const Mat& B) {
    int n = A.size(), k = B.size(), m = B[0].size();
    Mat C(n, vector<ll>(m, 0));
    for (int i = 0; i < n; i++)
        for (int t = 0; t < k; t++)
            for (int j = 0; j < m; j++)
                C[i][j] = (C[i][j] + A[i][t] * B[t][j]) % MOD;
    return C;
}

Mat mpow(Mat A, ll e) {
    int n = A.size();
    Mat R(n, vector<ll>(n, 0));
    for (int i = 0; i < n; i++) R[i][i] = 1;
    for (; e > 0; e >>= 1, A = mul(A, A))
        if (e & 1) R = mul(R, A);
    return R;
}

// a(0)=a(1)=a(2)=1，a(i) = a(i-1) + a(i-3) + 1，求 a(n) mod 1e9+7
int main() {
    ll n;
    cin >> n;
    if (n <= 2) { cout << 1 << "\n"; return 0; }
    // 状态向量 v(i) = [a(i), a(i-1), a(i-2), 1]^T
    Mat M = {
        {1, 0, 1, 1},   // a(i+1) = 1*a(i) + 0*a(i-1) + 1*a(i-2) + 1*1
        {1, 0, 0, 0},   // 新的 a(i-1+1) = a(i)
        {0, 1, 0, 0},   // 新的第三项 = 旧的第二项 a(i-1)
        {0, 0, 0, 1}};  // 常数 1 保持不变
    Mat v0 = {{1}, {1}, {1}, {1}};  // v(2)
    Mat vn = mul(mpow(M, n - 2), v0);
    cout << vn[0][0] << "\n";
    return 0;
}
```

输入 `10`，输出 `55`，与手算 a(3..10) = 3, 5, 7, 11, 17, 25, 37, 55 相符。

递推里出现 i 本身（如 `+ i`）时，增加分量 i 和 1，并写出 `(i+1) = i + 1`，规则相同。出现 `2^i` 项则增加一个每步乘 2 的分量。

## 例题 2：路径计数

题目：有向图（允许重边和自环），求从 1 号点恰好走 k 步到 n 号点的路径条数，k 可到 10^18。

DP 的写法是 `dp[t][v] = Σ dp[t-1][u]`（对每条边 u→v），状态数是点数 d。这个转移也是线性的，矩阵就是邻接矩阵 A：A[u][v] 等于 u 到 v 的边数。可以证明 Aᵏ[u][v] 恰好是 u 走 k 步到 v 的路径条数：乘一次矩阵，就是把「走 t 步」延长成「走 t+1 步」。

状态图和转移矩阵是同一件事的两种写法，下图用「不含连续两个 1 的 01 串」的计数演示了这种对应：

![状态图中的两个状态 A、B 与转移矩阵 [[1,1],[1,0]] 一一对应](/qmx-Gameknowledge/assets/algo/c6-08-matrix-states.svg)

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
typedef vector<vector<ll>> Mat;
const ll MOD = 1e9 + 7;

Mat mul(const Mat& A, const Mat& B) {
    int n = A.size(), k = B.size(), m = B[0].size();
    Mat C(n, vector<ll>(m, 0));
    for (int i = 0; i < n; i++)
        for (int t = 0; t < k; t++)
            for (int j = 0; j < m; j++)
                C[i][j] = (C[i][j] + A[i][t] * B[t][j]) % MOD;
    return C;
}

Mat mpow(Mat A, ll e) {
    int n = A.size();
    Mat R(n, vector<ll>(n, 0));
    for (int i = 0; i < n; i++) R[i][i] = 1;
    for (; e > 0; e >>= 1, A = mul(A, A))
        if (e & 1) R = mul(R, A);
    return R;
}

// 有向图（允许重边、自环），求从 1 号点恰好走 k 步到 n 号点的路径条数
int main() {
    int n, m;
    ll k;
    cin >> n >> m >> k;
    Mat A(n, vector<ll>(n, 0));
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        A[u - 1][v - 1]++;  // A[u][v] = u 到 v 的边数
    }
    Mat P = mpow(A, k);     // P[u][v] = 恰好走 k 步从 u 到 v 的条数
    cout << P[0][n - 1] % MOD << "\n";
    return 0;
}
```

输入：

```
3 4 3
1 2
2 3
3 1
1 3
```

输出 `1`。长度为 3 且从 1 到 3 的路径只有 1→3→1→3 这一条。

## 适用与不适用

适用：

- 系数固定的线性递推，包括多项式项、指数项（通过加分量）。
- 图上固定步数的路径计数；边权为 1 的图用邻接矩阵，有边权 w 的边（w 很小）可以把一个点拆成 w 个点串起来再用邻接矩阵。
- 把乘法换成「取 min，加法换成 +」就得到 (min,+) 矩阵乘法，同样满足结合律，可以求「恰好走 k 步」的最短路。

不适用：

- 转移系数依赖 i 且没有规律。
- 状态数 d 很大。d = 100、log n = 60 时约 100³×120 = 1.2×10⁸ 次乘加，还可以接受；d = 1000 就不行了。
- 转移里有取 max、分支判断且不能写成半环运算。

当 d 较大、递推是常系数线性递推时，可以用 Kitamasa 或多项式方法把复杂度降到 O(d² log n) 甚至更低，这里不展开。

## 常见坑

- 状态向量的分量顺序和矩阵的行列顺序必须一致，建议先写出 v(i+1) 的每一行再填数。
- 幂指数写错：从 v(2) 推到 v(n) 要乘 M^(n-2) 而不是 Mⁿ。边界（n 小于初值个数）要单独处理。
- 取模：`A[i][t] * B[t][j]` 最大约 10^18，对 long long 还安全；模数超过 3×10⁹ 时要换 `__int128`。
- 单位矩阵忘记初始化，或 `e == 0` 时返回了零矩阵。
- 在循环里反复拷贝大矩阵（传值而不是引用）会让常数很大。
