> 适用版本：C++17。前置：6.4 区间 DP，6.2 线性 DP。什么时候需要学：区间 DP 是 O(n³) 而 n 到几千，或者形如 `dp[j][i] = min_k dp[j-1][k] + w(k,i)` 的分层 DP 超时。

## 要点

- 原始 DP 有两类：区间型 `f[l][r] = min_k f[l][k] + f[k+1][r] + w(l,r)`（O(n³)），分层型 `dp[j][i] = min_k dp[j-1][k] + w(k,i)`（O(m·n²)）。
- 瓶颈：每个状态都枚举全部决策点 k。
- 优化条件：代价 w 满足四边形不等式，并在区间包含关系上单调。此时最优决策点 opt 具有单调性。
- 区间型：Knuth 优化，枚举范围缩成 `[opt[l][r-1], opt[l+1][r]]`，整体 O(n²)。
- 分层型：分治优化，利用 `opt(i)` 随 i 单调不减，每层 O(n log n)。

## 四边形不等式是什么

设 w(a, b) 是区间 [a, b] 的代价。对任意 a ≤ b ≤ c ≤ d，若

```
w(a, c) + w(b, d) ≤ w(a, d) + w(b, c)
```

则称 w 满足**四边形不等式**。直观上：两个交错的区间 [a,c]、[b,d] 的代价和，不超过「包含」与「被包含」这一对区间的代价和。

区间型 Knuth 优化还要求 w 满足**区间包含单调性**：若 [b,c] ⊆ [a,d]，则 w(b,c) ≤ w(a,d)。

常见的满足条件的代价：

- `w(l, r) = s[r] - s[l-1]`（区间和，非负数组）：四边形不等式取等号，对区间包含也单调。
- `w(k, i) = (s[i] - s[k])²`（s 单调不减）：两边相减得 `2·(s[d]-s[c])·(s[b]-s[a]) ≥ 0`，不等式成立。

证明一个新的 w 是否满足，通常就是把两边展开作差，看符号。拿不准时，用随机数据把 w 的不等式暴力检查一遍，再用朴素 DP 对拍优化后的结果。

## Knuth 优化（区间型）

区间 DP 的标准形式：

```
f[l][r] = min_{l ≤ k < r} f[l][k] + f[k+1][r] + w(l,r),   f[i][i] = 0
```

当 w 满足上面两个条件时，令 `opt[l][r]` 为使 f[l][r] 取最小的最大（或最小）k，则有

```
opt[l][r-1] ≤ opt[l][r] ≤ opt[l+1][r]
```

这个定理的证明较长，思路是用四边形不等式推出 f 本身也满足四边形不等式，再由此推出决策点单调。这里记住结论即可。

![opt[l][r] 的枚举范围被左边一格 opt[l][r-1] 与下边一格 opt[l+1][r] 夹住](/qmx-Gameknowledge/assets/algo/c6-11-knuth.svg)

于是枚举 k 时不必从 l 扫到 r-1，只扫 `[opt[l][r-1], opt[l+1][r]]`。为什么整体是 O(n²)：固定区间长度 len，所有区间 (l, l+len-1) 的扫描范围依次相接——前一个区间的上界 `opt[l+1][r]` 正好是后一个区间的下界，总长度是 O(n)。共 n 个长度，总共 O(n²)。

因为用到了 `opt[l][r-1]` 和 `opt[l+1][r]`，必须按区间长度从小到大递推。

### 例题：石子合并（直线）

n 堆石子排成一行，每次合并相邻两堆，代价是两堆的总数，求全部合并成一堆的最小总代价。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// 石子合并（直线）：f[l][r] = min over k of f[l][k] + f[k+1][r] + sum(l..r)
// 代价 w(l,r) = sum(l..r) 满足四边形不等式，决策点满足 opt[l][r-1] <= opt[l][r] <= opt[l+1][r]
const int N = 2005;
ll f[N][N];
int opt[N][N];

int main() {
    int n;
    cin >> n;
    vector<ll> s(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        ll x;
        cin >> x;
        s[i] = s[i - 1] + x;
    }
    for (int i = 1; i <= n; i++) {
        f[i][i] = 0;
        opt[i][i] = i;                       // 区间长度为 1 时，决策点就是自己
    }
    for (int len = 2; len <= n; len++) {
        for (int l = 1; l + len - 1 <= n; l++) {
            int r = l + len - 1;
            f[l][r] = LLONG_MAX;
            // 只枚举 [opt[l][r-1], opt[l+1][r]]，k 表示左半区间为 [l,k]
            for (int k = opt[l][r - 1]; k <= min(r - 1, opt[l + 1][r]); k++) {
                ll v = f[l][k] + f[k + 1][r] + s[r] - s[l - 1];
                if (v < f[l][r]) {
                    f[l][r] = v;
                    opt[l][r] = k;
                }
            }
        }
    }
    cout << f[1][n] << "\n";
    return 0;
}
```

输入 `4` 与 `4 5 9 4`，输出 `44`。

## 分治优化（分层型）

分层 DP 的标准形式（把序列分成恰好 m 段）：

```
dp[j][i] = min_{k < i} dp[j-1][k] + w(k, i)
```

若 w 满足四边形不等式，则最优决策点 `opt(i)` 随 i 单调不减。

做法：对一层 `dp[j][·]`，递归函数 `solve(l, r, optl, optr)` 表示计算 `dp[j][l..r]`，且已知它们的最优决策点都在 `[optl, optr]`。取中点 `mid = (l+r)/2`，在 `[optl, optr]` 里线性扫描求出 `dp[j][mid]` 和最优点 bk；然后 `solve(l, mid-1, optl, bk)`、`solve(mid+1, r, bk, optr)`。

![solve 取中点求出 bk 后，左半边只看 [optl, bk]，右半边只看 [bk, optr]](/qmx-Gameknowledge/assets/algo/c6-11-dc.svg)

复杂度：递归树每一层所有节点的决策区间加起来只有 O(n)（区间只在端点 bk 处重叠），一共 log n 层，所以一层 DP 是 O(n log n)，m 层共 O(m·n log n)。

### 例题：切成 m 段，每段和的平方之和最小

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// 把 a[1..n] 切成恰好 m 段连续的非空段，使「每段和的平方」之和最小
// dp[j][i] = min over k<i of dp[j-1][k] + (s[i]-s[k])^2，决策点 opt(i) 随 i 单调不减
const int N = 5005;
ll s[N];
vector<ll> prv, cur;

// 计算 cur[l..r]，已知它们的最优决策点在 [optl, optr] 内
void solve(int l, int r, int optl, int optr) {
    if (l > r) return;
    int mid = (l + r) / 2;
    ll best = LLONG_MAX;
    int bk = -1;
    // 决策点 k 要满足 k < mid（前 j-1 段至少覆盖 k 个元素，第 j 段非空）
    for (int k = optl; k <= min(mid - 1, optr); k++) {
        if (prv[k] == LLONG_MAX) continue;
        ll v = prv[k] + (s[mid] - s[k]) * (s[mid] - s[k]);
        if (v < best) {
            best = v;
            bk = k;
        }
    }
    cur[mid] = best;
    solve(l, mid - 1, optl, bk);          // 左半边的决策点不会超过 bk
    solve(mid + 1, r, bk, optr);          // 右半边的决策点不会小于 bk
}

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        ll x;
        cin >> x;
        s[i] = s[i - 1] + x;
    }
    prv.assign(n + 1, LLONG_MAX);
    prv[0] = 0;                           // 0 段覆盖 0 个元素，代价 0
    for (int j = 1; j <= m; j++) {
        cur.assign(n + 1, LLONG_MAX);
        solve(j, n, j - 1, n - 1);        // 前 j 段至少覆盖 j 个元素
        prv = cur;
    }
    cout << prv[n] << "\n";
    return 0;
}
```

输入 `5 2` 与 `1 2 3 4 5`，输出 `117`。最优方案是 `[1,2,3] [4,5]`：6² + 9² = 117。

代码里 `prv[k] == LLONG_MAX` 的判断，是跳过「前 j-1 段不可能恰好覆盖 k 个元素」的非法状态；外层 `solve(j, n, j-1, n-1)` 保证第 j 层至少覆盖 j 个元素。

## 适用与不适用

适用：

- 区间型：石子合并、最优二叉搜索树、一类区间 DP，且 w 满足四边形不等式与区间包含单调。
- 分层型：把序列切成 m 段，段代价满足四边形不等式。

不适用：

- 代价函数不满足条件。例如最大化（max）形式的 DP 要重新检查不等号方向，不能直接套用。
- 环形石子合并要先把序列倍增拷贝成 2n，再对长度不超过 n 的区间做 DP，条件仍需检查。
- 分层 DP 的 w(k,i) 本身很难 O(1) 求出时（如「区间内不同数的对数」），要边递归边移动指针维护 w，复杂度需要另外分析。
- 层数 m 很大时，m·n log n 仍可能太大，可考虑 WQS 二分（凸性）等方法。

## 常见坑

- 没验证四边形不等式就套用，结果在大数据上才出错。务必用随机数据与朴素 DP 对拍。
- Knuth 优化里的初始化：`opt[i][i] = i`，并且按区间长度递推；方向或边界错了会读到没算过的格子。
- 分层 DP 里 k 的上界要同时受 `mid - 1` 和 `optr` 限制，下界受 `optl` 限制。
- 分治里 bk 只在存在合法决策时才有意义；如果整段都不合法（INF），要避免用 `-1` 作为新边界。
- 有多个最优决策时，统一取最小的或最大的，保持 opt 的单调性定义一致。
