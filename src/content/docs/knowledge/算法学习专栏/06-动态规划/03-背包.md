> 适用版本：C++17。前置知识：6.1 的四步设计方法与滚动数组。

## 要点

- 背包问题的模型是：有一批物品，每件有重量和价值，在容量有限的背包里选一些，使价值最大。四种变体的区别只在「每件物品能用几次」。
- 01 背包每件至多用 1 次，一维数组里**容量倒序**；完全背包不限次数，**容量正序**。
- 多重背包（每件最多 c 次）用二进制拆分，把一种物品拆成 O(log c) 件 01 背包物品。
- 分组背包每组至多选一件：外层枚举组，中间倒序枚举容量，内层枚举组内物品。
- 要求「恰好装满」时，把 `dp[0]` 设为 0，其余设为负无穷。

## 01 背包

n 件物品，第 i 件重量 `w[i]`、价值 `v[i]`，背包容量 C，每件最多选 1 次，求最大总价值。

状态：`dp[i][j]` 表示只考虑前 i 件物品、容量为 j 时的最大价值。

转移：对第 i 件物品只有两种选择。

- 不选：`dp[i-1][j]`。
- 选（要求 `j >= w[i]`）：前 i-1 件在剩下的容量 `j - w[i]` 里能得到的最大价值，再加上 `v[i]`，即 `dp[i-1][j-w[i]] + v[i]`。

取较大者。边界：`dp[0][*] = 0`。

![01 背包二维表：物品 (1,1) (3,4) (4,5) (5,7)，容量 7，橙色格 dp[3][7] 取 9，由蓝色的两个格子转移而来](/qmx-Gameknowledge/assets/algo/c6-03-table.svg)

读表：第 3 行第 7 列的 9，来自「选第 3 件」：`dp[2][3] + 5 = 4 + 5`，比不选的 `dp[2][7] = 5` 更大。

## 降成一维：为什么要倒序

观察转移：`dp[i][j]` 只依赖上一行的 `dp[i-1][j]` 和 `dp[i-1][j-w]`，而且依赖的列号 `j-w` 比 j **小**。于是可以只用一维数组，让 `dp[j]` 表示「当前处理到的物品之前」的结果，处理第 i 件物品时原地更新。

关键是更新顺序。算 `dp[j]` 需要上一行的 `dp[j-w]`，所以此时 `dp[j-w]` 必须还没被本轮覆盖。列号小的会被列号大的读取，所以要**先更新大的，后更新小的**，即 j 从 C 倒着枚举到 w。

![同一件物品（重量 2，价值 3）倒序循环结果为 0 0 3 3 3 3 3，正序循环结果为 0 0 3 3 6 6 9，后者重复使用了物品](/qmx-Gameknowledge/assets/algo/c6-03-order.svg)

图里只有一件物品。倒序时每个格子读到的都是本轮之前的值，最多放 1 件；正序时 `dp[4]` 读到的 `dp[2]` 已经是本轮更新过的 3，相当于同一件物品放了第二次。

```cpp
// 01 背包：每件物品最多用一次。dp[j] = 容量不超过 j 时的最大价值
int knap01(const vector<int> &w, const vector<int> &v, int C) {
    vector<int> dp(C + 1, 0);
    for (size_t i = 0; i < w.size(); i++)
        for (int j = C; j >= w[i]; j--)               // 倒序：保证每件物品只用一次
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    return dp[C];
}
```

时间 O(nC)，空间 O(C)。

## 完全背包：只改一个循环方向

每件物品可以选无限次。转移变成 `dp[i][j] = max(dp[i-1][j], dp[i][j-w] + v)`：选了第 i 件之后，剩下的容量里还可以继续选第 i 件，所以依赖的是**同一行**的 `dp[i][j-w]`。

一维写法里，这正好需要读到「本轮已经更新过」的 `dp[j-w]`，于是容量改成**正序**。前面那张对比图里的正序结果，就是完全背包的结果：

```cpp
// 完全背包：每件物品可用无限次
int knapComplete(const vector<int> &w, const vector<int> &v, int C) {
    vector<int> dp(C + 1, 0);
    for (size_t i = 0; i < w.size(); i++)
        for (int j = w[i]; j <= C; j++)               // 正序：允许同一件物品被重复选
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    return dp[C];
}
```

记法：01 背包倒序，是因为不想让一件物品被用两次；完全背包正序，是因为就想让它能被用多次。

## 多重背包：二进制拆分

第 i 种物品最多 `c[i]` 件。最直接的做法是把它当作 `c[i]` 件相同的 01 物品，总物品数是 `Σc[i]`，可能很大。

二进制拆分：把 c 件拆成若干「包」，大小依次是 1, 2, 4, ... 直到不够下一个 2 的幂，剩余的单独作为最后一包。每一包当作一件 01 物品（重量和价值都乘以包的大小）。这样 0 到 c 之间任何件数都能由某些包凑出来。

![13 件物品拆成 1、2、4、6 四包，可以凑出 0 到 13 的任意件数](/qmx-Gameknowledge/assets/algo/c6-03-split.svg)

为什么对：1, 2, 4 能凑出 0 到 7；再加上剩余的 6，能凑出 6 到 13，两段合起来覆盖 0 到 13，而且最多就是 13，不会多拿。如果最后一包不取余数 6 而取 8，就能凑出超过 13 的数，答案会偏大。

```cpp
// 多重背包：第 i 种物品最多 c[i] 件，二进制拆分后当作 01 背包
int knapMulti(const vector<int> &w, const vector<int> &v, const vector<int> &c, int C) {
    vector<int> W, V;
    for (size_t i = 0; i < w.size(); i++) {
        int k = 1, left = c[i];
        while (left > 0) {                             // 拆成 1, 2, 4, ..., 最后是余数
            int take = min(k, left);
            W.push_back(w[i] * take);
            V.push_back(v[i] * take);
            left -= take;
            k <<= 1;
        }
    }
    return knap01(W, V, C);
}
```

复杂度从 O(C·Σc) 降到 O(C·Σlog c)。数据更大时还有 O(nC) 的单调队列做法，需要先学 6.9。

## 分组背包

物品分成若干组，每组里**至多选一件**。对每一组，枚举「这组选哪一件，或者都不选」。

写法上要注意循环顺序：**先枚举组，再倒序枚举容量，最后枚举组内物品**。如果把组内物品放在容量外层，同一组里就可能选多件。

```cpp
// 分组背包：每组至多选一件。groups[g] 里每项是 (重量, 价值)
int knapGroup(const vector<vector<pair<int, int>>> &groups, int C) {
    vector<int> dp(C + 1, 0);
    for (auto &g : groups)
        for (int j = C; j >= 0; j--)                   // 容量在外层倒序，组内物品在内层
            for (auto [w, v] : g)
                if (j >= w) dp[j] = max(dp[j], dp[j - w] + v);
    return dp[C];
}
```

道理：容量倒序保证 `dp[j-w]` 还是上一组之后的值；对同一个 j，组内每件物品读到的都是上一组的结果，所以同组至多选一件。

## 「恰好装满」与「不超过」

前面的 `dp[j]` 初始全 0，含义是「容量**不超过** j 的最大价值」。如果题目要求背包必须**恰好**装满，初始值要改：`dp[0] = 0`，其余全设为负无穷（表示不可达）。这样只有从 `dp[0]` 一步步转移过来的状态才有效值。最后 `dp[C]` 仍是负数就说明装不满。

```cpp
// 恰好装满：dp[0] = 0，其余初始化为"不可达"
int knapExact(const vector<int> &w, const vector<int> &v, int C) {
    const int NEG = INT_MIN / 2;
    vector<int> dp(C + 1, NEG);
    dp[0] = 0;
    for (size_t i = 0; i < w.size(); i++)
        for (int j = C; j >= w[i]; j--)
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    return dp[C] < 0 ? -1 : dp[C];                     // -1 表示装不满
}
```

如果是「求方案数」或「能否凑出」，也是同样套路：把 `max` 换成加法或布尔或，初始 `dp[0] = 1`（或 true）。

## 完整程序

把上面几个函数放在一起，可以直接编译运行：

```cpp
#include <bits/stdc++.h>
using namespace std;

// 01 背包：每件物品最多用一次。dp[j] = 容量不超过 j 时的最大价值
int knap01(const vector<int> &w, const vector<int> &v, int C) {
    vector<int> dp(C + 1, 0);
    for (size_t i = 0; i < w.size(); i++)
        for (int j = C; j >= w[i]; j--)               // 倒序：保证每件物品只用一次
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    return dp[C];
}

// 完全背包：每件物品可用无限次
int knapComplete(const vector<int> &w, const vector<int> &v, int C) {
    vector<int> dp(C + 1, 0);
    for (size_t i = 0; i < w.size(); i++)
        for (int j = w[i]; j <= C; j++)               // 正序：允许同一件物品被重复选
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    return dp[C];
}

// 多重背包：第 i 种物品最多 c[i] 件，二进制拆分后当作 01 背包
int knapMulti(const vector<int> &w, const vector<int> &v, const vector<int> &c, int C) {
    vector<int> W, V;
    for (size_t i = 0; i < w.size(); i++) {
        int k = 1, left = c[i];
        while (left > 0) {                             // 拆成 1, 2, 4, ..., 最后是余数
            int take = min(k, left);
            W.push_back(w[i] * take);
            V.push_back(v[i] * take);
            left -= take;
            k <<= 1;
        }
    }
    return knap01(W, V, C);
}

// 分组背包：每组至多选一件。groups[g] 里每项是 (重量, 价值)
int knapGroup(const vector<vector<pair<int, int>>> &groups, int C) {
    vector<int> dp(C + 1, 0);
    for (auto &g : groups)
        for (int j = C; j >= 0; j--)                   // 容量在外层倒序，组内物品在内层
            for (auto [w, v] : g)
                if (j >= w) dp[j] = max(dp[j], dp[j - w] + v);
    return dp[C];
}

// 恰好装满：dp[0] = 0，其余初始化为"不可达"
int knapExact(const vector<int> &w, const vector<int> &v, int C) {
    const int NEG = INT_MIN / 2;
    vector<int> dp(C + 1, NEG);
    dp[0] = 0;
    for (size_t i = 0; i < w.size(); i++)
        for (int j = C; j >= w[i]; j--)
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    return dp[C] < 0 ? -1 : dp[C];                     // -1 表示装不满
}

int main() {
    vector<int> w = {1, 3, 4, 5}, v = {1, 4, 5, 7};
    cout << knap01(w, v, 7) << "\n";                   // 9：选重量 3 和 4
    cout << knapComplete(w, v, 7) << "\n";             // 9：例如 3 + 3 + 1
    cout << knapMulti({2, 3}, {3, 4}, {3, 2}, 10) << "\n";            // 14：重量 2 的 2 件 + 重量 3 的 2 件
    cout << knapGroup({{{1, 1}, {3, 4}}, {{4, 5}, {5, 7}}}, 7) << "\n";   // 9：每组选一件
    cout << knapExact(w, v, 7) << " " << knapExact({2, 4}, {3, 5}, 5) << "\n";   // 9 -1
}
```

## 例题

背包的难点常常在「看出这是背包」。下面两题是典型的转化。

**分割等和子集（LeetCode 416）。** 能否把数组分成两部分，和相等？总和为奇数直接不行；否则就是问「能不能选出一些数，和恰好等于总和的一半」，是 01 背包的「恰好」版本，`dp[j]` 用布尔值表示能否凑出 j。

**零钱兑换（LeetCode 322）。** 每种硬币无限个，凑出金额 amount 最少要多少枚。硬币的面值是「重量」，每枚价值为 1，求恰好装满时价值最小，是完全背包。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 分割等和子集（LeetCode 416）：能否把数组分成两个和相等的子集
// 转成 01 背包：能否选出一些数，和恰好为总和的一半。dp[j] = 能否凑出和 j
bool canPartition(const vector<int> &a) {
    int sum = accumulate(a.begin(), a.end(), 0);
    if (sum % 2) return false;
    int C = sum / 2;
    vector<char> dp(C + 1, 0);
    dp[0] = 1;
    for (int x : a)
        for (int j = C; j >= x; j--)                  // 01 背包，倒序
            dp[j] = dp[j] || dp[j - x];
    return dp[C];
}

// 零钱兑换（LeetCode 322）：每种硬币无限个，凑出金额 amount 最少要几枚，凑不出返回 -1
// 完全背包 + 恰好装满。dp[j] = 凑出 j 的最少硬币数
int coinChange(const vector<int> &coins, int amount) {
    const int INF = 1e9;
    vector<int> dp(amount + 1, INF);
    dp[0] = 0;
    for (int c : coins)
        for (int j = c; j <= amount; j++)             // 完全背包，正序
            dp[j] = min(dp[j], dp[j - c] + 1);
    return dp[amount] >= INF ? -1 : dp[amount];
}

int main() {
    cout << canPartition({1, 5, 11, 5}) << " " << canPartition({1, 2, 3, 5}) << "\n";   // 1 0
    cout << coinChange({1, 2, 5}, 11) << " " << coinChange({2}, 3) << "\n";              // 3 -1
}
```

## 常见坑

- **01 背包写成正序。** 结果偏大，等价于完全背包。反过来完全背包写成倒序，结果偏小。
- **分组背包把组内物品放在容量外层。** 同一组里会选到多件。
- **二进制拆分忘了余数。** `1, 2, 4` 加上余数，而不是一直乘 2 到超过为止。
- **「恰好」和「不超过」混淆。** 初始值不同：不超过时全 0；恰好时 `dp[0]=0`、其余负无穷。
- **容量太大。** 状态数是 O(C)，C 到 10^9 时不能用这种做法，要换思路（例如价值很小时交换「容量」与「价值」的角色）。
- **物品重量大于容量。** 循环下界写成 `j >= w[i]`，不要让下标变成负数。
