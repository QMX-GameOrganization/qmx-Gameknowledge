> 适用版本：C++17。前置：6.9 单调队列优化 DP，叉积（向量乘法）的概念。什么时候需要学：DP 转移式展开后出现 `s[i]·s[j]` 这样的交叉项，n 在 10^5 以上，O(n²) 超时。

## 要点

- 原始 DP：`dp[i] = min_{j<i} dp[j] + (S[i]-S[j])² + M`，每个 i 枚举全部 j，O(n²)。
- 瓶颈：展开平方后有交叉项 `-2·S[i]·S[j]`，不能像 6.9 那样把式子拆成「j 的部分」加「i 的部分」。
- 做法：把每个 j 看成平面上的点 (X_j, Y_j)，转移变成「斜率为 S[i] 的直线向上平移，碰到的第一个点」，只有下凸壳上的点可能最优。
- 当 S[i] 单调递增、点的 X 也单调时，凸壳可以用单调队列维护，整体 O(n)。
- 点或查询不单调时，用二分（凸壳上二分）或 Li Chao 树，O(n log n)。

## 瓶颈在哪：交叉项

经典题（Print Article）：n 个单词，第 i 个单词的费用是 c[i]（非负），把单词按顺序切成若干段，每段的代价是（该段费用之和）² + M，求最小总代价。令 S 为 c 的前缀和：

```
dp[i] = min_{0 ≤ j < i} dp[j] + (S[i] - S[j])² + M
```

展开平方：

```
dp[i] = min_j ( dp[j] + S[j]² - 2·S[i]·S[j] ) + S[i]² + M
```

括号里的项含 `S[i]·S[j]`，它同时依赖 i 和 j，窗口最值（6.9）处理不了。

## 变成几何问题

令 `X_j = 2·S[j]`、`Y_j = dp[j] + S[j]²`，括号里变成 `Y_j - S[i]·X_j`。把它记作 b：

```
b = Y_j - k·X_j      其中 k = S[i]
```

等价于 `Y_j = k·X_j + b`：过点 (X_j, Y_j)、斜率为 k 的直线在 Y 轴上的截距。dp[i] 要的是所有 j 中最小的截距。

几何上：画一条斜率为 k 的直线，从下方向上平移，第一个碰到的点就使截距最小。

![点 (X_j, Y_j) 和下凸壳，斜率为 S[i] 的直线向上平移时第一个碰到的点就是最优决策](/qmx-Gameknowledge/assets/algo/c6-10-hull.svg)

被碰到的点一定在点集的**下凸壳**上，不在凸壳上的点永远不是最优，可以直接丢弃。下凸壳从左到右，相邻两点连线的斜率依次变大。

## 用单调队列维护凸壳

本题 c[i] ≥ 0，所以 S 单调不减，X_j 随 j 增加而不减，新点总是加在最右边；查询斜率 k = S[i] 也随 i 单调不减。这样两端都只需要弹出：

- **弹队首**：队首两点 q0、q1 的斜率 `slope(q0,q1) ≤ k`，说明 q1 至少和 q0 一样好，而以后 k 只会更大，q0 不会再有用，弹出。
- **弹队尾**：插入新点 c 之前，若队尾两点 a、b 满足 `slope(a,b) ≥ slope(b,c)`，b 在 a、c 连线的上方或线上，不在下凸壳上，弹出 b。重复到不再成立为止，再让 c 入队。

![三点判断：b 在 a、c 连线下方时保留，上方或线上时弹出；队首按斜率与 S[i] 比较](/qmx-Gameknowledge/assets/algo/c6-10-pop.svg)

斜率比较写成交叉相乘，避免除法和浮点误差：

```
slope(a,b) ≥ slope(b,c)  ⇔  (Yb - Ya)·(Xc - Xb) ≥ (Yc - Yb)·(Xb - Xa)
```

两个因子都可能到 10^18 量级，乘积超过 long long，下面的代码用 `__int128` 比较。每个点最多入队出队一次，总复杂度 O(n)。

## 例题 1：Print Article

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
typedef __int128 LL;

// dp[i] = min over j<i of dp[j] + (S[i]-S[j])^2 + M，S 为前缀和，c[i] >= 0
// 令 X_j = 2*S[j]，Y_j = dp[j] + S[j]^2，则 dp[i] = min(Y_j - S[i]*X_j) + S[i]^2 + M
int n;
ll M;
vector<ll> S, dp;

ll X(int j) { return 2 * S[j]; }
ll Y(int j) { return dp[j] + S[j] * S[j]; }

// 点 a、b 连线的斜率 (Y_b - Y_a) / (X_b - X_a)，用交叉相乘避免除法
// 返回 slope(a,b) <= k 即 (Y_b - Y_a) <= k * (X_b - X_a)（X 单调不降且 X_b > X_a）
bool slopeLE(int a, int b, ll k) { return (LL)(Y(b) - Y(a)) <= (LL)k * (X(b) - X(a)); }

// 三点 a<b<c：b 是否在 ac 连线上方或线上（此时 b 永远不会成为最优决策）
bool badMiddle(int a, int b, int c) {
    return (LL)(Y(b) - Y(a)) * (X(c) - X(b)) >= (LL)(Y(c) - Y(b)) * (X(b) - X(a));
}

int main() {
    cin >> n >> M;
    S.assign(n + 1, 0);
    dp.assign(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        ll c;
        cin >> c;
        S[i] = S[i - 1] + c;
    }
    deque<int> q;
    q.push_back(0);                       // dp[0] = 0
    for (int i = 1; i <= n; i++) {
        // 查询斜率 S[i] 单调递增：队首斜率不超过 S[i] 的点都不会再有用
        while (q.size() >= 2 && slopeLE(q[0], q[1], S[i])) q.pop_front();
        int j = q.front();
        dp[i] = dp[j] + (S[i] - S[j]) * (S[i] - S[j]) + M;
        // 插入 i：维护下凸壳，弹掉队尾不再位于凸壳上的点
        // 当 X 相同（S 相同）时，只保留 Y 更小的点
        while (q.size() >= 2 && badMiddle(q[q.size() - 2], q.back(), i)) q.pop_back();
        if (!q.empty() && X(q.back()) == X(i)) {
            if (Y(q.back()) <= Y(i)) continue;   // 新点更差，直接丢弃
            q.pop_back();
        }
        q.push_back(i);
    }
    cout << dp[n] << "\n";
    return 0;
}
```

输入 `5 5` 与 `5 5 5 5 5`（n=5，M=5，每个 c=5），输出 `150`。五个单词各自成段是 5×(5²+5)=150；合成两段、三段的方案都更大。

代码里有一处细节：S 相同的两个点 X 相同，只保留 Y 更小的，保证队列里 X 严格递增，斜率比较里的 `X_b - X_a` 才不会为 0。

## 例题 2：不单调的情形与 Li Chao 树

AtCoder DP Contest 的 Z（Frog 3）：n 块石头，高度 h[i]，从 1 号跳到 n 号，跳一次的代价是 `(h[i]-h[j])² + C`，求最小总代价。

```
dp[i] = min_{j<i} dp[j] + (h[i]-h[j])² + C
```

这题 h 严格递增，用单调队列也能做。但如果高度不单调，X 和查询斜率都乱序，单调队列就失效了。Li Chao 树不依赖这些单调性：

- 每个 j 对应一条直线 `y = -2·h[j]·x + (dp[j] + h[j]²)`，查询 x = h[i] 处所有直线的最小值，再加上 `h[i]² + C`。
- Li Chao 树是一棵按 x 的取值范围建立的线段树，每个节点保存**一条**直线：在该区间中点处最优的那条。
- 插入新直线时，先在中点处比较，较优者留在节点，较差者最多只在左端或右端更优，递归放进对应一侧的子树。查询时沿着 x 所在的叶子走一条路径，取路径上所有直线在 x 处的最小值。

![在 [1,8] 上插入新直线 A：B 在中点更优留在根节点，A 只在右端更优，被放入右子树](/qmx-Gameknowledge/assets/algo/c6-10-lichao.svg)

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// Li Chao 树：维护若干条直线，查询某个 x 处的最小值，x 取值范围 [1, MAXX]
const int MAXX = 1000000;
struct Line {
    ll k, b;
    ll eval(ll x) const { return k * x + b; }
};
const ll INF = (ll)4e18;
Line tr[4 * MAXX + 5];                  // 每个线段树节点保存一条直线

void insertLine(int o, int l, int r, Line nw) {
    int mid = (l + r) / 2;
    // 让 tr[o] 保存在 mid 处更优的那条
    if (nw.eval(mid) < tr[o].eval(mid)) swap(nw, tr[o]);
    if (l == r) return;
    // nw 现在是在 mid 处较差的线：它最多在一侧可能更优
    if (nw.eval(l) < tr[o].eval(l)) insertLine(2 * o, l, mid, nw);
    else if (nw.eval(r) < tr[o].eval(r)) insertLine(2 * o + 1, mid + 1, r, nw);
}

ll query(int o, int l, int r, int x) {
    ll res = tr[o].eval(x);
    if (l == r) return res;
    int mid = (l + r) / 2;
    if (x <= mid) return min(res, query(2 * o, l, mid, x));
    return min(res, query(2 * o + 1, mid + 1, r, x));
}

// AtCoder DP Z：dp[i] = min over j<i of dp[j] + (h[i]-h[j])^2 + C
int main() {
    int n;
    ll C;
    cin >> n >> C;
    vector<ll> h(n), dp(n);
    for (auto& x : h) cin >> x;
    for (int i = 0; i < 4 * MAXX + 5; i++) tr[i] = {0, INF};   // 空直线：永远不会更优
    dp[0] = 0;
    insertLine(1, 1, MAXX, {-2 * h[0], dp[0] + h[0] * h[0]});
    for (int i = 1; i < n; i++) {
        dp[i] = query(1, 1, MAXX, (int)h[i]) + h[i] * h[i] + C;
        insertLine(1, 1, MAXX, {-2 * h[i], dp[i] + h[i] * h[i]});
    }
    cout << dp[n - 1] << "\n";
    return 0;
}
```

输入 `5 6` 与 `1 2 3 4 5`，输出 `20`，即 AtCoder 题面的样例。插入和查询都是 O(log V)，V 是 x 的取值范围（这里是 10^6），总复杂度 O(n log V)。

## 适用与不适用

适用：转移式能整理成 `min/max_j (A_j - k_i · B_j) + C_i` 的形式，即 j 的两个量和 i 的一个量的线性组合。

选哪种实现：

- B_j 与 k_i 都单调：单调队列，O(n)。
- B_j 单调，k_i 不单调：凸壳存在数组里，查询时二分，O(n log n)。
- B_j 不单调：Li Chao 树，或者用 CDQ 分治、平衡树维护凸壳。
- 求最大值时凸壳变成上凸壳，弹出条件的不等号方向反过来，务必重新推导一遍，不要直接照抄。

不适用：转移式里 i 和 j 的耦合不是线性乘积（如 `min(a[i], a[j])`、`s[i]·s[j]²`），需要别的优化方式。如果 w(j,i) 满足四边形不等式，可以走 6.11。

## 常见坑

- 推导时把 X、Y 的符号弄反，导致凸壳的上下方向错了。先用小数据对拍，几组随机数据就能暴露。
- 忘记处理 X 相同的点，交叉相乘时两边都是 0，条件恒成立，会误弹有用的点。
- 乘积溢出：dp 值、前缀和的平方已经接近 10^18，斜率比较必须用 `__int128` 或 `long double`（后者有误差，竞赛里常见但不严谨）。
- 弹队首的条件用 `≤` 还是 `<` 不影响结果，但弹队尾必须包含「共线」的情形，否则队列会残留冗余点，数据特殊时可能退化。
- Li Chao 树的 x 范围必须覆盖所有查询点（这里是 [1, 10^6]）；用空直线 `{0, INF}` 初始化节点，INF 取 4×10^18，既大于任何真实值，又不会在求值时溢出。
