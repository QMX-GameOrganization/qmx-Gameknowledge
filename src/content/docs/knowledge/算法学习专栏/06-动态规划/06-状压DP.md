> 适用版本：C++17。前置知识：位运算（0.1 篇）；6.1 的四步设计方法。什么时候需要学：题目里某个量很小（n ≤ 20，或棋盘宽度 ≤ 10），而状态需要记录「每个位置的情况」时。

## 要点

- 状压 DP 把一个很小的集合编码成一个整数 `mask`，第 i 位为 1 表示元素 i 在集合里。mask 本身作为 DP 的一维下标。
- n 个元素有 2^n 个状态，所以 n 通常不超过 20。时间常是 O(2^n · n²) 或 O(2^n · n)。
- 两类典型题：集合型（旅行商、分配任务，状态是已处理的集合）和棋盘型（逐行或逐列处理，状态是当前行的占用情况）。
- 枚举子集的写法 `for (s = mask; s; s = (s-1) & mask)` 会使所有 mask 的总枚举量为 3^n。

## 用整数表示集合

![集合 {0,2,3} 对应二进制 01101，下方列出判断、加入、删除、全集、补集、元素个数和枚举子集的写法](/qmx-Gameknowledge/assets/algo/c6-06-mask.svg)

常用操作都是一行代码：

| 操作 | 写法 |
| --- | --- |
| 元素 i 是否在集合里 | `mask >> i & 1` |
| 加入元素 i | `mask \| (1 << i)` |
| 删除元素 i | `mask & ~(1 << i)` |
| 全集（n 个元素） | `(1 << n) - 1` |
| 补集 | `full ^ mask` |
| 元素个数 | `__builtin_popcount(mask)` |

mask 从 0 到 `2^n - 1` 恰好表示每个子集一次，所以可以直接用 mask 做数组下标，并且按 mask 从小到大的顺序填表，加入元素得到的新 mask 一定比原来大，天然满足依赖顺序。

## 例 1：旅行商问题（TSP）

n 个城市，两两之间有距离。从城市 0 出发，每个城市恰好经过一次，最后回到 0，求最短总路程。

暴力枚举所有排列是 O(n!)，n=20 时不可能。观察：走到哪里之后，**已经去过哪些城市**和**现在在哪**，就足以决定后面怎么走，走过的具体顺序不重要。

状态：`dp[mask][i]` 表示已访问的城市集合为 mask、当前停在 i 的最短路程（i 必须在 mask 里）。

转移：从 `dp[mask][i]` 出发，去一个还没去过的城市 j：

```
dp[mask | (1 << j)][j] = min(dp[mask][i] + d[i][j])      j 不在 mask 里
```

边界：`dp[1][0] = 0`（只访问了城市 0），其余为无穷大。答案：访问完全部城市后，最后停在 i，再加上回到 0 的路程，取最小：`min(dp[full][i] + d[i][0])`。

![4 个城市的 TSP 状态图，按已访问个数分四列，每个状态标出 mask 与当前城市以及最短路程，箭头是取到最小值的转移](/qmx-Gameknowledge/assets/algo/c6-06-tsp.svg)

图中 mask 写成二进制，从右往左第 i 位对应城市 i；`0111 @2` 表示去过 0、1、2，停在 2。最后一层的三个状态加上回到 0 的路程后，最小值是 80。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 旅行商问题（TSP）：n 个城市，从 0 出发走遍所有城市恰好一次并回到 0，求最短总路程。
// dp[mask][i] = 已访问集合为 mask、当前停在 i 时的最短路程（i 必须在 mask 里）
const int INF = 1e9;

int tsp(const vector<vector<int>> &d) {
    int n = d.size();
    if (n == 1) return 0;
    vector<vector<int>> dp(1 << n, vector<int>(n, INF));
    dp[1][0] = 0;                                      // 只访问了城市 0，停在 0
    for (int mask = 1; mask < (1 << n); mask++) {
        if (!(mask & 1)) continue;                     // 起点 0 必须在集合里
        for (int i = 0; i < n; i++) {
            if (!(mask >> i & 1) || dp[mask][i] >= INF) continue;
            for (int j = 0; j < n; j++) {
                if (mask >> j & 1) continue;           // j 还没去过
                int nmask = mask | (1 << j);
                dp[nmask][j] = min(dp[nmask][j], dp[mask][i] + d[i][j]);
            }
        }
    }
    int ans = INF;
    for (int i = 1; i < n; i++)                        // 最后一个城市 i，再回到 0
        ans = min(ans, dp[(1 << n) - 1][i] + d[i][0]);
    return ans;
}

int main() {
    vector<vector<int>> d = {{0, 10, 15, 20}, {10, 0, 35, 25}, {15, 35, 0, 30}, {20, 25, 30, 0}};
    cout << tsp(d) << "\n";                            // 80
}
```

复杂度：状态 `2^n · n` 个，每个状态枚举 n 个下一站，时间 O(2^n · n²)，空间 O(2^n · n)。n=20 时约 4×10^8 次基本操作，需要注意常数。

## 例 2：蒙德里安的梦想（骨牌铺满棋盘）

用 1×2 的骨牌铺满 n 行 m 列的棋盘，横放竖放都行，问有多少种铺法。n 很小（不超过 11），m 可以较大。

按列从左到右处理。当前处理第 i 列时，有些行已经被**从第 i-1 列横着伸过来**的骨牌占了。用 mask 表示这些行：

状态：`f[i][s]` 表示前 i 列处理完，第 i 列被左边伸过来的横牌占住的行集合为 s 的方案数。

转移：第 i 列还可以再选一些行 t，放横牌伸向第 i+1 列。需要满足两个条件：

1. s 和 t 不重叠（同一格不能被两张牌盖）。
2. 第 i 列剩下的空格（既不在 s 也不在 t）只能放竖牌，所以每一段**连续空格的长度必须是偶数**。

![左边合法：s = 第 0 行，t = 第 3 行，行 1 和 2 放一张竖牌；右边不合法：剩下 3 个连续空格，竖牌凑不齐](/qmx-Gameknowledge/assets/algo/c6-06-domino.svg)

预处理 `ok[x]`：x 中每段连续的 0 的长度是否都是偶数。转移条件就是 `!(s & t) && ok[s | t]`。边界 `f[0][0] = 1`，答案 `f[m][0]`（最后一列不能再有伸出去的骨牌）。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 蒙德里安的梦想：用 1x2 的骨牌铺满 n 行 m 列的棋盘，有多少种方案？
// 逐列处理。f[i][s] = 前 i 列已经铺好，第 i 列中被"从第 i-1 列伸过来的横牌"占住的行集合是 s 时的方案数
// 转移：第 i 列再选一些行 t，横放骨牌伸向第 i+1 列。要求 s 与 t 不重叠，
// 且剩下的空格（既不在 s 也不在 t 里）能被竖牌填满，即连续空格段的长度都是偶数。
long long tiling(int n, int m) {
    int S = 1 << n;
    vector<char> ok(S, 1);                             // ok[x]：x 中每段连续的 0 长度为偶数
    for (int x = 0; x < S; x++) {
        int cnt = 0;
        for (int i = 0; i < n; i++) {
            if (x >> i & 1) { if (cnt & 1) ok[x] = 0; cnt = 0; }
            else cnt++;
        }
        if (cnt & 1) ok[x] = 0;
    }
    vector<vector<long long>> f(m + 1, vector<long long>(S, 0));
    f[0][0] = 1;
    for (int i = 0; i < m; i++)
        for (int s = 0; s < S; s++) {
            if (!f[i][s]) continue;
            for (int t = 0; t < S; t++)
                if (!(s & t) && ok[s | t]) f[i + 1][t] += f[i][s];
        }
    return f[m][0];                                    // 最后一列不能再有伸出去的骨牌
}

int main() {
    cout << tiling(2, 2) << " " << tiling(4, 4) << " " << tiling(8, 8) << "\n";   // 2 36 12988816
}
```

复杂度：O(m · 4^n)，每一列枚举 s 和 t 两个 mask。n=11 时 4^11 约 4×10^6，乘上 m 仍然可以接受；也可以只枚举合法的 `(s, t)` 对来加速。

## 子集枚举

有些题的转移是「把集合 mask 拆成一个子集 sub 和剩下的部分」，需要枚举 mask 的所有子集。标准写法：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 枚举 mask 的所有非空子集：sub = (sub - 1) & mask
    int mask = 0b1011;
    for (int sub = mask; sub > 0; sub = (sub - 1) & mask) cout << bitset<4>(sub) << " ";
    cout << "\n";                                      // 1011 1010 1001 1000 0011 0010 0001
    // 对所有 mask 枚举其子集（含空集），总次数是 3^n
    int n = 10;
    long long total = 0;
    for (int m = 0; m < (1 << n); m++)
        for (int sub = m; ; sub = (sub - 1) & m) {
            total++;
            if (sub == 0) break;
        }
    cout << total << " " << (long long)pow(3, n) << "\n";   // 59049 59049
}
```

`(sub - 1) & mask` 的作用是：把 sub 减 1 后，用 mask 过滤掉不属于 mask 的位，得到比 sub 小的下一个子集，从大到小不重不漏地遍历。

对所有 mask 都枚举子集，总次数是 3^n，不是 4^n：每个元素有三种情况，不在 mask 里、在 mask 里但不在 sub 里、在 sub 里。n=15 时约 1.4×10^7，n=20 时约 3.5×10^9 就太大了，所以子集 DP 的 n 一般到 15 左右。

## 常见坑

- **运算符优先级。** 移位的优先级高于 `&`，所以 `mask >> i & 1` 和 `mask & 1 << i` 都是对的；但 `==` 的优先级高于 `&`，`mask & x == x` 会被当成 `mask & (x == x)`，必须写成 `(mask & x) == x`。位运算一律加括号最安全。
- **用 `1 << n` 时 n 太大。** `int` 在 n ≥ 31 时溢出；需要 `1LL << n`，但这时状态数早就放不下了。
- **内存。** `dp[1 << 20][20]` 的 int 数组约 80 MB，要看题目限制。TSP 里 `dp[mask][i]` 可以只保留 mask 包含 0 的一半。
- **起点没有固定。** TSP 的 `dp[1][0] = 0` 之外都应是无穷，否则会从任意城市出发。
- **棋盘型的合法性没预处理。** 每次转移都现算「相邻位是否冲突」会让复杂度多一个因子，预处理出所有合法行状态，只在它们之间转移。
- **无穷大相加溢出。** `INF = 1e9` 时 `INF + INF` 会溢出 int，转移前先判断 `dp[mask][i] < INF`。
