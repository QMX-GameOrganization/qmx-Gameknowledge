> 适用版本：C++17。前置知识：6.1 的四步设计方法；前缀和（1.3 篇）。

## 要点

- 区间 DP 的状态是一段连续区间 `dp[l][r]`，大区间的答案由它内部更小的区间合并而来。
- 填表顺序必须是**按区间长度从小到大**，或者 l 从大到小、r 从小到大。写成普通的 `for i, for j` 会读到还没算的格子。
- 典型转移是枚举分割点 k：`dp[l][r] = min/max(dp[l][k] + dp[k+1][r]) + 代价`，复杂度 O(n³)。
- 环形问题把数组复制一份接在后面，转成直线上长度为 n 的窗口。
- 戳气球这类「操作会改变相邻关系」的题，要反过来想「最后一个」操作的对象。

## 什么时候想到区间 DP

问题的操作作用在**相邻**的元素上（合并相邻两堆、两端匹配括号、删除一段），并且大区间的最优解可以由两个小区间的最优解拼出来。n 一般在 100 到 500 之间，因为 O(n³) 能承受。

## 例 1：石子合并

n 堆石子排成一行，每次选相邻两堆合并成一堆，代价是新堆的重量，求合并成一堆的最小总代价。

状态：`dp[l][r]` 表示把第 l 到 r 堆合并成一堆的最小代价。

转移：任何合并方案的**最后一步**，都是把某个分割点 k 左右两边各自合并好的两堆合并。左边的最小代价是 `dp[l][k]`，右边是 `dp[k+1][r]`，最后一步的代价是整段 `l..r` 的重量和（用前缀和 O(1) 求）：

```
dp[l][r] = min(dp[l][k] + dp[k+1][r]) + sum(l..r)    l <= k < r
```

边界：长度为 1 的区间不需要合并，`dp[l][l] = 0`。

### 填表顺序

`dp[l][r]` 依赖更短的区间 `dp[l][k]` 和 `dp[k+1][r]`，所以必须先把所有长度更短的区间算完。外层循环枚举**区间长度**，内层枚举左端点。

以石子 `3 4 5 2 1` 为例，算 `dp[0][4]` 时要枚举四个分割点：

### 环形：复制一份

如果石子围成一圈，首尾也算相邻，就把数组复制一遍接在后面，变成长度 2n 的直线。以任意位置 l 为起点、长度为 n 的窗口，就是环上的一种「断开方式」。对所有 l 取答案的最小值。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 石子合并（直线）：每次合并相邻两堆，代价是两堆重量之和，求合并成一堆的最小总代价
// dp[l][r] = 把第 l..r 堆合并成一堆的最小代价
long long stoneMerge(const vector<int> &a) {
    int n = a.size();
    vector<long long> pre(n + 1, 0);                   // 前缀和，O(1) 求区间重量
    for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + a[i];
    vector<vector<long long>> dp(n, vector<long long>(n, 0));   // 长度为 1 的区间代价为 0
    for (int len = 2; len <= n; len++)                 // 先枚举区间长度
        for (int l = 0; l + len - 1 < n; l++) {
            int r = l + len - 1;
            dp[l][r] = LLONG_MAX;
            for (int k = l; k < r; k++)                // 最后一次合并发生在 k 与 k+1 之间
                dp[l][r] = min(dp[l][r], dp[l][k] + dp[k + 1][r]);
            dp[l][r] += pre[r + 1] - pre[l];           // 最后一次合并的代价是整段重量和
        }
    return dp[0][n - 1];
}

// 环形：把数组复制一份接在后面，对每个长度为 n 的窗口求答案，取最小
long long stoneMergeCircle(const vector<int> &a) {
    int n = a.size();
    vector<int> b(a);
    b.insert(b.end(), a.begin(), a.end());
    int N = 2 * n;
    vector<long long> pre(N + 1, 0);
    for (int i = 0; i < N; i++) pre[i + 1] = pre[i] + b[i];
    vector<vector<long long>> dp(N, vector<long long>(N, 0));
    for (int len = 2; len <= n; len++)
        for (int l = 0; l + len - 1 < N; l++) {
            int r = l + len - 1;
            dp[l][r] = LLONG_MAX;
            for (int k = l; k < r; k++) dp[l][r] = min(dp[l][r], dp[l][k] + dp[k + 1][r]);
            dp[l][r] += pre[r + 1] - pre[l];
        }
    long long ans = LLONG_MAX;
    for (int l = 0; l < n; l++) ans = min(ans, dp[l][l + n - 1]);
    return ans;
}

int main() {
    cout << stoneMerge({3, 4, 5, 2, 1}) << "\n";                           // 33
    cout << stoneMerge({2, 9, 5, 1}) << " " << stoneMergeCircle({2, 9, 5, 1}) << "\n";   // 34 28
}
```

`{2, 9, 5, 1}` 排成一行时，1 和 2 不相邻，最小代价是 34；围成一圈后 1 和 2 相邻，可以先合并它们，代价降到 28。

复杂度：状态 O(n²)，每个状态枚举 O(n) 个分割点，总共 O(n³)。环形版本数组长度翻倍，运算量大约是直线版的 4 倍。

## 例 2：最长回文子序列

给字符串 s，求它最长的回文子序列（不要求连续）的长度。例如 `bbbab` 的答案是 4（`bbbb`）。

状态：`dp[l][r]` 表示 `s[l..r]` 中最长回文子序列的长度。

转移看区间两端：

- `s[l] == s[r]`：两端可以同时作为回文的两端，`dp[l][r] = dp[l+1][r-1] + 2`。
- 不相等：两端至少有一个用不上，`dp[l][r] = max(dp[l+1][r], dp[l][r-1])`。

边界：`dp[l][l] = 1`。这里区间缩小一步就是更小的区间，所以可以用 l 倒序、r 正序的写法，而不必按长度。依赖的 `dp[l+1][*]` 在 l 倒序时已经算好，`dp[l][r-1]` 在同一行里 r 正序时也已经算好。

## 例 3：戳气球

n 个气球排成一排，每个有一个数。戳破第 i 个气球得到 `nums[i-1] × nums[i] × nums[i+1]` 枚金币，戳破后左右两个气球变成相邻；越界的位置当作 1。求能得到的最大金币数。

直接按「第一个戳谁」来拆会出问题：戳破一个之后，剩下的气球的邻居关系变了，左右两边的子问题不再独立。

反过来想「**最后一个**戳谁」。设开区间 (l, r) 里最后被戳的是 k。此时 l 和 r 一直还在，所以戳破 k 得到的是 `a[l] × a[k] × a[r]`；而 k 之前，(l, k) 内的气球和 (k, r) 内的气球互不影响，邻居只会是 l、k 或 r，是两个独立的子问题。

![数组 1 3 1 5 8 1，l=0、k=3、r=5，两条弧线分别表示 dp[0][3] 与 dp[3][5]，下方给出转移公式](/qmx-Gameknowledge/assets/algo/c6-04-balloon.svg)

```
dp[l][r] = max( dp[l][k] + dp[k][r] + a[l] * a[k] * a[r] )    l < k < r
```

这里的区间是开区间，两端补上虚拟的 1 之后，答案是 `dp[0][n+1]`。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 最长回文子序列（LeetCode 516）
// dp[l][r] = s[l..r] 中最长回文子序列的长度
int longestPalSubseq(const string &s) {
    int n = s.size();
    vector<vector<int>> dp(n, vector<int>(n, 0));
    for (int l = n - 1; l >= 0; l--) {                  // l 倒着枚举，保证 dp[l+1][..] 已经算好
        dp[l][l] = 1;
        for (int r = l + 1; r < n; r++) {
            if (s[l] == s[r]) dp[l][r] = dp[l + 1][r - 1] + 2;   // 两端相同，一起放进回文
            else dp[l][r] = max(dp[l + 1][r], dp[l][r - 1]);     // 否则丢掉一端
        }
    }
    return n ? dp[0][n - 1] : 0;
}

// 戳气球（LeetCode 312）：戳破 i 得到 nums[i-1] * nums[i] * nums[i+1] 枚金币，越界当作 1
// 逆向思考：dp[l][r] = 只戳破开区间 (l, r) 内的气球能得到的最大金币，k 是区间里"最后"被戳的气球
int maxCoins(const vector<int> &nums) {
    int n = nums.size();
    vector<int> a(n + 2, 1);                            // 两端补 1
    for (int i = 0; i < n; i++) a[i + 1] = nums[i];
    vector<vector<int>> dp(n + 2, vector<int>(n + 2, 0));
    for (int len = 2; len <= n + 1; len++)              // r - l = len，区间内有 len-1 个气球
        for (int l = 0; l + len <= n + 1; l++) {
            int r = l + len;
            for (int k = l + 1; k < r; k++)             // k 最后被戳，此时 l 和 r 还在
                dp[l][r] = max(dp[l][r], dp[l][k] + dp[k][r] + a[l] * a[k] * a[r]);
        }
    return dp[0][n + 1];
}

int main() {
    cout << longestPalSubseq("bbbab") << "\n";          // 4
    cout << maxCoins({3, 1, 5, 8}) << "\n";             // 167
}
```

戳气球的复杂度是 O(n³)。三个 DP 的共同套路是：先想清楚区间的**最后一步**（最后一次合并、两端是否配对、最后一个被戳的气球），再把它拆成两个更小的区间。

## 常见坑

- **填表顺序错误。** 外层枚举 l、内层枚举 r 且都从小到大，会读到还没算的 `dp[k+1][r]`。要么按长度枚举，要么 l 倒序。
- **前缀和下标错位。** `sum(l..r) = pre[r+1] - pre[l]`，`pre[0] = 0`。
- **`LLONG_MAX` 相加溢出。** 初始化成 `LLONG_MAX` 之后只能作为比较的起点，不能直接参与加法；上面的写法在赋值时才相加，所以安全。
- **环形忘了答案要对每个窗口取最小或最大。**
- **戳气球按「第一个」拆。** 子问题不独立，应该枚举「最后一个」。
- **开区间和闭区间混用。** 戳气球里 `dp[l][r]` 不包含 l 和 r 本身，分割点从 `l+1` 到 `r-1`。
