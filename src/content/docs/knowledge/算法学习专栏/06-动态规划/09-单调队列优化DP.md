> 适用版本：C++17。前置：2.1 单调栈与单调队列，6.3 背包（多重背包的朴素写法）。什么时候需要学：DP 转移形如「在一段连续区间里取最大/最小」，且区间随 i 向右滑动。

## 要点

- 原始 DP：`dp[i] = min/max_{j ∈ [L(i), R(i)]} (dp[j] + 与 j 无关或可拆开的项)`，直接枚举 j 是 O(n·窗口)。
- 瓶颈：每个 i 都重新扫一遍窗口。
- 优化条件：窗口的左右端点都随 i 单调不减；被取最值的量可以拆成「只和 j 有关的部分」加「只和 i 有关的部分」。
- 做法：把「只和 j 有关的部分」放进单调队列，队首就是窗口最值，每个下标最多入队出队各一次，总复杂度 O(n)。
- 多重背包可以按体积的余数分组，每组内变成滑动窗口问题，复杂度从 O(W·Σc) 降到 O(n·W)。

## 瓶颈在哪

以「跳跃游戏 VI」为例：数组 a[0..n-1]，从下标 0 出发，每次向右跳 1 到 k 步，落到的位置得分为 a[i]，求到达 n-1 时的最大总分。

```
dp[i] = a[i] + max(dp[j])，j ∈ [i-k, i-1]
```

直接枚举 j，每个 i 扫 k 个位置，总共 O(nk)。n = k = 10^5 时是 10^10，跑不完。

注意 dp[j] 和 i 没有任何乘积或交叉项：`a[i]` 是只和 i 有关的部分，窗口里要比较的 dp[j] 是只和 j 有关的部分。窗口 [i-k, i-1] 每次整体右移一格，这正是「滑动窗口最大值」。

## 单调队列怎么维护

队列里存下标，满足两条性质：

1. 下标从队首到队尾严格递增，且都在当前窗口内。
2. 对应的 dp 值从队首到队尾严格递减。

这样队首始终是窗口最大值。每个新下标 i 的处理分三步：

1. 弹队首：队首下标小于 i-k，已经滑出窗口。
2. 取队首算出 dp[i]。
3. 弹队尾：队尾的 dp 值不超过 dp[i] 的下标，窗口只会越来越靠右，它们比 i 更早过期、值又不更大，永远不会成为最大值。然后 i 入队。

![k=3 时计算 dp[6]：弹出已滑出窗口的队首，取队首算出 dp[6]，再弹队尾并放入 6](/qmx-Gameknowledge/assets/algo/c6-09-window.svg)

每个下标最多入队一次、出队一次，总共 O(n)。

## 例题 1：跳跃游戏 VI

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// dp[i] = a[i] + max(dp[j])，j 取 [i-k, i-1]；起点 0，终点 n-1，求 dp[n-1]
int main() {
    int n, k;
    cin >> n >> k;
    vector<ll> a(n), dp(n);
    for (auto& x : a) cin >> x;
    deque<int> q;            // 存下标，对应的 dp 值从队首到队尾严格递减
    dp[0] = a[0];
    q.push_back(0);
    for (int i = 1; i < n; i++) {
        while (!q.empty() && q.front() < i - k) q.pop_front();  // 滑出窗口
        dp[i] = a[i] + dp[q.front()];                          // 队首是窗口最大值
        while (!q.empty() && dp[q.back()] <= dp[i]) q.pop_back();  // 保持单调
        q.push_back(i);
    }
    cout << dp[n - 1] << "\n";
    return 0;
}
```

输入 `6 2` 与 `1 -1 -2 4 -7 3`，输出 `7`（路径 1 → -1 → 4 → 3）。这是 LeetCode 1696 的官方样例。

## 例题 2：长度不超过 k 的最大子段和

题目：数组 a[1..n]，找一个长度在 1 到 k 之间的连续子数组，使和最大。

设 s 为前缀和，右端点固定为 r 时，子段和是 `s[r] - s[l]`，其中 l 的范围是 `[r-k, r-1]`。所以要的是窗口内 s[l] 的最小值，窗口随 r 向右滑，单调队列维护 s 值递增的下标。

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// 长度在 [1, k] 之间的连续子数组，求最大和
// 令 s 为前缀和，右端点 r 固定时，答案是 s[r] - min(s[l])，l 取 [r-k, r-1]
int main() {
    int n, k;
    cin >> n >> k;
    vector<ll> s(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        ll x;
        cin >> x;
        s[i] = s[i - 1] + x;
    }
    deque<int> q;            // 存下标，s 值从队首到队尾严格递增
    q.push_back(0);
    ll ans = LLONG_MIN;
    for (int r = 1; r <= n; r++) {
        while (!q.empty() && q.front() < r - k) q.pop_front();
        ans = max(ans, s[r] - s[q.front()]);
        while (!q.empty() && s[q.back()] >= s[r]) q.pop_back();
        q.push_back(r);
    }
    cout << ans << "\n";
    return 0;
}
```

输入 `5 2` 与 `3 -2 5 -1 4`，输出 `5`。长度不超过 2 的子段里 `5`（单独一个）已是最大，`5 -1 4` 长度为 3 超出限制。

## 例题 3：多重背包的单调队列优化

多重背包：第 i 种物品体积 w、价值 v、最多 c 个，背包容量 W。朴素转移：

```
new[j] = max_{0 ≤ t ≤ min(c, j/w)} dp[j - t·w] + t·v
```

对每个 j 枚举 t，复杂度 O(W·c)，所有物品加起来是 O(W·Σc)。

观察被转移的位置 j、j-w、j-2w……它们除以 w 的余数都相同。固定余数 r，把这些位置按顺序编号 u = 0, 1, 2, …，位置 j = r + u·w。令 `g[u] = dp[r+u·w] - u·v`，则

```
new[r+u·w] = u·v + max_{u-c ≤ u' ≤ u} g[u']
```

这就是一个窗口大小为 c+1 的滑动窗口最大值，每个余数组独立做一遍，一种物品的总代价是 O(W)。

![w=3、c=2 时，j=10 属于余数 1 的那一组，它的窗口覆盖 dp[4]、dp[7]、dp[10]](/qmx-Gameknowledge/assets/algo/c6-09-residue.svg)

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// 多重背包：n 种物品，第 i 种体积 w、价值 v、数量 c，背包容量 W，求最大价值
int main() {
    int n, W;
    cin >> n >> W;
    vector<ll> dp(W + 1, 0), nd(W + 1);
    for (int i = 0; i < n; i++) {
        int w, c;
        ll v;
        cin >> w >> v >> c;
        for (int r = 0; r < w && r <= W; r++) {   // 按 j 除以 w 的余数分组
            deque<pair<int, ll>> q;               // (u, g[u])，g 从队首到队尾递减
            for (int u = 0, j = r; j <= W; u++, j += w) {
                ll g = dp[j] - (ll)u * v;         // g[u] = dp[r+u*w] - u*v
                while (!q.empty() && q.back().second <= g) q.pop_back();
                q.push_back({u, g});
                while (q.front().first < u - c) q.pop_front();  // 最多取 c 个
                nd[j] = q.front().second + (ll)u * v;
            }
        }
        dp = nd;
    }
    cout << dp[W] << "\n";
    return 0;
}
```

输入：

```
3 10
2 3 2
3 5 1
1 1 5
```

三行依次是物品的 `体积 价值 数量`，输出 `14`。

## 适用与不适用

适用：转移区间是连续的滑动窗口，且两端点单调右移；目标项能拆成「j 的部分」与「i 的部分」之和。

不适用：

- 目标项里有 i 和 j 的乘积（如 `(s[i]-s[j])²` 展开后的交叉项 `s[i]·s[j]`），窗口最值不再成立，要用斜率优化（6.10）。
- 窗口端点不单调（需要线段树或 ST 表）。
- 转移不是取最值而是求和。求和用前缀和即可，不需要队列。

## 常见坑

- 窗口边界差一：`front() < i - k` 弹出，保留的区间是 `[i-k, i-1]`，包含 i-k。
- 先弹队首、再取答案、最后弹队尾入队。顺序反了会把 i 自己放进它自己的窗口。
- 弹队尾时的比较用 `<=`（求最大）还是 `<`：相等的值保留更靠右的，因为它更晚过期，所以用 `<=` 弹出更靠左的。
- 多重背包里 `g[u]` 要用 `dp[j] - u*v`，不是 `dp[j]`，否则 `u*v` 无法提到窗口外。
- dp 初始值是 `-INF` 时，`dp[j] - u*v` 不要溢出。
