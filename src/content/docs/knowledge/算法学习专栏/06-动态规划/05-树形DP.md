> 适用版本：C++17。前置知识：4.4 一般树（子树、父子关系）、DFS；6.3 的 01 背包。

## 要点

- 树形 DP 的状态是「以 u 为根的子树」里的某个量，常见写法是 `dp[u][...]`。
- 计算顺序是后序：先递归处理所有孩子，回来后用孩子的结果更新 `dp[u]`。
- 最常见的模型是每个结点「选 / 不选」两种状态：选了 u，孩子的状态受限；没选 u，孩子自由。
- 子树里需要「选了几个」这类容量时，把孩子的表合并进父亲，本质是分组背包，叫树上背包。

## 为什么树上适合 DP

树没有环，每个结点只有一个父亲，子树之间互不相交。所以「以 u 为根的子树」是一个天然的子问题：它的答案只取决于 u 本身和它每个孩子子树的答案。这正好满足 DP 的最优子结构，而且 DFS 的后序遍历天然就是正确的计算顺序。

![后序遍历的计算顺序：叶子 6、7 先算，然后是 4，再到 1、2、3，最后根 5，箭头表示孩子的结果传给父亲](/qmx-Gameknowledge/assets/algo/c6-05-order.svg)

图中的编号是 `dp[u]` 被算出的先后。`dfs(u)` 的写法固定：

```cpp
void dfs(int u) {
    // 初始化 dp[u]
    for (int v : son[u]) {
        dfs(v);                // 先把孩子算完
        // 用 dp[v] 更新 dp[u]
    }
}
```

## 例 1：没有上司的舞会

某公司有 n 个人，每人有快乐值，上下级关系构成一棵树。选一些人参加舞会，任何人不能和他的直接上司同时参加，求快乐值之和的最大值。

状态：对每个人 u 定义两个值。

- `dp[u][0]`：不选 u 时，u 的子树里能得到的最大快乐值。
- `dp[u][1]`：选 u 时，u 的子树里能得到的最大快乐值。

转移：

- 不选 u，每个孩子 v 可选可不选，取较大者：`dp[u][0] = Σ max(dp[v][0], dp[v][1])`。
- 选 u，每个孩子都不能选：`dp[u][1] = happy[u] + Σ dp[v][0]`。

边界：叶子没有孩子，`dp[leaf][0] = 0`，`dp[leaf][1] = happy[leaf]`。答案是根的 `max(dp[root][0], dp[root][1])`。

![7 个人的树，每个结点标出 (不选, 选) 两个值，根 5 的值是 (4, 5)](/qmx-Gameknowledge/assets/algo/c6-05-party.svg)

下面是洛谷 P1352 的输入格式：先给 n，然后 n 行快乐值，再若干行 `l k` 表示 l 是 k 的直接下属，以 `0 0` 结束。没有上司的人是根，用一个 `hasBoss` 数组找出来。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 没有上司的舞会（洛谷 P1352）
// 输入：n；n 行快乐值；随后若干行 "l k" 表示 l 是 k 的直接下属；以 "0 0" 结束。
// 选一些人，任何人不能和他的直接上司同时被选，使快乐值之和最大。
// dp[u][0] = 不选 u 时 u 子树的最大快乐值；dp[u][1] = 选 u 时的最大快乐值。
const int N = 6005;
int n, happy[N], hasBoss[N];
long long dp[N][2];
vector<int> son[N];

void dfs(int u) {
    dp[u][0] = 0;
    dp[u][1] = happy[u];
    for (int v : son[u]) {
        dfs(v);
        dp[u][0] += max(dp[v][0], dp[v][1]);   // u 不选：每个孩子选或不选都行
        dp[u][1] += dp[v][0];                  // u 选：每个孩子都不能选
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> happy[i];
    int l, k;
    while (cin >> l >> k && (l || k)) son[k].push_back(l), hasBoss[l] = 1;
    int root = 1;
    while (hasBoss[root]) root++;              // 没有上司的那个人是根
    dfs(root);
    cout << max(dp[root][0], dp[root][1]) << "\n";
}
```

用图中的例子验证：7 个人的快乐值都是 1，关系行依次是 `1 3`、`2 3`、`6 4`、`7 4`、`4 5`、`3 5`，最后一行 `0 0`，程序输出 5，与图中手算一致。

复杂度 O(n)：每个结点只处理一次，每条边只被访问一次。

递归深度等于树高，树退化成链且 n 很大（10^5 以上）时可能栈溢出，需要改成按 BFS 序倒序处理，或手动开大栈。

## 例 2：树上背包（选课）

有 n 门课，每门课最多有一门先修课，选一门课前必须先选它的先修课。每门课有学分，求选 m 门课的最大学分。洛谷 P2014 的输入是：第一行 `n m`，之后 n 行，第 i 行是 `先修课编号 学分`，没有先修课写 0。

先修关系构成森林。为了统一，加一个编号为 0 的虚拟根（学分 0），把没有先修课的课都挂到 0 下面。问题变成：在以 0 为根的树里选出包含根在内的 m+1 个结点，要求选了某个结点就必须选它的父亲，使学分最大。

状态：`dp[u][j]` 表示在 u 的子树里选 j 个结点（**必须包含 u**）的最大学分。

转移是一个背包合并：对 u 的每个孩子 v，把「v 的子树里选 k 个」当作一个物品组，k 取 1 到 sz[v]，价值是 `dp[v][k]`。每个孩子对应一组，组内至多选一个 k（选 0 个就是不选这个孩子），所以这是**分组背包**，容量是 j：

```
dp[u][j] = max(dp[u][j], dp[u][j-k] + dp[v][k])      j 倒序
```

倒序和 6.3 里的原因相同：要让 `dp[u][j-k]` 还是「合并 v 之前」的值，这样孩子 v 不会被算两次。

![合并前 dp[u] 只有 j=1 值为 2，孩子 dp[v] 有 k=1 为 3、k=2 为 5，合并后 dp[u] 为 2 5 7](/qmx-Gameknowledge/assets/algo/c6-05-knap.svg)

图里 u 的学分是 2。合并孩子 v（学分 3，v 的孩子学分 2，需先选 v）：`dp[u][2] = 2 + 3 = 5`，`dp[u][3] = 2 + 5 = 7`。

### 代码与复杂度

```cpp
#include <bits/stdc++.h>
using namespace std;

// 选课（洛谷 P2014）的树上背包写法。
// 输入：n m，随后 n 行，第 i 行是 "先修课编号 学分"（0 表示没有先修课）。
// 选 m 门课，选课必须先选先修课，求最大学分。
// 加虚拟根 0（必选），问题变成：在以 0 为根的树里选 m+1 个点，选了点就必须选它的父亲。
// dp[u][j] = 在 u 的子树里选 j 个点（必须包含 u）的最大学分。
const int N = 305;
int n, m, score_[N], sz[N], dp[N][N];
vector<int> child[N];

void dfs(int u) {
    sz[u] = 1;
    dp[u][1] = score_[u];
    for (int v : child[u]) {
        dfs(v);
        // j 倒序，类似 01 背包；k 是分给孩子 v 子树的名额，至少 1（选 v 才会选 v 下面的点），
        // 并且 j - k 不能超过 u 已有的结点数 sz[u]
        for (int j = min(sz[u] + sz[v], m + 1); j >= 2; j--)
            for (int k = max(1, j - sz[u]); k <= min(sz[v], j - 1); k++)
                dp[u][j] = max(dp[u][j], dp[u][j - k] + dp[v][k]);
        sz[u] += sz[v];
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        int p;
        cin >> p >> score_[i];
        child[p].push_back(i);
    }
    dfs(0);
    cout << dp[0][m + 1] << "\n";         // 学分非负，dp 默认 0 不影响取 max
}
```

用一个小例子验证：3 门课，输入 `3 2`、`0 3`、`1 5`、`0 1`（第 2 门课的先修课是第 1 门），选 2 门课，输出 8，即选第 1、2 门。

复杂度：合并 v 时，j 最多枚举 `sz[u] + sz[v]` 个，k 最多枚举 `sz[v]` 个，并且 `j - k <= sz[u]`，所以一次合并的代价不超过 `sz[u] × sz[v]`。把所有合并加起来，相当于每一对结点恰好在它们的最近公共祖先处被配对一次，总共 O(n²)。如果把 `sz` 截断到 `m+1`，则为 O(nm)。这个性质是树上背包能在 n 为几千时通过的原因。

## 树形 DP 的一般步骤

1. 定义 `dp[u][...]`，说明它代表「以 u 为根的子树」里的什么。额外的维度通常是「u 选不选」「子树里选了几个」「u 是否被覆盖」。
2. 想清楚 u 的状态对孩子的状态有什么限制，写出由孩子的 `dp[v][...]` 推出 `dp[u][...]` 的式子。
3. 叶子是边界。
4. 找根（输入没给就找入度为 0 的点，无向树任选一个点当根并记录父亲避免回头）。
5. 答案通常在根上，也有的题要对所有结点取最大值（例如「以某点为最高点的路径」）。

## 常见坑

- **无向树忘了防回头。** 无向边存双向，`dfs(u, parent)` 里要跳过 `v == parent`，否则会无限递归。
- **找错根。** 输入是「l 是 k 的下属」这类有向关系时，根是没有上司的那个人，不一定是 1 号。
- **多棵树（森林）没有处理。** 要么对每个根各跑一次，要么像选课那样加虚拟根。
- **树上背包的 j 没有倒序**，会让同一个孩子被合并多次。
- **dp 初值不对。** 树上背包里 `dp[u][1]` 初始是 u 自己的价值，其他 j 在合并之前是不可达，要注意初值和取 max 时是否会混入不合法状态。
- **深度太大栈溢出。** 链状数据 n=10^5 时递归会爆栈。
