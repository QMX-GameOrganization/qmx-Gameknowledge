## 1. 建图与合并条件

拓扑系统查询已登记带段，包含 Disabled。依靠结构版本和 ConveyorSegment、GridPose、网格参数的变更过滤跳过稳定拓扑；发生变化时扫描图，不是已经实现局部增量重建。

根据相邻格、旋转后的输入输出方向和网格参数建立前后继，拒绝闭环。同速同间距的连续链可以合并；速度或间距不同的相邻段保持路径边界。一个成员禁用会暂停所在合并路径。

## 2. 旧物品怎样找到新位置

重建先生成托管 Node 和 Plan 临时结构。未改变且 Matches 的路径复用原 Entity 和队列，只更新必要状态；改变的路径才展开物品。

旧队列累加得到物品累计路程，找到物品所在旧带段，再通过同一段在新路径中的位置映射：`新段.Start + (旧路程-旧段.Start)/旧段.Length × 新段.Length`。新位置排序后再编码为 EntryGap 与 GapToNext。找不到原段的物品进入回收记录。

## 3. 校验、提交和操作保护

提交前检查新位置范围、排序后的最小间距等约束，全部合法后创建/复用路径、写 Membership，再删除不保留的旧路径。验证失败不会先破坏旧队列，但提交阶段任意异常的完整数据库式回滚并不是现有保证。

主动拆除带段会保护本段在途物品；不要求整条路径都空。旋转带段则检查所在整条路径是否有物品。外部强制销毁与正常建造入口的保护规则不同，前者可能通过 RecoveredBeltItem 留回收记录。
