> 适用版本：Unity 2021 LTS 到 Unity 6000.x。编辑器界面的布局和菜单名称随版本略有差异，以你使用的版本为准。

## 要点

- **场景**（Scene）是一个关卡或一个界面，里面装着很多物体。
- **游戏物体**（GameObject）是场景里的一个"东西"：玩家、敌人、摄像机、一盏灯、一面墙。它本身只是个空容器。
- **组件**（Component）是挂在物体上的功能模块：决定它长什么样、有没有物理、怎么行动。
- **脚本也是组件。** 你写的 C# 类，挂到物体上，就成了这个物体的一个组件。
- 每个物体都有一个 **Transform** 组件，保存位置、旋转、缩放，且不能删除。

## 三层结构

![场景里有很多物体，每个物体由多个组件组成，你的脚本是其中一个组件](/qmx-Gameknowledge/assets/csharp/scene-components.svg)

一个"玩家"在 Unity 里并不是一个叫 `Player` 的巨大类，而是**一个物体加上一组组件**：

| 组件 | 作用 | 谁写的 |
| --- | --- | --- |
| Transform | 位置、旋转、缩放 | Unity 自带 |
| MeshRenderer | 把模型画出来 | Unity 自带 |
| Rigidbody | 让物体受重力、受力运动 | Unity 自带 |
| Collider | 碰撞范围，用于碰撞检测 | Unity 自带 |
| PlayerController | 读输入、移动、受伤、死亡 | **你写的脚本** |

想让一个物体"会飞"，就给它加一个飞行相关的组件；想让它"可被攻击"，加一个血量组件。这种设计叫**组合**：用小零件拼出复杂对象，而不是靠一层层继承。

## 和 C++/C# 的概念对应

| Unity 里的说法 | 对应的语言概念 |
| --- | --- |
| GameObject | Unity 提供的一个类，场景里每个物体是它的一个对象 |
| 组件（Component） | 一个类的对象，被某个 GameObject 持有 |
| 你的脚本 `PlayerController` | 你写的类，继承自 `MonoBehaviour`（0.3 篇） |
| 把脚本挂到物体上 | 在这个 GameObject 上创建一个该类的对象 |
| 同一个脚本挂到两个物体 | 同一个类，两个独立的对象，各有各的字段值 |
| Inspector 里调的数值 | 对象的字段（成员变量）的初始值 |

最后两行很关键：**类是图纸，挂在物体上的脚本才是对象**。这与 3.1 篇"类与对象"完全对应。

## 编辑器里的主要面板

| 面板 | 作用 |
| --- | --- |
| Hierarchy（层级） | 当前场景里所有物体的列表，物体可以嵌套（父子） |
| Scene（场景视图） | 在三维空间里摆放、移动物体 |
| Game（游戏视图） | 玩家实际看到的画面，点 Play 时运行 |
| Inspector（检查器） | 选中物体后，显示它的全部组件及其可调参数 |
| Project（项目） | 工程里的资源文件：脚本、模型、图片、预制体 |
| Console（控制台） | 显示 `Debug.Log` 输出、警告和报错 |

在 Inspector 里看到的每一块折叠区域就是一个组件。脚本中的 `public` 字段或 `[SerializeField]` 字段也会出现在脚本组件里，可以直接填数值、拖入其他物体，这是 Unity 最常用的"配置"方式。

## 父子关系与 Transform

物体可以拖到另一个物体下面，成为它的**子物体**。子物体的位置、旋转跟随父物体：

- 角色（父）带着武器（子）移动，武器会跟着走。
- Inspector 里显示的子物体位置是**相对于父物体**的"局部坐标"，代码里用 `transform.localPosition`；相对于世界原点的"世界坐标"用 `transform.position`。

## 预制体（Prefab）

把一个配置好的物体（含所有组件和参数）保存成**预制体**，相当于一个"模板"。之后能在场景里放很多个，或在代码里用 `Instantiate(prefab)` 动态生成，比如子弹、敌人、特效。改预制体，所有实例一起更新。

## 动手试试

1. 新建一个 3D 项目，在 Hierarchy 空白处右键 → 3D Object → Cube，选中它，在 Inspector 里找到 Transform、Mesh Filter、Mesh Renderer、Box Collider 四个组件。
2. 点 Inspector 里的 Add Component，添加 Rigidbody，然后点击 Play。立方体会掉落吗？再把它的 Transform Y 位置调到 5 重试。
3. 把一个 Cube 拖到另一个 Cube 下面，移动父物体，观察子物体的 Position 数字有没有变。

做完这三步，你已经理解了"物体由组件构成"。下一篇把自己写的脚本也变成组件：[脚本就是组件：MonoBehaviour 与生命周期](../03-脚本就是组件/)。
