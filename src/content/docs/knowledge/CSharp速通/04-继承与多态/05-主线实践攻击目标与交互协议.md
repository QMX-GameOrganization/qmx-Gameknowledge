> 标记：`【主线实践】`。本篇承接 4.1～4.4，解决“新增目标是否需要修改攻击者”的工程问题。

> **代码归属**：`【主线代码】`。本篇代码写入 `Assets/Speedrun/Game/`，会被后续章节继续引用；不能只放在 `Labs/`。

## 先定义能力，再定义对象

```csharp
public interface IDamageable
{
    void TakeDamage(int rawDamage, GameObject source);
}

public interface IInteractable
{
    bool TryInteract(GameObject actor);
}
```

玩家攻击脚本只查询 `IDamageable`，不判断目标具体是 `Goblin`、`Barrel` 还是 `Trap`。敌人可以继承 `EnemyBase` 复用移动和死亡流程，木桶则只实现接口，不必继承敌人。

```csharp
if (Physics.Raycast(origin, direction, out RaycastHit hit, attackRange, targetMask)
    && hit.collider.TryGetComponent<IDamageable>(out var target))
{
    target.TakeDamage(attackPower, gameObject);
}
```

这段代码是 `【主线必做】`：它直接决定玩家能否攻击不同目标。接口是 `【主线必做】`，具体的敌人 AI 可以先用最小实现，复杂行为列为 `【可选扩展】`。

## 验收

- [ ] 玩家攻击敌人和木桶都能产生伤害；
- [ ] 攻击脚本没有 `if (target is Goblin)` 之类的具体类型分支；
- [ ] 新增一个可受伤对象只需实现接口并配置 Collider；
- [ ] 非攻击目标不会被误伤；
- [ ] 目标销毁后不会留下无效订阅或引用。
