> 适用版本：语法以 C# 9.0 为准（Unity 2021 LTS 到 Unity 6000.x 的语言版本）。示例分两类：纯 C# 控制台示例可以直接运行；标注"以下为 Unity 代码示意"的需要在 Unity 工程里使用。涉及版本差异、尚未核实的地方，正文里标"待核实"。

## 这套资料是什么

这是一套 C# 语法速通，共 28 页（含本目录），分 6 章。读者默认学过 C++ 的基础语法、STL 容器和基础数据结构，但**还没有学过枚举、类、继承**这些内容，也没有接触过 Unity。

目标是**一遍读完、能看懂 Unity 脚本、能开始写**，而不是把语言学成专家。所以每篇的结构都一样：先给"要点"，再用短代码讲清楚，穿插 C++ 对照，最后列常见坑。例子取自游戏：角色血量、技能、背包、状态机、对象池。

语言细节靠阅读记不牢，**真正熟悉要在 Unity 里写**。读完第 6 章就可以开始做小项目，遇到不确定的再回来查。

## 与其他专栏的关系

本栏位只讲"语法和用法"。需要更深入时：从 C++ 角度补面向对象，看「面向对象串讲」；值类型、GC、装箱的底层，看「C# 与 Unity 内存基础」和「C# 底层专栏」；高性能并行，看「Unity Job 与 Burst」。

## 阅读顺序

| 章 | 主题 | 解决的问题 |
| --- | --- | --- |
| 1 入门 | C++ 对照、类型转换、异常、字符串、位运算 | 把 C++ 习惯切换到 C#，先能读懂基础代码 |
| 2 基础 | 枚举、数组与集合、值/引用类型、函数、结构体 | 数据怎么存，赋值时发生了什么 |
| 3 封装 | 类、方法与构造、属性与索引器、静态与扩展、运算符重载 | 怎么把数据和行为包成对象 |
| 4 继承与多态 | 继承、object 与装箱、多态与接口、命名空间 | 怎么复用与扩展，怎么写出"不用改调用点"的代码 |
| 5 进阶 | 泛型、委托与事件、排序、反射特性、多线程 | Unity 脚本里随处可见的高级语法 |
| 6 通向 Unity | MonoBehaviour、协程、速查表 | 把语法接回引擎，开始动手 |

建议顺序：1 → 2 → 3 → 4 为主线，必读；5 里的**泛型与委托事件**最常用，应优先读；6 在开始写 Unity 脚本时读；2.3（值类型与引用类型）和 6.3（速查表）值得反复看。
