## 这套资料是什么

这是一套**Unity 与 C# 一起讲**的语法速通，共 32 页（含本目录），分 7 章。读者默认学过 C++ 的基础语法、STL 容器和基础数据结构，但**还没有学过枚举、类、继承**这些内容，也没有接触过 Unity。

为什么要放在 Unity 里讲：只学语法容易枯燥，也不知道每个概念会用在哪；而不理解"物体、组件、脚本、游戏循环"，Unity 代码又看不懂。所以第 0 章先建立引擎的整体图景，之后每篇都有两个固定小节：

- **在 Unity 里用到它**：这个语法在引擎里出现在哪里，能解决什么问题。
- **动手试试**：一个 5 到 15 分钟的小练习，放进练习脚本里做。

每篇的结构一致：先给"要点"，再用短代码讲清楚，穿插 C++ 对照，对难懂的地方配图，最后列常见坑。目标是**一遍读完、能看懂 Unity 脚本、能开始写**，而不是把语言学成专家；真正的熟练要靠在 Unity 里反复使用。

## 与其他专栏的关系

本栏位只讲"语法和用法"。需要更深入时：从 C++ 角度补面向对象，看「面向对象串讲」；熟悉编辑器界面，看「认识 Unity」；值类型、GC、装箱的底层，看「C# 与 Unity 内存基础」和「C# 底层专栏」；高性能并行，看「Unity Job 与 Burst」。

## 阅读顺序

| 章 | 主题 | 解决的问题 |
| --- | --- | --- |
| 0 先认识 Unity | 游戏循环、场景/物体/组件、MonoBehaviour 与生命周期、练习方法 | 脚本为什么不用写 Main 就能运行，写出来的代码跑在哪 |
| 1 入门 | C++ 对照、类型转换、异常、字符串、位运算 | 把 C++ 习惯切换到 C#，先能读懂基础代码 |
| 2 基础 | 枚举、数组与集合、值/引用类型、函数、结构体 | 数据怎么存，赋值时发生了什么 |
| 3 封装 | 类、方法与构造、属性与索引器、静态与扩展、运算符重载 | 怎么把数据和行为包成对象 |
| 4 继承与多态 | 继承、object 与装箱、多态与接口、命名空间 | 怎么复用与扩展，怎么写出"不用改调用点"的代码 |
| 5 进阶 | 泛型、委托与事件、排序、反射特性、多线程 | Unity 脚本里随处可见的高级语法 |
| 6 通向 Unity | 综合练习、协程、速查表 | 把语法装进一个能玩的小东西，开始动手 |

建议顺序：**0 → 1 → 2 → 3 → 4 为主线，必读**；5 里的泛型与委托事件最常用，应优先读；6 在主线读完后做。2.3（值类型与引用类型）和 6.3（速查表）值得反复看。
