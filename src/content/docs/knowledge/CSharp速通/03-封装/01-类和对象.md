> 适用版本：C# 9.0。本章默认你没有用过 C++ 的 class。知识库里的「面向对象串讲」从 C++ 角度讲同一套概念，想多一个视角可以对照看。

## 要点

- **类**（class）是自定义类型的"图纸"，**对象**是按图纸造出来的具体个体：一个 `Player` 类，可以造出你和队友两个对象。
- C# 的 `class` 是**引用类型**：`Player p = new Player();` 里的 `p` 保存的是指向对象的引用，对象在堆上，不用你手动释放。
- 成员默认是 `private`，外部要访问必须显式写 `public`。
- `private` 的价值是"别人不能随便把我的状态改坏"，下一篇的属性会把这件事做完整。

## 为什么需要类

一个角色有名字、生命值、攻击力，如果分开存：

```csharp
string[] names = { "战士", "法师" };
int[] hps     = { 120, 80 };
int[] atks    = { 15, 30 };
```

删掉一个角色要同步改三个数组，下标一不小心就错位。更自然的做法是**把属于同一个角色的数据装进一个类型**。

## 定义类与创建对象

```csharp
class Player
{
    public string name = "无名";     // 字段（成员变量），可以直接写初始值
    public int hp = 100;
    private int gold;                // 没写初始值，自动为 0；private：只有类内部能访问
}

class Demo
{
    static void Main()
    {
        Player a = new Player();     // new 创建对象，返回引用
        a.name = "战士";
        a.hp = 120;

        Player b = new Player { name = "法师", hp = 80 };   // 对象初始化器，一次设好多个字段

        Player c = a;                // 复制引用：c 和 a 指向同一个对象
        c.hp = 1;
        Console.WriteLine(a.hp);     // 1

        // a.gold = 5;               // 编译错误：gold 是 private
        Player none = null;          // 引用可以为空
        // Console.WriteLine(none.hp); // NullReferenceException
    }
}
```

对照 C++：`new` 之后没有 `delete`。当没有任何变量再引用某个对象，垃圾回收器（GC）会在之后某个时刻自动回收它。你不再担心"忘了释放"，但也失去了"精确知道什么时候释放"的控制。

## 访问修饰符

| 修饰符 | 谁能访问 | 常见用途 |
| --- | --- | --- |
| `public` | 任何地方 | 对外提供的接口 |
| `private` | 只有本类内部（**默认**） | 内部状态和辅助逻辑 |
| `protected` | 本类和子类 | 留给子类使用（第 4 章） |
| `internal` | 同一个程序集（项目）内 | 项目内部共享，对外隐藏 |

类本身不写修饰符时默认为 `internal`；类的成员不写时默认为 `private`。

## Unity 里的特别之处

脚本里的字段想在 Inspector 面板里调参，有两种写法：

```csharp
// 以下为 Unity 代码示意
public class Enemy : MonoBehaviour
{
    public int maxHp = 100;                  // public 字段：显示在 Inspector，也被外部访问
    [SerializeField] private float speed = 3f; // private 但仍显示在 Inspector，外部访问不了
    private int currentHp;                   // 不显示
}
```

推荐后一种：既能让策划在 Inspector 调数值，又不把字段暴露给其他脚本。

## 术语对照

| 你听到的词 | 在代码里指 |
| --- | --- |
| 成员变量、字段、field | 类里直接声明的变量 |
| 实例、对象 | `new` 出来的那个具体的东西 |
| 实例化 | 执行 `new` |
| 成员 | 字段、方法、属性等的统称 |

## 动手试试

用 0.2 篇学到的"类是图纸，挂载才是对象"亲自验证：

```csharp
using UnityEngine;

public class EnemyInfo : MonoBehaviour
{
    [SerializeField] private string enemyName = "无名";   // 不要叫 name，会遮住 Unity 自带的 name 属性
    [SerializeField] private int hp = 100;

    void Start()
    {
        Debug.Log($"{enemyName} hp={hp}");
    }
}
```

场景里放两个 Cube，都挂 `EnemyInfo`，在 Inspector 里分别填 `史莱姆`、30 和 `哥布林`、80。运行后 Console 会输出两行，说明同一个类产生了两个互不影响的对象。再把 `hp` 改成 `public`，对比 Inspector 里显示是否有变化。

## 常见坑

- 把 `Player a = b;` 当拷贝，改一个影响另一个。
- 字段全部写成 `public`，最后谁都能改，出问题找不到源头。
- 在 Unity 里 `new` 一个继承了 `MonoBehaviour` 的类，会得到警告且无法正常工作，要用 `AddComponent` 或在场景中挂载。
- 引用字段没有赋值就使用，得到 `NullReferenceException`。
