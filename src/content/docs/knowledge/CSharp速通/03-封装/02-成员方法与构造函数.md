> 适用版本：C# 9.0。

## 要点

- **成员方法**是属于对象的函数，能直接读写本对象的字段，用 `对象.方法()` 调用。
- **构造函数**与类同名、没有返回类型，在 `new` 时自动运行，用来把对象初始化到合法状态。
- 一旦你写了带参数的构造函数，编译器就不再自动提供无参构造函数。
- C# 里不需要手写析构函数来释放内存，GC 会处理。需要释放文件、网络等资源时用 `IDisposable`（这里只提一句）。

## 成员方法

```csharp
class Player
{
    public string name;
    public int hp;
    public int maxHp = 100;

    public void TakeDamage(int amount)
    {
        hp -= amount;                    // 直接使用本对象的字段，不用写 this.
        if (hp < 0) hp = 0;
    }

    public void Heal(int amount)
    {
        hp = Math.Min(hp + amount, maxHp);
    }

    public bool IsDead() => hp <= 0;
}

Player p = new Player { name = "战士", hp = 50 };
p.TakeDamage(80);
Console.WriteLine(p.IsDead());          // True
```

同一个方法被不同对象调用，访问的是各自的字段。`TakeDamage` 在 `p` 上调用，改的就是 `p.hp`。

## this

`this` 表示"当前对象"，主要用于参数名和字段名相同的情形：

```csharp
public void SetName(string name)
{
    this.name = name;        // 左边是字段，右边是参数
}
```

也可以把 `this` 当成参数传给别的函数："把我自己交给你"，例如 `manager.Register(this);`。

## 构造函数

```csharp
class Player
{
    public string name;
    public int hp;
    public readonly int maxHp;           // readonly：只能在声明处或构造函数里赋值

    public Player(string name, int maxHp)            // 带两个参数的构造函数
    {
        this.name = name;
        this.maxHp = maxHp;
        this.hp = maxHp;
    }

    public Player(string name) : this(name, 100)     // 重载 + 调用另一个构造函数
    {
    }
}

Player a = new Player("战士", 150);
Player b = new Player("法师");           // maxHp 默认 100
// Player c = new Player();              // 编译错误：我们写了构造函数，就没有无参的了
```

`: this(...)` 让一个构造函数把工作交给另一个，避免重复初始化代码。`readonly` 字段适合那些"创建后不应再变"的设定，例如最大生命值、角色编号。

## 对象创建的顺序

`new Player("战士")` 时依次发生：先分配内存并全部清零，再执行字段声明处的初始值，最后运行构造函数体。因此字段在构造函数开始时就已经有值，而不是随机值。

## 没有析构函数这件事

C++ 的析构函数在对象离开作用域时立刻运行，常用于释放资源（RAII）。C# 的 GC 回收时机不确定，所以：

- 内存不用管。
- 需要及时释放的资源（文件、数据库连接、原生内存）实现 `IDisposable`，并用 `using` 语句保证释放。
- 手写终结器 `~Player()` 几乎用不到，这属于进阶话题，放在「C# 底层专栏」。

```csharp
using (var reader = new System.IO.StreamReader("save.txt"))   // 离开代码块时自动 Dispose
{
    string line = reader.ReadLine();
}
```

## Unity 里的特别之处

继承了 `MonoBehaviour` 的脚本**不要写构造函数**，Unity 自己负责创建它们。初始化放在 `Awake` / `Start`：

```csharp
// 以下为 Unity 代码示意
public class Enemy : MonoBehaviour
{
    private int hp;
    void Awake() { hp = 100; }       // 对象刚被创建时调用，适合初始化自身
    void Start() { /* 所有对象的 Awake 都执行完后，适合获取其他对象 */ }
}
```

普通的 C# 类（不继承 `MonoBehaviour` 的数据类、工具类）则正常使用构造函数。

## 动手试试

普通类用构造函数，`MonoBehaviour` 用 `Awake`：

```csharp
using UnityEngine;

public class Weapon                                     // 普通类，可以 new
{
    public readonly string name;
    public readonly int damage;

    public Weapon(string name, int damage)
    {
        this.name = name;
        this.damage = damage;
    }
}

public class Soldier : MonoBehaviour
{
    private Weapon weapon;

    void Awake()
    {
        weapon = new Weapon("长剑", 15);               // 在 Awake 里创建
    }

    void Start()
    {
        Debug.Log($"{weapon.name} 伤害 {weapon.damage}");
    }
}
```

挂到物体上运行。然后在 `Start` 里临时加一行 `new Soldier();`，看 Console 出现的警告：Unity 提示不能用 `new` 创建 `MonoBehaviour`。

## 常见坑

- 写了带参构造函数后，其他地方的 `new Player()` 全部编译失败。需要的话补一个无参构造。
- 构造函数里访问其他尚未创建的对象。
- 在 `MonoBehaviour` 里写构造函数，被调用的时机和线程由引擎决定，容易出现奇怪的 bug。
- 期待对象"离开作用域就立刻被销毁"。
