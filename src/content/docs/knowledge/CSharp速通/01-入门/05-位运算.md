> 适用版本：C# 9.0。C# 11 才有的 `>>>` 在 Unity 6000.x 的语言版本中不可用。

> **本篇主线标记**：本篇的 LayerMask 查询是 `【主线实践】`，普通位运算例子是 `【可选扩展】`；它只负责筛选攻击/射线目标，不替代运行时集合。

## 要点

- 运算符和 C++ 完全一致：`&`（与）、`|`（或）、`^`（异或）、`~`（取反）、`<<`、`>>`。
- 一个 `int` 有 32 个二进制位，可以当 32 个开关用：这就是"状态标志"。
- Unity 的**碰撞层**（Layer）和 `LayerMask` 就是这种用法，你很快就会在射线检测里遇到。
- 比较运算符的优先级**高于** `&` 和 `|`，所以判断位时必须加括号。

## 用一个整数保存多个状态

给角色做一套异常状态：中毒、燃烧、冰冻，它们可以同时存在。

```csharp
const int Poison = 1 << 0;      // 0001
const int Burn   = 1 << 1;      // 0010
const int Freeze = 1 << 2;      // 0100

int status = 0;

status |= Poison | Burn;                    // 添加状态：0011
status &= ~Burn;                            // 移除燃烧：0001
bool poisoned = (status & Poison) != 0;     // 判断：括号不能省
status ^= Freeze;                           // 翻转冰冻：0101

Console.WriteLine(Convert.ToString(status, 2)); // 以二进制输出：101
```

四种基本操作可以背成模板：

| 要做的事 | 写法 |
| --- | --- |
| 打开某位 | `x \|= flag` |
| 关闭某位 | `x &= ~flag` |
| 翻转某位 | `x ^= flag` |
| 检查某位 | `(x & flag) != 0` |

下一篇的枚举加上 `[Flags]` 后，可以把这些常量换成有名字的类型，更不容易写错。

## 移位

```csharp
int a = 1 << 3;     // 8，相当于乘以 2 的 3 次方
int b = 16 >> 2;    // 4，相当于除以 4（向下取整）
int c = -16 >> 2;   // -4，有符号数右移保留符号位
```

在以前的引擎代码里，乘除 2 的幂常写成移位。现在编译器会自动优化，只在真的处理"位"的时候用移位，别为了"快"强行用。

## Unity 里的 LayerMask

Unity 有 32 个碰撞层，编号 0 到 31。`LayerMask` 本质就是一个 32 位整数，第 N 位为 1 表示"包含第 N 层"。

```csharp
int enemyLayer = 8;                          // 假设第 8 层是 Enemy
int mask = 1 << enemyLayer;                  // 只包含 Enemy 层
int everythingButEnemy = ~mask;              // 除了 Enemy 之外所有层
int enemyOrWall = (1 << 8) | (1 << 9);       // Enemy 和 Wall 两层

// 射线检测只命中指定层的写法：
// Physics.Raycast(origin, direction, out hit, 100f, mask);
```

![用三行位图展示 1 << 8、(1 << 8) | (1 << 9) 和 ~(1 << 8) 在低 12 位上的取值](/qmx-Gameknowledge/assets/csharp/layermask.svg)

这正是"为什么射线检测的最后一个参数不是层编号，而是 `1 << 层编号`"的答案。

## 动手试试

> **代码归属**：`【实验代码】`。本段只放进 `Assets/Speedrun/Labs/` 临时验证；要进入小游戏主线，请跟随后文或目录中的 `【主线实践】` 文章，在 `Assets/Speedrun/Game/` 重新接入并完成验收。

1. 打开 Edit → Project Settings → Tags and Layers，在 User Layer 8 填 `Enemy`，9 填 `Wall`。
2. 在脚本里写 `[SerializeField] private LayerMask mask;`，Inspector 会显示成多选下拉，勾选 Enemy 和 Wall。
3. `Start` 里输出：

```csharp
Debug.Log(mask.value);                                   // 勾了 8、9 两层应为 768
Debug.Log((1 << 8) | (1 << 9));                          // 同样是 768
Debug.Log(LayerMask.GetMask("Enemy", "Wall"));           // 也是 768
```

三个数相同，说明 `LayerMask` 就是你在本篇里手算的那个整数。

## 项目应用决策：位标志和普通枚举的区别

方块地牢中的“玩家状态”同一时刻通常只有一个，应使用普通 `enum`；“受影响的效果”可能同时有中毒、减速和护盾，才适合用 `[Flags] enum` 或位掩码。

`LayerMask` 是 Unity 把位集合用于物理查询的例子：射线检测墙和敌人时传入一个掩码，避免每次查询后再手工过滤对象。它适合**集合成员判断**，不适合代替 `List<Enemy>` 保存运行时对象。

验收：射线只命中 `Enemy` 或 `Wall` 层；新增一个层时只改 Inspector 配置，查询代码不变。若需求要求保存对象、遍历对象或显示顺序，应回到集合而不是继续叠加位运算。

## 常见坑

- 写成 `x & flag != 0`：因为 `!=` 的优先级高于 `&`，实际被解析为 `x & (flag != 0)`，C# 里这是类型错误，C++ 里则是悄悄的逻辑错误。**一律加括号**。
- 把 `&`、`|` 当成 `&&`、`||`：对 `bool` 也合法，但**不会短路**，右边总会被求值。
- 对有符号 `int` 左移到符号位，得到负数。需要全 32 位标志时，用 `uint`。
- 想"清除所有状态"却写成 `status &= 0`：可行但不直观，直接 `status = 0`。
