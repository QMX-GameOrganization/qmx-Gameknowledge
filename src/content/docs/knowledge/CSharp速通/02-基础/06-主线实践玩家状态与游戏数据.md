> 标记：`【主线实践】`。本篇把 2.1～2.5 的语法连成项目数据模型。

> **代码归属**：`【主线代码】`。本篇代码写入 `Assets/Speedrun/Game/`，会被后续章节继续引用；不能只放在 `Labs/`。

## 数据所有者

- `PlayerState` 表示互斥的玩家阶段；
- `DamageInfo` 表示一次伤害的值快照；
- `PlayerStats` 持有会随游戏变化的状态；
- `Inventory` 持有收集物数量；
- Unity 组件只负责把这些对象接到场景，不把所有字段塞进一个 MonoBehaviour。

```csharp
public enum PlayerState { Idle, Run, Attack, Dead }

public readonly struct DamageInfo
{
    public readonly int Amount;
    public readonly string Source;

    public DamageInfo(int amount, string source)
    {
        Amount = amount;
        Source = source;
    }
}

public sealed class PlayerStats
{
    public int MaxHp { get; }
    public int Hp { get; private set; }
    public PlayerState State { get; set; }

    public PlayerStats(int maxHp)
    {
        MaxHp = maxHp;
        Hp = maxHp;
        State = PlayerState.Idle;
    }

    public void ApplyDamage(DamageInfo damage)
    {
        Hp = Math.Max(0, Hp - damage.Amount);
        if (Hp == 0) State = PlayerState.Dead;
    }
}
```

代码中的 `class`、`struct` 和 `enum` 分别对应身份状态、值快照和有限状态。它们不是为了展示三种写法，而是为了让后续攻击、HUD 和重开知道谁拥有哪份数据。

## 验收

- [ ] 玩家状态不能同时是 `Run` 和 `Dead`；
- [ ] 修改一个 `DamageInfo` 副本不会改掉另一个副本；
- [ ] 两个玩家对象的 `PlayerStats` 不共享血量；
- [ ] 库存可以按物品 ID 查询并显示收集数量；
- [ ] 场景重开时能创建一份新的初始状态。
