> 适用版本：C# 9.0。集合类的泛型细节在 5.1 篇补充，这里先给你一张"STL 到 C#"的对照表，足够开始写 Unity 脚本。

## 要点

- 数组 `int[]` 是**引用类型**，用 `new` 创建，长度创建后不能变，不需要也不能 `delete`。
- 访问越界会抛 `IndexOutOfRangeException`，不是未定义行为。
- `int[] b = a;` 是让 `b` 指向同一个数组，**不是拷贝**。
- 日常动态数组用 `List<T>`，它就是 `std::vector`；字典用 `Dictionary<K,V>`，就是 `std::unordered_map`。

## 一维数组

```csharp
int[] cooldowns = new int[5];                  // 5 个元素，全是 0
string[] skills = { "火球", "冰锥", "治疗" };    // 初始化列表，长度自动为 3
int[] nums = new int[] { 1, 2, 3 };

cooldowns[0] = 30;
Console.WriteLine(skills.Length);              // 3，Length 是属性，不带括号

foreach (string s in skills)                   // 只读遍历，s 不能被赋值
    Console.WriteLine(s);

// cooldowns[5] = 1;                           // 运行时抛 IndexOutOfRangeException
```

`foreach` 里的迭代变量是只读的：你可以修改它指向对象的内容（引用类型时），但不能改变它本身。如果需要通过下标写回元素，用普通 `for`。

## 多维数组与交错数组

```csharp
int[,] map = new int[3, 4];                    // 3 行 4 列的矩形数组，内存连续
map[1, 2] = 7;
Console.WriteLine(map.GetLength(0));           // 3，第 0 维长度
Console.WriteLine(map.GetLength(1));           // 4

int[][] rooms = new int[3][];                  // 交错数组：数组的数组，每行可以不等长
rooms[0] = new int[2];
rooms[1] = new int[5];
rooms[2] = new int[1];
rooms[1][3] = 9;
```

瓦片地图常用 `int[,]`，每行长度不同的数据（例如每个房间的怪物列表）适合交错数组。多维数组 `[,]` 的访问速度比交错数组稍慢，对性能敏感的代码里很多人会用一维数组手动计算下标 `y * width + x`。

## 数组是引用类型：别名陷阱

```csharp
int[] a = { 1, 2, 3 };
int[] b = a;            // 只复制了"指向数组的引用"
b[0] = 99;
Console.WriteLine(a[0]); // 99，a 和 b 是同一个数组

int[] c = (int[])a.Clone();      // 真拷贝（浅拷贝）
int[] d = new int[a.Length];
Array.Copy(a, d, a.Length);      // 另一种拷贝方式
```

这是你从 C++ 过来最需要适应的一点，2.3 篇会系统解释"值类型与引用类型"。

## 常用的 Array 静态方法

```csharp
int[] scores = { 50, 20, 80 };
Array.Sort(scores);                    // 升序：20, 50, 80
Array.Reverse(scores);                 // 反转：80, 50, 20
int idx = Array.IndexOf(scores, 50);   // 1
Array.Clear(scores, 0, scores.Length); // 全部置 0
```

## STL 到 C# 容器对照

| C++ STL | C# | 说明 |
| --- | --- | --- |
| `std::array` / 原生数组 | `T[]` | 定长，引用类型 |
| `std::vector<T>` | `List<T>` | 动态数组，`Add`、`Remove`、`Count` |
| `std::unordered_map<K,V>` | `Dictionary<K,V>` | 取值失败用 `TryGetValue` |
| `std::unordered_set<T>` | `HashSet<T>` | 去重、判断是否存在 |
| `std::queue<T>` | `Queue<T>` | `Enqueue`、`Dequeue` |
| `std::stack<T>` | `Stack<T>` | `Push`、`Pop` |
| `std::list<T>` | `LinkedList<T>` | 很少用，见 5.1 |
| `std::map<K,V>`（有序） | `SortedDictionary<K,V>` | 按键排序 |

```csharp
using System.Collections.Generic;              // 这些容器都在这个命名空间

List<string> bag = new List<string>();
bag.Add("药水");
bag.Add("长剑");
bag.Remove("药水");
Console.WriteLine(bag.Count);                  // 1，注意 List 用 Count，数组用 Length

Dictionary<int, string> items = new Dictionary<int, string>
{
    { 1001, "铁剑" },
    { 1002, "木盾" }
};
if (items.TryGetValue(1001, out string name))
    Console.WriteLine(name);
```

和 STL 的一个重要区别：`Dictionary` 用 `items[key]` 取不存在的键会**抛异常**，不像 `std::map` 的 `operator[]` 会默默插入默认值。

## 在 Unity 里用到它

- 数组和 `List<T>` 字段可以直接在 Inspector 里设置长度并**拖入多个物体**，这是 Unity 最常用的配置方式，比如巡逻路点、出生点、掉落物清单。
- `GameObject.FindGameObjectsWithTag("Enemy")` 返回的是数组，可以用 `foreach` 遍历。
- `foreach` 对数组不会产生垃圾；对旧式的非泛型集合会装箱（4.2 篇）。

## 项目应用决策：容器选择取决于访问方式

- 长度固定、按索引访问的路线点或波次配置用数组；
- 需要增删、遍历和 Inspector 配置的敌人列表用 `List<T>`；
- 按 ID 查找物品或存档字段用 `Dictionary<TKey,TValue>`；
- 先进先出的伤害事件或生成队列用 `Queue<T>`。

不要因为“都能存对象”就随意替换容器。主线验收要检查增删、查找和顺序三种操作，确认集合的选择对应需求；高频生成销毁再进入对象池，而不是用 `List` 假装池化。

## 常见坑

- 误把数组赋值当拷贝，改一个数组影响了另一个。
- 数组用 `Length`，`List` 用 `Count`，混用会编译错误，写顺手即可。
- 在 `foreach` 遍历 `List` 的过程中增删元素：会抛 `InvalidOperationException`。需要边遍历边删时用倒序 `for`。
- 每帧 `new int[...]` 或 `new List<...>()`：产生垃圾，提前创建并复用。
