> 适用版本：Dying Light 1.55.0.0。依据 `DL1/Teach/Logic/进阶教学.md` 第 10 节与 `Perception.cs`。**视距和角度是原声明参数；插值方式、半角取法、记忆时长是教学设计，没有经过原引擎验证。**

## 要点

- 感知用“快照”：眼点、前向、目标点、物理视线结果、昼夜与冷静状态，一次性收齐，决策函数不再读场景。
- 可见性的判定顺序：先物理遮挡，再视距，再近距全角，再按方向点乘。
- 追逐记忆只允许使用**最后一次看见的位置**，不允许用当前不可见目标的真实位置，否则 AI 作弊。

`zombie_params_level_0.scr` 又声明冷静/警戒视距为 6、夜间倍率 1、全角近距范围 2。教材手工选择“基表后应用 level0 所声明字段”的数据集，**不声称它是所有普通丧尸或所有关卡运行时最终配置**。完整 `include`、预设覆盖和难度装配尚未执行。

注意夜间倍率在所选数据里是 1，所以不能演示成“夜间必然看得更远”。

## 教学实现

```csharp
public static bool Visible(Observation Observation, SightSettings Settings)
{
    if (!Observation.LineOfSight) return false;                      // 1. 物理遮挡
    var Offset = Observation.Target - Observation.Eye;
    float Distance = Offset.Length();
    float Range = (Observation.Calm ? Settings.CalmRangeMeters : Settings.AlertRangeMeters)
                * (Observation.Night ? Settings.NightRangeMultiplier : 1);
    if (Distance > Range) return false;                             // 2. 视距
    if (Distance <= Settings.FullAngleRangeMeters) return true;     // 3. 近距全角
    float Fraction = Math.Clamp((Distance - Settings.NearDistanceMeters)
                              / (Settings.FarDistanceMeters - Settings.NearDistanceMeters), 0, 1);
    float Angle = Settings.NearAngleDegrees + (Settings.FarAngleDegrees - Settings.NearAngleDegrees) * Fraction;
    float MinimumDot = MathF.Cos(Angle * MathF.PI / 360);           // 总视角 ÷ 2，再转弧度
    return Vector3.Dot(Observation.Forward, Offset / Distance) >= MinimumDot;   // 4. 方向
}
```

每步的设计意图：

| 步骤 | 原因 |
| --- | --- |
| 先查物理视线 | 最便宜的否决，遮挡了就不用算别的 |
| 视距带夜间倍率 | 数据里就有这个乘数，调用方按状态选取 |
| 近距全角 | 贴脸一定看得到，不论朝向 |
| 角度随距离线性插值 | 近处视角宽，远处视角窄 |
| 用点乘比较 `cos(半角)` | 避免每次 `acos`，只在配置层算一次余弦 |

有一处细节：`Angle × π / 360` 是“总视角除以二再转弧度”，这是教材的教学约定，原引擎是否如此未验证。

## 追逐记忆

```csharp
public void Tick(double Seconds, bool Visible, Vector3 Target, bool CanAttack)
{
    if (!double.IsFinite(Seconds) || Seconds < PreviousTime) throw new ArgumentOutOfRangeException(nameof(Seconds));
    PreviousTime = Seconds;
    if (Visible) { LastSeenAt = Seconds; LastSeenPosition = Target;
                   State = CanAttack ? ePursuitState.Attack : ePursuitState.Chase; }
    else if (LastSeenPosition.HasValue && Seconds - LastSeenAt < MemorySeconds)
        State = ePursuitState.Search;
    else { LastSeenPosition = null; State = ePursuitState.Idle; }
}
```

状态机只有四个状态：`Idle → Chase/Attack → Search → Idle`。要点：

- 可见时更新“最后可见位置”和时间；
- 不可见期间只保留位置，状态为 `Search`，满 `MemorySeconds` 后忘记并回 `Idle`；
- `CanAttack` 由外部明确传入，教学代码不凭字段名猜攻击距离、冷却或可达性；
- 时间必须单调不倒退。

## 自测（教材）

- 5 米前方无阻挡可见，6.01 米不可见；
- 距离近但被墙挡仍不可见；
- 1 米身后因全角可见，5 米身后不可见；
- 丢失视线后记忆保留旧位置，满 5 秒（教学输入）才退出搜索。

## 尚未覆盖

真实物理射线、听觉传播、气味与伪装、UV 反应、群体感知、夜魔特殊感知、原报警级别算法。这一章只把原范围参数接到一个可修改的感知/追逐内核上。

## 值得学的点

- **感知快照**：把世界读取收敛到一个只读结构，让决策函数纯净，容易测试。
- **“记住最后见到的位置”是廉价且有效的拟真**，同时杜绝 AI 作弊。
- **距离相关的视角锥**：近宽远窄，比固定锥更接近直觉。
- **数据值与教学约定分开标注**：角度单位、半角取法、记忆时长在文中都被明确标为教学约定。

## 常见坑

- 用余弦阈值比较时忘了把总视角除以二。
- 目标不可见时仍读取目标当前位置。
- 把教学测试里的 5 米、5 秒当作原作参数。
