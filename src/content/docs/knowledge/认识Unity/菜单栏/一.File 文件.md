![](https://cdn.nlark.com/yuque/0/2026/png/61618570/1792410231183-0d8726c6-11d5-42b2-93d2-740f47db2a36.png)

### Scene Templates in Project 场景模板

| 模板                               | 简单介绍                                           |
| -------------------------------- | ---------------------------------------------- |
| **Basic(URP)**                   | 使用通用渲染管线（URP）的基础场景，包含摄像机、方向光等基础配置，适合日常学习和搭建场景。 |
| **Indoors(URP)**                 | 使用 URP 的室内示例场景，预设了室内物体和灯光，适合学习室内光照效果。          |
| **Outdoors(URP)**                | 使用 URP 的室外示例场景，预设了环境和光照，适合学习室外渲染效果。            |
| **Empty**                        | 完全没有游戏对象的空场景，需要自己添加摄像机、灯光等。                    |
| **Basic(Built-in / Deprecated)** | 使用传统内置渲染管线的基础场景，该模板已标记为弃用，主要用于旧项目或旧教程。         |
