所属专题：**考试 → 毛概**。

本文按简答题、论述题的答题口径整理。复习时先记核心结论，再按要点展开；具体表述以任课教师要求及所用教材版本为准。

## 1. 为什么说实事求是是毛泽东思想的精髓？

**实事求是是毛泽东思想的基本点，是贯穿毛泽东思想各个组成部分的立场、观点和方法，是毛泽东思想的精髓。**

1. **体现马克思主义的根本要求。**实事求是，就是一切从实际出发，理论联系实际，坚持在实践中检验真理和发展真理，体现了辩证唯物主义和历史唯物主义的世界观、方法论。
2. **是毛泽东思想形成和发展的根本途径。**毛泽东坚持把马克思列宁主义基本原理同中国具体实际相结合，在反对教条主义、总结中国革命实践经验的过程中，形成和发展了毛泽东思想。
3. **贯穿毛泽东思想的全部内容。**无论是新民主主义革命道路，还是社会主义改造和社会主义建设的探索，都体现了从中国实际出发、解决中国具体问题的要求。
4. **是中国革命和建设取得胜利的重要思想保证。**坚持实事求是，党就能制定符合实际的路线、方针和政策；偏离实事求是，事业就会遭受挫折。

**速记：根本要求—形成途径—贯穿全部—胜利保证。**

## 2. 毛泽东思想的历史地位

1. **马克思主义中国化时代化的第一个重大理论成果。**毛泽东思想创造性地运用和发展了马克思列宁主义，为马克思主义中国化时代化奠定了基础。
2. **中国革命和建设的科学指南。**它指导党和人民取得新民主主义革命胜利，建立中华人民共和国，完成社会主义改造，确立社会主义基本制度，并对中国社会主义建设道路进行了艰辛探索。
3. **中国共产党和中国人民宝贵的精神财富。**实事求是、群众路线、独立自主是毛泽东思想活的灵魂，具有长远指导意义。

**答题注意：**毛泽东思想是被实践证明了的关于中国革命和建设的正确理论原则和经验总结，是中国共产党集体智慧的结晶。不能把毛泽东晚年的错误等同于毛泽东思想。

**速记：第一个重大理论成果—科学指南—精神财富。**

## 3. 新民主主义的基本纲领

新民主主义基本纲领包括**政治纲领、经济纲领和文化纲领**。

### 政治纲领

推翻帝国主义和封建主义的统治，建立一个无产阶级领导的、以工农联盟为基础的、各革命阶级联合专政的新民主主义共和国。

### 经济纲领

- 没收封建地主阶级的土地归农民所有。
- 没收官僚资产阶级的垄断资本归新民主主义的国家所有。
- 保护民族工商业。

其中，**保护民族工商业是新民主主义经济纲领中极具特色的一项内容**。新民主主义革命的对象包括官僚资本主义，但一般不消灭民族资本主义。

### 文化纲领

发展无产阶级领导的、人民大众的、反帝反封建的文化，即**民族的、科学的、大众的文化**。

**速记：政治建政权；经济“两没收、一保护”；文化“民族、科学、大众”。**

## 4. 新民主主义革命道路为什么能走通？

中国革命走的是**农村包围城市、武装夺取政权的道路**。这条道路能走通，既有必要性，也有可能性，关键在于符合中国国情。

### 必要性

1. **半殖民地半封建社会的国情决定必须进行武装斗争。**中国内部没有民主制度，外部没有民族独立，革命无法主要通过合法、和平的方式取得胜利。
2. **敌强我弱的力量对比决定必须首先到农村积蓄力量。**反动统治力量主要集中在大城市，农村是其统治的薄弱环节。
3. **农民是中国革命的主力军。**中国是农业大国，农民占人口绝大多数，必须深入农村发动和组织农民。

### 可能性

1. 中国政治经济发展不平衡，为革命力量在农村生存和发展提供了空间。
2. 近代中国特别是大革命的影响，为农村革命根据地的建立提供了群众基础。
3. 全国革命形势的继续向前发展，为根据地的坚持和发展提供了客观条件。
4. 相当力量的正式红军的存在，为根据地的创建和发展提供了军事保障。
5. **党的领导及其正确政策，为这条道路提供了最重要的主观条件。**

### 实践保证

党把**土地革命、武装斗争、农村革命根据地建设**结合起来：土地革命是民主革命的基本内容，武装斗争是主要形式，农村革命根据地是战略阵地，最终实现由农村包围城市、夺取全国政权。

**速记：必要性—可能性—工农武装割据。**

## 5. 新民主主义革命的三大法宝及其关系

三大法宝是：**统一战线、武装斗争、党的建设。**

1. **统一战线：**团结一切可以团结的力量，发展进步势力，争取中间势力，孤立顽固势力，最大限度壮大革命力量。
2. **武装斗争：**中国革命的重要特点和主要形式。必须建立党领导的人民军队，坚持人民战争。
3. **党的建设：**建设一个具有广泛群众性、思想上政治上组织上完全巩固的马克思主义政党，为革命提供坚强领导。

**三者的关系：**

- **统一战线和武装斗争，是战胜敌人的两个基本武器。**
- **统一战线是实行武装斗争的统一战线，武装斗争是统一战线的中心支柱。**
- **党的组织是掌握统一战线和武装斗争这两个武器、实行对敌冲锋陷阵的英勇战士。**

因此，三者相互联系、相互配合；**党的领导是统一战线和武装斗争取得胜利的根本保证。**

**速记：两个武器，一个掌握武器的英勇战士。**

## 6. 党在过渡时期的总路线及其依据

### 总路线的内容

**从中华人民共和国成立，到社会主义改造基本完成，这是一个过渡时期。党在这个过渡时期的总路线和总任务，是要在一个相当长的时期内，逐步实现国家的社会主义工业化，并逐步实现国家对农业、对手工业和对资本主义工商业的社会主义改造。**

概括为：**“一化三改”。**

- “一化”：社会主义工业化。
- “三改”：对农业、手工业、资本主义工商业的社会主义改造。

**社会主义工业化是主体，三大改造是两翼，二者相互促进。**其实质是使生产资料的社会主义所有制成为我国国家和社会的唯一的经济基础。

### 提出的依据

1. **社会主义性质的国营经济力量相对强大。**它掌握国家经济命脉，成为社会主义改造的重要经济基础。
2. **资本主义经济力量弱小，发展困难。**民族资本主义无法承担实现国家工业化的历史重任，需要通过国家资本主义等形式逐步进行社会主义改造。
3. **个体农业、手工业难以适应国家工业化建设的需要。**通过合作化发展生产、改善经营条件，成为客观要求。
4. **国际环境提供了有利条件。**当时社会主义国家的发展及苏联的援助，为我国实行社会主义工业化和社会主义改造提供了支持。

**速记：一化三改、主体两翼；国营基础、资本薄弱、合作需要、国际条件。**

## 7. 社会主义改造的历史经验

1. **坚持社会主义工业化建设与社会主义改造同时并举。**通过改造生产关系促进生产力发展，同时依靠工业化为社会主义改造提供物质基础。
2. **采取积极引导、逐步过渡的方式。**根据不同改造对象的特点，采取由低级到高级、适合中国情况的过渡形式。
3. **用和平方法进行改造。**对资本主义工商业实行和平赎买，把对企业的改造与对资本家的改造结合起来，减少社会震荡，维护社会稳定。

### 三类改造的过渡形式

| 改造对象 | 主要过渡形式 |
| --- | --- |
| 农业 | 互助组 → 初级农业生产合作社 → 高级农业生产合作社 |
| 手工业 | 供销小组 → 供销合作社 → 生产合作社 |
| 资本主义工商业 | 由低级到高级的国家资本主义形式，逐步发展到全行业公私合营 |

**评价时可补充：**社会主义改造也存在后期要求过急、工作过粗、改变过快、形式过于简单划一等问题，应全面总结经验教训。

**速记：建设改造并举—逐步过渡—和平方法。**

## 8. 调动一切积极因素为社会主义事业服务

这一方针是毛泽东在**《论十大关系》**中提出的社会主义建设的基本方针。

1. **出发点：立足中国实际，探索适合中国情况的社会主义建设道路。**以苏联经验为借鉴，独立自主地处理社会主义建设中的重大关系。
2. **积极因素的范围：**包括党内和党外、国内和国外的各种有利因素，其中既有现实的积极因素，也有潜在的积极因素。
3. **基本要求：**调动一切积极因素，团结一切可以团结的力量，尽可能把消极因素转化为积极因素，为社会主义建设服务。
4. **实现途径：**正确处理重工业与轻工业、农业，中央与地方，沿海工业与内地工业等关系；正确处理人民内部矛盾，兼顾国家、集体和个人利益，扩大社会主义民主。
5. **领导保证：**坚持中国共产党的领导，发挥党总揽全局、协调各方的作用。

**核心理解：通过正确处理各种关系，把各方面的积极性充分调动起来，共同建设社会主义。**

**速记：处理关系—团结力量—转化消极因素。**

## 9. 邓小平理论的精髓

**解放思想、实事求是，是邓小平理论的精髓。**

1. **解放思想：**在马克思主义指导下，打破习惯势力和主观偏见的束缚，研究新情况，解决新问题。
2. **实事求是：**一切从实际出发，理论联系实际，在实践中检验真理和发展真理。
3. **二者相互联系、相互促进。**解放思想是实事求是的前提，实事求是是解放思想的目的和归宿，二者统一于中国特色社会主义实践。
4. **这一思想路线贯穿邓小平理论的形成和发展。**它推动党重新确立正确思想路线，科学认识社会主义本质和社会主义初级阶段，作出改革开放的重大决策。

**答题注意：**解放思想不是脱离实际、随心所欲，而是使思想和实际相符合，使主观和客观相符合。

**速记：解放思想、实事求是；前提与归宿，统一于实践。**

## 10. 社会主义改革开放和社会主义市场经济理论

### 社会主义改革开放理论

1. **改革是中国的第二次革命。**改革是社会主义制度的自我完善和发展，其目的在于解放和发展生产力。
2. **改革是社会主义社会发展的直接动力。**通过改革不适应生产力发展的生产关系和上层建筑，增强社会主义制度的生机和活力。
3. **改革是全面的改革。**以经济体制改革为重点，同时推进其他领域的体制改革。
4. **判断改革和各方面工作是非得失，主要看“三个有利于”。**
5. **对外开放是建设中国特色社会主义的一项基本国策。**中国的发展离不开世界，要吸收和借鉴人类社会创造的一切文明成果，坚持独立自主、自力更生与对外开放相结合。
6. **正确处理改革、发展、稳定的关系。**改革是动力，发展是目的，稳定是前提。

**“三个有利于”：**

- 是否有利于发展社会主义社会的生产力。
- 是否有利于增强社会主义国家的综合国力。
- 是否有利于提高人民的生活水平。

### 社会主义市场经济理论

1. **计划经济不等于社会主义，市场经济不等于资本主义。**计划多一点还是市场多一点，不是社会主义与资本主义的本质区别。
2. **计划和市场都是经济手段。**计划和市场各有优势，在不同社会制度中都可以运用。
3. **社会主义也可以搞市场经济。**市场经济可以与社会主义基本制度结合，建立社会主义市场经济体制。
4. **社会主义市场经济的优势，来自社会主义制度与市场经济优势的结合。**既运用市场机制促进资源配置、提高效率，又发挥社会主义制度的优越性。

**理论意义：**突破了把计划经济和市场经济看作社会基本制度范畴的传统观念，为我国经济体制改革明确了方向。

**速记：改革动力—开放国策—三个有利于—计划市场都是手段。**

## 11. 邓小平理论的历史地位

1. **马克思列宁主义、毛泽东思想的继承和发展。**邓小平理论坚持解放思想、实事求是，结合新的实践，丰富和发展了马克思主义。
2. **中国特色社会主义理论体系的开篇之作。**它初步回答了经济文化比较落后的中国如何建设社会主义、如何巩固和发展社会主义的一系列基本问题，成功开创了中国特色社会主义。
3. **改革开放和社会主义现代化建设的科学指南。**它指导党和人民走上改革开放和社会主义现代化建设道路，推动中国发展进入新的历史时期。

**速记：继承发展—开篇之作—科学指南。**
