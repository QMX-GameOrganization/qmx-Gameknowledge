> 适用版本：以 Unity 6000.x 的 Burst 1.8.x / Collections 2.x / Mathematics 1.3.x 为主线；本项目 Unity 7000.0.0a8 中 Burst 2.0.0 与 Collections 6.7.0 为转发到引擎内置模块的壳包。

## 使用说明

- 本页汇总各章节文末“参考”里实际用到的来源，已去重并按类别分组。每条给出用途、URL 和引用它的章节号。
- URL 是各章节写作时引用的地址，本页没有重新逐个抓取。文档分散在不同版本路径下，某个页面在你的版本里找不到，不代表内容不存在，见“已知问题与注意”。
- 章节号对应目录：0.x 导读，1.x Job 系统，2.x Burst，3.x 项目实践，4.x 速查与资料。
- “目录”指总目录页，“4.3”指学习目标清单。

### Burst 2.0 与 7000 alpha 的官方资料不足

- 没有找到 Burst 2.0.0 相对 1.8.x 的变更说明和升级指南（2.12）。1.8 到 2.0 的行为变化、错误码增删，全部待核实。
- 本项目的 Burst 2.0.0 是转发壳包，`TypeForwarders.cs` 只能说明类型名存在，不能说明行为与 1.8.x 相同（0.1）。Burst 2.0.0 的默认浮点模式是否仍为 `Strict`（待核实，3.2）。
- 清单里没有 `BurstDiscardAttribute`，它在 7000.0.0a8 中的所在程序集待核实（2.1、2.5）。
- `Jobs > Burst` 菜单、AOT 设置页的选项名，按 1.8.31 与 6.7 手册整理，7000.0.0a8 未逐项实测。6.7 手册的 AOT 页没有列出 `Use Platform SDK Linker`（2.11）。
- Web 平台上 Burst 的限制没有读到手册页面；Enter Play Mode Options 与 Burst 的关系，官方手册没有专门讲（2.11）。
- Collections“6.4 起为核心包”和“6.7 起为内置模块”两种说法的关系（待核实）。Mathematics 在 7000.0.0a8 中是否内置、`Unity.Collections` 与 `Unity.Mathematics` 的程序集名称与引用方式（待核实），见 0.1。

### Entities 在 7000 alpha 的状态

- 本项目 `Packages/manifest.json` 与 `packages-lock.json` 都没有 `com.unity.entities`。Entities 在 7000.0.0a8 上的版本、是否可用（待核实）。0.4 以 Entities 1.4.x 手册为准。
- ECS Samples 仓库的目录结构与样例内容没有读过（待核实）。

### 手册自身的笔误或不一致（各章已记载）

- Function pointers 页写 `SynchronousCompilation = true`，但 `BurstCompileAttribute` 的 API 页只有 `CompileSynchronously`（2.7）。
- Burst AOT 设置入口：AOT 设置页写 `Edit > Project Settings > Burst AOT Settings`，Building your project 页写 `Edit > Player Settings > Burst AOT Settings`（2.11）。
- Memory aliasing 页的示例写成小写开头的 `getUnsafePtr()`，实际是 `GetUnsafePtr()`（2.10）。
- Burst 日志示例里的 `FixedString128`，较新的 Collections 中叫 `FixedString128Bytes`（2.5）。
- Processor specific SIMD extensions 页的左压缩片段里 `movemask_ps(a)` 应传比较结果 `mask`（2.4）。
- Parallel jobs 页的“用一半 worker”示例把 `const` 用在运行时值上，且给 `Schedule` 传了三个参数，不能照抄（1.1）。
- 平台页一处写 x86/x64 运行时只支持 `SSE2` 与 `SSE4`，另一处又列了 AVX 与 AVX2 目标，对应关系没说清（2.11）。
- Burst 手册没有收录 `BC1016`、`BC1042` 的专页，消息原文来自社区（2.2、2.12）。

### 社区来源的可信度

- 第 8 节的帖子和 issue 只用来核对报错原文与菜单位置，不是官方文档。
- `-diag-job-temp-memory-leak-validation` 命令行参数、`job reflection data has not been automatically computed` 这类报错措辞，都来自论坛，待核实（1.5、2.9）。
- 3.3 引用的 Job System 手册页和 Burst 手册首页，只确认了页面结构，没有读到 `[NativeDisableParallelForRestriction]` 对 `IJobParallelFor` 下标限制的逐条说明，该语义依据 1.6 的整理。

## 11 如何查文档

在 Unity 7000.0.0a8 这类 alpha 下查 API，建议按下面的顺序。

1. 先看清包的形态。本项目的 `com.unity.burst` 2.0.0 与 `com.unity.collections` 6.7.0 的 `package.json` 里写着转发（`"type": "shim"` 等），类型在引擎内置模块里，命名空间不变。Mathematics 从 6.5 起是内置模块，项目里没有它的包目录。
2. 查对应 6000.x 的手册。Job System 看 Unity Manual；Collections 看 6.7 之后的 Unity Manual 或 Collections 2.5 包手册；Burst 看 1.8 包手册，再对照 6000.7 Manual 的 `burst/` 页面；Mathematics 看 Scripting API 与 Manual 的 Unity Mathematics APIs。在文档页右上角切换到对应版本，找不到页面说明它在那个版本不存在。
3. 用本地 `Library/PackageCache/com.unity.burst@…/Runtime/TypeForwarders.cs` 验证 Burst 类型是否存在；Collections 容器和 Job 类型看 `Library/PackageCache/com.unity.collections@…/Unity.Collections/AssemblyTypeForwarders.cs`。类型名存在，不代表行为与 1.8.x 相同，行为以新版文档和实机为准。
4. 查 CHANGELOG 确认改名、移除和修复版本：Collections 看本地 `CHANGELOG.md`（6.4 起不再维护），Burst 看在线 1.8 CHANGELOG。
5. 菜单、选项名和行为差异，用一个最小 Job 加 Burst Inspector 在编辑器里实测，以实际界面为准。
6. 仍然核实不了的内容，在笔记里标“待核实”，不要当成确定结论。
