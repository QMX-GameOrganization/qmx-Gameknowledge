> 适用版本：以 Unity 6000.x 的 Burst 1.8.x / Collections 2.x / Mathematics 1.3.x 为主线；Unity 6.4 起 Collections 作为核心包随编辑器分发；本项目的 Unity 7000.0.0a8 中 Burst 2.0.0 与 Collections 6.7.0 是转发（shim）到引擎内置模块的壳包，API 仍在 `Unity.Burst` / `Unity.Collections` 命名空间，文档迁到了 Unity Manual。涉及版本差异处会写明，核实不了的标"待核实"。

## 这套资料是什么

这是一套面向游戏开发者的 Unity C# Job System 与 Burst 编译器中文学习资料，共 48 个页面（含本目录页），分为 6 个部分。它以 Minecraft 风格体素程序化生成项目（Unity 7000.0.0a8）为实践场景：区块密度采样、面可见性计算、网格构建，都是典型的“数据量大、逻辑简单、可并行”的负载，适合用 Job + Burst 加速。

官方 Entities 手册把 DOTS 需要使用的 Unity 主要部分列为五个：Entities、Job System、Burst、Collections、Mathematics。本资料详细覆盖 Job System、Burst、Collections、Mathematics，并新增 05-Entities 专题；0.4 页保留为总览，深入内容见 05-Entities。

## 怎么读

- 每个页面的结构一致：先给结论和要点，再讲原理，再给用法与代码，再列常见坑，最后是小结和自测题。时间紧时只读开头的要点和小结。
- 先读导读部分建立整体图景，再按“基础 → Job → Burst → 实践”的顺序往下读。
- 自测题附简短答案，建议先自己答再看答案。
- 学习进度的核对用“学习目标清单”页，它按 6 个阶段给出练习与验收标准，另有阶段 7（Entities 基础与工厂实践）。

## 与本项目的对应关系

项目代码位于 `Assets/Scripts/WorldGen/`，下表列出与本资料各章对应的现有代码。

| 项目代码 | 现状 | 对应章节 |
| --- | --- | --- |
| `Voxels/VoxelFaceVisibilityJob.cs` | 已是 `[BurstCompile]` 的 `IJobParallelFor`，输入输出为 `NativeArray<byte>` | 1.2、1.8、3.1 |
| `Voxels/VoxelChunk.cs` | `solid` 是托管 `byte[]`，`Fill` 逐体素调用 `IDensityFunction.Sample` | 1.4、1.5、3.3 |
| `Voxels/ChunkDensitySampler.cs` | 区块采样器，`Fill(VoxelChunk, ...)` 在后台线程运行 | 3.2、3.3 |
| `Density/ValueNoiseFunction.cs`、`OctaveNoiseFunction.cs`、`BlendedNoiseFunction.cs` | 托管类，通过接口 `IDensityFunction.Sample(in DensityContext)` 虚调用 | 2.2、2.3、3.2 |
| `Density/CubicSplineFunction.cs` | 样条密度函数 | 3.2 |
| `Voxels/VoxelMeshBuilder.cs` | `BuildChunkData`、`CreateMesh` 等，托管循环生成顶点 | 1.9、3.4 |
| `Voxels/ChunkGenerationPipeline.cs` | 用 `Task.Run` 做后台采样与建网格，`Pump` 在主线程回收结果 | 1.10、3.5 |

要点：项目目前混合了托管 `Task.Run` 管线与一个已有的 Burst Job；学习的主线是把采样和建网格逐步迁到 Job + Burst。

## 使用说明

- 文中代码示例没有在 Unity 内编译。复制前请核对 API 名称、命名空间和所用 Unity 版本的差异。
- 涉及项目类名、方法名的地方以 `Assets/Scripts/WorldGen/` 下的真实代码为准，代码改动后可能不再一致。
- 性能数字没有给出固定倍数，因为结果取决于硬件、数据规模和写法。每章都强调要用 Profiler 或计时自行测量。
- 带“（待核实）”的内容表示在写作时没能从官方来源确认，使用前请自行验证。
- 文中引用其它章节时只写章节标题，不含链接，请在侧边栏中查找。
