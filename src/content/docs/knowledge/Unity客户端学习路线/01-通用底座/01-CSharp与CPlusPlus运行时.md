## 目标

你不需要把 C# 和 C++ 学成语言专家，但需要能判断一段代码的对象身份、生命周期、分配行为和线程边界。

## C# 必学

- 值类型和引用类型，结构体复制和引用共享。
- 装箱、拆箱、闭包、迭代器、异步和 LINQ 的分配来源。
- 委托、事件、取消订阅和对象生命周期。
- `async`、协程、线程、任务和 Unity 主线程限制。
- 泛型、接口、反射、序列化和 IL2CPP/AOT 限制。
- GC、对象池、数组复用、缓存和数据布局。

## C++ 必学

- 栈、堆、对象生命周期和 RAII。
- 拷贝、移动、完美转发和智能指针。
- 虚函数、对象布局、模板和容器迭代器失效。
- `const`、引用、指针、所有权和资源释放。
- 线程、互斥、原子操作和数据竞争。
- 编译、链接、符号、动态库和原生插件边界。

## 练习顺序

1. 用 C# 写一个带取消订阅的事件驱动状态机。
2. 写一个无额外分配的数组对象池，并用 Profiler 检查。
3. 用 C++ 写一个 RAII 文件或资源句柄。
4. 用 C++ 写一个移动构造和拷贝构造对比实验。
5. 在 Unity 中把一段高频循环从托管对象改成连续数据，并比较 GC 和耗时。

## 验收问题

- 为什么 `Update` 中创建临时集合会造成卡顿。
- 事件订阅为什么必须和生命周期绑定。
- 协程为什么不能直接等同于后台线程。
- Unity 对象销毁后，C# 引用为什么可能仍然存在。
- C++ 中谁拥有资源，谁负责释放，如何处理异常和提前返回。
