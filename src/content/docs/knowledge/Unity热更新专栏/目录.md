> 适用版本：以 Unity 2021 LTS 到 Unity 6000.x、IL2CPP 后端为主线。Addressables 按 1.2x 到 2.x 写，HybridCLR、xLua、ILRuntime 的版本支持随各自仓库更新。各篇里无法核实的细节标"待核实"。

## 这套资料是什么

这是为扩充知识库而写的 Unity 热更新专栏，共 20 篇，分 8 章，另有本目录页。读者默认已有 Unity/C# 开发经验，不讲 Unity 基础，直接讲热更新要解决什么问题、资源和代码两条线各自的原理、各方案的限制和取舍，以及上线时的版本、回滚、安全问题。

代码热更部分与 C# 底层专栏的第 4 章（Mono 与 IL2CPP、泛型共享与 AOT 限制）直接衔接：理解了 IL2CPP 为什么不能加载新 IL，才能看懂各方案在绕开什么。

## 与 C# 底层专栏的对应关系

| 热更新里的问题 | 对应的 C# 底层知识 |
|---|---|
| IL2CPP 为什么不能 `Assembly.Load` 新 dll | C# 底层专栏 2.1（CLR 执行模型与 JIT）、4.1（Mono 与 IL2CPP 差异） |
| 热更代码里 `List<MyStruct>` 报 no AOT code | C# 底层专栏 4.2（泛型共享与 AOT 限制） |
| Lua/ILRuntime 跨界调用产生 GC | C# 底层专栏 3.4（GC.Alloc 来源）、6.1（委托与闭包） |
| 热更层的 `Update` 里创建临时对象 | C# 底层专栏 3.4、3.5（对象池与结构体化） |
| Lua 引用 C# 对象的跨 GC 泄漏 | C# 底层专栏 3.1（GC 基础）、2.5（Dispose 与终结器） |
| 原生回调与委托桥接 | C# 底层专栏 2.2（P/Invoke 与 Marshal） |

## 版本与核实说明

- 本专栏没有运行环境做编译验证，所有代码块是示意写法，实际 API 签名以所装版本为准。
- 各页末尾的"参考资料"链接多数在写作时没有逐条打开验证，引用前请抽查，尤其是 HybridCLR 文档的子路径与 Addressables 手册的锚点。
- 性能数据没有统一基准，文中只给定性判断，量化结论以项目实测为准。
- 标"待核实"的条目是写作时没能确证的版本差异、命令名或实现细节，不要直接当作面试标准答案背。
- Unity 6.8 起 CoreCLR 取代 Mono、IL2CPP 保留的计划来自 C# 底层专栏已核实的官方论坛帖，HybridCLR 等方案对新版本的支持情况需要另行查证。
