# 游戏知识库

记录游戏设计、开发、工具、运营与项目复盘经验，让团队知识可以持续积累和复用。

## 内容区域

- **知识库**：按文件夹组织的长期维护文档，左侧导航会自动根据目录结构生成。
- **项目文章**：项目介绍、开发记录、源码学习和阶段总结。
- **使用指南**：写作规范、协作流程和站点维护说明。

所有页面都使用 Markdown 编写。创建文件或文件夹后，Starlight 会自动更新对应的导航层级，不需要手动编辑导航配置。
