如果你想在工作、学习或玩游戏的间隙记几个英语单词，**Amiya Words（阿米娅单词）** 是一个轻量的 Windows 桌面背单词工具。它把单词学习做成桌面浮窗，通过卡片、选择题和语音提醒，让背单词不必依赖一个完整的学习时段。

项目地址：[BlueDevilDrowned/AmiyaWords](https://github.com/BlueDevilDrowned/AmiyaWords)

## 这个软件能做什么

Amiya Words 基于开源项目 [ToastFish](https://github.com/Uahh/ToastFish) 二次开发，保留了原项目的词库、学习流程和基础功能，并围绕桌面浮窗和语音体验进行了扩展。

- 左键点击浮窗即可开始或结束学习。
- 右键点击浮窗可以打开设置。
- 支持单词卡片和中文四选一两种学习模式。
- 四选一模式支持键盘 `1`、`2`、`3`、`4` 选择答案，按 `5` 表示“不认识”。
- CET4 单词和交互提示可以使用本地生成的阿米娅中文音色。
- 单词语音、交互语音和重复提醒语音可以分别开关。
- 可以设置正确与错误提示音的播放概率。
- 支持自定义浮窗图片，并自动裁剪为圆形。
- 结果弹窗会显示正确答案、中文释义和颜色反馈，也可以自动淡出。

## 适合怎样的使用场景

它适合放在桌面上长期运行，在碎片时间里完成少量复习。浮窗不会要求你打开一个完整的学习页面，看到提示后可以直接作答；如果当前不方便学习，也可以随时结束本轮练习。

这种设计更接近“持续提醒”，而不是一次性完成很长的学习任务。对于希望每天保持英语输入、又容易忘记打开背词软件的人来说，桌面浮窗是一个比较直接的入口。

## 如何使用

从 Release 下载发行版并解压，运行：

```text
AmiyaWords.exe
```

首次运行后，可以在浮窗上点击右键，进入“弹窗设置”，调整以下选项：

- 浮窗图片和颜色
- 单词、交互和提醒语音
- 结果弹窗自动消失时间
- 提示音播放概率

## 如果想自己构建

项目面向 Windows，使用 WPF 和 .NET Framework 4.7.2 开发。构建环境建议为 Visual Studio 2019 或更高版本。

1. 克隆仓库并打开 `ToastFish.sln`。
2. 选择 `Release` 配置。
3. 使用 Visual Studio 的 .NET Framework MSBuild 构建项目。
4. 构建完成后运行生成的程序。

项目使用的是旧式 WPF 工程，因此构建时应确保 Visual Studio 安装了对应的 .NET Framework 开发组件。

## 关于语音资源

仓库中的阿米娅音频由 GPT-SoVITS 生成，作为本地学习语音资源使用。如果要修改、分发或在其他项目中使用相关音频，需要同时确认模型、参考音频和角色语音素材的授权条款。

## 写在最后

Amiya Words 是一个把个人兴趣、桌面工具和英语学习结合起来的小项目。它没有试图做成复杂的学习平台，而是把“每天记几个词”这件事放到桌面上，用更低的使用成本帮助学习形成习惯。

如果你有新的词库、交互方式或语音体验想法，也可以在 GitHub 仓库中提交 Issue 或 Pull Request。
