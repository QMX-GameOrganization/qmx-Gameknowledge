> 标记：`【主线实践】`。本篇是装配和回归，不新增 C# 语言知识。

## 运行链

```text
GameBootstrap
  → PlayerMover / CameraFollow
  → PlayerStats / Health / Inventory
  → AttackController → IDamageable
  → HpChanged / ScoreChanged / GamePhaseChanged
  → HUDController / ResultPanel
  → Exit.TryInteract → Victory
```

场景中至少放置：玩家、两个敌人、一个陷阱、三个收集物、一个出口和 Canvas。每个对象的脚本、Collider、Layer 和 Inspector 引用都必须能从场景反查，不把关键依赖藏在静态字段里。

## 胜负和重开

```csharp
public enum GamePhase { Playing, Victory, Defeat }

public sealed class GameSession : MonoBehaviour
{
    public GamePhase Phase { get; private set; } = GamePhase.Playing;

    public void TryWin(bool objectiveComplete)
    {
        if (Phase == GamePhase.Playing && objectiveComplete)
            Phase = GamePhase.Victory;
    }

    public void Defeat()
    {
        if (Phase == GamePhase.Playing)
            Phase = GamePhase.Defeat;
    }
}
```

这是 `【主线必做】` 的最终状态边界：胜利和失败只能从 `Playing` 进入一次。重开时重新加载场景或重建所有状态所有者，不能只把 UI 面板隐藏起来。

## 最终回归

- [ ] Build 启动进入 `Dungeon`；
- [ ] 玩家移动、攻击、受伤和收集都能观察到结果；
- [ ] 收集目标后到出口进入胜利；
- [ ] 血量归零进入失败并停止继续操作；
- [ ] 胜利和失败都能重开并恢复初始状态；
- [ ] 连续完成“启动 → 胜利”和“启动 → 失败 → 重开”各两次；
- [ ] Console 没有未处理异常。

通过这份回归后，才可以说“跟完整个主线，拼出了一个小游戏”。
