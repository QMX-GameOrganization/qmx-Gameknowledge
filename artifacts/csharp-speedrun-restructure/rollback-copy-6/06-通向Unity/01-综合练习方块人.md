> 适用版本：Unity 2021 LTS 到 Unity 6000.x。输入使用传统 Input Manager（`Input.GetAxisRaw`）；若项目只启用了新 Input System，需要在 Player 设置里把 Active Input Handling 改为 Both（见 1.4 篇）。

## 要点

- 这篇不讲新语法，而是把前面学过的东西**装在一个能玩的小东西里**。
- 完成后你会有：一个能用 WASD 移动的方块；一个踩上去会扣血的陷阱；血量归零后方块停止移动；Console 里随时看到血量变化。
- 四个脚本各管一件事，通过**事件**和**接口**连接，彼此不直接依赖。

## 搭建场景

1. 新建场景，创建一个 Plane 作为地面。
2. 创建 Cube，命名 `Player`，位置略高于地面。添加组件 `Rigidbody`，勾选 **Is Kinematic**（我们用代码移动它，不让物理引擎干涉）。
3. 创建另一个 Cube，命名 `Spike`，缩放成 `(2, 0.2, 2)` 放在地面上；它的 Box Collider 勾选 **Is Trigger**。
4. 创建一个空物体 `Logger`。
5. 按下面的顺序创建四个脚本，分别挂到对应物体上。

前面几篇的练习里已经出现过同名类型：3.3 篇的 `Health`、4.3 篇的 `IDamageable`、5.2 篇的 `HpLogger`。动手前先把旧脚本删掉（或移出 Assets），否则编译器会报 `CS0101`（同一命名空间里重复定义）。

## 脚本一：Health（血量，实现接口，发出事件）

```csharp
using System;
using UnityEngine;

public interface IDamageable { void TakeDamage(int amount); }

public class Health : MonoBehaviour, IDamageable
{
    [SerializeField] private int maxHp = 100;
    private int hp;

    public event Action<int, int> OnHpChanged;       // 旧值，新值
    public event Action OnDied;

    public int Hp => hp;
    public bool IsDead => hp <= 0;

    void Awake() { hp = maxHp; }

    public void TakeDamage(int amount)
    {
        if (IsDead || amount <= 0) return;
        int old = hp;
        hp = Mathf.Max(hp - amount, 0);
        OnHpChanged?.Invoke(old, hp);
        if (IsDead) OnDied?.Invoke();
    }
}
```

## 脚本二：PlayerController（移动与状态）

```csharp
using UnityEngine;

public enum PlayerState { Idle, Run, Dead }

[RequireComponent(typeof(Health))]
public class PlayerController : MonoBehaviour
{
    [SerializeField] private float speed = 5f;
    public PlayerState State { get; private set; } = PlayerState.Idle;
    private Health health;

    void Awake() { health = GetComponent<Health>(); }
    void OnEnable() { health.OnDied += HandleDied; }
    void OnDisable() { health.OnDied -= HandleDied; }

    void Update()
    {
        if (State == PlayerState.Dead) return;
        Vector3 dir = new Vector3(Input.GetAxisRaw("Horizontal"), 0f, Input.GetAxisRaw("Vertical"));
        State = dir.sqrMagnitude > 0f ? PlayerState.Run : PlayerState.Idle;
        transform.position += dir.normalized * speed * Time.deltaTime;
    }

    void HandleDied()
    {
        State = PlayerState.Dead;
        Debug.Log("玩家死亡");
    }
}
```

## 脚本三：Spike（陷阱）和脚本四：HpLogger（旁观者）

```csharp
using UnityEngine;

public class Spike : MonoBehaviour
{
    [SerializeField] private int damage = 20;

    void OnTriggerEnter(Collider other)
    {
        if (other.TryGetComponent<IDamageable>(out var target))   // 不关心对方是谁，只要能受伤
            target.TakeDamage(damage);
    }
}

public class HpLogger : MonoBehaviour
{
    [SerializeField] private Health target;                        // 把 Player 拖进来

    void OnEnable() { target.OnHpChanged += Log; }
    void OnDisable() { target.OnHpChanged -= Log; }
    void Log(int oldHp, int newHp) { Debug.Log($"血量 {oldHp} → {newHp}"); }
}
```

`Spike` 挂到 `Spike` 物体，`HpLogger` 挂到 `Logger` 并把 `Player` 拖进 `Target`；`Health` 和 `PlayerController` 挂到 `Player`（`RequireComponent` 会自动补上 `Health`）。点击 Play，用 WASD 走进陷阱，每次进入扣 20 点，第 5 次后 Console 出现"玩家死亡"，方块再也动不了。

## 每个语法出现在哪

| 代码里 | 对应知识 |
| --- | --- |
| `Time.deltaTime` | 游戏循环与帧间隔（0.1） |
| `Awake` / `OnEnable` / `OnDisable` | 生命周期（0.3） |
| `enum PlayerState` | 枚举（2.1） |
| `Hp`、`IsDead`、`State` 属性 | 属性（3.3） |
| `IDamageable` + `TryGetComponent` | 接口与多态（4.3） |
| `event Action<int,int>` | 委托与事件（5.2） |
| `GetComponent<Health>()` | 泛型方法（5.1） |
| `[RequireComponent]`、`[SerializeField]` | 特性（5.4） |
| `Vector3` 运算 | 运算符重载与结构体（2.5、3.5） |

## 常见坑

- 陷阱没反应：触发器事件要求至少一方有 `Rigidbody`，且陷阱的 Collider 必须勾 **Is Trigger**。
- 方块一进陷阱就穿过去：Cube 太薄、速度太快时可能漏检，先把陷阱调厚一点。
- `HpLogger` 报 `NullReferenceException`：没把 `Player` 拖进 `Target` 字段。
- 重复定义 `IDamageable`、`Health` 等类型：编译报 `CS0101`，说明工程里已经有同名类型。
- 死亡后仍能移动：确认 `Update` 开头有 `if (State == PlayerState.Dead) return;`，且 `HandleDied` 确实被订阅（看 `OnEnable` 里是否有 `+=`）。
