> 适用版本：C# 9.0。Unity 中取整常用 `Mathf.RoundToInt`、`Mathf.FloorToInt`，本篇以纯 C# 为主。

## 要点

- **不会丢信息的转换**编译器自动做（隐式）；**可能丢信息的转换**必须你亲手写（显式），表示"我知道有风险"。
- `(int)3.9f` 是**截断**为 3，不是四舍五入。
- 字符串转数字用 `int.TryParse`，不会抛异常，适合处理玩家输入和存档。
- `Convert.ToInt32` 是四舍五入，但采用"银行家舍入"：`2.5` 得 2，`3.5` 得 4。

## 隐式转换：小范围到大范围

```csharp
int level = 10;
long exp = level;          // int -> long，不丢信息
float ratio = level;       // int -> float，可以
double d = ratio;          // float -> double，可以
```

大致规则：`byte → short → int → long → float → double` 方向上可以隐式。`int` 到 `float` 在数值很大时会损失精度，但编译器仍允许，因为数值范围放得下。

## 显式转换：写强转，并知道丢什么

```csharp
float damage = 37.9f;
int hp = (int)damage;      // 37，小数被截断
int big = 300;
byte b = (byte)big;        // 44，高位被丢掉（300 % 256）

int max = int.MaxValue;
int wrap = max + 1;        // 默认不检查溢出，回绕成 int.MinValue
int safe = checked(max + 1); // 在 checked 里溢出会抛 OverflowException
```

C# 的 C 风格强转 `(T)x` 只用于数值类型之间，以及引用类型的向下转换（见 4.1）。没有 `static_cast` 等四种形式。

## 字符串和数字互转

| 方法 | 失败时 | 适用场景 |
| --- | --- | --- |
| `int.Parse(s)` | 抛 `FormatException` | 确定输入合法 |
| `int.TryParse(s, out int v)` | 返回 `false` | 玩家输入、存档、配置文件 |
| `Convert.ToInt32(x)` | 抛异常；对 `float` 做四舍五入 | 需要四舍五入的转换 |
| `x.ToString()` | 不会失败 | 数字转字符串 |

```csharp
string saved = "120";
if (int.TryParse(saved, out int hp))      // out 的含义见 2.4
    Console.WriteLine($"读到血量 {hp}");
else
    Console.WriteLine("存档损坏，使用默认值");

Console.WriteLine(Convert.ToInt32(2.5));  // 2
Console.WriteLine(Convert.ToInt32(3.5));  // 4
Console.WriteLine((int)2.5f);             // 2，截断
```

读存档、读 JSON 配表时都应该用 `TryParse`，别让一条脏数据把整个加载流程抛崩。

## is 与 as：预览

当一个变量的真实类型只有运行时才知道时，用 `is` 判断、`as` 转换。这里先用 `object`（万物之父，4.2 节详述）演示：

```csharp
object o = 42;
if (o is int n)                 // 判断并同时取出，n 只在这个 if 里可用
    Console.WriteLine(n + 1);

object o2 = "hello";
int? maybe = o2 as int?;        // as 失败不抛异常，得到 null
Console.WriteLine(maybe == null);   // True
```

引用类型之间的 `as` 和 `is`，在学完继承后（4.1）会用得更多，比如"这个碰撞对象是不是敌人"。

## 在 Unity 里用到它

- 玩家在输入框里填的是字符串，要用 `int.TryParse` 转成数字，别用 `Parse`。
- 伤害常是 `float`，血量常是 `int`，之间的转换要选对方式。Unity 提供了专门的取整函数：

| 想要 | 写法 | 例：37.9 | 例：-1.5 |
| --- | --- | --- | --- |
| 截断小数 | `(int)x` | 37 | -1 |
| 四舍五入 | `Mathf.RoundToInt(x)` | 38 | -2 |
| 向下取整 | `Mathf.FloorToInt(x)` | 37 | -2 |
| 向上取整 | `Mathf.CeilToInt(x)` | 38 | -1 |

注意负数：`(int)-1.5f` 是 -1（朝零截断），`Mathf.FloorToInt(-1.5f)` 是 -2（朝负无穷）。算格子坐标时容易因此偏一格。

## 动手试试

在 `Lab.Start` 里先**预测**再运行：

```csharp
float damage = 37.9f;
Debug.Log((int)damage);
Debug.Log(Mathf.RoundToInt(damage));
Debug.Log((int)-1.5f);
Debug.Log(Mathf.FloorToInt(-1.5f));
Debug.Log(int.TryParse("12a", out int n));   // 预测输出，以及 n 的值
```

## 常见坑

- 以为 `(int)x` 会四舍五入，导致血量少 1。需要四舍五入时写 `Math.Round` 或 `Mathf.RoundToInt`。
- 把 `int / int` 当小数用：`7 / 2` 得 3。需要小数时写 `7 / 2f`。
- 对不可信字符串用 `Parse`，一条坏数据让整段逻辑抛异常。
- 忘记默认不检查溢出：伤害累加、经验累计用 `int` 可能悄悄回绕为负数。
