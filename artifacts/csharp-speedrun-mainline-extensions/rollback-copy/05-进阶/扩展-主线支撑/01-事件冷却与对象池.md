> 标记：`【主线支撑】`。本篇不重复解释语法定义，而是把 5.1、5.2 和 6.2 的结果接到同一条战斗流程。

## 三条连接

1. `Health.OnHpChanged` 是 `【主线必做】`：HUD、音效和胜负系统订阅它；
2. 攻击冷却是 `【主线支撑】`：用协程或时间戳阻止连续攻击；
3. 子弹/特效池是 `【主线支撑】`：用 `ObjectPool<T>` 或等价泛型池借出和归还对象。

```csharp
public event Action<int, int> HpChanged;

private IEnumerator AttackCooldown(float seconds)
{
    onCooldown = true;
    yield return new WaitForSeconds(seconds);
    onCooldown = false;
}
```

事件传递“发生了变化”，方法表达“请执行动作”，协程表达“等待后继续”，对象池管理“对象何时借出、何时归还”。四者不能互相替代。

## 验收

- [ ] 血量变化同时更新 HUD 和调试日志；
- [ ] 禁用 HUD 后取消订阅，重新启用后能恢复；
- [ ] 冷却时间内重复按攻击键不会生成多次攻击；
- [ ] 连续生成 20 个投射物后，Hierarchy 中的对象数量不会无限增长；
- [ ] 场景重开时所有借出的对象都被归还或销毁。
